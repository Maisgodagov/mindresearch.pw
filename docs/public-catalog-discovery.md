# Поиск и страницы публичного каталога

Реализовано и развёрнуто 11.11.2026. Релиз Selectel: `catalog-20261111`.

`GET /api/public/catalog?q=...&section=...&topic=...&topic=...&page=2`

Ответ: `items`, `total` (после фильтров), `catalogTotal`, `page`, `pageCount`, `pageSize` (20), `topics` (тема, раздел, количество во всём опубликованном каталоге).

Темы объединяются через ИЛИ, раздел и поисковые слова — через И. Поиск без учёта регистра, с нормализацией пробелов и е/ё: название, официальное название, аббревиатура, тема, описание, названия источников. Сначала точное совпадение аббревиатуры, затем начало заголовка и совпадение официального названия; далее сортировка по заголовку и slug. Это поиск по фрагментам, без исправления опечаток и морфологии.

Сервер читает только опубликованные версии из MySQL; фильтрация и сортировка выполняются в API, после чего выдаются 20 записей. Черновики не читаются этим запросом. Проверка бланка для количества вопросов выполняется только для текущей страницы. Для текущего масштаба в сотни методик отдельный поисковый сервис и миграция БД не нужны.

Номер страницы ограничивается последней доступной страницей; пустая выборка имеет `page=1`, `pageCount=1`. Невалидные параметры возвращают 400. Поисковая строка ограничена 200 символами, выбор тем — 50 значениями.

Фронт хранит параметры в URL, сбрасывает страницу при изменении фильтров/поиска, задерживает запрос на 250 мс и отменяет устаревшие запросы. HTML без JavaScript также разбит на страницы с переходами. Фильтрованные страницы и страницы с параметром page имеют noindex и canonical на основной каталог. Прежний `/api/public/methods` сохранён для совместимости.

Проверки: `discovery.test.ts` (805 синтетических записей, поиск, границы, HTTP и HTML), `repository.test.ts` (SQL без черновиков), `scripts/check-public-catalog.cjs` (реальный локальный API), `scripts/check-public-pagination.cjs` (браузер, синтетические 805 записей, desktop/mobile).
