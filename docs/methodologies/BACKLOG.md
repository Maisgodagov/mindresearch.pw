# Очередь методик

Источник — переданные пользователем списки №1–100 и №101–238. В первом списке отсутствует пункт №15, поэтому фактическое число записей — 237, а не 238. Пропуск сохранён намеренно: недостающая позиция не восстанавливается по догадке. Возможные дубли остаются отдельными записями до исследования конкретных версий.

Статусы: `[ ] queued`, `[x] done/already-available`, `ru-ineligible` (не проходит фильтр русской апробированной версии), `blocked` (доказательств/прав недостаточно), `implemented-local` (код и тесты локально готовы, релиз ещё не подтверждён). Новый публичный каталог формируется только из версий, прошедших российский фильтр из `WORKFLOW.md`; исторические существующие методики автоматически не меняются.
