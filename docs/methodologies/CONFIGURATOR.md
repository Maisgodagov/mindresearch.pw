# Конструктор методик в админке

Админка позволяет завести черновик методики, описать пункты и числовые варианты ответа, добавить источники и настроить расчёт шкал. Расчёт задаётся данными, без исполняемых выражений и пользовательского кода.

## Поддерживаемая формула

- Один числовой ответ на пункт; одинаковый непрерывный целочисленный диапазон ответов для всех пунктов.
- Один или несколько профилей шкал. Для каждой шкалы задаются включённые пункты, подмножество обратно кодируемых пунктов и способ агрегирования: сумма или среднее.
- Обратное кодирование выполняется по формуле `min + max - ответ`.
- Расчёт появляется только после ответа на все пункты, используемые хотя бы одной шкалой.
- Нормативные таблицы, диагностические пороги, веса пунктов, пропуски, условные ветви и многомерные/множественные ответы конструктор не рассчитывает. Их нельзя имитировать шкалой суммы или среднего.

## Проверка перед публикацией

Сервер требует название, автора, версию, описание, основание для использования полного текста и ключа, хотя бы один источник, заполненные вопросы, корректные шкалы и не менее двух контрольных примеров. Контрольный пример содержит ответы по номерам пунктов и ожидаемый результат для каждой шкалы. Значения сравниваются с настроенной формулой; отдельно автоматически проверяются границы диапазона для каждой шкалы.

Проверки выявляют ошибки в диапазоне, нумерации, обратных пунктах, формулах и ручных контрольных примерах. Они не устанавливают подлинность ключа, валидность адаптации или наличие прав на воспроизведение. Перед публикацией администратор вручную сверяет формулировки, ключ, контрольные ответы, источники и основание использования с первоисточниками. Неопределённые или неподтверждённые правила остаются вне каталога.

После публикации версия и формула неизменяемы. Для пересмотра создаётся отдельная версия, чтобы не менять результаты старых и новых прохождений задним числом.
