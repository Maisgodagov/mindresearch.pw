# 1249. Опросник субъективного отчуждения

Решение worker: `blocked`.
Основание: Для ОСОтч-В доступен русский бланк из 60 пунктов и ответы по шкале согласия 0–100%, но страница методики прямо указывает, что ключ не публиковался. В найденных источниках нет надёжного точного ключа и формулы подсчёта взрослой версии; угадывать их нельзя. Разрешённые файлы не созданы.
