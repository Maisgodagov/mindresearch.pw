# 1543. Роли жертвы и агрессора в ситуации буллинга

Решение worker: `blocked`.
Основание: Публикация Бушиной и Муминовой подтверждает русскую адаптацию ROBVQ: две шкалы по 8 пунктов и пятибалльные ответы. Найденный отдельный ключ относится к иной модификации: 30 пунктов виктимности и шесть частотных значений, включая «ежедневно». Он не подтверждает точный ключ для исходной русской версии с двумя шкалами; переносить его или угадывать соответствие шкалам нельзя. Разрешённые файлы не создавались.
