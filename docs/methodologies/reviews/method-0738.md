# Мотивация выполнения домашних заданий (МДЗ)

- Решение: добавить русскую версию для учащихся 3–11-х классов.
- Русский текст: все 13 пунктов и инструкция с пятибалльными ответами опубликованы в приложении к статье; страница Psytests предоставляет русскоязычную страницу методики и бланк.
- Ключ: статья авторов задаёт три основные шкалы и три субшкалы автономной мотивации; пункты прямые, обратных пунктов нет.
- Подсчёт: ответы кодируются от 1 («Неверно (НЕТ)») до 5 («Верно (ДА)»). Для каждой шкалы вычисляется среднее арифметическое ответов на входящие в неё пункты. Общие шкалы: автономная — 1, 3, 5, 7, 9, 13; интроецированная — 2, 8, 11; экстернальная — 4, 6, 10, 12. Подшкалы: познавательная — 1, 7; саморазвития — 3, 9; идентифицированная — 5, 13. Пропусков и реверсивных пунктов в реализации нет.
- Ограничения: отдельные нормативные пороги в источнике не приведены; баллы следует использовать как шкальные показатели без нормативных выводов.
