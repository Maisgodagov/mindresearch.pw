# Тест отношений беременной ТОБ(б) — решение по пункту 1817

- **Статус:** `blocked` — не создавать регистрацию без точного ключа.
- **Русский текст:** полный текст 45 утверждений опубликован в [Тесте отношений беременной ТОБ(б): онлайн-калькулятор, текст, структура и обработка](https://statblank.com/metodiki/tob-otnosheniya-beremennoy-dobryakov). Страница первоисточника [Тест отношений беременной, ТОБ(б)](https://psytests.org/parent/tobb.html) указывает автора И. В. Добрякова, вариант для беременных и ссылки на бланк/прохождение. Путеводитель [«Материнство: тесты и опросники»](https://psytests.org/guide/clinical-reproductive-ru.html) также описывает назначение ТОБб.
- **Ключ:** точное распределение каждого утверждения по пяти типам в доступных источниках не приведено. Калькулятор описывает подсчёт по ключу, однако сама таблица соответствий не отображается. Ссылка на бланк psytests ведёт на страницу, недоступную для чтения; страницу прохождения также не удалось извлечь. Первичная публикация [«Семейный диагноз и семейная психотерапия» Э. Г. Эйдемиллера, И. В. Добрякова и И. М. Никольской](https://prepod.nspu.ru/pluginfile.php/287770/mod_assign/introattachment/0/%D0%AD%D0%B9%D0%B4%D0%B5%D0%BC%D0%B8%D0%BB%D0%BB%D0%B5%D1%80%2C%20%D0%94%D0%BE%D0%B1%D1%80%D1%8F%D0%BA%D0%BE%D0%B2%20%D0%A1%D0%B5%D0%BC%D0%B5%D0%B9%D0%BD%D1%8B%D0%B9%20%D0%B4%D0%B8%D0%B0%D0%B3%D0%BD%D0%BE%D0%B7%20%D0%B8%20%D1%81%D0%B5%D0%BC%D0%B5%D0%B9%D0%BD%D0%B0%D1%8F%20%D0%BF%D1%81%D0%B8%D1%85%D0%BE%D1%82%D0%B5%D1%80%D0%B0%D0%BF%D0%B8%D1%8F.pdf) подтверждает происхождение методики и её разделы, но доступный извлечённый фрагмент не содержит ключа подсчёта.
- **Структура и предполагаемый подсчёт по описанию вторичного источника:** 45 утверждений, 9 разделов по 5; в каждом разделе выбирают одно утверждение. Пять типа ПКГД: оптимальный, гипогестогнозический, эйфорический, тревожный, депрессивный. По каждому типу считается число выбранных утверждений (0–9), общая сумма равна 9; 7–9 обозначены как определяющий тип. Это не заменяет отсутствующую однозначную таблицу соответствий и недостаточно для реализации.
- **Итог:** русский текст критерию подходит, но надёжный точный ключ не подтверждён доступным источником. Не угадывать; модуль не создан.
