# Оценка стилей мышления Бензигер (взрослая форма)

- Статус: `blocked`.
- Русский текст: страница методики PsyTests сообщает о варианте для взрослых и ссылке на бланк, но сам бланк недоступен для проверки в рамках этого просмотра. Страница отмечает, что первоисточник и автор перевода не установлены, сведений об адаптации нет.
- Ключ: надёжный точный ключ для данной русской формы не подтверждён. В самой странице сказано, что эквивалентность коммерческой BTSA сомнительна; найденная англоязычная форма из вторичного источника не подтверждает ключ/соответствие пунктов русского бланка. Не создаю регистрацию и не угадываю подсчёт.
- Количество пунктов, шкалы и формула: не устанавливаются по доступным проверенным источникам; автоматический подсчёт не реализуется.

  - [Бланк русской методики — PsyTests](https://psytests.org/typo/benzA-bl.html): ссылка на русскую форму со страницы методики; содержимое бланка не удалось независимо получить и сверить.
