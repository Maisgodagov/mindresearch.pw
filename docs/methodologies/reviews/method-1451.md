# Проверьте, какой вы преподаватель (М. И. Станкин)

- Решение: подготовить русскоязычную 14-пунктовую версию; первичная страница Psytests атрибутирует тест Станкину (1998) и говорит, что онлайн-форма сделана по первоисточнику.
- Первичный источник и русская страница/бланк: [М. И. Станкин, «Профессиональные способности педагога: Акмеология воспитания и обучения» (М.: МПСИ; Флинта, 1998), запись электронного каталога МГППУ](https://lib.mgppu.ru/OpacUnicode/index.php?url=%2Fnotices%2Findex%2FIdNotice%3A21290%2FSource%3Adefault); [страница методики «Проверьте, какой вы преподаватель» с атрибуцией автору и заявлением о соответствии первоисточнику](https://psytests.org/pedag/stnknB.html); [русский бланк теста](https://psytests.org/pedag/stnknB-bl.html).
- Полный русский текст и ключ: [тест «Какой вы педагог?» — бланк модификации Р. Р. Калининой](https://sapt1.ucoz.ru/Sot_slyzhba/Prepodavatelyam/pedagogam-test_kakoj_vy_pedagog.pdf). Этот источник подтверждает наличие русских формулировок и таблицу баллов, но является модификацией с изменёнными формулировками для воспитателей; она не подтверждает дословно весь внесённый исходный текст. Поэтому решение о точном соответствии ключа исходной версии следует считать предварительным и сверять с изданием Станкина.
- Дополнительная публикация: [М. И. Станкин, тест «Проверьте, какой вы преподаватель» — текст и воспроизведённый ключ](https://statblank.com/metodiki/proverte-kakoy-vy-prepodavatel). Источник явно отмечает, что ключ приведён по модификации Калининой и сопоставляет её с исходной формой.
- Пункты: 14, ответы «Да» / «Нет».
- Шкалы: один суммарный показатель самооценки педагогической грамотности, диапазон 0–19; отдельные субшкалы в найденных источниках не заданы.
- Формула ключа: по каждому пункту начисляются указанные в таблице баллы за «Да» и «Нет», затем баллы суммируются. «Да»: 1, 0, 0, 0, 2, 1, 1, 0, 1, 1, 0, 0, 0, 1; «Нет»: 0, 1, 1, 2, 0, 0, 0, 2, 0, 0, 2, 1, 2, 0. По ключу максимальная сумма — 19. Реверсирование в источниках не описано; применены прямые весовые значения каждого ответа.
- Контрольный расчет: все ответы «Да» дают 7 баллов (сумма весов таблицы).
- Ограничение: полный первичный бланк и ключ оригинального издания 1998 года не удалось независимо проверить; таблица ключа доступна в публикациях модификации Калининой. Автоматическая реализация использует этот ключ и требует сверки по печатному первоисточнику перед публикацией.
