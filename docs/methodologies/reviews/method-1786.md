# Тест на религиозность — Ю. В. Щербатых

- Решение: подготовлена регистрация по русскому тексту и ключу автора (версия 1995 года).
- Русский текст и раскладка бланка: [«Тест для определения структуры индивидуальной религиозности» Ю. В. Щербатых — авторская страница с текстом и бланком](https://www.no-stress.ru/testy/religiousness.html); также [страница методики «Тест на религиозность» на PsyTests](https://psytests.org/rel/relig.html) и ее [страница русского бланка](https://psytests.org/rel/relig-bl.html).
- Публикация: [Мягков И. Ф., Щербатых Ю. В., Кравцова М. С. «Психологический анализ уровня индивидуальной религиозности»](https://www.no-stress.ru/testy/religiousness.html) // Психологический журнал. 1996. Т. 17, № 6. С. 119–122 (библиографическая запись и ссылка на статью приведены автором методики).
- Объем: 40 утверждений, ответы «Да», «Может быть», «Нет»; бланк автора — 5 строк × 8 столбцов.
- Шкалы: восемь столбцов/шкал — философская концепция, магия, поиск поддержки и утешения, внешние признаки, загадочные явления, вера в творца, религиозное самосознание, моральные нормы.
- Формула: за обычный пункт «Да» = 2, «Может быть» = 1, «Нет» = 0; для пунктов 5, 6, 9, 24, 27, 33, 35 — обратное направление («Нет» = 2, «Может быть» = 1, «Да» = 0). Балл каждой шкалы — сумма пяти соответствующих пунктов в своем столбце (диапазон 0–10). Это соответствие следует из опубликованной автором таблицы бланка 5×8 и словесного описания шкал по столбцам.
- Ограничение источника: на доступной странице первичной публикации показана библиографическая запись, а полный текст пунктов, ключ и бланк размещены на авторской странице; нормы в доступном ключе не приведены.
