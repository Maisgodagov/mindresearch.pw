# Формула темперамента А. Белова (1971)

- Решение: добавить русскую форму; текст и ключ подсчёта доступны.
- Русский бланк: [Тест «Формула темперамента» А. Белова, бланк и ключ (PDF)](https://pu8vertol.ru/Psiholog/TEST/belov.temperament.pdf), с. 1–4: полный текст 80 утверждений, инструкция отмечать «+»/«−», разбивка блоков и формула подсчёта.
- Первоисточник: [А. Белов. «Формула темперамента», журнал «Знание — сила», 1971, № 9, с. 54](https://psytests.org/typo/belov.html); библиографическую запись и указание на первоисточник приводит страница методики. Выпуск доступен в [архиве журнала «Знание — сила» за 1971 год](https://publ.lib.ru/ARCHIVES/Z/%27%27Znanie_-_sila%27%27_%28jurnal%29/_ZS.html).
- Сверка полной онлайн-версии: [Формула темперамента — описание и прохождение](https://psytests.org/typo/belov.html) и [страница прохождения с инструкцией](https://psytests.org/typo/belov-run.html).

**Состав:** 80 пунктов, четыре блока по 20: флегматик (1), меланхолик (2), холерик (3), сангвиник (4). Каждый пункт имеет два варианта: свойство выражено («Да», код 1) / не выражено («Нет», код 0). Реверсивных пунктов в ключе нет.

**Подсчёт:** по каждому блоку отдельно суммируются положительные ответы `Aтип`. Затем доля типа равна `100 × Aтип / A`, где `A` — сумма положительных ответов по всем четырём блокам. Формула профиля записывается в порядке холерик, сангвиник, флегматик, меланхолик. При `A = 0` доли математически не определены; реализация оставляет четыре сырых количества равными нулю без процентного вывода.

**Ограничение:** это ориентировочная популярная типология классических темпераментов, а не диагностический инструмент и не стандартизированная оценка.
