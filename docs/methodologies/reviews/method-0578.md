# Методика для диагностики актуальных потребностей личности (А. В. Капцов, 2008)

- Решение: подготовлена русская версия; исходная публикация содержит полный текст, ключ и правила подсчёта.
- Русский бланк: [«Методика для диагностики актуальных потребностей личности — бланк»](https://psytests.org/life/pyrkap-bl.html) содержит 105 пар, образованных из 15 утверждений. Онлайн-бланк сайта обозначен как визуализация; текст и алгоритм сверены по первоисточнику.
- Первоисточник и ключ: [А. В. Капцов. «Методика для диагностики актуальных потребностей личности», Вестник Самарской гуманитарной академии. Серия «Психология», 2008, № 2 (4), с. 59–70](https://cyberleninka.ru/article/n/metodika-dlya-diagnostiki-aktualnyh-potrebnostey-lichnosti.pdf). В приложении дана инструкция, 15 формулировок, попарный бланк и обработка.
- Описание страницы методики: [«Методика для диагностики актуальных потребностей личности» на Psytests](https://psytests.org/life/pyrkap.html).
- Количество: 15 исходных утверждений; каждое сопоставляется с остальными, итого 105 вопросов-пар. В каждом выбирается одно предпочтительное утверждение.
- Шкалы: 15 потребностей: безопасность/удовольствие; эмоциональное общение; ориентировка/свобода; активность/готовность к будущему; доминирование; достижение; эмоциональное насыщение; познание; подготовленность; статус; быть личностью; нравственно-эстетические потребности; смысл жизни; самовыражение; управление. Сырой балл каждой — число выборов соответствующего утверждения, диапазон 0–14; реверсивных пунктов нет.
- Формула: для потребности *i* суммируется число выбранных ответов с её кодом среди всех 14 пар, содержащих утверждение *i*. Авторские зоны интерпретации: 1–5 — удовлетворённость, 6–8 — частичная неудовлетворённость, 9–14 — неудовлетворённость. Интегральные средние: психофизиологический уровень = среднее потребностей 1–5; социальный = 6–10; высший = 11–15. По видам деятельности: труд = среднее 1, 6, 11; общение = 2, 7, 12; познание = 3, 8, 13; рекреация = 4, 9, 14; управление = 5, 10, 15. Стандартизация по таблицам в исходной статье отдельно не реализована в модуле.
- Возрастные данные: статья приводит нормативные описательные статистики для групп 16–18, 19–24, 25–39 и 40–65 лет, раздельно для мужчин и женщин; сырые баллы здесь не переводятся в стены.
- Проверка: вручную проверено, что утверждение 1 участвует в 14 парах и выбор его во всех них даёт 14 очков по первой шкале и 0 по остальным.
