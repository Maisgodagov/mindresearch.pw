# Мотивационная структура информационной активности (МСИА)

- Решение: подготовлена регистрация `test_761` по полной русской версии; основание ключа и подсчёта найдено в опубликованном методическом материале.
- Русский текст: [Бланк МСИА на Psytests.org](https://psytests.org/cyber/msia-bl.html) содержит 40 утверждений в 8 блоках. Публикация содержит также текст пунктов и инструкцию.
- Публикация и ключ: [«Информационный навигатор»: методические рекомендации по организации и проведению занятий](https://sobes.tatarstan.ru/file/sobes/File/%D0%A2%D0%B5%D1%85%D0%BD%D0%BE%D0%BB%D0%BE%D0%B3%D0%B8%D1%8F%20%D0%98%D0%BD%D1%84%D0%BE%D1%80%D0%BC%D0%B0%D1%86%D0%B8%D0%BE%D0%BD%D0%BD%D1%8B%D0%B9%20%D0%BD%D0%B0%D0%B2%D0%B8%D0%B3%D0%B0%D1%82%D0%BE%D1%80.pdf), приложение 1, печатные с. 38–42 (PDF с. 36–41): инструкция, соответствие всех пунктов пяти мотивам и обработка данных. Авторы указаны как Ю. Н. Долгов, А. С. Копова, Г. Н. Малюченко, В. М. Смирнов.
- Описание методики и библиография: [страница МСИА на Psytests.org](https://psytests.org/cyber/msia.html) приводит авторов (2009) и источник В. М. Смирнов, А. С. Коповой, «Психология медиа-безопасности: учебное пособие» (Саратов: СарГУ, 2012). [Путеводитель по методикам киберпсихологии](https://psytests.org/guide/cyberpsychology-ru.html) относит МСИА к методикам информационного поведения и медиапотребления.
- Пункты и шкалы: 40 пунктов; 5 шкал по 8 пунктов: познавательная, коммуникативная, релаксационная, реактивирующая и компенсаторная мотивация. Внутри каждого блока участник ранжирует пять утверждений баллами 1–5; в опубликованном источнике разрешены одинаковые баллы, хотя рекомендуется прибегать к этому только при необходимости. Отдельных реверсивных пунктов нет.
- Формула: для каждой шкалы суммируются баллы назначенных ей пунктов по всем восьми блокам; диапазон каждой суммы 8–40. Источник задаёт интерпретационные диапазоны 33–40 (явное преобладание), 25–32 (средняя), 17–24 (слабая), 8–16 (крайне слабая выраженность). Ключ закодирован по таблице «Бланк подсчёта данных» источника. Валидационный пример проверяет вручную: при всех ответах 1 каждая шкала из восьми пунктов даёт 8.
- Применимость: публикация прямо описывает применение МСИА для оценки мотивации медиапотребления подростков; возрастные нормативы в источнике для этой методики не заявлены.
