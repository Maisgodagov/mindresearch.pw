# Анкета «Учитель — ученик» (Е. И. Рогов)

- Решение: подготовлена; полный русский текст и точный ключ подтверждены источником.
- Русский текст: [Рогов, «Настольная книга практического психолога», анкета «Учитель — ученик», с. 469–470 (скан)](https://knigario.ucoz.ru/_ld/0/16_____.pdf). Онлайн-описание модификации: [psytests.org](https://psytests.org/pedag/ts1uu.html).
- Ключ и подсчёт: в том же скане приведены явные списки пунктов и полярность ответов для всех трёх параметров; каждый ответ, совпавший с ключом, даёт 1 балл.
- Количество пунктов: 24; ответы: «Нет» / «Да».
- Шкалы: гностическая (1, 4, 7, 10, 19, 22 — «Да»; 13, 16 — «Нет»), эмоциональная (8, 11, 14, 23 — «Да»; 2, 5, 17, 20 — «Нет»), поведенческая (3, 6, 12, 18 — «Да»; 9, 15, 21, 24 — «Нет»). Диапазон каждой — 0–8.
- Формула: для каждой шкалы сумма совпадений ответа с приведённым ключом; отрицательно сформулированные пункты — 13, 16, 2, 5, 17, 20, 9, 15, 21, 24 — засчитываются обратной полярностью. Общий показатель при необходимости является суммой трёх шкал (0–24).
- Ручная контрольная проверка: все «Нет» дают 2/4/4; все «Да» дают 6/4/4 по гностической, эмоциональной и поведенческой шкалам соответственно.
