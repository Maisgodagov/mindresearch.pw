# Типология доминирующего инстинкта (опросник В. И. Гарбузова)

- Решение: `prepared` для документированной 35-пунктовой части.
- Русский текст: полный бланк 35 утверждений и четыре варианта ответа опубликованы в [бланке опросника на Psytests](https://psytests.org/typo/garbuzov-bl.html). Страница описания указывает автора и первичную публикацию: [В. И. Гарбузов, «Практическая психотерапия…» (СПб., 1994)](https://psytests.org/typo/garbuzov.html).
- Ключ: [И. Г. Малкина-Пых, «Справочник практичного психолога» (2005), раздел 2.2.17 «Опросник Гарбузова для выявления доминирующего инстинкта»](https://sci.house/osnovyi-psihologii-scibook/2217-oprosnik-garbuzova-dlya-viyavleniya.html). Раздел содержит таблицу соответствия вопросов семи типам и правило определения максимальной суммы; за каждый отмеченный ответ начисляется балл по бланку обработки. Сверка таблицы: [«Опросник В. Гарбузова для выявления доминирующего инстинкта»](https://lektsii.org/18-64695.html).
- Количество пунктов: 35 утверждений; в расширенном онлайн-бланке Psytests есть ещё пять ассоциативных заданий, для которых здесь не найден надёжный ключ, поэтому они исключены.
- Шкалы и ключи: I эгофильный — 1, 8, 15, 22, 29; II генофильный — 2, 9, 16, 23, 30; III альтруистический — 3, 10, 17, 24, 31; IV исследовательский — 4, 11, 18, 25, 32; V доминантный — 5, 12, 19, 26, 33; VI либертофильный — 6, 13, 20, 27, 34; VII дигнитофильный — 7, 14, 21, 28, 35. Реверсивных пунктов в опубликованном ключе нет.
- Формула: ответы кодируются от 0 («Совсем нет») до 3 («Совершенно точно»); по каждой шкале суммируются пять соответствующих ответов (диапазон 0–15). Наибольшая сумма указывает на ведущую направленность; равные максимумы описаны источником как смешанный тип. Ассоциативная часть не реализована.
- Ограничение: карточка представляет описательную типологию автора методики, не клиническую диагностику; онлайн-бланк предупреждает, что это визуальное отображение, а не оригинальная раздаточная форма.
