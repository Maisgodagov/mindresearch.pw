# 1477. Психогеометрический тест

Решение worker: `blocked`.
Основание: Для русской версии Psytests доступен текст нескольких последовательных выборов фигур, но надежный точный ключ и однозначный алгоритм подсчета именно для этой версии не подтверждены. Русская книга Алексеева и Громовой и другие бланки описывают иной формат — полное ранжирование пяти фигур; переносить его ключ на выбранную версию означало бы угадывать. Разрешенные файлы не создавал.
