# Опросник мотивации чтения школьников (ОМЧШ), версия для учащихся 5–9-х классов

- Решение: prepared. Полный опубликованный русскоязычный бланк и точный ключ доступны.
- Русский текст: все 18 утверждений и семь вариантов ответа приведены в приложении к статье авторов (с. 168; PDF, стр. 12). Пункты 1–14 начинаются общей фразой «Я читаю в свободное время, потому что…»; пункты 15–18 имеют отдельную инструкцию.
- Выборка/применимость: учащиеся 5–9-х классов; разработка проверена на выборке 428 школьников.
- Шкалы: автономная мотивация (пункты 2, 4, 6, 8, 10, 12, 14); контролируемая мотивация (1, 3, 5, 7, 9, 11, 13); амотивация (15–18). Ответы кодируются от 1 («Совершенно не согласен») до 7 («Полностью согласен»).
- Формула: для каждой шкалы отдельно вычисляется арифметическое среднее кодированных ответов её пунктов. Обратных пунктов в опубликованном ключе нет. Диапазон шкалы 1–7; нормативные пороги не заявляются.
- Проверочный пример: ответы 1, 2, 3, 4, 5, 6, 7, повторённые по порядку во всех 18 позициях, дают среднее 4 на каждой шкале.
