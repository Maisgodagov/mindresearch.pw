# GAQ — Goddess Archetype Questionnaire
- Статус: blocked
- Русский текст: полный бланк psytests.org содержит 91 пункт и 5 вариантов ответа.
- Источники: [русская страница и бланк](https://psytests.org/typo/gaq.html), [англоязычный оригинальный опросник и инструкции](https://goddess-power.com/questions.htm).
- Шкалы и ключ: 7 архетипов (Афина, Афродита, Персефона, Артемида, Деметра, Гера, Гестия); оригинал задаёт для каждой из 13 категорий соответствие буквенных пунктов шкалам и суммирование рейтингов. Обратные пункты в ключе не указаны.
- Формула оригинала: ответы кодируются 3, 2, 1, −1, −2 для диапазонов частоты 90%+, 70–89%, 50–69%, менее 50% и «не подходит»; значения суммируются отдельно по каждой шкале согласно таблице ключа.
- Причина: русская версия предлагает «почти всегда», «большую часть времени», «половину времени», «меньше 50%», «совсем не подходит», но не задаёт порогов, позволяющих однозначно преобразовать первые варианты в оригинальные интервалы; особенно «половину времени» не соответствует диапазону 50–69%. Точный алгоритм для русской версии поэтому не установлен, баллы не угадывались. Модуль не создан.
