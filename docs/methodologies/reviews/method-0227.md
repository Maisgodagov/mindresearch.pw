# Диагностика психологической безопасности личности — И. И. Приходько (2013)

- Статус: подготовлено; русский текст доступен, ключ и перекодировка ответов однозначно опубликованы.
- Русский текст: [Бланк «Диагностика психологической безопасности личности» (мужской вариант)](https://psytests.org/stress/dpbl-bl.html). Он содержит все 88 формулировок и семь вариантов ответа. Текст пунктов совпадает с образцом бланка статьи; сайт помечает свой вариант бланка как визуальное отображение, а не оригинальный офлайн-бланк.
- Первоисточник ключа: И. И. Приходько, [«Разработка психодиагностического инструментария определения психологической безопасности личности специалистов экстремальных видов деятельности»](https://books.ndcnangu.co.ua/statti_NDL_3/prihodko_vu_2013_11.pdf), *Вестник Университета*, 2013, № 11, с. 242–253. Перекодировка ответов дана в табл. 1 на с. 245; шкальные ключи и нормы — на с. 250–251 (в PDF страницы 6–12). Это основной источник регистрации.
- [Каталог служебной психологии](https://psytests.org/guide/work-service-ru.html) относит методику Приходько к инструментам психологической безопасности для военнослужащих и сотрудников МВД; это ориентир по применимости, не источник ключа.
- Пункты: 88. Ответы кодируются от 1 до 7, но числа на сайте — лишь обозначения категорий. Прямой пересчёт: ответам 1–7 соответствуют 6, 5, 4, 3, 2, 1, 0 баллов; обратный — 0, 1, 2, 3, 4, 5, 6. Обратные пункты перечислены явно в каждой шкале регистрации.
- Шкалы: морально-коммуникативная (5 прямых, 15 обратных пунктов); мотивационно-волевая / жизнестойкость (11 прямых, 12 обратных); ценностно-смысловая (5 прямых, 18 обратных); внутренний комфорт (3 прямых, 19 обратных). Индекс психологической безопасности — сумма четырёх шкал (эквивалентно сумме пересчитанных пунктов).
- Формула: для каждого пункта прямой балл равен `7 − ответ`; обратный балл равен `ответ − 1`. Шкальный результат — сумма баллов её пунктов; индекс — сумма четырёх шкальных результатов. Нормативы статьи приведены для категорий военнослужащих; регистрация не применяет их к другим группам и выдаёт только сырые суммы.
