- Объем: 36 пунктов, ответы по семибалльной шкале согласия от «Абсолютно не согласен» до «Абсолютно согласен».
- Шкалы (число пунктов): целевая организация спортивной деятельности (4); адаптация к изменениям спортивной ситуации (6); формирование спортивного настроя (6); мониторинг в ситуациях ошибок и трудностей (8); анализ и оценка спортивной деятельности (8); метакогнитивные переживания (4).
- Подсчет: для пунктов с прямым ключом используется ответ 1–7. Обратные пункты 1, 2, 12, 19, 20, 21, 22, 28 и 4, 6, 13, 25 пересчитываются по таблице 1→7, 2→6, 3→5, 4→4, 5→3, 6→2, 7→1. Для каждой шкалы берется среднее значение баллов входящих в нее пунктов. Это эквивалентно формуле reverse = 8 − response; нормы не используются как диагностические заключения.
- Возрастная применимость: авторы рекомендуют спортсменов от 14 лет; формулировки не рекомендуются для младших.
- Контроль ключа вручную: при ответе 4 на все пункты пересчитанные обратные ответы также равны 4, поэтому среднее каждой из шести шкал равно 4.
