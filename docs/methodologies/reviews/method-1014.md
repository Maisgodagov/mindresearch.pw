# 1014. Опросник метакогнитивных состояний

Решение worker: `blocked`.
Основание: В русской версии SMI доступны 20 пунктов и варианты ответов, но надёжный ключ для подсчёта четырёх шкал не подтверждён первичным источником; доступная публикация сообщает, что распределение пунктов по шкалам в русском источнике отсутствует. Не стал угадывать ключ и создавать модуль.
