# Типология киберагрессии (CATQ), русскоязычная адаптация

- Решение: подготовлена регистрация `test_1931`. Русская подростковая адаптация и точный ключ с правилами подсчёта опубликованы; использованы 23 пункта итоговой формы, а не 29 пунктов англоязычного оригинала.
- Русская форма и ключ: [С. С. Антипина, «Опросник “Типология киберагрессии”: структура и первичные психометрические характеристики»](https://cyberpsy.ru/tests/oprosnik-tipologiya-kiberagressii/) (2021), приложение с полным текстом и алгоритмом. Полная журнальная публикация: [Вестник Кемеровского государственного университета, 23(1), 113–122, DOI 10.21603/2078-8975-2021-23-1-113-122](https://doi.org/10.21603/2078-8975-2021-23-1-113-122). Визуальная сверка формулировок: [Бланк CATQ на Psytests.org](https://psytests.org/cyber/cybatq-bl.html).
- Первоисточник: [K. C. Runions, M. Bak, T. Shaw, “Disentangling functions of online aggression: The Cyber-Aggression Typology Questionnaire (CATQ)”](https://doi.org/10.1002/ab.21663), *Aggressive Behavior*, 43(1), 74–84 (2017). Оригинал описывает 29 пунктов; здесь зарегистрирована опубликованная русская адаптация Антипиной с 23 пунктами.
- Пункты: 23; варианты ответа одинаковы для каждого пункта: «Точно про меня», «Скорее про меня», «Скорее не про меня», «Точно не про меня». Баллы соответственно 1, 2, 3, 4. Обратных пунктов нет.
- Шкалы и формула: сырая сумма баллов по пунктам 1–6 — импульсивно-ответная; 7–12 — произвольно-ответная; 13–18 — произвольно-инициативная; 19–23 — импульсивно-инициативная киберагрессия. Общий показатель — сумма всех 23 оценок. Диапазоны: 6–24 для первых трёх шкал, 5–20 для четвёртой, 23–92 для общей суммы.
- Формулировки/описание версии: [описание CATQ и адаптации](https://psytests.org/cyber/cybatq.html); [раздел CATQ в руководителе по киберпсихологии](https://psytests.org/guide/cyberpsychology-ru.html).
