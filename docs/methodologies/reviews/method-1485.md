# Психологическая диагностика безопасности образовательной среды школы

- Решение: `blocked` — полный русский бланк для учителя доступен, но прямой первоисточник и опубликованные копии не дают однозначно восстановить полный алгоритм ключа для всего бланка без допущений.
- Русский текст: [Бланк для учителя «Диагностика безопасности образовательной среды школы»](https://psytests.org/school/baevA-bl.html) (42 пункта, версии «учитель»). Страница предупреждает, что бланк не оригинальный и предписывает брать бланки и инструкции подсчёта из первоисточника.
- Первоисточник: [И. А. Баева. «Психологическая безопасность в образовании» (монография, СПб.: Союз, 2002), глава 3.3, печатные страницы 173–185](https://xn--h1albh.xn--p1ai/wp-content/uploads/2022/03/Baeva-I.-A.-Psihologicheskaya-bezopasnost-v-obrazovanii1.pdf). Электронная копия подтверждает структуру из трёх частей: интегральное отношение к среде, выбор пяти значимых характеристик и индекс психологической безопасности; перечисляет девять факторов защищённости и шкалу индекса 0–4. Однако в доступном тексте нет однозначной привязки каждого из первых 13 учительских вопросов к трем компонентам для извлечения полного точного ключа, а способ преобразования ответа 1–5 по 27 пунктам в опубликованный интервал 0–4 не указан явно.
- Навигационный источник: [Путеводитель по методикам педагогической психологии](https://psytests.org/guide/learning-pedagogic-ru.html).
- Шкалы/формула: описаны вербальные шкалы из 3, 5 и 9 категорий с переводом в позитивное/нейтральное/негативное отношение; три положительных направления, пять средовых характеристик и девять факторов защищенности. Для выборки автор задаёт процент показателя `Y = Xj × 100 / Xij`; ИПБ обозначен диапазоном 0–4, индекс удовлетворенности агрегирует оценки отобранных характеристик. Полного ключа, достаточного для безошибочного расчёта по всем ответам учительской версии, источник в доступном виде не даёт.
- Итог: модуль не создавался. Не восстанавливал недостающую нумерацию компонентов и шкальное преобразование предположениями.
