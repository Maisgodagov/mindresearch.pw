# Фрайбургский личностный опросник, форма B (FPI-B)

- Решение: подготовлена регистрация русскоязычной формы B под кодом `test_2015`.
- Русский бланк: [«Фрайбургский личностный опросник/Тестовый материал (Форма B)» — 114 пунктов](https://psylab.org.ua/tools_%D0%A4%D1%80%D0%B0%D0%B9%D0%B1%D1%83%D1%80%D0%B3%D1%81%D0%BA%D0%B8%D0%B9_%D0%BB%D0%B8%D1%87%D0%BD%D0%BE%D1%81%D1%82%D0%BD%D1%8B%D0%B9_%D0%BE%D0%BF%D1%80%D0%BE%D1%81%D0%BD%D0%B8%D0%BA/%D0%A2%D0%B5%D1%81%D1%82%D0%BE%D0%B2%D1%8B%D0%B9_%D0%BC%D0%B0%D1%82%D0%B5%D1%80%D0%B8%D0%B0%D0%BB_%28%D0%A4%D0%BE%D1%80%D0%BC%D0%B0_B%29); инструкция, варианты «да/нет» и пункты 1–114 доступны полностью.
- Ключ и обработка: [А. А. Крылов (ред.), «Практикум по общей, экспериментальной и прикладной психологии», раздел «Фрайбургский личностный опросник», с. 40–42 скана (с. 41–43 печатной нумерации)](https://elib.kspu.ru/get/13287). В PDF приведены таблица ключа всех 12 шкал и перевод первичных оценок в девятибалльные стандартные оценки; перечень ответов совпадает с [опубликованным ключом и бланком ПсиЛаб](https://psylab.org.ua/tools_%D0%A4%D1%80%D0%B0%D0%B9%D0%B1%D1%83%D1%80%D0%B3%D1%81%D0%BA%D0%B8%D0%B9_%D0%BB%D0%B8%D1%87%D0%BD%D0%BE%D1%81%D1%82%D0%BD%D1%8B%D0%B9_%D0%BE%D0%BF%D1%80%D0%BE%D1%81%D0%BD%D0%B8%D0%BA).
- Библиография адаптации: [А. А. Крылов, Т. И. Ронгинский, Ф. Короди. Русская адаптация FPI, форма B (1989), описанная в разделе «Адаптации и модификации» страницы ПсиЛаб](https://psylab.org.ua/tools_%D0%A4%D1%80%D0%B0%D0%B9%D0%B1%D1%83%D1%80%D0%B3%D1%81%D0%BA%D0%B8%D0%B9_%D0%BB%D0%B8%D1%87%D0%BD%D0%BE%D1%81%D1%82%D0%BD%D1%8B%D0%B9_%D0%BE%D0%BF%D1%80%D0%BE%D1%81%D0%BD%D0%B8%D0%BA); справочная запись о первичном издании [Практикума по экспериментальной и практической психологии под ред. А. А. Крылова, СПбГУ, 1997](https://psylab.org.ua/tools_%D0%A4%D1%80%D0%B0%D0%B9%D0%B1%D1%83%D1%80%D0%B3%D1%81%D0%BA%D0%B8%D0%B9_%D0%BB%D0%B8%D1%87%D0%BD%D0%BE%D1%81%D1%82%D0%BD%D1%8B%D0%B9_%D0%BE%D0%BF%D1%80%D0%BE%D1%81%D0%BD%D0%B8%D0%BA#literature).
- Объём и ответы: 114 утверждений, два ответа («да», «нет»); первый пункт — проверка готовности отвечать откровенно. Версия предназначена для возраста от 16 лет согласно описанию русской формы.
- Шкалы: I невротичность (17), II спонтанная агрессивность (13), III депрессивность (14), IV раздражительность (11), V общительность (15), VI уравновешенность (10), VII реактивная агрессивность (10), VIII застенчивость (10), IX открытость (13), X экстраверсия–интроверсия (12), XI эмоциональная лабильность (14), XII маскулинность–феминизм (15).
- Формула: для каждой шкалы первичный балл — число ответов, совпавших с ключом: `Σ 1(response[item] = keyedAnswer[item])`. Перечни «да» и «нет» заданы по каждому пункту; оставшиеся ответы балла не добавляют. Перекрёстное включение некоторых пунктов в базовые и производные шкалы сохранено по печатному ключу. Стандартные оценки 1–9 не включены в автоматический расчёт: исходная таблица преобразования имеет отсутствующие значения для ряда сырых баллов и шкал, а задача регистрации ограничена точным первичным подсчётом.
- Ручная контрольная сверка: при ответах «нет» ожидаются сырые баллы `1, 1, 0, 0, 8, 0, 0, 1, 0, 2, 1, 5` по шкалам I–XII; это количество ключевых ответов «нет». При ответах «да» — `16, 13, 14, 11, 7, 10, 10, 9, 13, 10, 13, 10`, то есть число ключевых ответов «да».
