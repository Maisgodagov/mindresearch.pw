# 742. Мотивация к обучению

Решение worker: `blocked`.
Основание: Надёжный ключ найден: совпадения ответов «+» с четырьмя группами 1–5, 2–6, 3–7, 4–8 пунктов дают по одному баллу, ведущая группа определяется по наибольшей сумме. Однако источник содержит противоречие: группы охватывают лишь пункты 1–8, 9–16 повторяют тот же шаблон с пропусками, а 17–20 не распределены по группам. Поэтому полный точный подсчёт 20 пунктов подтвердить нельзя. Модуль и review не созданы.
