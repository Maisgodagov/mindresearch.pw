## Текст и варианты ответа
Воспроизведены все 20 пунктов в нумерации статьи. На каждый пункт предлагаются «Да» (код 1) и «Нет» (код 0).

## Ключ и обратные пункты
- «Да»: 1, 2, 3, 6, 8, 10, 11, 12, 14, 16, 18, 19, 20.
- «Нет»: 4, 5, 7, 9, 13, 15, 17.
- Ключи взаимоисключающие и покрывают все 20 пунктов; отдельного обратного преобразования нет.

## Формулы и пропуски
По каждому совпадению ответа с ключом начисляется один балл. Итог — целочисленная сумма 0–20. Расчёт выполняется лишь для полного протокола с ровно 20 допустимыми ответами.

## Нормы и ограничения интерпретации
- 1–7: мотивация боязни неудачи.
- 8–13: мотивационный полюс ярко не выражен; для 8–9 указана тенденция к боязни неудачи, для 12–13 — к успеху.
- 14–20: мотивация на успех.
- Для арифметически возможного 0 авторская категория не задана: отображается только балл без интерпретации.
- Современная выборка валидизации не превращается в универсальные нормы; результат не является клиническим диагнозом.

## Ручные контрольные расчёты
- Все ответы «Да»: 13 совпадений; все «Нет»: 7.
- Ответы ровно по ключу: 20; противоположные ключу ответы: 0.
- Границы категорий проверены: 1, 7, 8, 9, 10, 11, 12, 13, 14, 20.
