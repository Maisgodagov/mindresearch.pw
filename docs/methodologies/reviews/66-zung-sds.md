# 66. Zung Self-Rating Depression Scale (SDS)

Статус: `ru-ineligible` для текущего прохода.

Найдено описание русской адаптации Т.И. Балашовой и широко циркулирующие русские формы. Однако надёжная публикация, устанавливающая психометрические свойства именно этой формы на выборке, набранной в России, не найдена. Отдельные адаптации на русском языке для иных стран не подтверждают российскую апробацию. Пороговые таблицы на агрегаторах не принимаются как первичный источник.

Ориентиры для дальнейшего поиска:
- Описание методики в НЦПЗ: https://www.ncpz.ru/lib/1/book/22/chapter/37
- Русская адаптация упоминается в документах, но без необходимой проверки версии/выборки: https://www.consultant.ru/document/cons_doc_LAW_416912/640cd8316714e83089e6951cc4424dbacae2cedd/

Не добавлять до обнаружения российской психометрической публикации по точному варианту Балашовой.
