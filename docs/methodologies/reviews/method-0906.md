# Опросник диагностики потенциально-экстремистских настроений среди молодежи

- Решение: подготовлен; найден полный пригодный русский текст и точный ключ.
- Русский бланк и ключ: [Психодиагностический комплекс для образовательных организаций и правоохранительных органов, направленный на выявление экстремистской направленности личности](https://chspu.ru/wp-content/uploads/2025/01/%D0%98%D1%82%D0%BE%D0%B3_%D0%9F%D1%81%D0%B8%D1%85%D0%BE%D0%B4%D0%B8%D0%B0%D0%B3%D0%BD%D0%BE%D1%81%D1%82%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D0%B9-%D0%BA%D0%BE%D0%BC%D0%BF%D0%BB%D0%B5%D0%BA%D1%81-%D0%B4%D0%BB%D1%8F-%D0%BE%D0%B1%D1%80%D0%B0%D0%B7%D0%BE%D0%B2%D0%B0%D1%82%D0%B5%D0%BB%D1%8C%D0%BD%D1%8B%D1%85-%D0%BE%D1%80%D0%B3%D0%B0%D0%BD%D0%B8%D0%B7%D0%B0%D1%86%D0%B8%D0%B9-%E2%80%94-%D0%BC%D0%B0%D0%BA%D0%B5%D1%82-%D0%BE%D1%82-28.12.2024-compressed.pdf), раздел 2.16, с. 105–108; здесь приведены все пункты, пятибалльные варианты ответа, правила реверса, состав шкал и нормы.
- Первоисточник методики: [Идрисов К. А., Хажуев И. С., Саидов А. А. «Психосоциальный подход в профилактике террористической направленности молодежи: опыт Чеченской Республики»](https://doi.org/10.33580/9785002122332), Махачкала: АЛЕФ, 2022, 312 с., ISBN 978-5-00212-233-2; название и библиографические данные также указаны с бланком в пособии ЧГПУ.
- Страница русской онлайн-версии: [Диагностика потенциально-экстремистских настроений (Psytests)](https://psytests.org/group/dpexn.html); описывает назначение и авторство, страницы запуска/бланка указаны там, но для реализации текст и ключ сверялись по пособию ЧГПУ.
- Количество пунктов: 46.
- Ответы: «Категорически не согласен» (1), «Скорее не согласен» (2), «Не определился» (3), «Скорее согласен» (4), «Полностью согласен» (5).
- Шкалы: религиозный экстремизм (25 пунктов); национальный экстремизм (10); социально-нормативно-правовой экстремизм (10); общий уровень экстремизма (41); насильственный экстремизм (9).
- Подсчёт: суммирование ответов по перечню пунктов каждой шкалы. Прямой пункт оценивается 1–5 в исходном направлении; обратный — реверсируется по формуле `6 − ответ`. Приведённые в пособии гендерные нормативные диапазоны не кодировались в scoring config.
- Контрольный пример вручную: при ответе 1 на все пункты прямые оцениваются по 1, обратные по 5; получаются религиозный `13×1 + 12×5 = 73`, национальный `10×1 = 10`, социально-нормативно-правовой `7×1 + 3×5 = 22`, общий `30×1 + 11×5 = 85`, насильственный `7×1 + 2×5 = 17`. Значения контрольных случаев в модуле совпадают с этим расчётом.
