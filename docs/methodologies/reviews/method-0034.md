# Тест RIASEC / Код Голланда — IIP RIASEC Markers, форма A

- Решение: prepared; русский текст всех пунктов и однозначное распределение по шкалам доступны.
- Русский текст и инструкция: [psytests.org, описание и бланк](https://psytests.org/typo/riasecO.html), [бланк с 48 пунктами и вариантами](https://psytests.org/typo/riasecO-bl.html). Версия OpenPsychometrics (2015), перевод psytests.org (2022).
- Ключ: [Interest Item Pool, RIASEC Markers, Activities Set A](https://jrounds.weebly.com/riasec-markers-scalesitems.html). Первичная страница авторов явно задаёт шесть групп по восемь занятий; русский бланк сопоставлен с ними по формулировкам занятий. Все пункты прямые, реверсивных нет.
- Количество пунктов: 48; шесть шкал по 8 пунктов: R (1, 7, 13, 19, 25, 31, 37, 43), I (2, 8, 14, 20, 26, 32, 38, 44), A (3, 9, 15, 21, 27, 33, 39, 45), S (4, 10, 16, 22, 28, 34, 40, 46), E (5, 11, 17, 23, 29, 35, 41, 47), C (6, 12, 18, 24, 30, 36, 42, 48).
- Ответы: 1 — Совсем не нравится; 2 — Скорее не нравится; 3 — Может быть да, может быть нет; 4 — Скорее понравится; 5 — Точно понравится.
- Подсчёт: для каждой шкалы сложить ответы её восьми пунктов; диапазон каждой суммы 8–40. Обратных пунктов нет. Вычисление отдельного кода из ведущих шкал в модуль не добавлено, поскольку страница ключа задаёт шкальные группы и суммы, но не правило разрешения равенств/выбора ведущих шкал.
