# 411. Кокология

Решение worker: `blocked`.
Основание: «Кокология» — серия разнородных игровых сценариев, а не единый опросник с общим ключом и правилом подсчёта. Русская страница описывает серию и перечисляет отдельные игры, но не задаёт единого точного алгоритма для пункта очереди; объединять отдельные сценарии или угадывать ключ нельзя. Разрешённые файлы не создавались.
