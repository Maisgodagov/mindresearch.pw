# Диагностика уровня эмпатических способностей — В. В. Бойко (1996)

- Решение: подготовлена регистрация как `test_1831`; русская форма содержит 36 пунктов с ответами «Да/Нет», полный ключ опубликован.
- Русский текст: мужской бланк [«Диагностика уровня эмпатических способностей — бланк»](https://psytests.org/boyko/boemp-bl.html). Использована мужская редакция из публикации ключа; бланк psytests служил сверкой формулировок.
- Источник текста и ключа: [«Методика диагностики уровня эмпатических способностей В. В. Бойко (тест-опросник на эмпатию Бойко)», PDF, с. 1–2](https://www.leocdn.ru/uploadsForSiteId/200154/texteditor/56f4476a-6d8e-497d-82b2-937c1c81e999.pdf). В PDF приведены все 36 утверждений, шесть ключей шкал и правила суммирования. Библиографический первоисточник, указанный на странице методики: В. В. Бойко. [«Энергия эмоций в общении: взгляд на себя и на других»](https://psytests.org/book/boyko1996.html). М.: Филинъ, 1996.
- Пункты и варианты: 36 утверждений, «Да»/«Нет». Ключевые ответы «Да» и обратные ключевые ответы «Нет» заданы списками пунктов в scoringConfig; при значении ответа «Да» = 1, «Нет» = 0 обратные пункты инвертируются.
- Шкалы: рациональный канал, эмоциональный канал, интуитивный канал, установки, способствующие эмпатии, проникающая способность в эмпатии, идентификация в эмпатии — по 6 пунктов каждая. Общий показатель — сумма шести шкал (0–36).
- Формула: для каждой шкалы подсчитывается число совпадений с ключом; общий показатель равен сумме всех ключевых совпадений. Вручную проверенный контрольный случай: все ответы «Нет» дают по шкалам 4, 3, 4, 1, 1, 4; сумма 17.
- Итого: текст и ключ доступны в русском варианте; в карточке указано, что формулировки даны в мужском грамматическом роде и версия предназначена для самооценки взрослых.
