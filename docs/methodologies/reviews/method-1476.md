# Психическая надёжность спортсмена (ПНС), В. Э. Мильман

- Решение: `blocked` — русский текст доступен, но ключ нельзя точно восстановить из доступных источников: таблица ключа в скане не сохраняет сопоставление значений с пунктами, шкалами и вариантами ответа. Модуль не создан.
- Русский бланк: [«Психическая надёжность спортсмена, ПНС — бланк»](https://psytests.org/sport/pns-bl.html), 22 пункта; девять вариантов для пункта 17, остальные пункты с тремя вариантами.
- Источник описания и ключа: [В. Э. Мильман, «Психическая надёжность спортсменов», в книге «Методики психодиагностики в спорте»](https://www.leocdn.ru/uploadsForSiteId/200528/texteditor/ce1c44e4-2052-4c4d-95fe-d29f49e616dd.pdf), учебное пособие, раздел 4.4, с. 91–95 PDF. Текст пособия описывает четыре компонента: соревновательную эмоциональную устойчивость (СЭУ), саморегуляцию (СР), мотивационно-энергетический компонент (МЭ), стабильность и помехоустойчивость (СтП). На с. 95 помещена таблица ключа, однако доступный текстовый слой утратил расположение значений по колонкам и строкам; начисление баллов и обратные пункты нельзя однозначно привязать к ответам.
- Каталог методики: [«Психическая надёжность спортсмена, ПНС»](https://psytests.org/sport/pns.html) указывает автора В. Э. Мильмана (1976) и назначение опросника. Путеводитель каталога: [«Спорт и достижения: тесты и опросники»](https://psytests.org/guide/sport-ru.html).
- Число пунктов: 22. Шкалы: СЭУ, СР, МЭ, СтП. Формула: по источнику подсчитываются баллы отдельно по каждому компоненту; 0 соответствует среднему уровню, отрицательная сумма — снижению, положительная — повышению. Точные правила суммирования ответов не установлены из читаемого ключа, поэтому алгоритм не реализован.
