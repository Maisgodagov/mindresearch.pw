# 77. Subjective Happiness Scale (SHS), русская версия

Статус: `blocked` — официально заявлено только некоммерческое использование, русская форма предоставляется автором по запросу.

## Версия и российская проверка

В оригинальной статье Lyubomirsky & Lepper (1999) описаны прямой перевод SHS на русский и обратный перевод, а также две российские выборки: студенты колледжа (N=67) и взрослые из сообщества (N=63). Статья сообщает внутреннюю согласованность α=.80 и α=.79 соответственно. Форма состоит из четырёх пунктов с ответами 1–7; пункт 4 кодируется обратно, итог — среднее четырёх ответов (1–7).

Официальная страница автора разрешает SHS только для некоммерческих (nonprofit) целей и просит обращаться к автору за переводом. До проверки режима платформы и получения официальной русской формы/разрешения перевод не встраивать. Не использовать полный текст, собранный по вторичным сайтам.
