# Психологический профиль потребителя — О. С. Посыпанова (2012)

- Решение: подготовлено. Русский текст всех 60 пунктов и четырёх вариантов ответа, а также точный ключ опубликованы в первоисточнике.
- Русская форма и первоисточник ключа: О. С. Посыпанова, [«Экономическая психология: психологические аспекты поведения потребителей»](https://library.nusta.edu.ua/depository/%D0%9E%D1%86%D0%B8%D1%84%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D1%96%20%D0%B4%D0%BE%D0%BA%D1%83%D0%BC%D0%B5%D0%BD%D1%82%D0%B8/%D0%AD%D0%BA%D0%BE%D0%BD%D0%BE%D0%BC%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B0%D1%8F%20%D0%BF%D1%81%D0%B8%D1%85%D0%BE%D0%BB%D0%BE%D0%B3%D0%B8%D1%8F.%20%D0%9F%D1%81%D0%B8%D1%85%D0%BE%D0%BB%D0%BE%D0%B3%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D0%B5%20%D0%B0%D1%81%D0%BF%D0%B5%D0%BA%D1%82%D1%8B%20%D0%BF%D0%BE%D0%B2%D0%B5%D0%B4%D0%B5%D0%BD%D0%B8%D1%8F%20%D0%BF%D0%BE%D1%82%D1%80%D0%B5%D0%B1%D0%B8%D1%82%D0%B5%D0%BB%D0%B5%D0%B9.%20%D0%9F%D0%BE%D1%81%D1%8B%D0%BF%D0%B0%D0%BD%D0%BE%D0%B2%D0%B0%20%D0%9E.%D0%A1..pdf), Калуга: Изд-во КГУ им. К. Э. Циолковского, 2012, 296 с.; приложение 1, печатные с. 272–280 (PDF с. 274–281): [описание и страница методики Psytests](https://psytests.org/life/pppot.html), [страница русского бланка](https://psytests.org/life/pppot-bl.html). Бланк сайта не открылся при проверке, поэтому текст сверен непосредственно с полным сканом монографии.
- Объём: 60 утверждений о бытовых товарах и выбранной товарной категории. Варианты: «Никогда или редко», «Иногда», «Часто», «Всегда / почти всегда»; баллы 0, 1, 2, 3.
- Шкалы: индивидуалист, инноватор, модник, традиционалист, консерватор, ситуативист, равнодушный. Для каждого типа суммируются баллы прямых пунктов и соответствующие ключу оценки свойств 49–59; пункты, указанные первоисточником как незначимые для типа, пропускаются. Для прямых пунктов каждого свойства ответ оценивается 0–3; обратные оценки для свойств заданы по ключу как 3–0. Пункты 1–48 и 60 кодируются 0–3 в порядке вариантов.
- Формула: сумма баллов по ключевым пунктам шкалы (пропущенные по ключу свойства не учитываются). Ведущий тип — шкала с максимальной суммой. Интерпретационные диапазоны первоисточника: 0–13 — не выражен; 14–27 — минимально выражен; 28–41 — средне выражен; 42–54 — максимально выражен.
- Проверка описания: `instrument.description` сообщает автору опроса измеряемый конструкт и охватываемые профилем аспекты; это не инструкция респонденту.
