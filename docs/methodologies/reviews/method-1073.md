# 1073. Опросник ориентации на социальные сравнения

Решение worker: `blocked`.
Основание: Доступный первичный русский бланк содержит все 13 пунктов и шкалу частоты 0–4, но опубликованные описания РООСС подтверждают только состав факторов: пункты 1–7 — сравнение с собой, 8–11 — со знакомыми, 12–13 — с незнакомыми. Надёжного точного правила подсчёта баллов по этим факторам в доступных источниках нет; бланк PsyTests отдельно предупреждает, что номера колонок не являются баллами и отсылает за подсчётом к первоисточнику. Поэтому алгоритм нельзя реализовать без догадки; разрешённые файлы не создавались.
