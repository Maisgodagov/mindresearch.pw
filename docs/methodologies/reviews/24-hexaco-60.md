# HEXACO-60

- Статус: `blocked`
- Авторы: Kibeom Lee, Michael C. Ashton
- Версия: 60-item HEXACO-PI-R self-report / observer-report family; конкретный язык в очереди не указан
- Целевая популяция: взрослые респонденты; зависит от языковой формы
- Правообладатель / издатель: авторы HEXACO-PI-R / hexaco.org
- Лицензия: `permission-required` / `restricted`

## Первичные источники

- Официальная страница материалов HEXACO-PI-R: https://hexaco.org/hexaco-inventory
- Официальный scoring key для 60-item version: https://hexaco.org/downloads/ScoringKeys_60.pdf
- Официальное руководство для non-academic use: https://hexaco.org/nonacademicuse.htm

## Установленные факты

Официальная страница HEXACO прямо указывает, что 60-item и 100-item версии доступны бесплатно только для non-profit academic research. Там же указано ограничение для онлайн-администрирования: авторы не разрешают сбор данных через онлайн survey site или приложение, доступное широкой публике; такие онлайн-страницы или приложения должны быть password-protected либо not searchable through search engines.

Официальный scoring key для 60-item version содержит полный ключ по шести факторам и фасетам, правило обратного кодирования и правило подсчёта средних. Для non-academic use официальная страница требует отдельную покупку лицензированных администраций; HEXACO-60 прямо перечислен как одна из форм.

## Причина блокировки

Хотя `HEXACO-60` является конкретной 60-пунктовой формой и официальный ключ доступен, текущая платформа не гарантирует соблюдение официальных условий: публичные ссылки на опросы, отсутствие обязательной парольной защиты и невозможность гарантировать исключительно non-profit academic research для всех пользователей.

Поэтому нельзя безопасно включать полный текст HEXACO-60 и автоматический подсчёт в общий каталог платформы без отдельного разрешения авторов или продуктового ограничения доступа под условия HEXACO.

## Что потребуется для разблокировки

1. Письменное разрешение авторов HEXACO-PI-R на публикацию полного текста HEXACO-60, веб-администрирование, автоматический подсчёт, хранение ответов и экспорт.
2. Явно выбранная форма: self-report или observer-report, язык, конкретный файл.
3. Подтверждение режима использования: non-profit academic research с password-protected / not searchable online доступом либо оплаченная/выданная лицензия для non-academic use.
4. Если методика будет доступна только отдельным исследователям, потребуется техническое ограничение каталога и ссылок, чтобы не нарушать условие authors' website.

## Итоговое решение

Методика в продукт не добавляется. Подменять HEXACO-60 открытой IPIP-реконструкцией нельзя без отдельной записи в очереди, потому что это другой инструмент.
