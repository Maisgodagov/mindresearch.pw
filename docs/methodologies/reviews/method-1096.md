# 1096. Опросник оценки сформированности стадий становления субъектности

Решение worker: `blocked`.
Основание: Русский бланк ОСС-2 доступен, но источник бланка указывает, что оригинальную инструкцию подсчёта следует брать из первоисточников. В доступных первичных публикациях не найден однозначный ключ, сопоставляющий варианты ответов шести стадиям; назначать его по смыслу было бы догадкой. Файлы не созданы.
