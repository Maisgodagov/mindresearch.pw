# МИПИ — методика исследования профессиональной идентичности

- Решение: пригодна; подготовлена регистрация русской 76-словной версии Л. Б. Шнейдер.
- Русский текст и бланк: [Методика исследования профессиональной идентичности, МИПИ — Psytests, описание и переход к прохождению](https://psytests.org/ident/mipi.html); онлайн инструкция: [Прохождение МИПИ](https://psytests.org/ident/mipi-run.html). Текст слов ассоциативного ряда и раздельный ключ сверены по [«Психология личности: идентичность и временная перспектива», приложение, МИПИ, с. 129–130](https://publishing.intelgr.com/archive/Psikhologiya-lichnosti-identichnost-i-vremennaya-perspektiva.pdf).
- Первичная библиография: [Л. Б. Шнейдер. «Личностная, гендерная и профессиональная идентичность: теория и методы диагностики». МПСИ, 2007](https://lib.mgppu.ru/OpacUnicode/app/index.php?url=%2Fnotices%2Findex%2FIdNotice%3A49903%2FSource%3Adefault) (библиографическая запись из каталога МГППУ); Psytests указывает это издание как источник версии.
- Количество пунктов: 76 слов-стимулов, каждый отмечается отдельно (можно выбрать любое количество слов). Ответы — один вариант «Относится ко мне» либо невыбранное слово.
- Шкалы: количество выбранных слов профессиональной категории A (30 слов) и непрофессиональной категории B (46 слов). Реверсивных пунктов нет.
- Формула по приложению: `S = A / (A + B) × 100`; при отсутствии выбранных слов результат неопределён и не рассчитывается. Ключ задаёт однозначные множества слов двух категорий. В регистрационном скоринге приведены сырые подсчёты A и B; доля S получается из них по указанной формуле.
- Контрольный пример: выбор «Азарт» и «Доход» даёт A=1, B=1, S=50.
- Ограничение: приложение излагает алгоритм процентного показателя; другие вторичные публикации описывают также отношение A/B и иные статусные интервалы. Здесь не смешиваются эти варианты: реализуемый ключ и формула следуют указанному приложению, а дополнительные статусные классификации не присваиваются.
