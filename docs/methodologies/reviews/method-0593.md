# Методика измерения стиля мышления (А. К. Белоусовой)

- Статус: подготовлено; русский текст и точный ключ опубликованы.
- Русская версия: [Опросник «Методика измерения стиля мышления» в приложении 1 пособия «Стиль мышления»](https://djvu.online/file/QcEDE7pW0E81O), Белоусова А. К., Пищик В. И., 2011, с. 139–141; страница онлайн-бланка [«Методика измерения стиля мышления»](https://psytests.org/typo/mism-bl.html).
- Первичный источник ключа и описания: [Белоусова А. К., Пищик В. И. «Стиль мышления: учебное пособие»](https://djvu.online/file/QcEDE7pW0E81O), Издательство Южного федерального университета, 2011, ISBN 978-5-9275-0833-4, приложение 1, с. 139–141. Библиографическая карточка методики: [страница PsyTests с авторами, годом и ссылкой на бланк](https://psytests.org/typo/mism.html).
- Пунктов: 32 утверждения. Варианты ответа: «да», «скорее да», «скорее нет», «нет».
- Шкалы: инициативный (1, 4, 7, 10, 15, 19, 30, 32), критический (2, 5, 11, 13, 16, 20, 25, 31), управленческий (3, 8, 12, 14, 17, 21, 23, 28), практический (6, 9, 18, 22, 24, 26, 27, 29).
- Формула: прямые пункты кодируются «да» = 4, «скорее да» = 3, «скорее нет» = 2, «нет» = 1; обратные пункты кодируются в противоположном направлении, то есть 5 минус исходный балл. Затем баллы суммируются отдельно по каждой шкале. Инициативные обратные: 4, 19, 30; критические: 5, 13, 20, 25, 31; управленческие: 14, 21, 28; практические: 6, 22, 26, 29.
- Ручная проверка: одинаковый ответ «да» даёт шкальные суммы 26, 17, 23, 20 соответственно; одинаковый ответ «нет» — 22, 23, 17, 20.
- Описание инструмента сообщает автору опроса измеряемые аспекты и подходящую группу; оно не является инструкцией респонденту.
