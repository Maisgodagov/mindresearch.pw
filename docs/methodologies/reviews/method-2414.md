# 2414. Шкала социокультурной адаптации

Решение worker: `blocked`.
Основание: Надёжного ключа для русской версии из 16 пунктов не удалось установить. Русский бланк задаёт ответы от «Без затруднений» до «Сильные трудности», но прямо предупреждает, что номера ответов не являются баллами и правила подсчёта следует брать из первоисточников. Статья Wilson et al. описывает другую модель SCAS-R и не подтверждает ключ для этого 16-пунктового бланка. Файлы не созданы.
