# 1307. Опросник эмоционального абьюза

Решение worker: `blocked`.
Основание: Русский бланк содержит 52 пункта и четыре варианта частоты, но не даёт ключа для этой версии и прямо предупреждает, что номера ответов не являются баллами. Найденный ключ для 25-пунктовой True/False формы не подтверждает подсчёт 52-пунктовой версии; распределение по шкалам и баллы нельзя надёжно вывести. Разрешённые файлы не создавались.
