# 1517. Реестр предполагаемых типов усвоения информации

Решение worker: `blocked`.
Основание: Надёжный русский текст найден, но однозначный точный ключ для его подсчёта не подтверждён: доступная русская копия у Сиротюк описывает десять рядов и четыре шкалы, однако извлечённый бланк повреждён и не позволяет надёжно установить соответствие всех слов шкалам; страницы бланка psytests недоступны для проверки. По workflow ключ нельзя угадывать, поэтому файлы не создавал.
