# Вторичная выгода от болезни — русскоязычная адаптация Вець (2021)

- Решение: prepared. В публикации доступны все 40 русских утверждений, инструкция, варианты ответа и однозначный ключ по шкалам.
- Источники: [страница методики Psytests](https://psytests.org/diag/sgal.html); [статья И. В. Вець, «Адаптация опросника “Вторичная выгода от болезни”»](https://cyberleninka.ru/article/n/adaptatsiya-oprosnika-vtorichnaya-vygoda-ot-bolezni), DOI: 10.28995/2073-6398-2021-4-130-151.
- Объём: 40 утверждений, две части по 20; ответы: «Нет, совершенно не согласен», «Скорее нет, чем да», «Затрудняюсь ответить», «Скорее да, чем нет», «Да, совершенно согласен».
- Шкалы и пункты: регрессия (4, 12, 14, 15, 19); триггеры соматизации (1, 2, 5, 10, 17); конформизм (3, 7, 8, 11, 20); симуляция (6, 9, 13, 16, 18); ресурсы восстановления (25, 29, 35, 37); цена восстановления (30, 31, 33, 34); пути восстановления (21, 23, 27, 36); автономия (22, 24, 26, 28, 40). В ключе реверсивные пункты отдельно не указаны; реверсирование не применяется.
- Формула: среднее исходных ответов 1–5 по пунктам каждой шкалы; общий уровень — среднее оценок по восьми шкалам, эквивалентное среднему по 40 пунктам, поскольку пункты непересекающиеся. Публикация описывает общий показатель как сумму оценок восьми шкал; при публикации шкал как средних этот показатель представлен его средним, с сохранением шкалы 1–5.
- Результат: точный русский текст и публикационный ключ доступны; регистрация использует код `test_181`.
