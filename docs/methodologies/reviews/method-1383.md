# Оценка уровня сформированности УУД учащихся начальных классов (Ю. Г. Коломиец)

- Решение: `prepared`. Найдены полный русский текст анкеты, варианты ответов и однозначный ключ в публикации автора.
- Русская версия: [«Психологический мониторинг формирования УУД в рамках ФГОС» — публикация Юлии Григорьевны Коломиец с полным текстом анкеты и ключом](https://psy.su/feed/3996/). Текст и ключ опубликованы автором 21.10.2014.
- Бланк и справка о версии: [«Оценка уровня сформированности УУД учащихся начальных классов» — страница методики Psytests](https://psytests.org/school/ousuud.html); [бланк методики](https://psytests.org/school/ousuud-bl.html). Страница указывает авторство Ю. Коломиец (2015), назначение для экспресс-диагностики учащихся 2–5 классов и публикацию в журнале «Школьный психолог».
- Библиографическая публикация: [Ю. Коломиец. «Пять минут на УУД. Анкеты для экспресс-диагностики» // Школьный психолог. 2015. № 1](https://psytests.org/school/ousuud.html) (библиографическая ссылка приведена на странице методики).
- Количество пунктов: 20; анкету заполняет учитель по наблюдаемому поведению ученика.
- Ответы и кодирование: «Всегда» = 2, «Иногда» = 1, «Никогда» = 0. Обратных пунктов нет.
- Шкалы и ключ: познавательные общеучебные УУД — пункты 1–5 (0–10; высокий 8–10, средний 5–7, низкий 0–4); регулятивные — 6–11 (0–12; высокий 10–12, средний 6–9, низкий 0–5); личностные — 12–15 (0–8; высокий 7–8, средний 4–6, низкий 0–3); коммуникативные — 16–20 (0–10; высокий 8–10, средний 5–7, низкий 0–4). Общий показатель — сумма пунктов 1–20 (0–40; высокий 32–40, средний 20–31, низкий 0–19).
- Формула: для каждой шкалы сумма кодов ответов по назначенным пунктам; общий показатель — сумма всех 20 кодов. Обратного перекодирования нет. Контрольные примеры вручную сверены с границами шкал: все ответы «Всегда» дают 10/12/8/10/40, а все «Иногда» — 5/6/4/5/20 по указанным шкалам.
- Ограничение: анкету следует трактовать как экспресс-оценку учителя, а не как самостоятельное диагностическое заключение.
