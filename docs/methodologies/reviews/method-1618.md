# 1618. Социально-коммуникативный опросник

Решение worker: `blocked`.
Основание: Русский текст форм SCQ подтверждён, но полный поэлементный ключ доступен только в комплекте руководства; открытые источники указывают, что ключ находится там, и не дают его содержимого. Точный подсчёт по ответам без угадывания реализовать нельзя, поэтому файлы не созданы.
