# Опросник для диагностики пограничного личностного расстройства, форма A

- Статус: `blocked`.
- Русский текст: полный бланк формы A доступен на [странице бланка «Опросник для диагностики ПЛР»](https://psytests.org/diag/lasplr-bl.html); страница описания указывает, что форма A разработана Т. Ю. Ласовской с коллегами по критериям DSM-III-R ([«Опросник для диагностики ПЛР»](https://psytests.org/diag/lasplr.html)).
- Публикация: Т. Ю. Ласовская, [«Опросник для диагностики пограничного личностного расстройства формы “А”»](https://psyjournals.ru/journals/cpp/archive/2014_n2/72315), *Консультативная психология и психотерапия*, 2014, т. 22, № 2, с. 48–77. В статье подтверждены четыре шкалы и существование ключей-масок, однако доступный текст публикации не раскрывает ключ пунктов (соответствие номеров пунктов ответам «Да/Нет»).
- Объём и шкалы: 80 пунктов, по 20 на шкалу: нестабильность/импульсивность, самоповреждающее поведение, непереносимость одиночества, суицидальное поведение. В бланке ответы «Да» и «Нет».
- Подсчёт: публикация говорит о подсчёте сырых сумм по ключу и переводе сырых баллов в стены с учётом возраста (таблицы 2–5); диагностические границы описаны для 8 стенов и выше по общей сумме, импульсивности, самоповреждающему или суицидальному поведению. Без точного покомпонентного ключа и обратных пунктов достоверно реализовать даже сырой подсчёт нельзя; ключ не реконструировался.
- Итог: модуль не создан, поскольку надёжный точный ключ подсчёта в проверенных прямых источниках не найден. Наличие русского текста подтверждено.
