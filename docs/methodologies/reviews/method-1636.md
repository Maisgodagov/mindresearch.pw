# Способность к речемыслительному прогнозированию (Л. А. Регуш)

- Статус: `blocked`.
- Русский текст: доступен полный бланк из 20 пар утверждений на странице «Бланк: Способность к речемыслительному прогнозированию» PsyTests. Текст представлен по-русски.
- Ключ и подсчёт: надёжно не подтверждены доступным первоисточником. Страница описания ссылается на публикацию Регуш 2022, МЕТ 101; ссылка на неё не открылась при проверке. В поисковом фрагменте обнаружена лишь неполная строка ключа, без полного соответствия пунктов шкалам и без достаточных правил подсчёта. По этой неполной информации нельзя точно реализовать подсчёт, поэтому ключ не реконструировался.
- Пункты и шкалы: 20 пунктов, по два альтернативных утверждения (а/б). Вторичный источник сообщает о семи шкалах (шесть характеристик прогностического мышления и склонность к риску), но полного первичного ключа, наименований и состава шкал недостаточно для точной регистрации.
- Формула: не реализована; автоматическое суммирование и обратные пункты не назначались без подтверждённого ключа.
- Решение: русская версия пригодна, но надёжный точный ключ/подсчёт в доступных прямых источниках не удалось подтвердить; методика заблокирована до получения полного первоисточника с ключом.
