# Субъектная позиция — решение по пункту 1690

- **Статус:** blocked.
- **Русский текст:** доступен. Страница [«Субъектная позиция» — PsyTests](https://psytests.org/emvol/subpos.html) описывает методику; страница [бланка «Субъектная позиция»](https://psytests.org/emvol/subpos-bl.html) и [Методические рекомендации для педагогов-психологов по разработке и реализации программ развития младших школьников](https://mgppu.ru/resources/NEW/project/415/Metodicheskie_rekomendacii_mladshie_shkol%27niki.pdf) содержат русскоязычные утверждения.
- **Ключ:** не удалось установить однозначно для полного доступного бланка. В статье авторов [«Методика исследования субъектной позиции учащихся разных возрастов»](https://psyjournals.ru/journals/pse/archive/2014_n1/68800) сказано, что сокращённый вариант содержит 12 пунктов — по 4 на шкалы «Субъектная позиция», «Объектная позиция» и «Негативная позиция». В статье перечислены эти пункты (ОП: № 5, 9, 13, 14; НП: № 18, 24, 27, 29; СП: № 12, 16, 19, 25), но сама полная формулировка пункта 29 в доступном тексте обрезана, а комплект остальных пунктов формы и соответствие нумерации опубликованному бланку не подтверждены. Авторы задают баллы прямых ответов: «Нет» — 0, «Скорее нет, чем да» — 1, «Скорее да, чем нет» — 3, «Да» — 4; для обратных вопросов — обратный порядок. При факторном анализе обратные вопросы исключались, однако полный однозначный ключ к версии бланка не опубликован в просмотренных источниках.
- **Количество пунктов и шкалы:** в описании PsyTests/публикации — 12 пунктов, 3 шкалы по 4; в доступном отдельном школьном бланке — расширенная форма. Эти формы нельзя объединить без предположений.
- **Подсчёт:** формула для сокращённого варианта — сумма оценок включённых пунктов по каждой шкале с реверсом обратных пунктов; общий балл не рассчитывается. Полную карту «пункт → шкала» и список обратных пунктов для доступной бланковой версии надёжно подтвердить не удалось.
- **Источники:** [статья авторов с описанием шкал, пунктов и оценивания](https://psyjournals.ru/journals/pse/archive/2014_n1/68800); [страница методики и русскоязычный онлайн-бланк PsyTests](https://psytests.org/emvol/subpos.html); [бланк для учащихся 3–4 классов в методических рекомендациях МГППУ](https://mgppu.ru/resources/NEW/project/415/Metodicheskie_rekomendacii_mladshie_shkol%27niki.pdf).

**Итог:** модуль не создаётся: надежный точный ключ и связь полной формы с опубликованным ключом не подтверждены. Не угадывать состав шкал и обратные пункты.
