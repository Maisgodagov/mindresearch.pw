# 1162. Опросник психосоциальной зрелости личности

Решение worker: `blocked`.
Основание: Русский бланк ПСЗ-50 содержит 50 пунктов и варианты «Очень редко», «Иногда», «Часто», «Почти всегда», но сам источник уточняет, что номера колонок не являются баллами. Надёжный ключ, реверсивные пункты и точный алгоритм подсчёта не удалось подтвердить по доступным первоисточникам; угадывать их нельзя, поэтому файлы не созданы.
