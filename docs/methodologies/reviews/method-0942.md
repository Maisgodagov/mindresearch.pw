# 942. Опросник для учителя по адаптации первоклассников

Решение worker: `blocked`.
Основание: Русский текст всех 46 пунктов и категории оценки найдены в публикации Т. А. Крайниковой 2017 года. Однако подтверждённое там правило начисления баллов не даёт надёжного точного алгоритма: указано 1 балл за пункты слева от линии, 2 — справа, максимум 70, а коэффициент записан как «К = n×100» без делителя. Размещение пунктов по сторонам линии в доступном тексте бланка не восстанавливается однозначно. Не буду угадывать ключ или формулу, поэтому файлы не созданы.
