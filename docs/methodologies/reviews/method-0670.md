# 670. Методика Паровозик

Решение worker: `blocked`.
Основание: Русский текст и однозначная таблица начисления баллов доступны, но правила перевода суммы в категории противоречат друг другу: источник задаёт позитивное состояние при сумме менее 3, а затем называет 3 балла низкой степенью НПС. Поскольку алгоритм должен точно соответствовать источнику, категория для суммы 3 не определяется однозначно. Файлы не созданы.
