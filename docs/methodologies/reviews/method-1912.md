# 1912. Типология MBTI

Решение worker: `blocked`.
Основание: Русский текст доступен, но его ключ нельзя надёжно реализовать для одной однозначно установленной версии. Psytests указывает на отдельные русские адаптации устаревших форм F и G; опубликованный ключ формы F использует разные трафареты, в том числе для T/F в зависимости от пола, и исключения для отдельных ответов. Источники не подтверждают, что этот ключ относится к полной форме из найденного русского бланка; действующая русская Step I имеет другой, недоступный в открытом доступе опросник и алгоритм. Чтобы не угадывать и не смешивать версии, файлы не созданы.
