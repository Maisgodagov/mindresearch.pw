# DASS-21 — русский перевод Фаттахова и Горобец

Проверка 14.10.2026: ошибка в формуле не обнаружена. Добавлены независимые проверки каждого пункта, всех значений ответа, границ и сохранения результата; сама формула и её версия сохранены.

Источники: [официальный русский бланк Фаттахова и Горобец на UNSW](https://www2.psy.unsw.edu.au/dass/Russian/Fattakhov/Fattakhov_DASS-21_rus.pdf); [официальный шаблон ключа DASS](https://www2.psy.unsw.edu.au/dass/Download%20files/Dass_template.pdf); [официальный FAQ](https://www2.psy.unsw.edu.au/Groups/Dass/DASSFAQ.htm).

21 пункт; ответы 0–3, период оценки — последняя неделя. Депрессия: 3, 5, 10, 13, 16, 17, 21; тревога: 2, 4, 7, 9, 15, 19, 20; стресс: 1, 6, 8, 11, 12, 14, 18. По каждой шкале складываются семь ответов, сумма умножается на 2 ровно один раз. Диапазон каждой шкалы 0–42, обратных пунктов нет. Общий диагноз из сумм не выводится.

Контроль: все 0 → 0/0/0; все 1 → 14/14/14; все 2 → 28/28/28; все 3 → 42/42/42. В каждом из 21 одиночных профилей ответ 3 должен дать 6 только в соответствующей шкале. Проверена сериализация числовых ответов в JSON и сохранение диапазона 0–42.
