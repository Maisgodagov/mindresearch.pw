# Цветовое зеркало Фрилинга — решение

- Статус: `blocked`.
- Русская версия доступна: [«Цветовое зеркало Фрилинга», страница методики и прохождения](https://psytests.org/classic/mirror.html) содержит инструкции девяти этапов; доступный набор — 23 цветовые карточки и четыре позиции. Библиографическое описание указывает адаптацию В. Н. Кононовой (2006).
- Публикации: [Кононова В. Н. «Цветовое зеркало: модификация теста Г. Фрилинга» (Когито-Центр, 2006)](https://ibooks.ru/products/29496); [Кононова В. Н., Нахаева И. В. «Исследование психометрической эквивалентности двух версий…» (Вестник МГУ, 2013, № 1, с. 136–151)](https://msupsyj.ru/pdf/vestnik_2013_1/vestnik_2013-1_136-151.Pdf).
- Ключ/подсчёт: публикация 2013 года сообщает о бумажном протоколе выкладок и последующей обработке специальной программой, но не даёт ключей для автоматического воспроизведения интерпретации. Руководство Кононовой описывает многоуровневый анализ, однако полный алгоритм и таблицы соответствий публично не доступны в проверенных источниках. Нельзя надёжно назначить ответы пунктам/шкалам или считать результат по открытым данным; не реконструирую алгоритм по догадке.
- Структура: 9 заданий-этапов (первые три выбора/оценка предпочтения, затем шесть выкладок по четыре цвета); числовых шкал с открытым однозначным ключом установить нельзя, поэтому формулу автоматического подсчёта не приводить.
- Итог: русская инструкция пригодна, но критерий надёжного точного ключа/подсчёта не выполнен; регистрацию не создавать.
