# Методика диагностики гендерного типа личности — русская версия О. Г. Лопуховой

- Статус: `implemented-local`, `test_55`, версия `lopukhova-bsri-russian-27-2013-v1`.
- Авторы / год: О. Г. Лопухова, 2013.
- Целевая популяция: взрослая российская выборка; публикация описывает проверку на N=200 (100 мужчин и 100 женщин), тест-ретест N=80.
- Используемая версия: оригинальная российская 27-пунктовая методика, не 60-пунктовый Bem Sex Role Inventory.
- Права: открытая лицензия/разрешение на цифровое воспроизведение полного бланка не установлены; права необходимо уточнить до публичного/коммерческого использования.

## Первичные источники

- О. Г. Лопухова (2013), [первичная публикация с бланком, ключом и интерпретацией](https://kpfu.ru/staff_files/F81285694/Lopuhova.pdf).
- [Запись публикации в репозитории КФУ](https://dspace.kpfu.ru/xmlui/handle/net/32750).

## Независимая сверка

- [PsyTests: русская версия BSRI](https://psytests.org/trait/bsriR.html) использована только для дополнительной проверки состава и порядка; она не заменяет публикацию автора.
- Сверены 27 качеств, порядок и распределение на три группы по девять пунктов.

## Текст и варианты ответов

- 27 качеств оцениваются по пятибалльной частоте проявления: от «никогда или почти никогда» (1) до «всегда или почти всегда» (5).
- Полный бланк и точные формулировки находятся в `apps/api/src/data/lopukhovaGenderTypeRu.ts`.

## Ключ и формулы

- Маскулинность: пункты 1, 4, 7, 10, 13, 16, 19, 22, 25.
- Фемининность: пункты 2, 5, 8, 11, 14, 17, 20, 23, 26.
- Буферные качества: пункты 3, 6, 9, 12, 15, 18, 21, 24, 27.
- Каждая исходная шкала — сумма девяти ответов (9–45). Для интерпретации из суммы вычитают нейтральную точку 27; автоматический расчёт показывает исходные суммы и поясняет центрирование в карточке.
- Тип по знакам центрированных маскулинности/фемининности: оба выше 0 — андрогинный; только маскулинность выше 0 — маскулинный; только фемининность выше 0 — фемининный. Если обе шкалы ниже 0, вывод «недифференцированный» допустим только при положительном центрированном результате буферной шкалы. Автоматическая категория не назначается, чтобы не скрыть это условие.
- Обратных пунктов нет. Пропуски не рассчитываются.

## Ручные контрольные расчёты

- Все ответы 1: каждая сумма = 9; центрированный результат = −18.
- Все ответы 5: каждая сумма = 45; центрированный результат = +18.
- Все ответы 3: каждая сумма = 27; центрированный результат = 0.
- Контроли зафиксированы в `apps/api/src/data/lopukhovaGenderTypeRu.ts` и проверены тестами `apps/api/src/scoring/lopukhovaGenderTypeRu.test.ts`.

## Итоговое решение

Реализованы точные пункты и три исходные суммы. Интерпретационные центрированные значения и тип не выдаются как автоматический числовой результат, поскольку используемый движок возвращает расчётные шкалы и не кодирует условную типологию; правило и оговорка доступны в методологической карточке. Публикация не устанавливает здесь открытую лицензию.
