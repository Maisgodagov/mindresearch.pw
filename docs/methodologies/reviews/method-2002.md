# ФТФ-1 — формализованный тест фрустраций Розенцвейга

- Решение: `blocked`.
- Русская версия: страница PsyTests описывает ФТФ-1, но доступное содержимое страницы не раскрывает бланк с пунктами и вариантами ответов.
- Ключ и подсчёт: надёжно сверить точное соответствие пунктов ключу ФТФ-1 и алгоритм подсчёта по открытому источнику не удалось. Полный ключ классического теста Розенцвейга относится к другой версии со свободными ответами; переносить его на ФТФ-1 нельзя.
- Пункты и шкалы: не регистрируются, поскольку комплект русского бланка ФТФ-1 и его специфический ключ недоступны для точной проверки.
- Формула: не реализуется без подтверждённой схемы кодирования и формулы подсчёта ФТФ-1.
- Итог: модуль методики не создаётся, чтобы не угадывать текст, ключ или алгоритм.
