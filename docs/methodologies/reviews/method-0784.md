# 784. Немецкий тест семейной динамики

Решение worker: `blocked`.
Основание: Адекватный русский текст представлен в версии методики PsyTests, однако доступный точный ключ для конкретных пунктов, их полярности и подсчёта проверить не удалось: бланк и страница прохождения не открылись. Вторичные публикации описывают шкалы FB-A, но не дают полного соответствия пунктов ключу. Не стал угадывать или создавать модуль без проверяемого ключа.
