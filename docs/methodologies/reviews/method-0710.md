# Многофакторный личностный опросник Кеттелла (16PF), форма A

- Решение: `blocked`.
- Русский текст: полный текст формы A на 187 пунктов и варианты ответов опубликованы на [странице теста Кеттелла 16PF (форма A), Psytests](https://psytests.org/multi/cat16pfA.html). Эта версия пригодна для проверки текста.
- Источник ключа: [«16-факторний особовий опитувальник Р. Б. Кеттелла (16-FPQ-187-A): текст и ключ», перепечатка материала](https://bibl.com.ua/filosofiya/23142/index.html). Перепечатка ключа повреждена: например, встречаются неоднозначные/искажённые обозначения ответов и номера (включая «111а» в строке шкалы O); нельзя надёжно восстановить полный ключ без догадок. Поэтому автоматический подсчёт не реализован.
- Библиография адаптации: [А. Н. Капустина, «Многофакторная личностная методика Р. Кеттелла» (каталожная запись библиотеки МГППУ)](https://lib.mgppu.ru/opacunicode/index.php?url=%2Fnotices%2Findex%2FIdNotice%3A241537%2FSource%3Adefault); [А. В. Батаршев, «Темперамент и характер. Психологическая диагностика», приложение с формой A](https://ru.djvu.online/file/BEGRJZBFm6s1Z).
- Объём и шкалы: версия A включает 187 пунктов, предназначена для взрослых; предполагает 16 факторов. Каждый пункт имеет три ответа. Надёжный полный ключ и проверяемая формула суммирования по каждому фактору в доступных источниках не подтверждены.
- Итог: модуль не создаётся. Критерий адекватного русского текста соблюдён, критерий точного и надёжного ключа/подсчёта — нет. Для регистрации требуется сверить полный ключ с экземпляром руководства/бланка адаптации, а не исправлять повреждённую перепечатку предположениями.
