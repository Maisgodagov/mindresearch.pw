# Опросник гэмблинг-зависимости (А-50), В. Е. Петров, 2017

- Решение: `blocked` — надежный точный ключ не найден в доступных первичных материалах; модуль не создан.
- Русский текст: доступен полный перечень из 50 пунктов с дихотомическими ответами «Верно» / «Неверно» в рабочей программе дисциплины «Психодиагностика» (2021, с. 17–19): [Рабочая программа дисциплины «Психодиагностика», ИСОиИТ](https://imeit.ru/sveden/files/riu/RP_Psixodiagnostika%283%29.pdf). Онлайн-страница Петрова подтверждает версию 2017 и назначение для психопрофилактической работы с сотрудниками и психологической помощи: [Опросник гэмблинг-зависимости (А-50), описание и бланк](https://psytests.org/petrov/pgambl.html).
- Ключ: авторская публикация — [Петров В. Е. Психологическая диагностика гэмблинг-зависимости у сотрудников правоохранительных органов](https://psyjournals.ru/nonserialpublications/epew2025/epew2025.pdf), библиографическая запись указывает журнал «Вопросы психологии экстремальных ситуаций», 2017, № 2, с. 43–48. В доступных материалах подтверждены две шкалы — «Гэмблинг-зависимость» и «Гэмблинг-осведомленность» — но нет таблицы соответствия всех 50 пунктов этим шкалам, правил кодирования ответов и реверсивных пунктов. Учебная программа содержит пункты, но не ключ.
- Шкалы и подсчёт: 50 пунктов; ответы «Верно» / «Неверно». Точный расчёт невозможен без полного ключа; отдельная публикация сообщает результаты по двум шкалам, но не раскрывает ключ.
- Итог: русская форма пригодна, однако ключ/подсчёт не поддаются надежной точной автоматической реализации без угадывания. Запись `blocked`.

Дополнительная навигационная страница: [Зависимое поведение: тесты и опросники, раздел об азартных играх](https://psytests.org/guide/clinical-addictive-ru.html).
