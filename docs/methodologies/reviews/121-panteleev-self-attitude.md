# Методика исследования самоотношения (МИС), С. Р. Пантилеев

- Статус: blocked
- Авторы / год: С. Р. Пантилеев; первичная публикация 1989 года в сборнике «Практикум по психодиагностике. Конкретные психодиагностические методики», с. 166–172.
- Целевая популяция: взрослая личность; методика применяется в исследованиях и консультировании.
- Используемая языковая версия: русская форма из 110 утверждений, девять шкал, ответы «да/нет».
- Лицензия и правообладатель: явного разрешения на воспроизведение полного бланка в цифровом сервисе не найдено; первоисточник — защищённый авторским правом сборник издательства МГУ.

## Текст и подсчёт
Подтверждается русская версия из 110 пунктов и девяти шкал. Для безопасной реализации необходима построчная сверка полного ключа и таблицы перевода сырых значений по первичному изданию; одних перепечаток недостаточно.

## Итоговое решение
Не добавлять, пока не получен доступ к первоисточнику для финальной сверки и разрешение правообладателя на воспроизведение текста бланка.
