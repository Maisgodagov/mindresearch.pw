# SCREENIVF_RUS — русская адаптация Соловьёвой (2021)

- Решение: `blocked` для точной регистрации в текущем формате `ConfigurableScoring`.
- Русский текст: опубликован полный бланк из 34 пунктов. [Бланк «Опросник SCREENIVF»](https://psytests.org/parent/sinf-bl.html) показывает пункты 1–34 и варианты ответов; русская адаптация с бланком и приложением по обработке опубликована в статье [Е. В. Соловьёвой «Диагностика психоэмоционального состояния женщин во время лечения бесплодия. Русскоязычная версия скринингового опросника SCREENIVF»](https://ppipold.idnk.ru/index.php/2011-02-24-13-44-24/55-2011-02-24-12-27-14/nomer-3-2021/1193-soloveva-e-v-g-moskva), *Прикладная психология и психоанализ*, 2021, № 3.
- Ключ: статья Соловьёвой (приложение 2 «SCREENIVF_RUS. Обработка результатов») задаёт пять суммируемых шкал: тревожность — пункты 1–10, реверсировать 1, 2, 4, 6, 7, порог риска ≥24; депрессия — 11–17, порог ≥4; недостаток социальной поддержки — 18–22, порог ≤15; беспомощность — пункты 23–34: 1, 4, 5, 6, 8, 11, порог ≥14; непринятие репродуктивной проблемы — оставшиеся пункты 2, 3, 7, 9, 10, 12, порог ≤11. [Статья валидации SCREENIVF](https://www.sciencedirect.com/science/article/pii/S0015028217303126) также подтверждает 34 пункта и пять доменов.
- Причина блокировки: конфигурация проекта задаёт единый диапазон числовых ответов для всего опросника, тогда как в русской форме первые 10 пунктов и социальная поддержка кодируются 1–4, депрессивная шкала — 0–3, а пункты восприятия бесплодия — 1–4. Для депрессии источник прямо предписывает сумму отмеченных баллов; общий сдвиг ответов ради одного диапазона изменил бы исходные баллы и опубликованный порог 4. Не применялось предположительное перекодирование.
- Источники описывают SCREENIVF для скрининга эмоционального риска при лечении бесплодия/ВРТ; [страница методики SCREENIVF](https://psytests.org/parent/sinf.html) указывает русскую адаптацию Соловьёвой (2021). [Путеводитель «Материнство: тесты и опросники»](https://psytests.org/guide/clinical-reproductive-ru.html) также относит её к оценке риска эмоциональной дезадаптации у пациенток ВРТ.
