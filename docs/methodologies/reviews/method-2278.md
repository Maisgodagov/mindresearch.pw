# Шкала оценки СДВГ Свенсона, SNAP-IV (краткая версия Psytests)

- Статус: `blocked`.
- Русский текст: доступен бланк Psytests из 18 пунктов для оценки поведения ребёнка, заполняемый родителем или учителем; варианты: «Никогда», «Иногда», «Часто», «Очень часто». Источники: [Бланк «Шкала оценки СДВГ Свенсона, SNAP-IV»](https://psytests.org/diag/snap4-bl.html), [описание русской версии и её ограничений](https://psytests.org/diag/snap4.html).
- Ключ: не подтверждён для именно этой 18-пунктной русской формы. Psytests предупреждает, что номера колонок — только обозначения, не баллы, и рекомендует брать оригинальные бланки и инструкции подсчёта из первоисточников. Его бланк не содержит распределения пунктов по шкалам или алгоритма подсчёта.
- Сверка источников ключа: [SNAP-IV 26 Rating Scale: Scoring Instructions (CADDRA)](https://caddra.ca/pdfs/downloads/SNAP_IV_Instructions.pdf) задаёт шкалу 0–3 и средние значения по доменам для 26-пунктной формы; [Parent and Teacher SNAP-IV Ratings… (PMC)](https://pmc.ncbi.nlm.nih.gov/articles/PMC3623293/) описывает другую краткую 26-пунктную форму. Они не устанавливают соответствие вариантов ответов и ключа именно бланку Psytests на 18 пунктов. [Русский клинический бланк SNAP-IV](https://kidz.vtf.ru/upload/iblock/665/uf4mmlgoz852c5b6b3hrwjnmb8zk2055.pdf) содержит собственный текст/порядок вопросов, шкалу «Никогда / Нечасто / Довольно часто / Очень часто» и 0–3 балла; это отдельная версия, её нельзя подставлять вместо текста Psytests.
- Количество пунктов и шкалы: в бланке Psytests — 18; заявлены невнимательность и гиперактивность/импульсивность. Убедительного ключа и формулы именно для этой версии не установлено.
- Итог: модуль не создавался, поскольку требование надёжного точного ключа для выбранной русской формы не выполнено. Не переносить формулу или пункты между различающимися формами SNAP-IV.
