# 90. Interpersonal Reactivity Index (IRI) — отложен

**Решение:** не добавлять до прояснения прав на цифровое воспроизведение русской версии.

## Что подтверждено

- Русская версия адаптирована Будаговской, Дубровской и Карягиной; апробация проведена в Москве на студенческой выборке: сначала N=203, далее N=318.
- В статье описаны четыре шкалы: децентрация (PT), фантазия (FS), эмпатическая забота (EC) и эмпатический дистресс (PD), приведены пункты и психометрические результаты.
- Статья отмечает отклонение от оригинального ключа для пункта 13 в русской версии; нельзя просто скопировать ключ Дэвиса без точной сверки таблиц адаптации.

## Почему отложен

- Статья доступна по лицензии CC BY-NC 4.0. Для использования адаптированного текста в платформе с неустановленным некоммерческим статусом недостаточно оснований.
- До разрешения нельзя публиковать весь набор русских пунктов, даже если исследовательский ключ можно восстановить.
