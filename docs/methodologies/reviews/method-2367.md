# 2367. Шкала самооценки проявлений ПТСР

Решение worker: `blocked`.
Основание: В доступном русскоязычном бланке psytests.org ответы указаны как «Никогда / Редко / Умеренно / Часто / Очень часто», причём сам сайт предупреждает, что номера ответов не являются баллами. Официальный ключ PCL-5 требует шкалу тяжести 0–4 («совсем нет»–«чрезвычайно»). Не удалось подтвердить надёжным прямым источником, что эти русские ответы соответствуют ключу; по регламенту нельзя угадывать. Файлы не создавались.
