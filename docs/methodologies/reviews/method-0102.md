# Опросник ВАК для подростков — Ананьев
- Решение: prepared.
- Русский текст: полный доступный текст 13 пунктов и вариантов ответа перенесён из [бланка ВАК Psytests](https://psytests.org/typo/kavak-bl.html); описание отличает подростковый ВАК от взрослого КАВД ([страница методики](https://psytests.org/typo/kavak.html)).
- Надёжный ключ: Ананьев, *Основы психологии здоровья*, книга 2: во всех абзацах постоянная последовательность вариантов В–А–К; суммировать ответы, более низкая сумма означает более выраженное качество. Библиографическая ссылка на издание приведена на [странице методики Psytests](https://psytests.org/typo/kavak.html); текст правила доступен в [поисковом фрагменте источника](https://www.studmed.ru/view/ananev-va-osnovy-psihologii-zdorovya-kniga-1_d8929095b3e.html?page=9).
- Количество пунктов: 13; по 3 варианта ответа в каждом.
- Шкалы и подсчёт: визуальная, аудиальная, кинестетическая; по ключу начисляются 1, 2, 3 балла соответственно первому, второму и третьему вариантам каждого пункта; диапазон каждой суммы 13–39. Обратных пунктов нет.
- Формула: `visual = Σ(1-й вариант)`, `auditory = Σ(2-й вариант)`, `kinesthetic = Σ(3-й вариант)` по пунктам 1–13; минимальная сумма обозначает более выраженную систему.
- Ручной контроль: ответы `1` во всех 13 пунктах дают визуальную 13, аудиальную 26, кинестетическую 39.
- Ограничение: на Psytests бланк обозначен как отображение теста; правило подсчёта сверено с описанием Ананьева, полный печатный первоисточник в доступе не проверялся.
