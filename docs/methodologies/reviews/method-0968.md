# 968. Опросник качества жизни SF-36

Решение worker: `blocked`.
Основание: Нашёл полный русский бланк SF‑36 и опубликованный ключ, но правила ключа содержат несогласованность с бланком: в обработке указаны пункты 4г и 4д, тогда как в русском бланке вопрос 4 содержит только 4а–4г. Автоматически реализовать точный подсчёт по этому источнику без догадки нельзя.
