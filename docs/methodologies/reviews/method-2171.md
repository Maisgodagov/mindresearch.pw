# 2171. Шкала краткой оценки негативных симптомов

Решение worker: `blocked`.
Основание: Точный подсчёт подтверждён клиническими рекомендациями: 13 пунктов оцениваются от 0 до 6, общий балл — их сумма (0–78). Русская версия указана в рекомендациях и на странице методики, однако получить полный текст пунктов и якоря оценок из доступных страниц не удалось. Без сверяемого текста нельзя надёжно заполнить регистрацию, не угадывая формулировки.
