# Тест-опросник родительского отношения (ОРО), Варга и Столин

- Решение: добавить русскую версию из полного 61-пунктового бланка с ключом подсчёта; не смешивать её с изменённой версией Psytests.
- Русский текст: [Бланк «Тест-опросник родительского отношения, ОРО»](https://psytests.org/parent/oro-bl.html) содержит все 61 утверждение и варианты «Да/Нет». Текст и ключ сверены с [PDF «Тест-опросник родительского отношения (А. Я. Варга, В. В. Столин)»](https://rstatic.oshkole.ru/org_downloads/131296/VargaStolinTest-oprosnik.pdf), страницы 1–4.
- Библиография: А. Я. Варга. «Тест-опросник родительского отношения» // *Практикум по психодиагностике. Психодиагностические материалы* / под ред. А. Я. Варги, В. В. Столина. М.: МГУ, 1988. 128 с. [Карточка издания и описание практикума](https://psytests.org/book/mgu1988.html). Полный текст издания здесь не размещён; онлайн-бланк является доступной русской копией.
- Описание методики и целевая группа: [Страница ОРО на Psytests](https://psytests.org/parent/oro.html) указывает авторов (1988), предназначение для родителей детей 3–10 лет и сообщает, что их онлайн-редакция удаляет пункты 6, 9 и 28 из соответствующих шкал. Это подтверждает, почему эта регистрация отдельно фиксирует полный 61-пунктовый вариант.
- Ключ и подсчёт: PDF-бланк, стр. 3, задаёт пять шкал и суммирование ответов «Да» (1 балл, «Нет» — 0). Для шкалы «Принятие–отвержение» направление ключевых ответов следует из описания полюсов шкалы на стр. 1: принятие соответствует ответам «Да» на пункты 20, 27, 37, 38, 43, 45, 53, 56; остальные пункты этой шкалы ключуются ответом «Нет». Остальные шкалы суммируют «Да». В исходном ключе пункты 9 и 28 намеренно входят каждый в две шкалы; они не удалялись.
- Состав: 61 пункт, дихотомические варианты «Да» и «Нет»; пять суммарных шкал: принятие–отвержение (30 пунктов), кооперация (8), симбиоз (7), авторитарная гиперсоциализация (7), «маленький неудачник» (8). Пункты 9 и 28 общие для двух шкал; шкалы не образуют непересекающиеся блоки.
- Формула: по каждой шкале складываются ключевые бинарные ответы; по шкале принятия–отвержения восемь пунктов с прямым ключом дают 1 за «Да», остальные 22 — 1 за «Нет»; по другим шкалам 1 даётся за «Да». Нормативные таблицы и интерпретационные пороги в автоматический расчёт не включены.
- Контрольный пример: все ответы «Нет» дают 21 по принятию–отвержению и 0 по остальным четырём шкалам.
- Ограничение источника: PDF доступен на сайте образовательной организации как копия материалов; первоисточник указан библиографически, но его полный скан в проверенных источниках недоступен. Основные пункты ключа совпадают с несколькими републикациями; направленность шкалы принятия проверена по описанию её полюсов в PDF. Не следует использовать этот ключ вместе с изменённым набором пунктов Psytests.
