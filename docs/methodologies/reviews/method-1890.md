Проверка 14.10.2026: подтверждена техническая ошибка. Таблица баллов первой шкалы покрывала только 21 из 30 пунктов, для остальных шкал строковые ответы yes/no не кодировались. Расчёт возвращал null. Инверсии первой шкалы были ранее выведены из смысла формулировок, а не из явного правила источника; такое основание неприемлемо.

Исправление реализует только этот однозначный алгоритм: yes = 1, no = 0, сумма по указанным пунктам. Состав шкал и тексты не менялись. Ключи совпадают с приложением [исследования из университетского репозитория КГПУ, с. 72 по печатной нумерации](https://elib.kspu.ru/get/24107).

## Граница подтверждённости

Это проверка вычисления сырой суммы конкретной опубликованной редакции, а не подтверждение её психометрической валидности. Копия содержит противоречия: порог 33 при ключе из 30 пунктов; противоположное направление первой шкалы в разных разделах. [Описание Psytests](https://psytests.org/parent/oro.html) также прямо сообщает о проблемах направления исходного ключа и об их собственной модификации, исключающей общие пункты. Она здесь не смешивается с выбранным бланком.

Поэтому интерфейс явно называет результат первой шкалы сырой суммой «Да», не присваивает направление «принятие/отвержение», уровни или процентили. Без подтверждённого первичного руководства считать эту сумму валидированным показателем принятия нельзя. Карточка фиксирует это ограничение.

Версия формулы: oro-published-30-8-7-7-8-yes-key-v2. Проверены все 61 одиночные ответы, все Да (30/8/7/7/8), все Нет (нули), общие пункты 9 и 28, недопустимые ответы, сохранение результатов и диапазонов. В рабочей базе до изменения: один опрос, ноль завершённых прохождений и результатов; пересчёт данных не нужен.
