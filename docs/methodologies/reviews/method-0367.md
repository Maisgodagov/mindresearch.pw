# Исследование свойств типа нервной системы (Вяткин, 1978)

- Решение: `blocked` — по доступным прямым источникам не удалось подтвердить полный текст пунктов и однозначный ключ/алгоритм подсчёта именно этой версии. Модуль не создавался.
- Русский источник: [«Исследование свойств типа нервной системы» — страница методики PsyTests](https://psytests.org/trait/ptsv.html) описывает спортивную модификацию Павловского опросника темперамента, три свойства и указывает ссылки на [онлайн-бланк](https://psytests.org/trait/ptsv-bl.html) и [форму прохождения](https://psytests.org/trait/ptsv-run.html); последние страницы недоступны для проверки текста в ходе этой обработки.
- Библиография: [Б. А. Вяткин, «Роль темперамента в спортивной деятельности» (М.: Физкультура и спорт, 1978)](https://psytests.org/trait/ptsv.html) — библиографическая ссылка на странице методики; каталог [Библиотеки БГПУ: запись книги Вяткина](https://bgpu.ru/irbis/cgi-bin/irbis64r_14/cgiirbis_64.exe?C21COM=S&I21DBN=BOOK&LNG=en&P21DBN=BOOK&S21CNR=20&S21FMT=fullwebr&S21LOG=1&S21P01=0&S21P02=0&S21P03=K%3D&S21REF=10&S21STN=1&S21STR=%D1%82%D0%B5%D0%BC%D0%BF%D0%B5%D1%80%D0%B0%D0%BC%D0%B5%D0%BD%D1%82&Z21ID=).
- Подтверждённый охват: три характеристики — сила процессов возбуждения, сила процессов торможения, подвижность нервных процессов; целевая группа по описанию — спортсмены.
- Пункты, шкалы и формула: не установлены для указанной версии, поскольку полный бланк и правила ключевания недоступны. Не подменял версию другой методикой наблюдения или общим тестом Стреляу.
- Путеводитель: [«Спорт и достижения: тесты и опросники»](https://psytests.org/guide/sport-ru.html) относит методику Вяткина к психофизиологическим/типологическим особенностям в спорте.
