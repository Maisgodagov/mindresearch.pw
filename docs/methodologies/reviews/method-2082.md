# Шкала временной ориентации на будущее (FTOS), русскоязычная версия

- Статус: prepared.
- Русский текст: полный бланк из восьми пунктов и инструкция приведены в статье русскоязычной адаптации; формулировки пунктов и семь вариантов ответа перенесены в регистрацию.
- Ключ: подтверждён там же явным ключом: «Воздействие» — пункты 2, 3, 6, 7, 8; «Дистанция» — 1, 4, 5r. Рассчитываются средние; пункт 5 реверсируется. При ответах 1–7 реверс: 8 − ответ.
- Количество пунктов и шкалы: 8 пунктов, 7 вариантов от «Совершенно не согласен» до «Полностью согласен»; две шкалы — «Воздействие» (5 пунктов) и «Дистанция» (3 пункта).
- Формула: для каждой шкалы вычисляется среднее закодированных ответов; для пункта 5 сначала применяется `8 − ответ`. Диапазон каждой шкалы — 1–7. В статье подтверждена двухфакторная структура русской версии. Публикационная выборка: N = 549, средний возраст 27,08 года; описание применения ограничено этой опубликованной русскоязычной адаптацией.
- `instrument.description` описывает измеряемый конструкт, аспекты шкалы и целевую группу/версию, а не инструкцию участнику.
