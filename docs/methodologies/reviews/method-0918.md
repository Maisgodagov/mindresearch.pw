# 918. Опросник для выявления ранних признаков алкоголизма

Решение worker: `blocked`.
Основание: Русский текст 35 пунктов и пороги классификации доступны в публикации Яхина и Менделевича, однако надёжный точный ключ не подтверждён: публикация описывает суммирование диагностических коэффициентов Кульбака для каждого ответа, но доступные источники не содержат таблицы этих коэффициентов. Бланк PsyTests прямо указывает, что не является оригинальным и отсылает за ключом к первоисточникам. Без коэффициентов точный подсчёт реализовать нельзя; файлы не созданы.
