# 772. Нарциссический опросник личности

Решение worker: `blocked`.
Основание: Русский NPI-40 текст доступен, но надёжный точный ключ для 40 пар ответов подтвердить не удалось: русская страница с бланком прямо отсылает за инструкцией подсчёта к первоисточнику, а первичная публикация Raskin и Terry описывает состав и подшкалы, но не предоставляет в доступном тексте ключа соответствия по всем парам. По условию не угадываю ключ; файлы не создавал.
