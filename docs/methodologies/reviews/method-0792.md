# Нормативность. Интеллект. Регуляция (НИР)

- Решение: `blocked` — полный русский текст пунктов и их последовательность нельзя считать надёжно проверенными по доступному прямому источнику; модуль не создаётся.
- Русский текст: страница [«Нормативность. Интеллект. Регуляция, НИР» на PsyTests](https://psytests.org/emvol/nir.html) сообщает назначение и ссылается на бланк, но [бланк НИР](https://psytests.org/emvol/nir-bl.html) сейчас не извлекается для проверки. Индексированный фрагмент учебника не даёт возможности вручную сверить все формулировки и их полноту.
- Источник ключа: С. В. Духновский, [«Психодиагностика: учебник и практикум для вузов», раздел о методике НИР](https://studme.org/403592/psihologiya/osoznannaya_samoregulyatsiya_lichnosti); библиографическая запись книги на PsyTests: [«Психодиагностика: учебник и практикум для вузов» (Юрайт, 2020)](https://psytests.org/book/duhn2020.html). Индексированный текст источника даёт шкалы, номера пунктов и реверсирование, однако этого недостаточно, чтобы безопасно регистрировать полный бланк.
- Подтверждённая структура ключа: 37 пунктов; шкалы Н (11 пунктов), И (10), Р (10), По («Образ себя», 6). Ответы по семибалльной шкале. Для отмеченных в ключе отрицательных номеров преобразование `S = 8 − M`, затем баллы шкалы суммируются. Н: 1, 5, 9, 13, 17, −21, −25, −28, −31, −33, −34; И: 2, 6, 10, 14, 18, −22, −26, −29, −36, 37; Р: 3, −7, −11, 15, −19, 23, 27, 30, 32, −35; По: 4, 8, 12, 16, 20, 24.
- Описание методики в [первичной странице PsyTests](https://psytests.org/emvol/nir.html): регулятивный компонент психологической надёжности сотрудника через социальную нормативность, тип интеллекта и регуляцию поведения.
