# Мотивация родительства — решение по пункту 748

- Статус: `blocked`.
- Русская версия: доступна форма для будущих биологических родителей; в бланке представлены русские формулировки мотивов и шкала оценки от 0 до 5.
- Источники формы: [Бланк «Мотивация родительства» (биологическая форма)](https://psytests.org/parent/mrodB-bl.html); [описание «Мотивация родительства»](https://psytests.org/parent/mrodB.html).
- Источник публикации: [Ю. Ф. Лахвич, Л. И. Науменко, «Мотивация родительства при усыновлении», журнал «Адукацыя i выхаванне», 2008, № 10](https://psytests.org/parent/mrodB.html) (библиографическая запись приведена в описании методики).
- Ключ и подсчёт: надёжного точного ключа для биологической формы не удалось подтвердить первоисточником. Доступная результатная страница Psytests сообщает о пяти типах мотивации и суммировании баллов (0–30 на шкалу), но не раскрывает однозначное соответствие пунктов шкалам; это недостаточно для точной реализации. [Пример страницы результатов и описание подсчёта](https://psytests.org/result?v=priK1RquLBpMXEtT).
- Масштаб формы: бланк биологической формы содержит список пунктов и пятибалльную оценку значимости от 0 до 5; число пунктов и точные ключевые принадлежности не фиксируются в регистрации без проверяемого ключа.
- Итог: регистрационный модуль не создаётся, чтобы не угадывать ключ или распределение пунктов по шкалам.
