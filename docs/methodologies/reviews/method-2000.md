# 2000. Фрайбургский опросник исследования факторов агрессии

Решение worker: `blocked`.
Основание: Не удалось надёжно установить точный ключ для выбранной русской версии. Статья Шамшиковой и Белашиной описывает 77 пунктов и шесть шкал, включая откровенность; страница русской версии сообщает, что ключ из диссертации 2020 года отличается от опубликованной адаптации по числу пунктов в шкалах. Без подтверждённого соответствия пунктов ключу нельзя реализовать точный подсчёт. Разрешённые файлы не созданы.
