# Почему ты занимаешься спортом? (форма Б)

- Решение: prepared. Русский текст бланка и полный ключ найдены.
- Русский текст: [Бланк Б «Почему ты занимаешься спортом?» в методических рекомендациях по спортивной подготовке по бобслею, приложение 8.5, с. 105–106](https://sport.gospmr.org/wp-content/uploads/2020/05/tpsp-bobsled-enp-0b4.pdf); копия отображения пунктов и шкалы: [Бланк методики на PsyTests](https://psytests.org/sport/ptzsA-bl.html).
- Ключ: [Методические рекомендации и материалы, таблица 15 «Ключ для подсчёта баллов отдельно по каждой группе мотивов», с. 103](https://sport.gospmr.org/wp-content/uploads/2020/05/tpsp-bobsled-enp-0b4.pdf). Авторы методики указаны как Е. Е. Хвацкая и Н. Е. Латышева; описание PsyTests датирует версию 1998 годом: [страница методики «Почему ты занимаешься спортом?»](https://psytests.org/sport/ptzsA.html).
- Пунктов: 25, форма Б для уже занимающихся спортом. В бланке ответы оцениваются по шкале от 1 («Не важно») до 10 («Очень важно»); у сайта-агрегатора полный текст инструкции гласит: «Пожалуйста, оцени, в какой мере приведенные ниже причины имеют значение для твоих занятий избранным видом спорта. Выбери цифру на шкале, соответствующую твоему мнению: от 1 (Не важно) до 10 (Очень важно). Постарайся оценить как можно точнее.»
- Шкалы и формула: для каждого ключевого диапазона вычисляется среднее арифметическое ответов (сумма баллов / количество пунктов): здоровье — 1–4; познавательные — 5–7; коммуникативные — 8–10; самоутверждения/результативные — 11–16; команды — 17–20; процессуальные — 21–24; родителей — 25. Обратных пунктов источник не задаёт. Для дошкольников в источнике дополнительно описано устное предъявление через три категории светофора (1–3, 4–7, 8–10); модуль реализует числовой формат формы Б.
- Проверка: контрольный пример с ответами 1–25 по номерам сверен вручную с диапазонами таблицы 15; ожидаемые средние: 2.5, 6, 9, 14, 18.5, 23, 25.
