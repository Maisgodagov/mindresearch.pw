# Методика диагностики социально-психологических установок личности — Потемкина (1993)

- Решение: `prepared`. Найдены полный русский текст 80 вопросов и однозначный ключ восьми шкал; алгоритм подтверждён методическими публикациями.
- Русская версия и бланк: [«Методика диагностики социально-психологических установок личности» — PsyTests, бланк из 80 утверждений](https://psytests.org/emvol/spul-bl.html); [страница методики, описание и библиографическая ссылка](https://psytests.org/emvol/spul.html); [страница прохождения с инструкцией «Да/Нет»](https://psytests.org/emvol/spul-run.html).
- Источник ключа: [«Методика диагностики социально-психологических установок личности в мотивационно-потребностной сфере О. Ф. Потемкиной», раздел 4.6 учебного пособия, с. 62–66](https://host.megaprolib.net/MP0109/Download/MObject/1486). Публикация содержит 80 пунктов, восемь ключей шкал и правило начисления.
- Первичная публикация: Потемкина О. Ф. «Методы диагностики социально-психологических установок личности» // *Методы психологической диагностики*. Вып. 1. Под ред. В. Н. Дружинина и Т. В. Галкиной. М.: ИП РАН, 1993. С. 35–47 (85 с. в сборнике). Библиографическое подтверждение: [статья в журнале «Вестник ЮУрГУ. Серия Психология» со ссылкой на издание](https://jpps.susu.ru/jpps/article/download/485/331/); описание и атрибуция версии: [PsyTests](https://psytests.org/emvol/spul.html).
- Количество пунктов: 80, два последовательных блока по 40. Ответы: «Да» и «Нет».
- Шкалы и ключ: в части I, шкалы процесс / результат / альтруизм / эгоизм — позиции соответственно 1,5,…,37; 2,6,…,38; 3,7,…,39; 4,8,…,40 внутри блока. В части II, шкалы труд / свобода / власть / деньги — те же позиции по модулю 4 соответственно (локальные номера 1,5,…,37; 2,6,…,38; 3,7,…,39; 4,8,…,40), с прибавлением 40 для глобальных номеров.
- Формула: ответ «Да» = 1, «Нет» = 0; итог каждой шкалы — сумма десяти ключевых ответов, диапазон 0–10. Отдельных реверсивных пунктов источник не указывает; в реализации их нет. Пункт 1 вручную проверен: «Да» даёт 1 по шкале процесса, «Нет» — 0.
- Описание для автора опроса: карточка сообщает, что методика охватывает восемь мотивационно-потребностных ориентаций и подходит для взрослых; формулировка не является инструкцией респонденту.
