# 310. Изучение мотивации учебной деятельности студентов

Решение worker: `blocked`.
Основание: Русский бланк на psytests содержит 32 утверждения с ответами «Да/Нет», но в доступных прямых источниках не нашёлся надёжный точный ключ и правила подсчёта для этой версии. Страница методики ссылается на книгу В. П. Симонова (2015), однако доступный текст книги не подтвердил ключ; приписывать алгоритм без подтверждения нельзя. Файлы не созданы.
