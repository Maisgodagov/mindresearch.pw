# Контурный апперцептивный тест CAT-H (модификация Н. Я. Семаго)

- Статус: `blocked`.
- Русский текст: русское описание и восемь сюжетных стимулов доступны на [странице методики PsyTests](https://psytests.org/classic/tatcah.html); версия описана как модификация CAT-H для детей 3–10 лет.
- Надёжный ключ: не найден. Источник предлагает ребёнку составить свободные истории по изображениям и указывает, что проведение и обработку выполняет опытный психолог со специальной подготовкой; полного ключа с однозначным соответствием пунктов шкалам и формализованным алгоритмом балльного подсчёта не приводит.
- Шкалы и подсчёт: автоматически воспроизводимые шкалы и правила подсчёта по доступному источнику не установлены.
- Итог: русский стимульный материал есть, но без надёжного однозначного ключа автоматическая реализация потребовала бы выдумать правила интерпретации. Методика не добавлена.
