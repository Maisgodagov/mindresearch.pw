# Качество межличностных отношений в образовательной среде — подростковая форма

- Решение: добавить. Доступны полный русский текст и однозначный ключ для подросткового бланка.
- Источники: [Г. С. Кожухарь, В. В. Ковров. «Экспресс-диагностика безопасности образовательной среды детей, попавших в трудную жизненную ситуацию», сборник диагностических методик, опросник для подростков и обработка, с. 71–79](https://mnu.kz/safekids-files/psy-help-ru.pdf); [страница методики КМЛО в ОС и библиография 2008 года](https://psytests.org/school/kmloA.html); [русская форма для подростка](https://psytests.org/school/kmloA-run.html); [русский бланк КМЛО в ОС](https://psytests.org/school/kmloA-bl.html).
- Пунктов: 48, восемь блоков по шесть пунктов; эта регистрация включает только форму для подростка. Ответы: от 0 «Совершенно не согласен» до 4 «Полностью согласен».
- Шкалы: доверие, агрессивность, доброжелательность, конфликтность, принятие, враждебность, толерантность, манипулятивное отношение. В каждом блоке чётные позиции оценивают отношение учащихся, нечётные — отношение взрослых; оба частных результата — суммы по трём соответствующим пунктам (0–12), общий — сумма шести пунктов (0–24).
- Формула: отмеченные звёздочкой обратные пункты перекодируются как `4 − ответ`. Индекс позитивного отношения — среднее всех преобразованных ответов по блокам 1, 3, 5 и 7; индекс негативного — среднее по блокам 2, 4, 6 и 8. Звёздочки и номера пунктов сверены по подростковому бланку; контрольный случай с ответом 2 на все пункты даёт 6/6/12 для частных/общей шкал каждого блока и 2 для обоих индексов.
