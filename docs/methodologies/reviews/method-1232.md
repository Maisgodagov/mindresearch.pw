- Первоисточник: [Гришина А. В. Тест-опросник степени увлеченности младших подростков компьютерными играми](https://msupsyj.ru/articles/article/5243/) // Вестник Московского университета. Серия 14. Психология. 2014. № 4.
- Пункты: 22. Шесть вариантов ответа: «никогда», «редко», «иногда», «часто», «очень часто», «постоянно»; кодирование соответственно 1–6.
- Шкалы (суммы): эмоциональное отношение (Иэ) — 4, 5, 13, 18, 20; самоконтроль (Ис) — 3, 8, 9, 11, 12, 15, 16, 21, 22; целевая направленность (Иц) — 1, 6, 7; родительское отношение (Ир) — 2, 17; предпочтение виртуального общения реальному (Ио) — 10, 14, 19. В источнике обратные пункты не указаны; реверсирование не применяется.
- Формула: исходная публикация задает регрессионный показатель Икз = 0,21 × Иэ + 0,43 × Ис + 0,08 × Ир + 0,34 × Ио + 0,3. Формула использует суммы шкал Иэ, Ис, Ир и Ио; Иц в формулу не входит. Реализация регистрации сохраняет доступные пять шкальных сумм без дополнительного производного расчета.
- Ограничение применения: методика предназначена для младших подростков; апробация описана на школьниках 11–12 лет, учащихся 5–6 классов Нижнего Новгорода.
