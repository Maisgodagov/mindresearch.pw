# Методика диагностики ценностных ориентаций старшеклассников

- Решение: подготовлена регистрация `test_605`.
- Русский текст: полный бланк из пяти блоков и инструкция представлены в приложении к [методическим материалам «Роль педагога в формировании личности школьника» (анкеты, страницы 11–13 PDF)](https://rd-no.dagestanschool.ru/file/download?id=176). Заголовок, авторство и ссылка на исходное издание также приведены на странице [методики PsyTests](https://psytests.org/life/dcoslk.html).
- Библиографический первоисточник: М. И. Лукьянова, Н. В. Калинина. *Психолого-педагогические показатели деятельности школы: критерии и диагностика*. М.: Сфера, 2004. Библиографическая карточка издания и описание книги: [Studmed — «Психолого-педагогические показатели деятельности школы»](https://www.studmed.ru/lukyanova-mi-kalinina-nv-psihologo-pedagogicheskie-pokazateli-deyatelnosti-shkoly-kriterii-i-diagnostika_4fe77bca0a2.html).
- Количество: 50 парных утверждений; 10 пунктов на каждую шкалу. Для каждого пункта сохранены оба русских варианта ответа. Ключ содержит прямые и обратные формулировки; реверсивных пунктов в смысле инверсии после начисления балла нет — оценивается совпадение с конкретным ключевым вариантом.
- Шкалы: познание; Я-ценность; Другой-ценность; общественно полезная деятельность; ответственность. Диапазон каждой шкалы — 0–10.
- Подсчёт: по одному баллу за ответ, совпадающий с ключом; баллы суммируются отдельно внутри каждого блока. Ключ на все пять блоков и правила суммирования приведены в [PDF с бланком и ключом (страницы 39–40)](https://xn--j1aaaehfdojs1d.xn--p1ai/ucf/6831c6c08475dae809df5122ba9b76ed.pdf). Уровни из источника: познание 8–10 / 5–7 / 0–4; Я-ценность и Другой-ценность 8–10 / 4–7 / 0–3; общественно полезная деятельность 9–10 / 4–8 / 0–3; ответственность 9–10 / 6–8 / 0–5 (высокий / средний / низкий).
- Ручная контрольная сверка: строка 1 ключа в PDF — `б, б, а, б, а`; она сопоставлена с первым вопросом каждого из пяти блоков. Также внесены проверки полного совпадения (5×10 баллов) и полного несовпадения (5×0 баллов).
