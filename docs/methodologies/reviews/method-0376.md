# 376. Каков ваш стиль в любви?

Решение worker: `blocked`.
Основание: Русский бланк содержит 50 вопросов, а страница результата сообщает о трёх шкалах со значениями от 0 до 50. Однако не найден надёжный ключ, который сопоставляет варианты ответов этих 50 вопросов шкалам Гленна Вильсона; принадлежность к стилям нельзя достоверно вывести из общей типологии Джона Ли. Модуль и review не созданы.
