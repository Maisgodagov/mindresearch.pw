# Конструктивно-деструктивная семья (КДС), Э. Г. Эйдемиллер и В. В. Юстицкис

- Статус: `prepared`.
- Русская версия: полный 20-пунктовый текст и инструкция доступны в приложении к книге; формулировки согласуются с указанным PsyTests вариантом. Ответы в источнике: согласен / не согласен / не знаю; для расчета «не знаю» кодируется нейтральным нулем.
- Ключ: в бланке сопоставлены 20 пунктов и четыре столбца ответа D/K; первичная публикация из книги указывает пороги шкал и общий показатель. D соответствует согласию с утверждением (1), K — несогласию (−1), неопределенный ответ дает 0. Реверсивных пунктов в ключе нет.

## Библиографические источники

- [Э. Г. Эйдемиллер, В. В. Юстицкис. «Психология и психотерапия семьи», приложение 3 «Опросник „Конструктивно-деструктивная семья“»](https://psy.wikireading.ru/13089) — полный текст, инструкция, бланк, правила обработки и пороги шкал.
- [Опросник «Конструктивно-деструктивная семья», КДС — PsyTests](https://psytests.org/family/kds.html) — карточка методики, авторство/год и ссылка на отдельный бланк; [онлайн-форма и инструкция КДС](https://psytests.org/family/kds-run.html).
- [«Ключ» КДС и техническое описание расчета — Компьютерная психологическая диагностика](https://cpd-program.ru/methods/kds.htm) — независимая публикация ключа с разбиением пунктов, D/K и порогом общего результата.

## Форма и расчет

20 утверждений, четыре шкалы по 5 пунктов: «Влияние» (1, 5, 9, 13, 17), «Фрустрация» (2, 6, 10, 14, 18), «Информация» (3, 7, 11, 15, 19), «Отчуждение» (4, 8, 12, 16, 20). Сумма D образует общий показатель деструктивных реакций. Для каждого пункта код: согласие = 1 (D), несогласие = −1 (K), «не знаю» = 0; балл шкалы — сумма пяти ответов, общий показатель — сумма D по всем пунктам. По опубликованным правилам пороги D: влияние ≥5, фрустрация ≥4, информация ≥5, отчуждение ≥3; общий показатель >12 означает деструктивный тип, <5 — конструктивный, от 5 до 12 включительно — неопределенный. Пороговые значения приведены для специалистской интерпретации; методика не предназначена для самостоятельной диагностики.

Проверка расчета вручную: все нулевые ответы дают 0 по четырем шкалам и общей сумме; согласие по всем пунктам дает 5 по каждой шкале и 20 по общей сумме. Описание `instrument.description` указывает измеряемые аспекты и целевую группу для автора опроса, а не инструкцию участнику.
