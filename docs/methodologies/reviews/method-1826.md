# 1826. Тест пространственного мышления

Решение worker: `blocked`.
Основание: Адекватный русский текст доступен, но полный надёжный ключ для форм А и Б не подтверждён первоисточником: страница методики прямо сообщает, что правильные ответы не раскрываются. Найденный в сторонней работе список ответов не позволяет проверить ключ по первоисточнику. Файлы не создавал.
