# Шкала физической ангедонии (СОФА; RPAS)

- Статус: подготовлена, код `test_2497`.
- Русский текст: опубликованная русскоязычная адаптация Н. Б. Лутовой и соавторов содержит полный текст всех 61 утверждения и варианты «Верно» / «Неверно» в Приложении 1 (с. 157–159).
- Надёжный ключ: в публикации адаптации однозначно указаны бинарная оценка, полный перечень инвертируемых пунктов и суммирование с учётом инверсии.
- Пункты и шкалы: 61 утверждение, одна суммарная шкала физической ангедонии; диапазон 0–61. Охватываются тактильные, вкусовые, обонятельные и иные телесные ощущения, физическая активность и связанные с ними повседневные переживания.
- Формула: ответ «Верно» = 1, «Неверно» = 0; пункты 1, 2, 3, 5, 7, 8, 10, 11, 13, 14, 17, 22, 25, 27, 31, 36, 38, 39, 40, 41, 42, 44, 45, 46, 52, 53, 55, 56, 57, 60, 61 инвертируются (0↔1). Итог — сумма 61 закодированного ответа; большее значение указывает на более выраженную физическую ангедонию.
- Ручная проверка: ответы опубликованного примера пациентки пересчитаны с инверсией, итог 16; контрольный случай всех ответов «Неверно» равен 31.
- Ограничение: опубликованный ROC-порог 18,5 балла получен для различения пациентов с расстройствами шизофренического спектра и здоровых респондентов в конкретной выборке; в регистрации он не используется как универсальный диагностический порог.
