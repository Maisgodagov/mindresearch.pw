# №836 — Опросник P-A-C (Роз Тейлор)

- Статус: blocked.
- Русский текст: доступен полный бланк на [странице «Бланк: Опросник P-A-C по Эрику Берну»](https://psytests.org/ta/pacq-bl.html): 60 утверждений, ответы «Да»/«Нет»; инструкция и перевод И. Александровой (2005) указаны на [странице методики](https://psytests.org/ta/pacq.html).
- Ключ: для русской 60-пунктной формы не найден надёжный полный ключ с распределением каждого пункта по шкалам и правилами начисления. Страница результата демонстрирует P (PZ+PT), A и C (CA+CE), но не раскрывает соответствие пунктов.
- Найденный [англоязычный Transactional Analysis Questionnaire, бланк и руководство по подсчёту (Bradford VTS, PDF, стр. 1–7)](https://www.bradfordvts.co.uk/wp-content/onlineresources/teaching-learning/learning-personality-styles/transactional-analysis/transactional%20analysis%20questionnaire.pdf) содержит 61 пункт и собственный перечень ключей. Его формулировки и состав не совпадают с русским бланком (например, английский пункт 61 отсутствует в русском, а ряд утверждений отличается), поэтому переносить этот ключ на русскую форму нельзя.
- Связанные источники: [страница «Транзактный анализ: тесты и опросники»](https://psytests.org/guide/framework-ta-ru.html) описывает назначение P-A-C как самооценку ведущего эго-состояния; библиография страницы методики указывает Роз Тейлор, «Уверенность в моих руках: 7-дневная программа по привлечению друзей и обретению веры в себя» (М.: Рипол, 2005). Надёжная опубликованная раскладка ключа для конкретной русской формы не обнаружена.
- Шкалы и формула: концептуально Родитель (Заботливый + Требовательный), Взрослый, Ребёнок (Адаптирующийся + Естественный); автоматический подсчёт и обратные пункты не реализованы из-за отсутствия подтверждённого соответствия пунктов и правил ключевания.
- Решение: модуль не создан. Русский текст есть, но точный ключ для этой версии не подтверждён; несовпадающий англоязычный вариант не является достаточным основанием для догадки.
