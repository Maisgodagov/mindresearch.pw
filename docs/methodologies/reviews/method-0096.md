# 96. Бланковый тест Ответственность

Решение worker: `blocked`.
Основание: Русская страница методики подтверждает назначение, автора и доступность бланка, но сам бланк и страница прохождения не открылись через прямой источник; поэтому полный текст пунктов и точный ключ/подсчёт проверить не удалось. Не угадывал и файлы не создавал.
