# Стратегии конструирования старения

- Решение: prepared. Русский бланк и точный ключ опубликованы авторами методики.
- Русская версия и ключ: [Стрижицкая О. Ю., Петраш М. Д. Разработка методики «Стратегии конструирования старения» — статья и приложение с бланком и ключом, *Вестник СПбГУ. Психология*, 2024, 14(1), с. 158–173](https://psyjournals.ru/journals/vspu_psychology/archive/2024_n1/vspu_psychology_2024_n1_Strizhitskaya_Petrash.pdf); карточка статьи и версия для чтения: [PsyJournals.ru — публикация](https://psyjournals.ru/journals/vspu_psychology/archive/2024_n1/Strizhitskaya_Petrash).
- Навигационная страница версии: [«Стратегии конструирования старения» — страница методики Psytests](https://psytests.org/life/skstar.html).
- Пункты: 19 (финальная версия приложения; первоначальный список из 22 был сокращен после психометрической проверки). Формат ответа — пять градаций от «Не делал(а) этого» (1) до «Делал(а) это регулярно» (5); средние градации 2, 3, 4.
- Шкалы: сохранение здоровья — пункты 1, 3–8, 19; метакогнитивные — 13–16; саморазвитие — 2, 9–12; генеративные — 17–18. Все пункты прямые, обратных нет.
- Формула: сумма пунктов каждой шкалы; общий показатель — сумма всех 19 ответов. Для сверки валидации использован профиль из 1 по всем пунктам: шкалы дают 8, 4, 5 и 2, общий показатель 19.
- Область применения: разработка опубликована по данным взрослых 40–75 лет; допускается оценка актуального или выбранного ретроспективного периода. Нормативные интерпретации не добавлялись.
