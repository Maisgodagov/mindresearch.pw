# Профессиональная деформация личности педагога (Зеер, Павлова, Зольников, 2002)

- **Решение:** prepared. Есть русская 42-пунктовая форма и опубликованный ключ для всех пунктов.
- **Русский текст:** [Бланк «Профессиональная деформация личности педагога»](https://psytests.org/pedag/pdeflp-bl.html) содержит 42 утверждения и четыре категории ответа; формулировки включены в модуль. Сайт указывает, что его отображаемый бланк не является оригинальным бланком для печати.
- **Источник методики и ключа:** Э. Ф. Зеер, А. М. Павлова, А. П. Зольников. *Практикум по психологии профессий: учебное пособие*. Екатеринбург: РГППУ, 2002, 174 с., в частности с. 170. [Полный текст пособия в электронном архиве РГППУ](https://elar.rsvpu.ru/bitstream/123456789/23548/1/5-8050-0067-9_2002.pdf). Библиографическое описание и указание авторов/года также приведены в [описании методики Psytests](https://psytests.org/pedag/pdeflp.html).
- **Сверочный источник ключа:** [«Профессиональная деформация личности педагога — обработка и онлайн-расчёт» (StatBlank)](https://statblank.com/metodiki/professionalnaya-deformaciya-lichnosti-pedagoga) приводит распределение пунктов по шкалам, баллы ответов и отсутствие обратных пунктов со ссылкой на издание Зеера, Павловой и Зольникова (2002). Это вторичный источник, использован для доступной сверки ключа; первичное основание ключа — указанное пособие.
- **Пункты и ответы:** 42 утверждения; «Нет, это неверно» = 0, «Пожалуй, это верно» = 1, «Скорей всего, верно» = 2, «Совершенно верно» = 3.
- **Шкалы и подсчёт:** суммировать ответы по номерам пунктов, обратных пунктов нет. Педагогическая агрессия — 1, 12, 23, 28, 34, 41; авторитарность — 2, 11, 36; демонстративность — 3, 13, 15, 21, 27, 38; дидактичность — 4, 22, 35; профессиональный догматизм — 5, 30, 40; доминантность — 6, 14, 18, 33; профессиональная индифферентность — 7, 16, 26; консерватизм — 19, 24, 39; ролевой экспансионизм — 8, 20, 31, 37; социальное лицемерие — 9, 17, 25, 32; поведенческий трансфер — 10, 29, 42. Формула каждой шкалы: сумма оценок её пунктов (диапазон отдельного ответа 0–3); нормативные уровни в модуле не вычисляются.
- **Проверка:** вручную проверен случай нулевого ответа по всем пунктам; суммы равны нулю по каждой шкале. Дополнительно включён предельный случай с ответом 3 по всем пунктам.
