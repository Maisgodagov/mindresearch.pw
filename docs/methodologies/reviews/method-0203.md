# 203. Диагностика готовности семьи быть субъектом

Решение worker: `blocked`.
Основание: Адекватный русский текст доступен: бланк Psytests содержит 30 утверждений и ответы «Да»/«Нет». Надёжный точный ключ и правила подсчёта в доступных материалах отсутствуют; страница бланка прямо указывает, что инструкции по подсчёту нужно брать из первоисточников. Ссылка на публикацию в eLibrary не открылась, поэтому ключ нельзя проверить без догадок. Разрешённые файлы не создавал.
