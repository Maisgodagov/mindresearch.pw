# Диагностика реальной структуры ценностных ориентаций личности (ЦОЛ), С. С. Бубнова

- Статус: `blocked` — конкретная отечественная методика идентифицирована, однако доступный первичный источник 1994 года не содержит открытых условий цифрового воспроизведения; полную форму и ключ необходимо сверить непосредственно с изданием ИП РАН.

По записи библиотеки Института психологии РАН первичная публикация — С. С. Бубнова, «Методика диагностики индивидуальной структуры ценностных ориентаций личности», сборник *Методы психологической диагностики*, вып. 2, 1994, с. 144–157. В доступных институциональных и научно-методических материалах описан 66-пунктовый опросник с ответами «да/нет», оценивающий 11 полиструктурных ценностных ориентаций и степень их реализации в повседневной жизни. Российские публикации применяют методику, но это не заменяет проверки психометрических свойств полного исходного протокола.

Полное руководство/ключ и условия использования в платформе не обнаружены в открытом первичном источнике. Копии бланка и ключа на сторонних ресурсах не дают права на републикацию. Не переносить 66 пунктов из вторичных копий до сверки по источнику ИП РАН и получения разрешения на цифровое воспроизведение.
