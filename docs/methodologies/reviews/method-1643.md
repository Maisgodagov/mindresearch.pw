# Степень выраженности прокрастинации (СВП), Киселева, 2015

- Решение: prepared. Полный русский текст, варианты ответов и однозначный ключ опубликованы в статье автора; ключ достаточно точен для реализации.
- Русская версия/бланк: [Степень выраженности прокрастинации, СВП — страница методики и бланк](https://psytests.org/emvol/pcsvr.html) (М. А. Киселева, 2015).
- Источник текста и ключа: [М. А. Киселева. «Теоретическое обоснование опросника “Степень выраженности прокрастинации” (СВП)»](https://sociosphera.com/files/conference/2015/k-03_13_15.pdf), сборник конференций НИЦ «Социосфера», Пенза, 2015, № 10, с. 23–27; опросник, ключ и пороги приведены на с. 26–27 PDF (печатные с. 26–27).
- Пунктов: 15. Ответы: «Неверно» = 0, «Иногда верно» = 1, «Верно» = 2. Обратных пунктов в ключе нет.
- Шкалы: общая прокрастинация (все 15 пунктов; 0–30); мотивационная недостаточность (1, 4, 7, 10, 13; 0–10); перфекционизм (2, 5, 8, 11, 14; 0–10); тревожность (3, 6, 9, 12, 15; 0–10).
- Формула: для каждой шкалы суммировать баллы её пунктов. Опубликованные уровни: общая — низкий 0–5, средний 6–14, высокий 15–30; каждая субшкала — низкий 0–3, средний 4–6, высокий 7–10. Реализация возвращает баллы, не подменяя их нормативными выводами.
- Ручная проверка: все ответы «Неверно» дают 0 по каждой шкале; все ответы «Верно» дают 30 по общей шкале и 10 по каждой субшкале.
