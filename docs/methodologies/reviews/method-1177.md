# 1177. Опросник рисков коммуникации с чат-ботом

Решение worker: `blocked`.
Основание: Страница методики содержит русскую версию и описывает четыре шкалы, но полный текст пунктов и точный ключ подсчёта в доступных источниках не найдены: страница бланка не открывается, а тест требует JavaScript. По workflow нельзя восстанавливать пункты или угадывать ключ; разрешённые файлы не созданы.
