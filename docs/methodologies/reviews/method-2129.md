# 2129. Шкала Дэвидсона для самооценки ПТСР

Решение worker: `ru-ineligible`.
Основание: Надёжный подсчёт DTS подтверждается публикацией Дэвидсона, но доступный русский источник не раскрывает текста пунктов и указывает, что переводчик не установлен и сведений об адаптации нет. Страница русского бланка недоступна для проверки, поэтому русский текст нельзя надёжно включить без угадывания. Файлы не созданы.
