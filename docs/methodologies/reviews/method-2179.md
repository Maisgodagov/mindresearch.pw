# 2179. Шкала личностной тревожности учащихся

Решение worker: `blocked`.
Основание: Русский текст существует: шкала А. М. Прихожан имеет формы А и Б по 40 ситуаций для школьников 10–12 и 13–16 лет, с ответами по шкале 0–4. Но доступные материалы не дают полного ключа: найденное описание указывает формат ответов, но не подтверждает однозначное соответствие пунктов шкалам и правила суммирования. По Workflow нельзя восстанавливать ключ догадкой, поэтому файлы не созданы.
