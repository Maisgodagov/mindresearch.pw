# Комплект тестов для диагностики педагогических способностей — решение по пункту 425

- **Статус:** blocked.
- **Русский текст:** доступен для отдельных методик комплекта на сайте PsyTests, в том числе для тестов альтруизма, доминантности, ведущей мотивации и рефлексивных/проективных педагогических умений. Однако это не единый опросник: оглавление пособия перечисляет многочисленные самостоятельные методики, а онлайн-версии прямо не гарантированы как соответствующие печатному изданию.
- **Надёжный ключ:** для регистрации всего комплекта не подтверждён. Печатное пособие недоступно для чтения и скачивания; объединённого ключа, единого подсчёта и полного проверяемого бланка всех частей в источниках нет. Подмена батареи одной выбранной методикой или сборка разных веб-версий потребовала бы догадки.
- **Объём и шкалы:** источник перечисляет ориентировочную батарею из разделов для первичных компонентов способностей (10 методик), педагогического потенциала (6) и педагогического мастерства (7), всего 23 позиции оглавления. Единой системы шкал и формулы для этих разных методик нет; подсчёт задаётся отдельно для каждой методики.
- **Итог:** условия для создания единой регистрации не соблюдены. Файл методики не создан.

## Библиографические источники

- [Н. А. Аминов, Н. А. Морозова, А. Л. Смятских. «Психодиагностика педагогических способностей: претесты» (М.: ИЦ проблем качества подготовки специалистов, 1994) — библиографическая страница и оглавление](https://psytests.org/book/amin1994.html). Страница сообщает, что полный текст книги на сайте недоступен, а размещённые онлайн-версии могут отличаться от печатного варианта.
- [«Педагогические претесты» — страница серии и вводное описание комплекта](https://psytests.org/pedag/amin.html). Описывает назначение набора для диагностики профессиональной пригодности кандидатов на учительскую профессию и ссылается на издание 1994 года.
- [«Педагогика: тесты и опросники» — тематический путеводитель по русскоязычным методикам](https://psytests.org/guide/learning-pedagogic-ru.html). Навигационный источник, подтверждающий описание комплекта; не является источником ключа.
