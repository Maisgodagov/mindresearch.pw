# SCL-K-9 — русскоязычная адаптация Золотаревой

- Решение: подготовлена регистрация; русский текст и ключ подтверждены публикацией адаптации.
- Источники: [Золотарева А. А. Русскоязычная адаптация симптоматического опросника SCL-K-9, приложение и ключ](https://publications.hse.ru/pubs/share/direct/861000874.pdf); [страница методики psytests.org](https://psytests.org/diag/sclk9.html).
- Количество пунктов: 9.
- Шкалы: одна общая шкала психопатологии (GSI), диапазон 0–36.
- Ответы: «Совсем нет» = 0, «Немного» = 1, «Умеренно» = 2, «Сильно» = 3, «Очень сильно» = 4.
- Формула: сложить коды ответов по всем 9 пунктам; обратных пунктов нет. Чем выше сумма, тем сильнее общая психопатология.
- Инструкция использует период прошедшей недели согласно приложению адаптации. На странице теста psytests.org указан прошедший месяц; зафиксирована версия публикации адаптации, её тексты пунктов и ключ.
