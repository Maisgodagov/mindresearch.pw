# Опросник озабоченности глобальными экологическими проблемами (ЭкО-30)

- Решение: prepared. Найдены пригодный русский текст 30 пунктов, варианты ответов и однозначный ключ для четырёх шкал.
- Русская форма и ключ: [Опросник экологических установок «ЭкО 30» (Кряж И. В.), приложение Д, с. 69–72](https://ekmair.ukma.edu.ua/server/api/core/bitstreams/256e8306-1f43-4027-a2e7-5fa6129ccf96/content). Дополнительная страница версии и библиография: [Опросник озабоченности глобальными экологическими проблемами (ЭкО-30), Psytests](https://psytests.org/eco/eco30.html).
- Первичный источник: [Кряж И. В. Психология смысловой регуляции экологически релевантного поведения: автореферат диссертации, 2013](https://ekhnuir.karazin.ua/server/api/core/bitstreams/f285c7ea-8195-4181-a7cc-23733215fddf/content). См. также авторскую монографию [Психология глобальных экологических изменений](https://ekhnuir.karazin.ua/), Харьковский национальный университет, 2012.
- Пунктов: 30. Ответы кодируются от −2 до 2: «Категорически не соглашусь», «Пожалуй, не соглашусь», «Затрудняюсь ответить», «Пожалуй, соглашусь», «Соглашусь однозначно».
- Шкалы и формула: сумма баллов по ключевым пунктам; обратные пункты инвертируются по правилу (x'=-x). Отрицание экологических проблем: −1, 3, 10, 13, 18, 21, 26; экологическая интернальность: 2, 6, 9, 12, 16, 22, 25, 28; биоцентризм: 4, −7, 11, 14, −20, −24, 27, −30; «Деньги» (финансово-экономические приоритеты): 5, 8, 15, 17, 19, 23, 29.
- Ограничение формулы: источники называют интегральную озабоченность общим показателем, но доступная публикация бланка не задаёт отдельного ключа или формулы его расчёта. Реализованы лишь четыре шкалы с явным ключом; непредусмотренный общий показатель не рассчитывается.
- `instrument.description` описывает экологические установки, аспекты шкал и русскую версию для исследовательских опросов; это описание для автора опроса, не инструкция респонденту.
