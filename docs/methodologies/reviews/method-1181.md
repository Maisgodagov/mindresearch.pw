# 1181. Опросник родительского стиля Янга

Решение worker: `blocked`.
Основание: Надёжный ключ подсчёта для исходных 17 шкал YPI не подтверждён прямым доступным источником. Русский бланк содержит 72 пункта, но прямо предупреждает, что его нумерация ответов не является ключом; авторская страница показывает только выборочные пункты и не публикует полный ключ. Поэтому модуль и review не создавал, чтобы не угадывать соответствие шкал и реверсивные пункты.
