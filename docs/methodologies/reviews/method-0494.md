# 494. Лого-Тест

Решение worker: `blocked`.
Основание: Русский бланк доступен, но он не подтверждает полный набор или подсчёт версии из очереди. Страница методики уточняет, что это сокращённый Logo-Test-R, а первичная статья описывает 14 пунктов, пятибалльные ответы и обратное направление подсчёта, но доступные источники не дают надёжного однозначного ключа для автоматического подсчёта этой русской формы. По workflow нельзя восстанавливать ключ догадками; файлы не созданы.
