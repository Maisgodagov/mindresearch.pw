# 1590. Ситуация буллинга в школе

Решение worker: `blocked`.
Основание: Русский бланк доступен, однако надёжного однозначного ключа и правил подсчёта нет: описание методики указывает, что оригинальный количественный анализ не предусмотрен, а онлайн-шкалы — лишь индикаторы. По workflow не угадываю подсчёт и не создаю модуль без ключа.
