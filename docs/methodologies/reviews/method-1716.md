# 1716. Тест Бартла на игровой психотип

Решение worker: `blocked`.
Основание: Русский текст доступен, но надёжный точный ключ для этой версии подтвердить не удалось. Русский бланк содержит 39 пунктов, тогда как первоисточники описывают исходный тест как набор из 30 случайно выбранных вопросов; страница автора теста требует равного числа вопросов для каждой пары категорий и суммирования ответов. Доступный русский бланк не задаёт соответствие вариантов категориям и не объясняет подсчёт. Переносить к нему ключ другой версии без сверки нельзя. Файлы не созданы.
