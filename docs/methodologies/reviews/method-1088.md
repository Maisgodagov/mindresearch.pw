# 1088. Опросник оценки прокрастинации

Решение worker: `blocked`.
Основание: Русский текст всех 40 пунктов и варианты «Да / Нет / ?» доступны в бланке, а публикация В. Е. Петрова подтверждает шкалы «Прокрастинация» и «Достоверность» и правила проверки пропусков/двойных ответов. Однако в доступной публикации диагностический ключ приведён только как ссылка на отсутствующую таблицу: не указаны принадлежность пунктов к шкалам и точные ключевые ответы. Восстановить ключ без догадок нельзя, поэтому файлы не создавались.
