# 1900. Тесты лидерства Питера Нортхауза

Решение worker: `blocked`.
Основание: На странице серии Нортхауза нет единого опросника. Для доступной русской формы «Опросник для определения лидерских качеств» указаны 14 пунктов, но её задание и формат отличаются от 18-пунктового Leadership Styles Questionnaire. Для 18-пунктовой формы найден точный ключ в материалах SAGE, однако русские формулировки и варианты ответов этой версии не обнаружены. Объединять формы или переводить недостающий текст нельзя; поэтому файлы не созданы.
