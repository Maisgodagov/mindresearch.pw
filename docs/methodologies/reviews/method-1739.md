# 1739. Тест интеллекта IQtest.dk

Решение worker: `blocked`.
Основание: Доступный русский бланк IQtest.dk содержит 39 заданий, но надежного точного ключа и подтвержденного алгоритма подсчёта в прямых источниках не найдено. Найденные полные ответы опубликованы сторонними авторами без подтверждения первоисточником; исходный Flash-файл недоступен, а русская страница сообщает лишь, что неправильные ответы не снижают результат. Чтобы не угадывать ключ, файлы не созданы.
