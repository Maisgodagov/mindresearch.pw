# PHQ-9, русскоязычная версия А. А. Золотарёвой

- Решение: подготовить регистрацию. Найдены пригодный русский текст всех пунктов и точные правила подсчёта в научной публикации.
- Русский текст и ключ: [«Диагностика депрессии: психометрическая оценка русскоязычной версии опросника здоровья пациента (PHQ-9)», приложение с русской версией и обработкой результатов](https://psyjournals.ru/journals/cpse/archive/2023_n4/Zolotareva). Статья описывает перевод с прямым и обратным переводом, экспертную проверку, а также девять пунктов приложения.
- Первоначальный инструмент: [Kroenke, Spitzer & Williams, “The PHQ-9: Validity of a Brief Depression Severity Measure” (2001)](https://doi.org/10.1046/j.1525-1497.2001.016009606.x).
- Дополнительная русская страница и варианты бланков: [«Опросник депрессивного состояния, PHQ-9» — PsyTests](https://psytests.org/depr/phq9z.html). Страница различает русскую адаптацию Золотарёвой и вариант Погосовой и ссылается на бланки; регистрация использует текст Золотарёвой из публикации, не смешивая версии.
- Пункты: 9; период оценки: прошедшие две недели. Одна шкала — общая выраженность депрессивных симптомов. Ответы для каждого пункта: 0 «Совсем нет», 1 «В течение нескольких дней», 2 «Более чем половину этого времени», 3 «Почти каждый день».
- Подсчёт: сложить баллы девяти пунктов без реверсивных пунктов; диапазон 0–27. Источник указывает, что показатель ≥10 указывает на вероятный диагноз большого депрессивного расстройства; это скрининговый показатель, не самостоятельное установление диагноза.
- Ручная проверка: ответы 0, 1, 2, 3, 0, 1, 2, 3, 1 дают 13; все нулевые ответы дают 0.
- `instrument.description` сообщает автору опроса, какие симптомы и за какой период охватывает инструмент, для какой группы предназначен скрининг и как использовать балл; это не инструкция участнику.
