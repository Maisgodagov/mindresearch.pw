# PDSQ — решение по пункту 1475

- Решение: `blocked`.
- Русский текст: русская версия PDSQ и бланк доступны на странице [Психиатрический диагностический скрининговый опросник, PDSQ — Psytests](https://psytests.org/diag/pdsq.html) (адаптация А. А. Марченко; страница предоставляет ссылку на бланк).
- Надёжный ключ: не подтверждён для доступной русской адаптации. Страница методики прямо указывает, что ключ в публикации приведён в виде формул Excel без структуры листа и неприменим; онлайн-версия использует оригинальный ключ, не устанавливая его тождественность русской адаптации. Поэтому автоматизируемое соответствие пунктов шкалам и подсчёт этой версии нельзя надёжно восстановить.
- Первоисточник: [Zimmerman & Mattia, “The Psychiatric Diagnostic Screening Questionnaire: Development, Reliability and Validity”](https://doi.org/10.1053/comp.2001.23126), *Comprehensive Psychiatry*, 42(3), 2001. Описывает оригинальный PDSQ и его диагностические подшкалы.
- Русский учебный источник: [Баурова, Марченко, Дьяконов и др., «Основные методы психологической диагностики в клинико-экспериментальных исследованиях» — карточка издания и оглавление](https://psytests.org/book/diak2021.html), СПб.: СпецЛит, 2021. Полный текст недоступен на странице; доступный сайт отдельно предупреждает о неприменимости опубликованного ключа.
- Оригинальная структура: 13 субшкал; в источниках указаны 125 дихотомических пунктов (в английской форме также приводится 6-пунктовый экран психоза). Ответы оригинала «да/нет», положительный ответ обычно кодируется 1, отрицательный 0; шкальные баллы — сумма ключевых ответов. Это не даёт надёжного точного ключа для русской адаптации.
- Итог: модуль не создан, поскольку русский текст имеется, но критерий надёжного точного ключа/подсчёта для него не соблюдён. Не переносить оригинальный ключ на адаптацию без подтверждения источником.
