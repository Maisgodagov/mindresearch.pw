# Тест диагностики удовлетворенности жизнью (ТДУЖ), версия 2010

- Решение: подготовлено; русский текст и ключ полностью доступны в публикации автора.
- Русская версия и бланк: [Тест диагностики удовлетворенности жизнью — PsyTests, страница методики и бланка](https://psytests.org/life/tduz.html).
- Первоисточник текста и ключа: [А. Б. Белоусова. «Тест диагностики удовлетворенности жизнью», Альманах современной науки и образования, 2010, № 3 (34), ч. I, с. 131–138, PDF](https://www.gramota.net/article/alm20100536/pdf). Полный бланк, ключ перекодирования и состав шкал находятся на с. 136–138. Публикационная запись: [страница статьи издательства «Грамота»](https://www.gramota.net/materials/1/2010/3-1/37.html).
- Контекст домена: [«Удовлетворённость жизнью: тесты и опросники» — путеводитель PsyTests](https://psytests.org/guide/meaning-satisfaction-ru.html), раздел «Удовлетворённость жизнью».
- Пункты: 44, каждый представлен парой противоположных утверждений; каждый из двух текстов сохранен в одной формулировке пункта с разделителем.
- Ответы: выбрать степень согласия с выбранным полюсом: полностью согласен (3), согласен, но не полностью (2), согласен в малой степени (1), не знаю, какое утверждение выбрать — левое или правое (0).
- Шкалы: 11 сфер по 4 пункта; четыре общие тенденции по 10 пунктов; общая удовлетворенность — сумма четырех тенденций. Все шкальные баллы являются суммами перекодированных пунктов; диапазоны соответственно 4–28, 10–70 и 40–280.
- Формула ключа: для восходящих (прямых) пунктов 2, 3, 5, 8, 11, 12, 13, 14, 17, 19, 22, 23, 25, 28, 31, 32, 33, 34, 37, 39, 42, 43 ответам 3/2/1/0/1/2/3 по расположению выбранного полюса соответствует 1/2/3/4/5/6/7 баллов. Для нисходящих (обратных) пунктов 1, 4, 6, 7, 9, 10, 15, 16, 18, 20, 21, 24, 26, 27, 29, 30, 35, 36, 38, 40, 41, 44 балл — 7 минус значение прямого пункта. Примеры перечисления и формула напрямую сверены по таблице обработки в статье. Шкальные суммы 1–11: последовательные блоки пунктов 1–4, 5–8, …, 41–44; шкалы 12–15: наборы пунктов указаны в статье; шкала 16 — сумма шкал 12–15.
- Ручной контрольный случай: для каждого пункта выбрано значение ответа, соответствующее полюсу максимального проявления тенденции; после обратного перекодирования каждый пункт дает 7. Ожидаемые суммы: 28 для каждой 4-пунктовой сферы, 70 для каждой 10-пунктовой тенденции, 280 для общей шкалы.
- Область применения: автор описывает тест как диагностику удовлетворенности жизнью студентов; не переносить эту версию на другие группы без отдельного обоснования. В статье отмечена необходимость дальнейшей доработки разработанного варианта.
