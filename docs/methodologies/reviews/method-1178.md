# Опросник родительского выгорания — И. Н. Ефимова (2013)

Проверка 14.10.2026: числовая формула верна; ошибочным оказался контрольный пример «все ответы 0 → истощение 0». Исправлен пример, формула и её версия сохранены.

Источник: [авторская статья «Возможности исследования родительского выгорания», Вестник МГОУ, № 4, 2013, с. 31–40, приложение с. 37–38 (копия)](https://www.scribd.com/document/1025922763/918-987-1-PB). Библиография сверена с [авторским списком публикаций](https://efimova.su/publikacii).

22 утверждения, варианты частоты 0–6. Истощение: 1, 2, 3, 6, 8, 13, 14, 16, 20, пункт 6 считается как 6 − ответ (диапазон 0–54). Деперсонализация: 5, 10, 11, 15, 22 (0–30). Редукция достижений: прямая сумма 4, 7, 9, 12, 17, 18, 19, 21 (0–48). У редукции меньший сырой балл соответствует большему выгоранию; этот факт явно указан в карточке. Общая сумма трёх шкал не рассчитывается.

Контрольные профили: все 0 → 6/0/0; все 6 → 48/30/48; все 3 → 27/15/24. Профили с исключением для пункта 6 достигают 0 и 54 по истощению. Проверены все семь значений ответа, каждый из 22 пунктов отдельно и сохранение результата из JSON-ответов.
