# 344. Индекс финансовых отношений

Решение worker: `blocked`.
Основание: Надёжный ключ подсчёта подтвердить не удалось. В издательском фрагменте Financial Relationship Index есть инструкция складывать ответы и пороговые диапазоны, но на страницах 22–23 отсутствует сама таблица ключа; кроме того, фрагмент содержит 19 пунктов, а другой источник описывает 20-вопросную версию. Русская страница Psytests подтверждает перевод, но не раскрывает алгоритм, а её бланк недоступен для сверки. Чтобы не угадывать ключ, файлы не создавал.
