# Методика диагностики сиблингового общения (модификация М. В. Кравцовой)

- Решение: пригодна для регистрации. Доступен связный русский бланк с 48 пунктами, вариантами ответов и однозначным ключом.
- Русская версия и ключ: [«Методика диагностики сиблингового общения» (модификация М. В. Кравцовой), приложение 2 методических материалов о сиблингах, с. 13–21](https://resursconsult.ru/uploads/file/Siblingi_Metodichka_po_dop._blokam_.pdf). Полный текст и ключ приведены в приложении; исходный текст ответов сохранён в регистрации, словесные ярлыки вариантов упорядочивают четыре позиции бланка.
- Публикация автора: [М. В. Кравцова, «Изучение сиблинговых взаимоотношений», в сборнике «Практикум по психологической диагностике семейных отношений», Минск: БГПУ, 2003, с. 167–174](https://psytests.org/family/mdsob.html) (библиографическая ссылка и авторство указаны на [странице методики PsyTests](https://psytests.org/family/mdsob.html)).
- Навигационная ссылка: [«Родительство и семья: тесты и опросники», раздел «Отношения между сиблингами»](https://psytests.org/guide/parenting-ru.html).
- Количество пунктов: 48; ответы — четыре упорядоченных варианта.
- Шкалы: доверительность общения (две субшкалы: самооценка и оценка сиблинга), взаимопонимание (две субшкалы: самооценка и оценка сиблинга), сходство взглядов, общие символы семьи, лёгкость общения, психотерапевтичность общения. У каждой субшкалы/шкалы шесть пунктов.
- Ключ: публикация задаёт пары «плюс/минус» для каждого номера шкалы. Для «+» ответам с 1-го по 4-й присваиваются 4, 3, 2, 1 балл; для «−» порядок обратный (1, 2, 3, 4). Обратные номера реализованы в scoringConfig.
- Формула: отдельно для каждой из восьми шкал вычисляется среднее арифметическое шести уже перекодированных ответов; диапазон индекса — 1–4, большее значение соответствует большей выраженности характеристики.
- Ручной контроль: для каждого прямого пункта выбран первый вариант (4 балла), а для каждого обратного — четвёртый (после реверса 4 балла); ожидаемое среднее каждой из восьми шкал равно 4.
- Описание карточки объясняет измеряемые аспекты, пригодность для оценки отношений с братом/сестрой и субъективный характер результата; это не инструкция участнику.
