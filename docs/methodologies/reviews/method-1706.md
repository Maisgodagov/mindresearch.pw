# 1706. Терапевтический опросник структуры личности Р-Д-В

Решение worker: `blocked`.
Основание: Русский текст формы А из 90 пунктов и ключ с формулой подсчёта обнаружены. Однако надёжная сверка точного текста формы и полного ключа по первичной публикации не завершена: страница Psytests с бланком и прохождением возвращает ошибку чтения, а доступный полный ключ размещён на стороннем ресурсе. Чтобы не угадывать и не регистрировать неподтверждённую версию, оба файла не созданы.
