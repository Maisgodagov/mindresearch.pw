# 1285. Опросник учебной активности студента

Решение worker: `blocked`.
Основание: Надёжный ключ найден для 24-пунктовой модифицированной самооценки учебной активности студентов, но он не совпадает с заявленной методикой Волочкова 2007 года: публикация описывает ВУАСТ версии 8 на 70 пунктов, семь первичных и четыре агрегированные шкалы. Русская страница и бланк исходной методики недоступны для сверки. Не стал переносить ключ модифицированной формы на другую версию или угадывать её содержание; файлы не созданы.
