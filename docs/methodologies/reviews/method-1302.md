# Опросник Шмишека — адаптация СПб НИИ ЛОР (Калягин, Карпов), 2004

- Решение: `prepared`; версия соответствует русскому бланку адаптации Калягина и Карпова.
- Русский текст: все 88 пунктов, ответы «Да» / «Нет» взяты из [«Опросник Шмишека», взрослый вариант на ПсиЛаб](https://psylab.org.ua/tools_%D0%9E%D0%BF%D1%80%D0%BE%D1%81%D0%BD%D0%B8%D0%BA_%D0%A8%D0%BC%D0%B8%D1%88%D0%B5%D0%BA%D0%B0) и сверены с [учебным пособием «Психологическая диагностика детей и подростков с нарушениями развития»](https://host.megaprolib.net/MP0109/Download/MObject/3154), стр. 59–61.
- Источник методики: H. Schmieschek, [“Fragebogen zur Ermittlung akzentuierter Persönlichkeiten”](https://pubmed.ncbi.nlm.nih.gov/5503319/), *Psychiatrie, Neurologie und medizinische Psychologie*, 1970, 22(10), 378–381. Русская адаптация указана в [странице методики СПб НИИ ЛОР](https://psytests.org/accent/shmi88.html): В. А. Калягин, Б. А. Карпов (2004).
- Ключ: [раздел «Ключ» методики на ПсиЛаб](https://psylab.org.ua/tools_%D0%9E%D0%BF%D1%80%D0%BE%D1%81%D0%BD%D0%B8%D0%BA_%D0%A8%D0%BC%D0%B8%D1%88%D0%B5%D0%BA%D0%B0), сверен с [таблицей 2.4 учебного пособия «Психологическая диагностика детей и подростков с нарушениями развития»](https://host.megaprolib.net/MP0109/Download/MObject/3154), стр. 61–62. В коде реализован этот ключ: демонстративность «нет» 51; застревание «нет» 12, 46, 59; педантичность «нет» 36; дистимность «нет» 31, 53, 65; эмотивность «нет» 25; тревожность «нет» 5. Для возбудимости опубликованный ключ включает также пункты 8 и 74.
- Объём: 88 дихотомических пунктов; 10 шкал — гипертимность, дистимность, циклотимность, возбудимость, застревание, эмотивность, экзальтированность, тревожность, педантичность и демонстративность.
- Подсчёт: число совпавших ключевых ответов по каждой шкале умножается на коэффициент (3 для гипертимности, дистимности, циклотимности, возбудимости, эмотивности и тревожности; 2 для застревания, педантичности и демонстративности; 6 для экзальтированности). Ключи «Нет» считаются обратными. Диапазон итоговой шкалы 0–24. Контрольный пример: при всех ответах «Нет» получаются соответственно 0, 9, 0, 0, 6, 3, 0, 3, 2, 2.
- Описание инструмента объясняет автору опроса измеряемые аспекты и область применения; это не инструкция участнику.
- Ограничение: в источниках встречаются редакции с отличающимися формулировками и ключами; регистрация фиксирует только вариант СПб НИИ ЛОР. Нормативные и диагностические выводы не добавлялись.
