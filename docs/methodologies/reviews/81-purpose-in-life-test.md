# 81. Purpose in Life Test (PIL)

Статус: `blocked` — версия не уточнена; известный русский вариант СЖО Леонтьева уже является отдельной адаптацией PIL, его нельзя дублировать как оригинальный PIL.

Исходная запись PIL не задаёт конкретную языковую форму или издание. На русском языке широко используется СЖО Д.А. Леонтьева (1992), адаптированная и переработанная версия, с собственным 20-пунктовым бланком, преобразованиями ответов и пятью шкалами. Её нельзя выдавать за прямой перевод исходного PIL. Для самостоятельной англоязычной версии PIL не подтверждена подходящая российская апробация русской формы.
