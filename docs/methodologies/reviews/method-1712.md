# 1712. Тест акцентуаций свойств темперамента

Решение worker: `blocked`.
Основание: Русский бланк содержит 125 пунктов и ответы «Да/Нет», но надёжный полный ключ с номерами пунктов по шкалам и правилами расчёта интегральных показателей не опубликован в доступных источниках. Издатель подтверждает, что ключи входят в комплект методики, однако сам ключ доступен только в комплекте. Файлы не создавались.
