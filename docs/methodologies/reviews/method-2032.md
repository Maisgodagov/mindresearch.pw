# Четырехмодальностный эмоциональный опросник (ЧЭО), Л. А. Рабинович

- Статус: blocked — в доступной публикации найден неполный/противоречивый ключ для точной автоматической реализации.
- Русская форма: страница [«Четырехмодальностный эмоциональный опросник» на Psytests.org](https://psytests.org/emo/m4rab.html) описывает редакцию Рабинович (1974) как авторскую и отмечает обратные вопросы. Полный текст и бланк связаны с этой страницей, но отдельно доступная публикация Ильина приводит другую, переработанную редакцию.
- Источник ключа и описания подсчёта: Е. П. Ильин, [«Эмоции и чувства», раздел «Четырехмодальностный эмоциональный опросник Л. А. Рабинович»](https://psy.wikireading.ru/hqShVgRLlz). Там указано 46 вопросов, четыре варианта ответа с баллами 4, 3, 1 и 0, четыре шкалы по 12 пунктов и суммирование баллов до 48 на шкалу. Однако таблица ключа для нескольких номеров одновременно указывает ответы «да» и «нет» для одной шкалы (в частности, 25, 31, 37; для страха 1, 15, 45), не объясняя правило совмещения. Однозначную по-пунктную схему начисления для опубликованной на Psytests авторской редакции установить нельзя без догадки.
- Шкалы: радость, гнев, страх, печаль; по 12 вопросов, заявленный диапазон 0–48.
- Формула, указанная в главе Ильина: сложить баллы выбранных вариантов по ключу; категории «безусловно, да» = 4, «пожалуй, да» = 3, «пожалуй, нет» = 1, «безусловно, нет» = 0. Точный алгоритм применения ключа к конфликтующим ответам и редакции с обратными вопросами источники однозначно не устанавливают.
- Первоисточник в библиографии страницы методики: Л. А. Рабинович, «Дифференциально-психофизиологический анализ эмоциональности как черты темперамента», диссертация, 1974. [Библиографическая запись на Psytests.org](https://psytests.org/emo/m4rab.html).

Итог: русская версия существует, но надёжного однозначного алгоритма подсчёта доступные источники не дают; регистрацию и автоматический ключ не создавал.
