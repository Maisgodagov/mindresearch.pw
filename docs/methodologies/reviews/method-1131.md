# Опросник предстартовых состояний — Е. Н. Митрофанова (2014)

- Статус: `blocked`.
- Русская страница методики сообщает назначение инструмента и библиографию, однако полный бланк вопросов и ответов не удалось проверить по доступным прямым материалам.
- Страница psytests указывает источник: [Е. Н. Митрофанова, «Диагностика предстартовых состояний спортсменов» (сборник «Естественно-научный подход в современной психологии», ИП РАН, 2014)](https://psytests.org/sport/oprs.html). Поисковая выдача страницы называет два оцениваемых показателя: эмоциональное возбуждение и вегетативная настройка организма.
- Русская версия: [страница «Опросник предстартовых состояний» на PsyTests](https://psytests.org/sport/oprs.html); доступная ссылка на бланк ведёт на [бланк ОПС](https://psytests.org/sport/oprs-bl.html), который не удалось получить для проверки.
- Для результата страницы описывают шкалу готовности организма (апатия — боевая готовность) и шкалу эмоциональной стабильности (спокойствие — лихорадка); страницы примеров также упоминают оценивание до соревнования и тренировки. Однако не найден доступный надёжный первичный источник с полным соответствием пунктов шкалам и формулой подсчёта.
- Количество пунктов, полный набор вариантов ответа, ключ и реверсивные пункты не подтверждены прямым источником. Формулу нельзя безопасно реализовать без этих данных.

## Решение

Русское описание методики доступно, но точный ключ/подсчёт не подтверждён проверяемым источником. Регистрация не создаётся: без полного бланка и ключа нельзя вручную проверить пример подсчёта или включить точные пункты и ответы.
