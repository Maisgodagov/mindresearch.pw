# Военно-профессиональная мотивация (ВПМ)

- Решение: подготовлено; доступен полный русский текст 60 пунктов и четырёх вариантов ответа, а приложение содержит ключи, шкалы и правила подсчёта.
- Русский текст: [бланк Psytests](https://psytests.org/work/vpmot-bl.html); полная копия текста, инструкции и приложения с ключом опубликованы в [Приложении № 2 ВПМ](https://znanio.ru/media/oprosnik-voenno-professionalnaya-motivatsiya-bv-ovchinnikov-af-borovikov-2716955). Описание назначения: [страница методики](https://psytests.org/work/vpmot.html), [путеводитель](https://psytests.org/guide/work-service-ru.html).
- Ключ: приложение содержит ответы по каждому из 60 пунктов в порядке а/б/в/г, распределение по десяти шкалам и коэффициенты. Числа ключа введены как баллы 1–4; в ключе реверсивные пункты не указаны.
- Количество пунктов: 60, по четыре ответа в каждом.
- Шкалы (по 6 пунктов): мировоззрение (1, 11, …, 51; коэффициент 2), широта интересов (2, 12, …, 52; 2), жизненные цели (3, 13, …, 53; 1), стремление к достижениям (4, 14, …, 54; 1), уравновешенность эмоций (5, 15, …, 55; 2), модальность эмоций (6, 16, …, 56; 1), полноценность влечений (7, 17, …, 57; 1), полноценность саморегуляции влечений (8, 18, …, 58; 2), военная доминанта общая (9, 19, …, 59; 1), военная доминанта специальная (10, 20, …, 60; 1).
- Формула: для каждого пункта прибавить балл, соответствующий выбранному варианту по ключу; сумму шести пунктов каждой шкалы умножить на опубликованный коэффициент; итоговый первичный показатель — сумма десяти взвешенных шкал. Публикация переводит его в стэны по диапазонам 84–192, 193–213, 214–229, 230–242, 243–254, 255–264, 265–273, 274–285, 286–293, 294–336 (стэны 1–10). Таблицу уровней и интерпретаций в алгоритм результата не добавляли.
- Ограничение: Psytests указывает, что первоисточник не установлен; используемая копия приложения размещена на образовательном портале как материал автора публикации.
