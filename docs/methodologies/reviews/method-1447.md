# Проактивный копинг (ОПК), сокращённая адаптация 2018 года

- Решение: `prepared`. Русский текст и точный ключ опубликованы авторами адаптации.
- Русская версия и бланк: [«Проактивный копинг, PCI», страница методики и бланки русских версий](https://psytests.org/coping/pcir.html); выбран именно вариант Агадуллиной, Белинской и др. (2018), а не перевод Старченковой (2009).
- Ключ и публикация адаптации: [Белинская Е. П., Вечерин А. В. «Адаптация диагностического инструментария: опросник „Проактивный копинг“», Социальная психология и общество, 2018, т. 9, № 3, с. 137–145](https://doi.org/10.17759/sps.2018090314). В приложении к статье приведены полный бланк и шкалирование; авторы указывают 27 утверждений, шесть шкал, прямое кодирование всех пунктов и суммирование внутри шкалы.
- Контекст конструкта: [«Совладание: тесты и опросники», путеводитель по копингу](https://psytests.org/guide/regulation-coping-ru.html).

27 пунктов. Ответы: «абсолютно не согласен» = 1, «частично согласен» = 2, «скорее согласен, чем не согласен» = 3, «полностью согласен» = 4. Все пункты прямые; реверсивных пунктов нет. Для каждой шкалы суммируются баллы её пунктов: проактивное совладание (1–6), рефлексивное совладание (7–11), стратегическое планирование (12–14), превентивное совладание (15–19), инструментальная поддержка (20–23), эмоциональная поддержка (24–27). Контрольные суммы при минимальных ответах: 6, 5, 3, 5, 4, 4; при максимальных: 24, 20, 12, 20, 16, 16.
