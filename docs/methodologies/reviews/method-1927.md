# Типы родительских установок в психологической поддержке ребенка-спортсмена

- Решение: prepared. Русские формулировки всех 38 утверждений и полный ключ опубликованы авторами; алгоритм точный.
- Русский текст и ключ: О. Г. Лопухова, Л. Р. Нурхамитова, [«Типы родительских установок в психологической поддержке ребенка-спортсмена: диагностический опросник»](https://doi.org/10.17759/sps.2023140311), *Социальная психология и общество*, 2023, т. 14, № 3, с. 173–186. Приложение содержит текст, инструкцию, подсчет и ключ; статья доступна также на [странице публикации PsyJournals.ru](https://psyjournals.ru/journals/sps/archive/2023_n3/Lopukhova_Nurkhamitova).
- Русский бланк для сверки представления: [«Типы родительских установок в поддержке ребенка-спортсмена — бланк»](https://psytests.org/sport/truprs-bl.html) на PsyTests.org. Для набора пунктов и подсчета приоритет отдан приложению статьи, поскольку сайт отмечает, что его бланк не является оригинальным.
- Объем: 38 утверждений, дихотомические ответы «Да» / «Нет»; «Да» получает 1, «Нет» — 0.
- Шкалы и ключ: «Нереализованные родительские амбиции» — пункты 1–9; «Вовлеченный, поддерживающий родитель» — 10–21; «Отстраненный, негативно настроенный родитель» — 22–38. Реверсивных пунктов авторский ключ не задает.
- Формула: для каждой шкалы сумма баллов за ответы «Да» делится на число пунктов шкалы (среднее арифметическое; диапазон каждой шкалы 0–1). Это относительная выраженность каждой установки. В статье дополнительно описаны нормативная стандартизация и классификация доминирующего/смешанного типа, но числовые границы таблицы частично неоднозначны в текстовой версии; они не используются в автоматическом подсчете.
- Назначение: родители детей, занимающихся спортом; инструмент создан для психолого-педагогического сопровождения детско-юношеского спорта.
- Контрольные примеры: все «Нет» дают 0 по каждой шкале; все «Да» — 1 по каждой шкале; одно «Да» в пункте 1 и остальные «Нет» дают 1/9, 0, 0.
