# Типы конспиративистской ментальности — В. И. Пищик (рабочая версия, 2023)

- Решение: подготовлено; доступен полный русский бланк и точный ключ в приложении 1 первичной публикации.
- Русская версия: [«Типы конспиративистской ментальности» — страница методики и бланк](https://psytests.org/life/tkonm.html) (страница ссылается на русскую авторскую публикацию и бланк); [статья и приложение с полным текстом методики, вариантами и ключом](https://rpj.ru.com/index.php/rpj/article/view/1369).
- Источник ключа: В. И. Пищик. [«Измерение конспиративистской ментальности: первичная психометрическая проверка диагностической методики»](https://doi.org/10.21702/rpj.2023.1.14), *Российский психологический журнал*, 2023, т. 20, № 1, с. 218–234; приложение 1, с. 232–234 (бланк, ключ и описания типов). Ключ однозначно размечает вариант А/Б каждого из 16 утверждений для типов устойчивый (У), ищущий (И), готовый (Г), результативный (Р); совпадение с меткой даёт 1 балл.
- Пункты: 16 составных пунктов, каждый предлагает выбор между двумя утверждениями (А/Б); респондент выбирает один вариант.
- Шкалы и формула: четыре независимые суммы по ключу (устойчивый, ищущий, готовый, результативный). Для каждой шкалы сумма индикаторов `1`, если выбранный вариант совпал с соответствующей меткой в ключе, иначе `0`. Обратных пунктов нет; один ответ может давать балл другой шкале, так как ключ фиксирует тип каждого варианта. Диапазон каждой шкалы 0–16.
- Ручная сверка контрольного случая: по вариантам, предписанным ключом во всех 16 пунктах, суммы составляют: устойчивый 7, ищущий 6, готовый 5, результативный 7.
- Область подтверждения: статья сообщает первичную проверку на 300 студентах вузов Ростова-на-Дону, мужчинах и женщинах 17–23 лет; авторы отмечают необходимость дальнейшей психометрической проверки и расширения шкал.
- Путеводитель: [«Социальные установки: тесты и опросники»](https://psytests.org/guide/social-attitude-ru.html) включает методику в обзор социальных установок.
