# Краткий интеллектуальный тест (КИТ), версия Г. В. Резапкиной

- Решение: добавить версию с пригодным русским текстом и опубликованным ключом.
- Русский текст, бланк, обработка и ключ: [«Тесты по определению способностей. Диагностика Г. Резапкина», раздел «Краткий интеллектуальный тест»](https://infourok.ru/testi-po-opredeleniyu-sposobnostey-diagnostika-grezapkina-3739563.html) (30 пунктов, инструкция, шесть групп и ответы). Изображения для заданий на выбор/составление фигур приведены на странице как иллюстрации; пункты сохранены с прямыми ссылками на эти иллюстрации.
- Библиографическая ссылка на публикацию автора: [Г. В. Резапкина, «Психодиагностика в стиле ретро», журнал «Школьный психолог», 2010, № 22, с. 38–42](https://lib.ndu.edu.ua/cgi-bin/irbis64r_12/cgiirbis_64.exe?C21COM=S&I21DBN=IBIS_PRINT&LNG=uk&P21DBN=IBIS&S21CNR=500&S21FMT=FULLW_print&S21P01=0&S21P02=1&S21P03=A%3D&S21REF=&S21STN=1&S21STR=%D0%A0%D0%B5%D0%B7%D0%B0%D0%BF%D0%BA%D0%B8%D0%BD%D0%B0%2C+%D0%93.&Z21ID=). Каталожная запись подтверждает выпуск и страницы; полный текст там не представлен.
- Описание русской онлайн-версии и целевой группы: [«Краткий интеллектуальный тест, КИТ» на PsyTests](https://psytests.org/iq/kit.html). Страница указывает на модификацию КОТ для учащихся 6–8 классов и аспекты интеллекта; формулировки и ключ взяты из опубликованного бланка выше.
- Объем: 30 заданий; варианты выбора воспроизведены без цифровых префиксов, открытые числовые ответы вводятся числом. В заданиях 6, 12, 18, 24 и 30 требуются иллюстрации, поэтому в тексте сохранены прямые ссылки на соответствующие изображения источника.
- Шкалы: по пять заданий — эрудиция (1, 7, 13, 19, 25), речевое развитие (2, 8, 14, 20, 26), внимание (3, 9, 15, 21, 27), математические способности (4, 10, 16, 22, 28), логика (5, 11, 17, 23, 29), пространственные представления (6, 12, 18, 24, 30). Каждый правильный ответ дает 1 балл; обратных пунктов нет. По каждой шкале: 4–5 — высокий, 2–3 — средний, 0–1 — низкий уровень. Общий счет — сумма правильных ответов из 30; опубликованные групповые процентили не кодируются как индивидуальные нормативы.
- Формула: для каждой шкалы суммировать индикаторы `ответ[i] === ключ[i]`; итоговый балл — сумма правильных ответов. Ключ в порядке пунктов: 2, 3, 3, 4, 1, 4, 4, 2, 1, 31, 1, 3, 4, 3, 270, 40, 3, 1, 345, 3, 4, 40, 10, 2, 2, 2, 14, 4, 1, 4.
- Ограничение: в публикации есть графические стимулы к пяти заданиям; приведенные ссылки указывают на изображения страницы-бланка. Методика описана для учащихся 6–8 классов.
