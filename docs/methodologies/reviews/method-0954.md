# 954. Опросник здоровья пациента

Решение worker: `blocked`.
Основание: Очередь указывает на семейство PHQ, для которого страница перечисляет несколько отдельных модулей, но не даёт полного русского текста и единого ключа всей батареи. Русский бланк и точный ключ PHQ-9 доступны, однако такая регистрация дублировала бы существующий PHQ-9 и подменяла бы запрошенное семейство отдельным модулем. Разрешённые файлы не создавал.
