# 1074. Опросник ОСА

Решение worker: `blocked`.
Основание: Русский бланк содержит 72 пункта и варианты ответов, а найденная публикация В. П. Прядеина указывает четыре шкалы и диапазоны интерпретации. Однако доступный ключ лишь задаёт группы пунктов по шкалам, не объясняя, как преобразуются семибалльные ответы в баллы шкал; первоисточник с однозначным алгоритмом подсчёта подтвердить не удалось. Чтобы не угадывать формулу, файлы не создавал.
