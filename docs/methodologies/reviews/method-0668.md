# 668. Методика оценки уровня интуитивности

Решение worker: `blocked`.
Основание: Русская версия методики доступна, но точный ключ и правила подсчёта не удалось подтвердить по надёжному источнику: страница бланка недоступна, а найденные публикации лишь упоминают шкалы интуитивности и внушаемости без ключа. По workflow ключ нельзя восстанавливать по догадке; файлы не созданы.
