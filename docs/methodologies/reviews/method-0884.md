# Опросник выявления буллинг-структуры (Е. Г. Норкина, 2016)

- Решение: blocked — пригодный русский текст и точный ключ найдены, но текущая конфигурация подсчёта не умеет выражать ключ, где для каждой шкалы и каждого пункта задан отдельный буквенный ответ. Реализация через доступную общую шкалу ответов дала бы неверный подсчёт, поэтому регистрационный модуль не создан.
- Русский текст: 25 пунктов для подростков; полный текст, варианты ответов, ключ пяти ролей и подсчёт опубликованы в статье Норкиной, с. 171–174. Для отдельных визуально размеченных русских бланков доступны [мужской бланк опросника на psytests.org](https://psytests.org/confl/bulling-bl.html) и женский бланк по ссылке на той же странице. В этой записи текст бланка не дублируется.
- Ключ: по каждому ответу, совпавшему с буквенным ключом соответствующей роли, начисляется 1 балл. Шкалы: инициатор, помощник инициатора, защитник жертвы, жертва, наблюдатель. Пункты 13, 17 и 20 в ключ не входят и рассматриваются отдельно как индикаторы насилия со стороны учеников/педагогов. Следовательно, каждая ролевая шкала суммирует совпадения по остальным 22 пунктам; обратных пунктов источник не задаёт.
- Формула: для каждой роли отдельно `S = Σ I(ответ по пункту совпал с буквой в столбце роли)`, по пунктам 1–12, 14–16, 18–19, 21–25; отдельного порога, нормы или правила разрешения равных/сочетающихся ролей в источнике не указано.
- Ручная сверка ключа: первичная статья и методические копии совпадают по строкам ключа; например, для пункта 1 ключи по пяти шкалам — А, Б, А, Б, Г, а для пункта 25 — В, Г, Б, В, А.
