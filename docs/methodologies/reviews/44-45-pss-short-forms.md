# PSS-10 / PSS-4 — ранняя проверка версии и прав

## 44. PSS-10

- Статус: `blocked` до подтверждения права на публикацию конкретного русского текста.
- Российские проверки подтверждены для разных форм: Абабков и соавт. (2016) и Золотарёва (2023). Не смешивать их формулировки, шкалу кодирования или ключи.
- Статья Золотарёвой опубликована по CC BY-NC 4.0. Для полной публикации формы нужна подтверждённая некоммерческая область использования либо отдельное разрешение. Для версии Абабкова право на воспроизведение в платформе отдельно не найдено.

## 45. PSS-4

- Статус: `blocked` до подтверждения права на публикацию конкретного русского текста.
- Русская форма входит в исследование Золотарёвой (2023), но статья имеет лицензию CC BY-NC 4.0; разрешение на использование полного бланка в платформе не подтверждено.
