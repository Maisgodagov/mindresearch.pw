# Суровость детского опыта (2024)

- Решение: подготовлена русская версия по публикации авторов; текст и ключ доступны в приложении.
- Русский текст и ключ: [«Батарея методик для психометрической оценки стратегии истории жизни», приложение, с. 1132–1133](https://journals.rudn.ru/psychology-pedagogics/article/download/45678/25238); онлайн [русский бланк «Суровость детского опыта»](https://psytests.org/diag/surdo-bl.html).
- Публикация: Е. Ш. Комягинская, А. А. Галлямова, А. А. Годованец, Д. С. Григорьев. [«Батарея методик для психометрической оценки стратегии истории жизни»](https://doi.org/10.22363/2313-1683-2024-21-4-1101-1136), *Вестник РУДН. Серия: Психология и педагогика*, 2024, т. 21, № 4, с. 1101–1136. Авторы описывают разработку 15-пунктовой шкалы, её трёхфакторную структуру и применение пятибалльного частотного ответа (с. 1118).
- Навигация: [страница методики «Суровость детского опыта»](https://psytests.org/diag/surdo.html); [путеводитель «Травма и ПТСР»](https://psytests.org/guide/clinical-trauma-ru.html) характеризует её как ретроспективную оценку неблагоприятной среды детства.
- Пункты: 15. Ответы: от «Совсем нет» (1) до «Очень часто» (5), с промежуточными вариантами «Немного» (2), «Что-то среднее» (3), «Часто» (4).
- Шкалы и формула: «Угрозы» — пункты 1–5; «Лишения» — 6–10; «Непредсказуемость» — 11–15. Для каждой шкалы рассчитывается среднее пяти ответов. Реверсивных пунктов нет. Распределение пунктов прямо указано в ключе приложения (с. 1133); среднее согласуется с приведёнными авторами средними значениями факторов (с. 1118).
- Проверка: вручную рассчитанный случай — ответы 1, 2, 3, 4, 5 в каждом блоке дают среднее 3 по всем трём шкалам.
