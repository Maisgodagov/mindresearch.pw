# 85. UCLA Loneliness Scale

Статус: `ru-ineligible` — для найденных русских редакций не подтверждена психометрическая проверка именно в России.

Найдено несколько неэквивалентных русских вариантов и переводов. UCLA Version 3 (I.N. Ishmukhametov, 2006) имеет опубликованные психометрические показатели, но статья прямо сообщает о студенческих выборках в Латвии. UCLA-R в модификации Pergamenshchik & Lepeshinsky также нельзя считать доказательством российской адаптации только по языку. Не собирать собственный перевод или переносить свойства латвийской выборки на Россию.
