# Методика изучения удовлетворенности родителей работой образовательного учреждения (Е. Н. Степанов, 2001)

- Решение: подготовлена; найден полный русский текст и точный алгоритм подсчета.
- Русская версия: [«Методика изучения удовлетворенности родителей работой школы» и ссылка на бланк](https://psytests.org/school/aandrD.html).
- Первоисточник и ключ: [Е. Н. Степанов (ред.). «Воспитательный процесс: изучение эффективности», раздел 2.3.8, с. 114–115, Москва: ТЦ «Сфера», 2001](https://geum.ru/next/art-192944.php) — полный текст раздела, варианты ответа, формула и пороги интерпретации; библиографическая карточка издания: [описание книги и оглавление на Psytests](https://psytests.org/book/step2001.html).
- Русский бланк для сверки версии: [Приложение 5 к программе воспитания «Кадетское братство», с. 39](https://avan.edu.27.ru/files/uploads/2023/vos/Programma_vospitaniyaKadeti.pdf). В этом локальном приложении имеются редакционные варианты формулировок по сравнению с книгой; регистрация использует пункты первоисточника.
- Количество пунктов: 15 утверждений.
- Шкала каждого пункта: 4 — совершенно согласен; 3 — согласен; 2 — трудно сказать; 1 — не согласен; 0 — совершенно не согласен. Обратных пунктов в опубликованном ключе нет.
- Формула: общий показатель (У = \sum\) баллов всех ответов родителей / общее число ответов. Для индивидуального заполненного бланка это среднее по 15 пунктам. Пороги источника: (У \ge 3) — высокий уровень; (2 \le У < 3) — средний; (У < 2) — низкий.
- Ручная проверка: ответы 4 по всем 15 пунктам дают сумму 60 и среднее (60/15=4), что попадает в высокий диапазон; ответы 0 по всем пунктам дают (0/15=0), низкий диапазон.
- Примечание о вариантах: в доступном современном приложении встречается сокращенная формулировка пункта 4 и перестановка местоимения «мой/наш». Для точного соответствия регистрации взят текст раздела 2.3.8 книги Степанова; формулировки ответов и шкала совпадают.
