# Шкала организационной приверженности (OCS-93), модификация В. И. Доминяка

- Статус: подготовлено.
- Русский текст: 18 утверждений и семибалльные варианты ответов сверены с русским бланком OCS-93; страница автора перевода указывает, что это его собственный перевод версии 1993 года.
- Надёжный ключ: страница В. И. Доминяка приводит распределение всех пунктов по подшкалам и правила реверсирования; совпадает с пунктами бланка.
- Количество пунктов: 18.
- Шкалы: аффективная (ACS: 1, 4, 7R, 10R, 13R, 16), продолженная (CCS: 2, 5, 8, 11, 14, 17), нормативная (NCS: 3R, 6, 9, 12, 15, 18).
- Подсчёт: для R-пунктов балл инвертируется в диапазоне 1–7 (8 минус исходный ответ); затем по каждой шкале рассчитывается среднее арифметическое шести пунктов. Общий балл не используется.
- Результат ручной проверки: при ответе 4 во всех пунктах каждая шкала равна 4; при последовательности ответов 1–7, повторённой для 18 пунктов, все три средних после предусмотренного реверсирования также равны 4.
- Ограничение: русская страница автора сообщает, что продолженную шкалу рекомендуется использовать с осторожностью из-за низкой внутренней согласованности в его выборке; отдельные нормативные выводы регистрация не задаёт.
