# 838. Опросник Q-сортировка

Решение worker: `blocked`.
Основание: Русский текст доступен, но надёжный однозначный ключ для версии из 60 пунктов не подтверждён прямым источником: найденный ключ относится к другому бланку на 53 пункта, а страница методики предупреждает, что адаптация Горфинкель и Келейникова не сохраняет процедуру Q-сортировки. Угадывать соответствие пунктов и переносить ключ нельзя; разрешённые файлы не создавались.
