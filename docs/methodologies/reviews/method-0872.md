# Опросник волевого самоконтроля (ВСК), версия Зверкова и Эйдмана (1990)

- Статус: prepared; доступен полный русский бланк и однозначный ключ.
- Русский текст: все 30 утверждений взяты из [бланка опросника ВСК на PsyTests](https://psytests.org/emvol/volsam-bl.html); инструкция и описание версии доступны на [странице методики «Опросник волевого самоконтроля, ВСК»](https://psytests.org/emvol/volsam.html). Бланк воспроизводит текстовую форму для визуального отображения; для ключа сверялись опубликованные правила подсчёта.
- Библиография: А. Г. Зверков, Е. В. Эйдман. «Диагностика волевого самоконтроля (опросник ВСК)» // [Практикум по психодиагностике. Психодиагностика мотивации и саморегуляции](https://psytests.org/book/mgu1990.html). М.: Изд-во МГУ, 1990, с. 116–126. Страница книги подтверждает авторство и включение методики; онлайн-копия ключа с исходным разделением трёх шкал — [Тест-опросник «Исследование волевой саморегуляции» (PDF)](https://chain-ddt.dou.tomsk.ru/wp-content/uploads/2025/04/Test-oprosnik-Issledovanie-volevoj-samoregulyatsii-Zverkov-A.V.-Ejdman-E.V.pdf), с. 1–3.
- Объём и ответы: 30 утверждений, дихотомические ответы «Да» / «Нет»; 6 пунктов маскировочные (8, 12, 15, 19, 23, 26), не входят в расчёт.
- Шкалы: общий волевой самоконтроль (В), настойчивость (Н), самообладание (С). Максимумы соответственно 24, 16 и 13 совпадений.
- Формула: для каждой шкалы начисляется 1 балл за совпадение ответа с ключом; несовпадения дают 0. Ключ В: «Да» 2, 3, 4, 5, 7, 9, 11, 17, 18, 20, 24, 27; «Нет» 1, 6, 10, 13, 14, 16, 21, 22, 25, 28, 29, 30. Ключ Н: «Да» 2, 5, 9, 11, 17, 18, 20, 24, 27; «Нет» 1, 6, 10, 13, 16, 22, 25. Ключ С: «Да» 3, 4, 5, 7, 24, 27; «Нет» 13, 14, 16, 21, 28, 29, 30. В модуле подсчёт реализован алгебраически эквивалентными весами при кодировании «Да»=1 и «Нет»=0: каждый keyed-«Нет» добавляет константу 1, а ответы умножаются на +1 для keyed-«Да» и −1 для keyed-«Нет».
- Ручная проверка примеров: все ответы «Да» по пунктам ключей и «Нет» по keyed-«Нет» дают В=12, Н=9, С=6; все ответы «Нет» дают В=12, Н=7, С=7.
- Ограничения: регистрация реализует практическую дихотомическую версию; альтернативная исследовательская версия с семибалльными ответами не включена. Нормативную таблицу не добавляли; опубликованные сырые суммы отображаются без нормативной интерпретации.
