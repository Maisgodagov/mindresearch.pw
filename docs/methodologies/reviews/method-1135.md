# Опросник привязанности к близким людям (ОПБЛ), Сабельникова и Каширский, 2015

- Решение: подготовлено; русский текст и ключ подтверждены первичной публикацией.
- Русский текст и бланк: [«Бланк: Опросник привязанности к близким людям» (psytests.org)](https://psytests.org/ipl/opbl-bl.html) и [инструкция и прохождение опросника](https://psytests.org/ipl/opbl-run.html).
- Первоисточник ключа и подсчета: [Н. В. Сабельникова, Д. В. Каширский. «Опросник привязанности к близким людям», Психологический журнал, 2015, т. 36, № 4, с. 84–97 (полный текст статьи с приложением, ключ на с. 97)](https://www.researchgate.net/publication/326919203_Oprosnik_privazannosti_k_blizkim_ludam). Статья описывает разработку, выборку и психометрическую проверку инструмента.
- Дополнительное описание предметной области: [«Привязанность: тесты и опросники» — путеводитель по взрослой привязанности](https://psytests.org/guide/close-attachment-ru.html).
- Состав: 30 утверждений; единая семибалльная шкала согласия от «Полностью не согласен» до «Полностью согласен».
- Шкалы и формула: среднее по пунктам после реверсирования указанных ниже ответов. «Избегание»: пункты 3, 11, 14, 15, 18, 19, 21, 22, 24, 25, 26, 27, 28, 29, 30; обратные (R) — 3, 11, 14, 15, 18, 19, 21, 22, 24, 26, 27, 28, 29. Прямые — 25 и 30. «Беспокойство»: пункты 1, 2, 4, 5, 6, 7, 8, 9, 10, 12, 13, 16, 17, 20, 23; реверсивных нет. Реверс для диапазона 1–7: `8 − ответ`; затем вычисляется среднее соответствующей шкалы. Формула соответствует приложению первичной статьи.
- Контрольный пример: при ответе 4 по всем пунктам обе шкалы равны 4. При единицах по всем пунктам беспокойство = 1, избегание = 6,6; при семерках — беспокойство = 7, избегание = 1,4.
