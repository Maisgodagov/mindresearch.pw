# Опросник «Фокус рефлексии» (ОФР)

- Статус: `blocked`.
- Русский текст: доступная страница Psytests описывает русскую онлайн-форму как состоящую из 93 вопросов-утверждений.
- Надёжный ключ: публикация разработчиков «Модально-дифференциальный подход в психодиагностике рефлексии» содержит ключ, но для версии из 124 пунктов. Ее нумерация включает пункты до 124 и не совпадает с онлайн-формой из 93 пунктов. Переносить ключ между этими вариантами нельзя; точный ключ именно для 93-пунктовой формы не подтверждён.
- Пункты: 93 в онлайн-версии; 124 в публикации с доступным ключом.
- Шкалы: в публикации описаны 12 шкал направленности рефлексии, механизм «рефлексия–мотив–воля» и шкала лжи; также приведены модальные шкалы. Они относятся к 124-пунктовой версии, а не подтверждённо к 93-пунктовой форме.
- Формула: для шкал направленности сырой балл — число совпадений ответа с ключом; для шкал модальности суммируются положительные ответы согласно отдельному ключу. Применение к 93-пунктовой форме без её собственного ключа невозможно.
- Итог: модуль не создан, так как нельзя подтвердить соответствие полного ключа русской форме из 93 пунктов.
