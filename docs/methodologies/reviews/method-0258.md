# 258. Диспозиционная шкала зависти

Решение worker: `blocked`.
Основание: Подтверждены русские пункты DES и оригинальный однофакторный ключ, однако доступный источник не позволяет надёжно установить полные подписи вариантов ответов русской версии. Английская форма PsyTests показывает пятибалльную шкалу, но её варианты нельзя переносить на русский перевод без проверки. Не стал угадывать; файлы не создавал.
