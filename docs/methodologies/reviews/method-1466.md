- Пункты: 94.
- Шкалы: Cm — Общительность–Замкнутость (16 пунктов); Dm — Доминантность–Подчиненность (20); Re — Ответственность–Безответственность (22); Ns — Эмоциональная стабильность–Неуравновешенность (20); Lw — Нормативность–Делинквентность (18); Fr — Гибкость–Ригидность (16); Wk — Трудолюбие–Леность (13); Af — Настойчивость–Конформность (13); Pc — Доброжелательность–Конфликтность (22); Ap — Активность–Пассивность (производная, без отдельного ключевого набора); Tf — Искренность–Лживость (контрольная, 24).
- Формула: для каждого указанного ключом утверждения ответ «Верно» кодируется как 2, нейтральный — 1, «Неверно» — 0 по прямому ключу; по обратному ключу — соответственно 0, 1, 2. Сумма кодированных значений по списку шкалы даёт сырой показатель. Для Tf совпадение с прямыми утверждениями имеет вес 1, с обратными — 2. Нормативный перевод в пакет не включён.
