# Психологический тип родителя — В. В. Ткачева (2006)

- Решение: подготовлено. Найдены полный русский бланк и точное правило подсчёта в издании автора.
- Русская версия: [«Семья ребенка с ограниченными возможностями здоровья: диагностика и консультирование», приложение 2, с. 122–124 — бланк анкеты](https://www.nbcmedia.ru/upload/iblock/46f/tkacheva_pdf_a4.pdf) содержит инструкцию, 21 пункт и ответы «Да/Нет»; формулировки воспроизведены в модуле. Онлайн-бланк [PsyTests: «Психологический тип родителя»](https://psytests.org/parent/ptr-bl.html) также доступен.
- Ключ: [В. В. Ткачева, «Семья ребенка с ограниченными возможностями здоровья: диагностика и консультирование», приложение 2, с. 121–122](https://www.nbcmedia.ru/upload/iblock/46f/tkacheva_pdf_a4.pdf): считать утвердительные ответы отдельно по пунктам 1, 4, 7, 10, 13, 16, 19 (психосоматический тип); 2, 5, 8, 11, 14, 17, 20 (невротичный); 3, 6, 9, 12, 15, 18, 21 (авторитарный). Доминирует шкала с наибольшей суммой; если суммы равны, тип не выделяется и реакция описывается автором как нормативная. Независимая сверка ключа: [Psylist, «Анкета “Психологический тип родителя” В. В. Ткачева», правила пользования](https://psylist.net/praktikum/00261.htm).
- Библиографическая запись первоисточника: [Российская государственная библиотека — В. В. Ткачева, «Технологии психологического изучения семей, воспитывающих детей с отклонениями в развитии» (2006)](https://search.rsl.ru/ru/record/01002919779); онлайн-публикация методики указывает это издание в качестве литературы: [PsyTests, описание методики](https://psytests.org/parent/ptr.html).
- Пункты и шкалы: 21 утверждение, бинарные ответы «Да»/«Нет»; 3 шкалы по 7 пунктов, обратных пунктов нет. За «Да» по ключевому пункту начисляется 1 балл, за «Нет» — 0.
- Формула: для каждой шкалы отдельно суммируются баллы утвердительных ответов по перечисленным номерам пунктов (диапазон 0–7). Наибольшая сумма определяет доминирующий тип; равные суммы не разделяют типы. Нормативных порогов нет.
