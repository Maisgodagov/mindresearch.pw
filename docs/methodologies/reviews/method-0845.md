# Опросник академической компетентности студентов (ОАК), О. П. Меркулова, 2024

- Решение: prepared. В статье опубликованы полный русскоязычный бланк и однозначный ключ; зарегистрирована версия для студентов высшего образования.
- Русский текст: все 69 утверждений и четыре ответа приведены в приложении к публикации. Ответы в интерфейсе отображаются без нумерационных цифр.
- Ключ: статья явно задает прямое кодирование «нет» = 0, «скорее нет» = 1, «скорее да» = 2, «да» = 3; для обратных пунктов обратный порядок 3, 2, 1, 0. Обратные пункты: 3, 4, 12, 21, 42, 43, 51, 64.
- Шкалы и подсчет: 6 содержательных шкал (академическая мотивация, самоорганизация учебной деятельности, эмоциональная саморегуляция, коммуникативные умения и навыки, речевые умения и навыки, способы работы с информацией), 3 уровня (репродуктивный, рефлексивный, функциональный) и общий показатель. Каждый результат — сумма ключевых баллов пунктов своей шкалы; общий показатель — сумма всех 69 пунктов. Теоретические диапазоны: общий 0–207, репродуктивный 0–84, рефлексивный 0–75, функциональный 0–48.
- Проверочный пример: для согласия «да» по всем пунктам после разворота обратных пунктов ожидается общий показатель 207, уровни 84/75/48 и содержательные суммы 33/36/33/33/36/36.
- Ограничение применимости: автор указывает, что нормативные данные преимущественно собраны на студентах педагогических и психологических направлений, а для других вузов и направлений нормы требуют уточнения. В этой реализации опубликованные процентили не закодированы как пороговые интерпретации.
