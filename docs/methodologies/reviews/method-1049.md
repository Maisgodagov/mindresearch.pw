# Опросник «Натурафил»

- Решение: prepared; русский текст всех 50 пунктов и однозначный ключ доступны.
- Версия: С. Д. Дерябо, В. А. Ясвин; методика для учащихся, нормы которой разработаны прежде всего для возраста 10–17 лет.
- Русский бланк: [«Опросник Натурафил — Бланк»](https://psytests.org/eco/natfil-bl.html) содержит 50 русскоязычных пунктов и варианты ответов «Да»/«Нет», а для эрудиционных пунктов также «Не знаю».
- Теоретическое описание и полный текст: [Е. И. Чердымова, «Экологическая психология» (учебное пособие), глава «Методики диагностики субъективного отношения к природе „Натурафил“», с. 57–63](https://repo.ssau.ru/jspui/bitstream/123456789/58739/1/%D0%A7%D0%B5%D1%80%D0%B4%D1%8B%D0%BC%D0%BE%D0%B2%D0%B0%20%D0%95.%D0%98.%20%D0%AD%D0%BA%D0%BE%D0%BB%D0%BE%D0%B3%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B0%D1%8F.pdf): приводит возраст/инструкцию, правило начисления 1 балла за ответ по ключу, ноль за «не знаю» и ключ по пяти шкалам.
- Первичная публикация авторов: [С. Д. Дерябо, В. А. Ясвин, «Возрастная динамика интенсивности субъективного отношения к природе» (Вопросы психологии, 1995, № 4, с. 19–28)](https://www.voppsy.ru/issues/1995/954/954019.htm) описывает конструкты шкал, десять пунктов на шкалу и формирование общего показателя; нормативная выборка школьников 10–17 лет.
- Независимая публикация ключа: [«Наука о человеке: гуманитарные исследования», т. 19, № 1 (2025), таблица 1 «Ключ методики „Натурафил“», с. 127–128](https://journal.omga.su/wp-content/files/19.1/%D1%81.%20123-131.pdf) подтверждает номерные пункты и правильные (+)/обратные (−) ответы по шкалам.
- Структура: 50 пунктов; ПА — перцептивно-аффективная, К — когнитивная, П — практическая, ПИ — поступочно-инфлюативная (по 10 пунктов); НЭ — дополнительная шкала натуралистической эрудиции (10 пунктов). Для каждого пункта ключ задаёт один результативный ответ; обратные пункты в коде означают ключевой ответ «Нет». «Не знаю» для НЭ всегда нерезультативно.
- Подсчёт: 1 балл за совпадение с ключом шкалы, иначе 0; результат каждой шкалы — сумма её десяти пунктов (0–10). Общая интенсивность = ПА + К + П + ПИ (0–40); НЭ в общую интенсивность не включается. Нормативные преобразования в стэны/Т-баллы не реализованы.
- Ручная проверка: набор ответов, совпадающий с каждым ключевым ответом, даёт по 10 баллов на каждой из пяти шкал; противоположные ответы (и «Не знаю» по НЭ) дают ноль.
- Описание инструмента сформулировано для автора опроса: отражает измеряемые аспекты и возраст применения, не является инструкцией участнику.
