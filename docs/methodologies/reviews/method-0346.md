# Индекс чувствительности к тревоге — 3 (ASI-3), русскоязычная версия

- Решение: `prepared` — найдены полный русский текст опросника, варианты ответов и прямой ключ подсчёта.
- Пункты: 18 утверждений; шкала согласия из пяти вариантов, кодируемых 0–4.
- Шкалы: социальные опасения (1, 6, 9, 11, 13, 17), когнитивные опасения (2, 5, 10, 14, 16, 18), физические опасения (3, 4, 7, 8, 12, 15); диапазон каждой 0–24. Интегральный показатель — сумма всех 18 пунктов, диапазон 0–72. Реверсивных пунктов нет.
- Формула: суммировать выбранные баллы соответствующих пунктов; исходная статья прямо задаёт группировку пунктов и суммирование. Реализация проверена вручную на крайних примерах: все 0 дают 0 по каждой шкале и итогу; все 4 дают 24 по каждой подшкале и 72 в сумме.
- Ограничение версии: русскоязычная апробация проведена на неклинической студенческой выборке 18–29 лет; авторы указывают на необходимость дополнительной проверки при использовании за её пределами. Интегральный показатель включён как описательная сумма ключа; интерпретацию как единой латентной шкалы следует учитывать с осторожностью, поскольку статья отмечает ограничения модели интегрального показателя.
