# 2180. Шкала локуса контроля при восстановлении

Решение worker: `blocked`.
Основание: Надёжный ключ подтверждён: 9 пунктов, внутренние 1, 3, 5, 9 оцениваются в обратном направлении, внешние 2, 4, 6, 8 — прямо; однако русский бланк указан как перевод с неизвестным автором и без данных об адаптации. Доступные источники не позволяют надёжно сопоставить этот ключ с формулировками русских пунктов, поэтому точную реализацию подготовить нельзя.
