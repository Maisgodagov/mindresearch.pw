# 682. Методика экспресс-диагностики родителей

Решение worker: `blocked`.
Основание: Русский бланк доступен (34 пункта), но надёжный полный ключ для точной версии не подтверждён: первоисточник описывает ключ семейного состояния, а для блока родительского отношения указывает, что выделена только первая шкала опросника Столина—Варги и добавлены пункты, не учитываемые при подсчёте; точный состав засчитываемых пунктов и правило для доступных 13 формулировок не удалось надёжно установить. Во избежание угадывания файлы не создавались.
