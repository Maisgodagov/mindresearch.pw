# Уровень сформированности педагогической рефлексии — О. В. Калашникова (1998)

- Решение: подготовлено. Русский текст и полный ключ доступны; алгоритм подтвержден опубликованным описанием.
- Библиография: [О. В. Калашникова. «Развитие педагогической рефлексии: практическое руководство для студентов педагогических вузов и начинающих учителей» (Екатеринбург: УГППУ, 1998)](https://elar.rsvpu.ru/bitstream/123456789/23127/1/Kalashnikova_1998.pdf). Это первичная публикация методики.
- Ключ и формула сверены по [«Определению уровня сформированности педагогической рефлексии (по О. В. Калашниковой)», разделы «Текст методики» и «Обработка результатов», с. 1–5 PDF](https://garmoniya.uglich.ru/uploads/files/1563884038_opredelenie-urovnja-sformirovannosti.pdf); источник приводит все 34 пункта, инструкцию, ключ и пороговые уровни. Страница [«Уровень сформированности педагогической рефлексии» на Psytests](https://psytests.org/pedag/refovk.html) указывает авторство и первичную библиографию; доступен также [русский бланк прохождения](https://psytests.org/pedag/refovk-run.html).
- Пунктов: 34. Ответы: «Да» / «Нет».
- Шкала: один суммарный показатель, 0–34; интерпретационные диапазоны источника: 0–11 низкий, 12–22 средний, 23–34 высокий уровень рефлексии.
- Формула: по 1 баллу за ответ, совпавший с ключом, и 0 за несовпавший; итог — сумма баллов. Ключ «Да»: 1, 2, 3, 5, 6, 7, 8, 9, 11, 12, 14, 16, 17, 18, 20, 21, 23, 24, 25, 26, 27, 28, 31, 34. Ключ «Нет»: 4, 10, 13, 15, 19, 22, 29, 30, 32, 33. Обратные пункты в вычислительной конфигурации не нужны: балл совпадения с ответом «Нет» задаётся явно через таблицу itemScores.
- Описание инструмента сообщает автору опроса измеряемые стороны рефлексии и целевую версию/группу; оно не является инструкцией участнику.
