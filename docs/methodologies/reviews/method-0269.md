# 269. Дом-Дерево-Человек

Решение worker: `blocked`.
Основание: Русское описание классического HTP доступно, но у этой версии нет однозначного автоматизируемого ключа: она требует рисования и последующей беседы с качественной интерпретацией. Найденный числовой подсчёт относится к отдельному заданию для оценки графических навыков, а не к ключу HTP; переносить его на методику нельзя. Файлы не созданы.
