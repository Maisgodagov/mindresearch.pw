# 404. Клинический опросник для выявления и оценки невротических состояний

Решение worker: `blocked`.
Основание: Полный русский бланк доступен, но точный алгоритм требует таблиц диагностических коэффициентов по шести шкалам. В доступных источниках таблицы представлены только как изображения; значения для реализации нельзя надёжно извлечь и угадывать. Разрешённые файлы не созданы.
