# Детский опросник Шмишека-Крук

- Статус: `blocked`.
- Русский текст: доступна родительская форма из 68 пунктов с ответами «Да»/«Нет»: [Бланк детского опросника Шмишека-Крук](https://psytests.org/accent/shmi68k-bl.html). Страница методики описывает её как модификацию для дошкольников и младших школьников, заполняемую родителями: [Детский опросник Шмишека-Крук](https://psytests.org/accent/shmi68k.html).
- Источники для сверки версии и подсчёта:
  - [Блейхер В. М., Крук И. В., Боков С. Н. Клиническая патопсихология (2002), раздел об опроснике и детская форма](https://library.mededtech.ru/rest/documents/Bleikher_patopsik/?anchor=paragraph_gn2j66) — описывает детскую форму Крук как 88-пунктовый самоотчёт ребёнка и даёт ключ/коэффициенты для него; это не 68-пунктовая родительская форма psytests.
  - [Путеводитель Psytests: Детское и подростковое развитие](https://psytests.org/guide/parenting-child-ru.html) — идентифицирует вариант Шмишека-Крук как родительский опросник для дошкольного и младшего школьного возраста.
  - [Кортнева Ю. В. Диагностика актуальной проблемы: методика Леонгарда-Шмишека (2004), каталог РГБ](https://search.rsl.ru/ru/record/01007854847) — библиографическая запись из библиографии страницы; публикация по взрослой методике не подтверждает ключ 68-пунктовой формы.
- Количество: 68 пунктов в русской родительской форме Psytests. В известном источнике Блейхера—Крук полная детская форма содержит 88 иных формулировок.
- Шкалы и формула: для 88-пунктовой версии опубликованы десять шкал и подсчёт совпадений ответов с ключом, умноженных на коэффициент. Этот ключ не переносим на 68-пунктовую родительскую форму: точное соответствие пунктов и реверсивных ответов не подтверждено прямым надёжным источником.
- Итог: модуль не создаётся; требуется источник с ключом именно для 68-пунктовой родительской редакции. Ключ и подсчёт не выводились по смыслу пунктов.
