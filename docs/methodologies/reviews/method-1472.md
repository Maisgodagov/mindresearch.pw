# Профиль самовосприятия подростков Хартер

- Решение: `blocked` — пригодный русский текст доступен, но надёжный точный ключ подсчёта для именно этой русской редакции не подтверждён доступными первичными материалами.
- Русский бланк: [«Профиль самовосприятия подростков Хартер — Бланк»](https://psytests.org/emvol/hspp-bl.html) содержит 45 пунктов. Инструкция в [русской форме прохождения](https://psytests.org/emvol/hspp-run.html) задаёт выбор одной из двух противоположных характеристик и одну из двух степеней соответствия.
- Библиография: [Н. К. Радина, Е. Ю. Терешенкова, «Личностный опросник С. Хартер для изучения персональной идентичности подростка» (2006), каталог библиотеки МГППУ](https://lib.mgppu.ru/OpacUnicode/app/index.php?url=%2Fnotices%2Findex%2FIdNotice%3A47525%2FSource%3Adefault), журнал «Психология и школа», № 4, с. 3–21; [Susan Harter, *The Self-Perception Profile for Adolescents: Manual and Questionnaires* (2012), описание первичного руководства](https://www.scribd.com/document/318375154/Self-Perception-Profile-for-Adolescents-pdf).
- Руководство Хартер описывает девять субшкал по пять пунктов и четырёхбалльное кодирование (1–4, направление зависит от того, какая альтернатива предъявлена первой), с усреднением пунктов каждой шкалы. Однако доступная русская веб-форма маркирует ответы как «частично подходит» / «полностью подходит» и не публикует ключ перекодировки сторон в баллы; бланк отдельно предупреждает, что не является оригинальным и что ключ следует брать из первоисточников. Нельзя надёжно подтвердить, что общий ключ руководства точно соответствует данной редакции адаптации.
- Шкалы: школьная компетентность, социальное принятие, атлетическая компетентность, физическая форма, профессиональная компетентность, романтическое влечение, поведенческие действия, близкие дружеские отношения, глобальная/общая самооценка; по 5 пунктов на шкалу, всего 45. Полная формула кодирования русских вариантов ответов не установлена.
- Решение по workflow: модуль не создан, поскольку ключ нельзя реализовать без догадки.
