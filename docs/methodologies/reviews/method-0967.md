# Опросник КАВД — В. А. Ананьев

- Решение: **blocked**. Доступны русские формулировки всех шести пунктов и четыре ранжируемых варианта в [бланке «Опросник КАВД»](https://psytests.org/typo/kavd-bl.html). Однако страница прямо указывает, что это не оригинальный бланк и инструкции подсчёта следует брать из первоисточников. Печатная копия таблицы соответствия вариантов шкалам доступна во [фрагменте методического пособия для профориентации школьников, с. 127–129](https://nvsu.ru/ru/Intellekt/1135/Formirovanie%20u%20obuchayushchihsya%20gotovnosti%20k%20osoznannomu%20viboru%20professii%20-%20Metod%20posobie%20-%202013.pdf), но надёжно подтвердить её именно из первичного издания Ананьева в доступном источнике не удалось. По workflow ключ не реконструируется по предположению, поэтому регистрацию не создаю.
- Русская версия и описание: [Опросник КАВД — Psytests](https://psytests.org/trait/kavd.html), В. А. Ананьев (1996); описание указывает на оценку ведущей сигнальной системы взрослого. [Путеводитель по популярным типологиям](https://psytests.org/guide/pop-typology-ru.html) кратко описывает назначение КАВД.
- Библиография: В. А. Ананьев. *Практикум по психологии здоровья*. СПб.: Речь, 2007. Библиографическая запись [Национальной электронной библиотеки](https://rusneb.ru/catalog/010003_000061_b290817dd063afda899453229b1679e3/).
- Объём: 6 пунктов, каждый с 4 вариантами; инструкция предполагает ранжирование четырёх вариантов от наиболее до наименее предпочтительного.
- Заявленные шкалы: кинестетическая, аудиальная, визуальная и дискретная. В найденной копии ключа каждая позиция варианта сопоставлена одному типу; подсчёт суммирует ранги по каждой шкале, меньшая сумма означает более выраженный тип. Из-за недостаточно подтверждённого ключа формулу в код не переношу.
