# 2066. Шкала виктимизации сверстников

Решение worker: `blocked`.
Основание: Надёжный ключ исходной MPVS подтверждён, но его нельзя точно применить к найденной русской версии: бланк PsyTests не подписывает все варианты ответов, а пятибалльная шкала в отдельном исследовании относится к модифицированному варианту. Чтобы не угадывать ответы и не смешивать версии, файлы не созданы.
