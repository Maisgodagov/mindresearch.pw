# Протестная активность личности (ПАЛ), версия из диссертации 2016 года

- Статус: `blocked`.
- Русский текст: полный бланк из 50 пунктов опубликован в приложении 2 диссертации А. Ш. Гусейнова (с. 488–490 печатной пагинации). Страница Psytests описывает методику и ссылается на отдельный бланк, но его содержимое недоступно для проверки в этом исследовании.
- Ключ: первичный источник содержит неоднозначности, не позволяющие реализовать точный подсчёт без предположений. В ключе оппозиции пункт 26 указан дважды; пункты 41–50 названы второй шкалой «негативизм», хотя в описании опросника и исследования заявлены пять шкал, включая эскапизм, а сами пункты 41–50 тематически посвящены уходу в виртуальность/мечты. Исправлять названия или состав шкал по содержанию формулировок было бы догадкой. Надёжной независимой публикации с точной исправленной раскладкой не найдено.
- Пункты: 50.
- Шкалы, заявленные в описании инструмента: негативизм, эмансипация, оппозиция, нигилизм, эскапизм. Достоверные диапазоны и состав шкал для автоматического подсчёта не установлены ввиду ошибки ключа.
- Ответы: источник задаёт частотную/согласительную шкалу от 0 до 4: «никогда» / «абсолютно не согласен» — 0; «редко» / «скорее не согласен» — 1; «иногда» / «нечто среднее» — 2; «часто» / «скорее согласен» — 3; «всегда» / «абсолютно согласен» — 4. Указан подсчёт суммы положительных ответов по ключевым пунктам, при этом отдельные реверсивные пункты не обозначены.
- Итог: русский текст пригоден, но надёжного однозначного ключа для точного подсчёта нет; регистрационный модуль не создавался.
