# Степень развития компонентов педагогического взаимодействия (Л. В. Байбородова)

- Решение: подготовлена русская школьная версия из 24 утверждений; текст и ключ подсчёта доступны в опубликованных воспроизведениях методики.
- Библиография: [Е. Н. Степанов (ред.), «Воспитательный процесс: изучение эффективности» (М.: Сфера, 2001), запись и оглавление](https://psytests.org/book/step2001.html) — методика перечислена в разделе 2.2; [страница методики «Степень развития компонентов педагогического взаимодействия»](https://psytests.org/pedag/rokpv.html) — версия для школьников, авторство Л. В. Байбородовой (2001), ссылка на бланк; [бланк «Методика для изучения степени развития основных компонентов педагогического взаимодействия»](https://lektsii.org/6-45534.html) — текст 24 пунктов, идеальные знаки и формула; [PDF «Программа воспитательной деятельности» (Анкета для учащихся № 2, стр. 73–74)](https://zddt.my1.ru/Innov_deyat/programma_panfilov_a.a.2.pdf) — русские формулировки всех 24 утверждений.
- Пункты и ответы: 24 утверждения; для каждого — «Согласен» (+) или «Не согласен» (−). Идеальные знаки по порядку: +, −, +, +, −, +, +, +, −, +, +, +, −, +, −, −, −, +, +, −, −, +, +, +.
- Шкалы: когнитивная (1, 4, 7, 10–13, 16, 19, 22; 10 пунктов), эмоциональная (2, 5, 8, 11, 14–17, 20; 9 пунктов), поведенческо-волевая (3, 6, 9, 12–15, 18–21, 24; 12 пунктов). Состав шкал и пересечения сохранены по источнику.
- Формула: по каждому пункту совпадение ответа с указанным идеальным знаком = 1, несовпадение = 0. Балл компонента — среднее совпадений по пунктам шкалы; диапазон 0–1, приближение к 1 соответствует более высокому уровню развития компонента. Обратные по смыслу утверждения отмечены в конфигурации ключом ожидаемого знака; преобразование выполнено непосредственным сравнением с идеальным ответом.
