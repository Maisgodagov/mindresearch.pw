# Методика исследования виктимного поведения (О. О. Андронникова)

- Статус: подготовлена; русский текст пунктов и двоичный ключ доступны.
- Русская форма: Psytests, [описание «Методика исследования виктимного поведения»](https://psytests.org/ipl/andvip.html) и [страница прохождения с инструкцией и ответами «Да/Нет»](https://psytests.org/ipl/andvip-run.html).
- Источник текста и ключа: [«Методика исследования склонности к виктимному поведению, разработанная О. О. Андронниковой»](https://lektsii.org/11-84815.html), содержит все 86 утверждений, инструкцию, ключи 7 шкал и процедуру подсчёта сырых баллов.
- Публикация автора: [О. О. Андронникова, «Формирование зависимого поведения как результат реализации виктимного потенциала личности» (Новосибирск: НГПУ, 2015)](https://search.rsl.ru/ru/record/01008564249), запись Российской государственной библиотеки; страница Psytests указывает эту монографию в литературе и заявляет сверку с первоисточником.
- Пункты: 86; ответы: «Да» / «Нет».
- Шкалы: социальная желательность ответов (9 ключей); агрессивное виктимное поведение (27); самоповреждающее и саморазрушающее, активный тип (21); гиперсоциальное, инициативный тип (14); зависимое и беспомощное, пассивный тип (19); некритичное поведение (19); реализованная виктимность (18).
- Формула: первичный балл каждой шкалы равен сумме совпавших с ключом ответов: для перечисленных в ключе «Да» начисляется 1 за ответ «Да», для ключевых «Нет» — 1 за ответ «Нет», остальные ответы дают 0. В программной записи ключевые «Нет» отмечены как обратные пункты. Стеновые таблицы не реализованы: публикация Psytests отдельно предупреждает, что доступные таблицы преобразования содержат несоответствия возможным максимумам; надёжно воспроизводимы сырые суммы по явному ключу.
- Возраст: исходное описание адресует старший подростковый и юношеский возраст; таблица стен приведена для 15–16-летних, но в расчёт не включена.
- Ручная проверка: в validation case для каждого пункта задан ответ, совпадающий с ключом (ключевые «Да» = Да, ключевые «Нет» = Нет); ожидаемые сырые суммы по шкалам равны количеству ключей — 9, 14, 11, 8, 16, 12, 12 соответственно.
