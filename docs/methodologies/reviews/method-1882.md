# Тест на языковое чутьё

- Решение: подготовлен; найден полный русскоязычный бланк и точный ключ разработчика.
- Источники:
  - [«Тест на языковое чутьё», лаборатория azps.ru, версия 1.0 (2008): полный бланк, инструкция, ключ и правила подсчёта](https://azps.ru/tests/kit/kit1001.html).
  - [«Тест на языковое чутьё», страница методики psytests.org](https://psytests.org/iq/langf.html) — описание теста и ссылка на исходную публикацию.
  - [«Когнитивный интеллект: тесты и опросники», раздел о вербальных способностях](https://psytests.org/guide/intelligence-cognitive-ru.html) — навигационное описание назначения методики.
- Русский текст: 46 заданий на вставку одного пропущенного слова в цитату; возраст 14+, отведённое время 25 минут. Задания перенесены из опубликованного бланка; повторяющиеся пропуски внутри цитат сохранены. Варианты ответа не заданы: участник вписывает слово.
- Шкала и подсчёт: одна шкала «Языковое чутьё», сумма верных ответов, диапазон 0–46. Ключ состоит из 46 слов в порядке заданий. По источнику, орфографические ошибки засчитываются, когда написанное слово распознано как ключевое; близкие по смыслу слова, не совпадающие с ключом, не засчитываются. Реверсивных пунктов нет.
- Ручная проверка: ответ «Этот» к пункту 1 — 1 балл; остальные ответы отсутствуют. Исполняемая реализация требует точного совпадения введённой строки с ключом и потому не автоматизирует допуск орфографических ошибок из бланка.
- Описание инструмента сообщает автору опроса о понимании смысла слов и нюансов русской речи, литературном контексте заданий и целевой группе; оно не является инструкцией участнику.
