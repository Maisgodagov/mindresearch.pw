# 1863. Тест фрустрационных реакций Розенцвейга

Решение worker: `blocked`.
Основание: Русский бланк доступен, но надёжного однозначного ключа для автоматического подсчёта нет: ответы свободные и требуют экспертной классификации. Источник русской версии прямо указывает, что автоматическая обработка невозможна; найденные правила также требуют интерпретировать содержание каждого ответа. По workflow ключ нельзя угадывать.
