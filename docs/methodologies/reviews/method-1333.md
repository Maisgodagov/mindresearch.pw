# Особенности самоутверждения в подростковом возрасте (Киреева, Дубовицкая, 2011)

- Решение: `prepared`. Подтверждены полный русский текст и однозначный ключ с правилами подсчёта.
- Русская версия: [Бланк «Особенности самоутверждения в подростковом возрасте»](https://psytests.org/emvol/ospv-bl.html) — полный текст 18 пунктов, доступный как русский бланк для сверки. Авторская формулировка содержания и инструкции сверена с [публикацией Киреевой и Дубовицкой](https://psyjournals.ru/journals/exppsy/archive/2011_n2/42046).
- Источник ключа и подсчёта: [«Методика исследования особенностей самоутверждения в подростковом возрасте», Е. А. Киреева и Т. Д. Дубовицкая, «Экспериментальная психология», 2011, т. 4, № 2, с. 115–124](https://psyjournals.ru/journals/exppsy/archive/2011_n2/42046), разделы «Обработка результатов» и «Ключ».
- Пунктов: 18 утверждений, каждое с тремя вариантами ответа. Участник выбирает наиболее и наименее подходящие варианты; оставшийся не отмечается.
- Шкалы: деструктивное самоутверждение (ДС), конструктивное самоутверждение (КС), отказ от самоутверждения (ОС). В публикации ключ дан по номеру и букве варианта для каждого пункта. Реверсивные пункты не указаны.
- Формула: для каждого пункта начислить 2 балла варианту «больше всего», 0 баллов варианту «меньше всего» и 1 балл невыбранному. Суммировать начисления отдельно по буквенно-номерным ключам ДС, КС и ОС. Каждый итог лежит в диапазоне 0–36; более высокий балл означает более выраженный соответствующий тип по описанию авторов. Нормативные пороги не вводились.
- Ограничение источника текста: PsyTests прямо предупреждает, что онлайн-бланк является визуальным отображением, а для офлайн-применения исходный бланк следует брать у авторов; точность ключа при этом сверена по авторской публикации.

Итог: русскоязычный текст и надёжный точный ключ доступны; регистрацию можно реализовать без предположений.
