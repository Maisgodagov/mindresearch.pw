## Источники

В тексте приведена инструкция: 1 балл за совпадение ответа «да/нет» со знаком ключа, 0 — за несовпадение; тест содержит семь барьеров.
2. [«Тест оценки психологических барьеров» — страница методики Psytests](https://psytests.org/work/ermolD.html), описание, авторство и ссылка на бланк.
3. [Бланк теста оценки психологических барьеров — Psytests](https://psytests.org/work/ermolD-bl.html). Ссылка доступна со страницы методики, но содержимое не удалось получить для проверки.

## Структура и подсчёт

Источник указывает семь подшкал по десять пунктов (70 пунктов): личная инициатива, ложная установка, автономность, достижение, риск, коммуникация и восприимчивость к новому. Ответы — «да»/«нет»; по каждому барьеру суммируются совпадения с ключом, каждое совпадение даёт 1 балл, несовпадение — 0.

Ключ в доступном представлении книги сверстан как знаки «+» и «−» без надёжного сохранения границ между отдельными позициями; часть знаков слипается, а для некоторых шкал выдача неполна. Онлайновая страница отсылает к отдельному бланку, который не удалось открыть. Поэтому нельзя без догадки восстановить полный item-by-item ключ и реверсивность. Критерий точного ключа не выполнен.
