# Анкета угроз психологической безопасности (2025)

- Решение: `prepared` — опубликованы полный русский бланк из 36 пунктов и явный ключ с правилами подсчёта.
- Русский текст и первичный ключ: [Финогенова Т. А. «Стандартизация „Анкеты угроз психологической безопасности“», приложение 1](https://psyjournals.ru/journals/epps/archive/2025_n1/Finogenova), DOI [10.17759/epps.2025020107](https://doi.org/10.17759/epps.2025020107). Публикация помечена CC BY-NC 4.0.
- Навигационный источник: [страница методики Psytests](https://psytests.org/life/aupb.html).
- Пункты: 36; четыре варианта ответа на каждый, один выбор. Инструкция ограничивает ответы событиями последнего года.
- Шкалы: военные (1–6), информационные (7–12), социальные (13–18), экономические (19–24), природные (25–30), здоровье (31–36), антропогенные, общий показатель.
- Ключ и формула: вариантам каждого пункта начисляется 0–3 балла в опубликованном порядке; сумма по каждой из шести предметных шкал. Антропогенный показатель — среднее арифметическое сумм военной, информационной, социальной и экономической шкал. Общий показатель — сумма баллов всех 36 пунктов. Обратных пунктов нет. Для предметных шкал в статье указаны диапазоны выраженности 0–5, 6–12, 13–18; для общего показателя — 0–35, 36–72, 73–108.
- Проверочный пример: все ответы с баллом 3 дают 18 по каждой шестипунктовой предметной шкале, 3 по среднему антропогенному показателю и 108 по общему показателю.
