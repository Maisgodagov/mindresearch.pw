# 91. Бергенская шкала трудовой зависимости

Решение worker: `blocked`.
Основание: Не подтверждён надёжный точный русскоязычный бланк: описание psytests.org сообщает о переводе, но его прямые страницы с пунктами и ключом недоступны. Первичная публикация Andreassen et al.
