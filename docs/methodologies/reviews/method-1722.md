# Тест Герчикова, Motype (форма на 23 пункта)

- Решение: подготовлено. Полный русскоязычный бланк доступен; таблица ключа и правило начисления подтверждаются учебным пособием. Регистрация соответствует распространённой форме из 23 вопросов.
- Русский текст: [«Бланк: Тест Герчикова, Motype»](https://psytests.org/work/motype-bl.html) — формулировки вопросов, варианты и лимиты выбора; [«Тест Герчикова, Motype»](https://psytests.org/work/motype.html) — описание, автор и библиографическая ссылка.
- Модель: [В. И. Герчиков, «Мотивация и система стимулирования», глава 6 (выдержки из книги)](https://tmconsult.ru/public/motype/%D0%93%D0%B5%D1%80%D1%87%D0%B8%D0%BA%D0%BE%D0%B2%20%D0%92.%D0%98.%20%D0%9C%D0%BE%D1%82%D0%B8%D0%B2%D0%B0%D1%86%D0%B8%D1%8F%20%D0%B8%20%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D0%B0%20%D1%81%D1%82%D0%B8%D0%BC%D1%83%D0%BB%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F.%20%D0%92%D1%8B%D0%B4%D0%B5%D1%80%D0%B6%D0%BA%D0%B8%20%D0%B8%D0%B7%20%D0%BA%D0%BD%D0%B8%D0%B3%D0%B8%20%D0%93%D0%BB%D0%B0%D0%B2%D0%B0%206.pdf) — авторская типологическая концепция; [страница «Тест Мотайп» компании «Топ-Менеджмент Консалт»](https://tmconsult.ru/public/motype/) — описание инструмента и публикаций автора.
- Ключ и подсчёт: [«Психология труда: практикум» (учебное пособие), приложение 6, таблица П6.1, с. 103](https://dokumen.pub/a80e8689fc63cdae8bae9d58d3dfddc6.html) содержит ключ для всех 23 вопросов. Там же указано сопоставить выбранные ответы с ключом, начислить 1 балл за каждое совпадение и сложить баллы по каждому типу.
- Объём: 23 пункта; в большинстве вопросов можно выбрать один или два ответа, в пункте 20 — сколько угодно. Для вопросов 6–14 используются три градации важности. Остальные варианты индивидуальны по пунктам.
- Шкалы: инструментальная, профессиональная, патриотическая, избегательная (в раннем обозначении — люмпенизированная), хозяйская. Реверсивных пунктов нет; ключ задаёт соответствие выбранных опций шкалам, часть позиций не начисляет баллов.
- Формула: для каждой шкалы суммируется по 1 баллу за каждый выбранный ответ, совпавший с её столбцом ключа; итог — простой профиль сумм. Нормативные преобразования и диагностические пороги не добавлены.
- Контрольный случай вручную сверён по таблице П6.1: выбран вариант 1 во всех пунктах, что даёт по ключу суммы 9, 3, 7, 0 и 7 для инструментальной, профессиональной, патриотической, избегательной и хозяйской шкал соответственно.
- Ограничение: в первоисточнике встречается термин «избегательная», а учебная форма ключа именует шкалу «люмпенизированной»; для единой реализации использована нейтральная метка «избегательная», сохраняя синоним в описании и этом обзоре. Гендерные грамматические окончания унифицированы без изменения содержания.
