# 1109. Опросник по мотивации учения

Решение worker: `blocked`.
Основание: Русская страница psytests.org описывает опросник Гатанова для учащихся 4–8 классов и его шкалы, но доступные материалы не дают проверяемого полного ключа и подсчёта именно для этой версии. Найденный в пособии ключ относится к отдельному 21-пунктному опроснику с другими шкалами; объединять эти версии было бы догадкой. Разрешённые файлы не созданы.
