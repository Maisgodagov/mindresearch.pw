# 1273. Опросник удовлетворенности материнством

Решение worker: `blocked`.
Основание: Доступен русский бланк из 30 пунктов с тремя вариантами ответа, но страница методики прямо указывает, что ключ не публиковался, а ключи онлайн-версии предположительные.
