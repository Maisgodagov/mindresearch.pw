# Шкала диспозиционного эгоизма К. Муздыбаева

- Решение: подготовлена; опубликованы русские формулировки всех десяти пунктов и однозначный ключ прямых/обратных пунктов.
- Русская версия и бланк: [«Шкала диспозиционного эгоизма — Бланк»](https://psytests.org/trait/sdego-bl.html) содержит формулировки и крайние подписи семибалльного ответа; средние позиции на бланке обозначены числами.
- Первичный источник: К. Муздыбаев, [«Эгоизм личности»](https://psyjournras.ru/s0205-95920000621-0-1-ru-21/), *Психологический журнал*, 2000, № 2, с. 27–39. Библиографическая запись: [каталог библиотеки Университета «Дубна»](https://lib.uni-dubna.ru/biblweb/search/bibl.asp?doc_id=61445&full=yes).
- Сверка полного бланка и ключа: [«Шкала диспозиционного эгоизма» в приложении к ВКР, приложение 1, с. 55–57 PDF](https://archive-coursework.mmu.ru/files/upload/Diplomas/2024/publish/p_8792_411.pdf): прямые пункты 1, 4, 5, 7, 8, 9, 10; обратные 2, 3, 6. Там же указаны диапазон суммы 7–70 и максимизация балла при согласии с прямыми и несогласии с обратными. Это вторичный источник; основной ключ сопоставлен с формулировками опубликованного бланка.
- Объём и подсчёт: 10 пунктов, одна шкала. Каждый ответ кодируется 1–7: от «совсем не согласен» до «полностью согласен»; крайняя средняя позиция — 4 («верно нечто среднее»). Для пунктов 2, 3 и 6 ответ реверсируется по формуле `8 − ответ`; затем складываются десять баллов. Возможный итог — 10–70 по самой формуле кодирования. В одном вторичном приложении указана нижняя граница 7, несовместимая с суммой десяти ответов минимум по 1; код реализует непосредственно подтверждённый ключ и диапазон ответов, без пороговой интерпретации.
- Ручная проверка: при ответе 7 на все пункты после реверса 2, 3 и 6 итог `7 + 1 + 1 + 7 + 7 + 1 + 7 + 7 + 7 + 7 = 52`.
