# 456. Краткий опросник жизнестойкости

Решение worker: `blocked`.
Основание: Адекватный русский текст есть (адаптация Алфимовой и Голимбет, 2012), но надёжный точный ключ и правила подсчёта для этой 12-пунктной версии по доступным первичным источникам подтвердить не удалось.
