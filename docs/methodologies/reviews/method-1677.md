# Стресс усердия — решение по регистрации

- Статус: `blocked`.
- Русский текст доступен для первого мини-теста: 10 вопросов «симптомы стрессового состояния»; варианты — «Да» / «Нет».
- Надёжный точный ключ не установлен. Страница [«Стресс усердия» на Psytests](https://psytests.org/stress/strusA.html) ссылается на [бланк](https://psytests.org/stress/strusA-bl.html), но он недоступен для проверки. В копии учебного материала [«Тесты „Стресс усердия“»](https://www.ektu.kz/files/DistanceEducation/Work/223554/5%20%D0%97%D0%B0%D0%BD%D1%8F%D1%82%D0%B8%D0%B5.pdf) порог — не менее двух ответов «Да» и рекомендация обратиться к врачу; иные перепечатки дают девять вопросов с порогом более трёх, что расходится по пунктам и подсчёту.
- Библиография: [И. В. Липсиц (сост.), «Секреты умелого руководителя», Москва: Экономика, 1991](https://lib.dm-centre.ru/lib/document/SVOD/ED0B352F-C780-40D8-B888-240A40C2E6D7/); русская веб-страница методики — [«Стресс усердия»](https://psytests.org/stress/strusA.html); локатор раздела в учебном PDF — [«Тесты „Стресс усердия“»](https://www.ektu.kz/files/DistanceEducation/Work/223554/5%20%D0%97%D0%B0%D0%BD%D1%8F%D1%82%D0%B8%D0%B5.pdf).
- Шкалы и формула не регистрируются: пока не сверены точное число пунктов и порог первоисточника. Обратных пунктов нет подтверждённых.
- Итог: модуль не создаётся, поскольку ключ/подсчёт нельзя надёжно определить без догадок.
