# 77. Анкета психофизиологического комфорта

Решение worker: `blocked`.
Основание: Русский текст подтверждён первоисточником (Водейко и Мазо, 1983): 21 пункт, ответы «Да/Нет», по одному баллу за каждое «Да»; первые три группы по семь пунктов отражают психический комфорт, физиологический комфорт и сон. Но доступные источники показывают расходящиеся формулировки и порядок пунктов, а полный однозначный набор всех 21 пунктов первоисточника подтвердить не удалось. По условию не угадываю и файлы не создавал.
