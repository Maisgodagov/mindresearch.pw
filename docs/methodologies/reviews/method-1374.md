# Оценка социально-перцептивной установки личности (Дубовицкая, Тулитбаева, Шашков, 2017)

- Решение: подготовлено; имеется полный русский текст, точный ключ и явное правило подсчёта в рецензируемой авторской публикации.
- Русская версия и бланк: [«Оценка социально-перцептивной установки личности» — страница методики PsyTests](https://psytests.org/ipl/ospul.html) и [страница прохождения с инструкцией](https://psytests.org/ipl/ospul-run.html). Русская формулировка и ключ ниже сверены с публикацией авторов.
- Первоисточник: [Т. Д. Дубовицкая, Г. Ф. Тулитбаева, А. В. Шашков. «Психодиагностическая методика оценки социально-перцептивной установки личности: психометрические характеристики и особенности использования», Вестник РУДН. Серия: Психология и педагогика, 2017, т. 14, № 2, с. 213–225](https://journals.rudn.ru/psychology-pedagogics/article/view/15981), [DOI: 10.22363/2313-1683-2017-14-2-213-225](https://doi.org/10.22363/2313-1683-2017-14-2-213-225). Раздел методики публикует окончательные 16 пословиц, инструкцию, варианты и ключ (см. также [PDF выпуска РУДН](https://journals.rudn.ru/psychology-pedagogics/issue/download/960/112)).
- Объём: 16 пословиц; один суммарный показатель, диапазон 0–32. Это не несколько субшкал.
- Ответы: «Согласен, соответствует моему мнению», «Не согласен, не соответствует моему мнению», «Трудно сказать».
- Формула: по пунктам 3, 11, 12, 13 ответ «да» = 2, «нет» = 0; по пунктам 1, 2, 4–10, 14–16 ответ «нет» = 2, «да» = 0; любой ответ «трудно сказать» = 1. Итог — сумма баллов всех 16 пунктов. Реверсивных пунктов отдельно нет: ключ задаёт положительный ответ для каждого пункта индивидуально.
- Ручная сверка: набор ответов, полностью совпадающий с ключом, даёт 32; 16 ответов «трудно сказать» дают 16.
- Группа: авторская стандартизация проведена на 342 студентах 18–34 лет; сайт методики не рекомендует психологическую диагностику детей младше 12 лет из-за трудностей понимания пословиц. Пороговые уровни из статьи в автоматический ключ не включены.
