# Анализ семейных взаимоотношений (АСВ), детская форма 3–10 лет

- Решение: `prepared`; зарегистрирована форма для родителей детей 3–10 лет, без смешения с подростковой формой.
- Русский текст: [бланк Psytests](https://psytests.org/parent/asvA-bl.html) и [методические рекомендации Курского центра соцпомощи](https://zentrnl.ru/wp-content/uploads/2025/07/metodicheskie-rekomendaczii-po-organizaczii-soczialno-psihologo-pedagogicheskogo-soprovozhdeniya-semi.pdf), приложение, с. 21–34. В модуле — полный русский текст 130 пунктов формы 3–10 лет, варианты «Да» / «Нет»; объединённые грамматические варианты даны в нейтральной записи.
- Ключ и подсчёт: тот же источник, с. 34–36; дополнительная сверка таблицы ключа и порогов в [публикации полного бланка АСВ](https://dip-psi.ru/psikhologicheskiye-testy/post/oprosnik-dlya-roditelej-analiz-semejnyh-vzaimootnoshenij-asv-v-v-yustickisa-i-e-g-ejdemillera). Ключ задаёт 20 шкал. За согласие по включённому пункту — 1 балл; несогласие — 0; реверсивных пунктов в ключе нет. Для Г+, Г−, У+ добавляются соответственно пункты 101/107/113/119/125, 102/108/114/120/126, 103/109/115/121/127; для РРЧ, ФУ, НРЧ — 104/110/116/122/128, 105/111/117/123/129, 106/112/118/124/130. Неопределённый ответ допускается инструкцией максимум в пяти пунктах; как положительный он не засчитывается.
- Пункты и шкалы: 130 утверждений; Г+, Г−, У+, У−, Т+, Т−, З+, З−, С+, С−, Н, РРЧ, ПДК, ВН, ФУ, НРЧ, ПНК, ВК, ПМК, ПЖК. Пороговые значения в порядке перечисления: 7, 8, 8, 4, 4, 4, 4, 3, 4, 4, 5, 6, 4, 5, 6, 7, 4, 4, 4, 4. Значение на пороге или выше соответствует отмечаемому источником признаку; тип воспитания выводится по сочетанию признаков, а не по отдельной шкале.
- Формула: сумма кодов «Да» по пунктам шкалы и указанной дополнительной группы (если она есть); код «Нет» = 0. Реверсия отсутствует. Ручная проверка в модуле: десять «Да» по дополнительной и основной группе Г+ дают Г+ = 10, остальные шкалы = 0.
- Ограничение версии: исходные формы 3–10 лет и 11+ лет различаются текстом. Использована только детская форма; эта запись не заявляет подростковую версию.
