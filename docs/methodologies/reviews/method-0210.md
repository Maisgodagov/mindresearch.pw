# Диагностика мотивов профессиональной деятельности специалиста (Т. Н. Францева, 2010)

- Решение: `blocked` — пригодный русский текст доступен, но надёжный полный ключ для точного автоматического подсчёта по доступным источникам не подтверждён.
- Русский бланк: [«Диагностика мотивов профессиональной деятельности специалиста — Бланк»](https://psytests.org/work/dmpd-bl.html) содержит 60 утверждений и варианты ответа от «Да, конечно» до «Нет, конечно». Бланк сайта прямо предупреждает, что номера ответов обозначают колонки, а не баллы для подсчёта, и рекомендует брать оригинальный бланк и инструкции по подсчёту из первоисточника.
- Публикация: [Т. Н. Францева, «Опросник для диагностики мотивов профессиональной деятельности специалистов»](https://cyberleninka.ru/article/n/oprosnik-dlya-diagnostiki-motivov-professionalnoy-deyatelnosti-spetsialistov), *Вестник Самарской гуманитарной академии. Серия: Психология*, 2010, № 2, с. 146–160. Полный текст публикации на странице издателя/агрегатора при проверке был закрыт проверкой доступа; доступная выдача подтверждает описание авторского опросника, но не предоставляет проверяемую таблицу ключа.
- Дополнительное подтверждение состава: [описание методики Францевой в исследовании профессиональной мотивации сотрудников научной организации](https://scipress.ru/pedagogy/articles/professionalnaya-motivatsiya-sotrudnikov-nauchnoj-organizatsii.html) называет шесть мотивов и кратко описывает их, но не содержит полного соответствия каждого из 60 пунктов шкалам и реверсивным ключам.
- Количество пунктов: 60. Ответы: пять градаций согласия. Подтверждённые названия шкал-мотивов: жизнеобеспечение, взаимодействие, познавательный мотив, активность, признание, самореализация. Источник также описывает пять способов регуляции мотивов: ценностную, эмоциональную, социальную, волевую и информационную.
- Формула: не реализована. Нельзя надёжно определить ключи всех пунктов, реверсивные пункты и правила агрегирования по доступному проверяемому источнику; приписывание пунктов шкалам по смыслу было бы догадкой. Следовательно, модуль с `scoringConfig` и `validationCases` не создавался.
