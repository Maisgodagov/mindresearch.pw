# Вопросник для выявления признаков вегетативных изменений — Вейн (1998)

- Решение: подготовлено; русский текст и однозначный балльный ключ доступны.
- Русский текст: [клинические рекомендации Минздрава РФ «Паническое расстройство», приложение Г1 (2024)](https://base.garant.ru/410407475/57ef4c56fa237671fb2de46e273bb55e/); формулировки также сверены с [публикацией таблицы вопросника](https://medi.ru/info/5651/) и [страницей методики](https://psytests.org/diag/svdvein.html).
- Ключ: в клинических рекомендациях приведены веса всех признаков; публикация указывает суммировать баллы. «Да» получает вес соответствующего подпункта, «Нет» — ноль. Обратных пунктов нет. Положительный порог — сумма строго больше 15.
- Состав: 11 пронумерованных вопросов, 14 учитываемых ответов-признаков (пункты 1–3 содержат по два отдельно оцениваемых подпункта).
- Шкала: общая сумма по 14 признакам, веса соответственно 3, 3, 3, 4, 5, 5, 4, 7, 7, 6, 7, 7, 5, 5; диапазон 0–76.
- Формула: Σ(ответ «Да» по признаку × вес признака); «Нет» = 0. Дисфункция констатируется при результате >15. Детальные уточнения к вопросам 4, 6, 8, 9 и 11 не имеют в приведённом ключе дополнительных баллов.
