# 1097. Опросник оценки уровня тревоги о здоровье

Решение worker: `blocked`.
Основание: Русский бланк SHAI-18 доступен, но надёжно подтвердить ключ и точный подсчёт именно этой версии по первоисточнику не удалось: Psytests предупреждает, что его бланк не оригинальный и отсылает за подсчётом к первоисточникам; найденные описания ключа доступны только на вторичных страницах. По workflow в этой ситуации нельзя угадывать, поэтому файлы не созданы.
