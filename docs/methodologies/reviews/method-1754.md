# Тест Маркерта (Christopher Markert, 1968; русское описание А. Добровича, 1972)

- Статус: `ru-ineligible`.
- Русский текст: страница [«Проективный тест Маркерта» на Psytests](https://psytests.org/fun/markert.html) описывает выбор фигур и ссылается на русскоязычную статью А. Добровича «В каком вы настроении?» (1972, № 6 журнала «Знание — сила»). Та же страница прямо сообщает, что полного перевода на русский нет, а журнальные интерпретации существенно сокращены. Доступного полного русского текста стимулов/пунктов и инструкции, достаточного для точного воспроизведения, не установлено.
- Ключ и подсчёт: первоисточник — [Christopher Markert, *This Person Is You* (Branden Press, 1968)](https://psytests.org/fun/markert.html) — назван в библиографии страницы методики; страница также ведёт к [оригинальному англоязычному тесту *This Person Is You*](https://psytests.org/fun/markert.html). Русская страница не публикует полный точный ключ/алгоритм; однозначное соответствие всех стимулов и подсчёта для автоматической реализации по доступным русским материалам подтвердить нельзя.
- Пунктов и шкал: русский источник сообщает о выборе из восьми абстрактных фигур; подтверждённый русский перечень пунктов, шкал и формула подсчёта отсутствуют.
- Решение: модуль не создаётся, поскольку нет пригодного полного русского текста и по доступным материалам нельзя подтвердить точный реализуемый ключ. Ничего не реконструировалось по догадке.
