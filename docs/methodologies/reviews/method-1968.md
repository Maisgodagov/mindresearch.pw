# Уровень невротической астении (УНА), версия НИПНИ

- Решение: `prepared`. Русский текст и полный однозначный ключ найдены в методических рекомендациях разработчиков.
- Русский текст: [Бланк УНА на PsyTests](https://psytests.org/diag/una-bl.html) и [методические рекомендации, приложения 1–4 (инструкция, опросник и коэффициенты)](https://studfile.net/preview/15556109/page:3/).
- Источник методики и подсчёта: [Вассерман Л. И., Вукс А. Я., Иовлев Б. В. и др. Шкала для психологической экспресс-диагностики уровня невротической астении (УНА): методические рекомендации. СПб.: НИПНИ им. В. М. Бехтерева, 1999](https://studfile.net/preview/15556109/). В документе приведены коэффициенты ответов по двум формам.
- Каталоговая страница: [Уровень невротической астении, УНА — описание и библиография](https://psytests.org/diag/una.html). Навигационный путеводитель: [Соматические симптомы: тесты и опросники](https://psytests.org/guide/clinical-somatic-ru.html).
- Пункты: 38 утверждений; ответы: «Почти всегда», «Часто», «Иногда», «Редко», «Почти никогда».
- Шкалы: мужская и женская версии УНА с раздельными таблицами диагностических коэффициентов. Формулировки типа «Я уверен в себе», «У меня хороший аппетит» и «Я просыпаюсь утром свежим и отдохнувшим» имеют обратное направление; они уже обработаны знаковыми коэффициентами источника и отдельно не реверсируются.
- Формула: для выбранной категории ответа каждого пункта берётся опубликованный коэффициент соответствующего пола; итог `As = сумма Dᵢ` по 38 пунктам. Отрицательный итог соответствует профилю ответов, более характерному для группы больных неврозами, положительный — для здоровых. Модуль сохраняет сырые дискриминантные суммы; вероятностные интервалы и нормы не включены.
- Ограничение реализации: формы разделены как две шкалы, поскольку текущий общий формат регистрации не предусматривает выбор пола как отдельного поля; для содержательной интерпретации следует использовать результат соответствующей версии.
