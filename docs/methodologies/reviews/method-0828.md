- Источник и ключ: В. Ю. Рыбников, «Экспресс-методика “Прогноз-2” для оценки нервно-психической неустойчивости кандидатов на учебу в ВУЗ», тезисы I всеармейского совещания, М.: Воениздат, 1990, с. 132–135; библиографическая запись и описание версии приведены на странице [«Анкета Прогноз-2» Psytests.org](https://psytests.org/stress/prognozB.html). Полная таблица ключей и правил обработки опубликована в разделе [«Ключи» методики «Прогноз-2» ПсиЛаб](https://psylab.org.ua/tools_%D0%90%D0%BD%D0%BA%D0%B5%D1%82%D0%B0_%D0%BE%D1%86%D0%B5%D0%BD%D0%BA%D0%B8_%D0%BD%D0%B5%D1%80%D0%B2%D0%BD%D0%BE-%D0%BF%D1%81%D0%B8%D1%85%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B9_%D1%83%D1%81%D1%82%D0%BE%D0%B9%D1%87%D0%B8%D0%B2%D0%BE%D1%81%D1%82%D0%B8_%22%D0%9F%D1%80%D0%BE%D0%B3%D0%BD%D0%BE%D0%B7-2%22).
- Количество пунктов: 86; бинарные варианты ответа: «Да» / «Нет».
- Шкалы: искренность (15 ключевых ответов «Нет»); нервно-психическая устойчивость (59 ключевых совпадений «Да» и 11 совпадений «Нет»).
- Формула: по каждому пункту шкалы начисляется 1 за совпадение ответа с ключом, иначе 0; баллы суммируются. По НПУ источник также задаёт перевод суммы в стены: 41+ → 1; 40–35 → 2; 34–29 → 3; 28–21 → 4; 20–16 → 5; 15–10 → 6; 9–6 → 7; 5–4 → 8; 3–2 → 9; 1–0 → 10. Здесь сохраняется сырой балл. Для шкалы искренности источник не рекомендует использовать результаты при 10 и более баллах без выяснения причин.
- Ручной контроль: при ответе «Да» на все 86 пунктов шкала искренности = 0; НПУ = 59 (совпадения «Да» по 59 пунктам).
