# Дифференциальный тест перфекционизма (полная версия, 2013)

- Статус: `blocked` — регистрационный модуль не создаётся.
- Русский текст: полный 24-пунктовый бланк доступен в приложении 1 учебно-методического пособия; варианты шкалы согласия 1–7 и инструкция также приведены. Это вторичный воспроизводящий источник, а страница методики отдельно указывает русскую полную форму.
- Надёжный ключ: не подтверждён для полной версии. Первичная публикация подтверждает две равные шкалы, но найденная нумерация пунктов по шкалам и инструкция суммировать баллы доступны только во вторичном приложении. Этого недостаточно для надёжной автоматической реализации по заданному критерию.
- Объём и шкалы: 24 утверждения; нормальный перфекционизм (12 пунктов) и патологический перфекционизм (12 пунктов); ответы оцениваются по 7-балльной шкале согласия.
- Подсчёт: во вторичном приложении предписано суммировать ответы отдельно по шкалам; для реализации точный первичный ключ пунктов не подтверждён. Реверсивные пункты первичным источником для полной формы не установлены.
