# 594. Методика измерения типа ментальности

Решение worker: `blocked`.
Основание: Подтверждены русские формулировки и полный ключ, но текущий scoringConfig не умеет считать совпадения с разными ключевыми буквами для каждого пункта. Создать точную реализацию без изменения общей логики подсчёта невозможно; не стал подменять ключ неверным алгоритмом.
