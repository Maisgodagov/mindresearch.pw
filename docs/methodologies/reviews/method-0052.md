# Адаптированность студентов в вузе (Дубовицкая, Крылова, 2010)

- Решение: prepared.
- Русский текст: полный текст всех 16 пунктов и варианты ответа доступны в первоисточнике; формулировки перенесены без нумерационных цифр.
- Источники: [статья авторов в PsyJournals](https://psyjournals.ru/journals/psyedu/archive/2010_n2/27814) (включает текст опросника и ключ); [бланк PsyTests](https://psytests.org/learn/asvvuz-bl.html) (сверка текста и ответов); [страница методики](https://psytests.org/learn/asvvuz.html).
- Количество пунктов: 16; ответы: «Да», «Трудно сказать», «Нет».
- Шкалы: адаптированность к учебной группе (1–8); адаптированность к учебной деятельности (9–16). Каждая шкала: 0–16 баллов.
- Ключ и формула: прямые пункты 1, 3, 4, 6, 9, 10, 13, 14 оцениваются как 0/1/2 для ответов Да/Трудно сказать/Нет; обратные 2, 5, 7, 8, 11, 12, 15, 16 — 2/1/0. Балл каждой шкалы — сумма соответствующих восьми пунктов после перекодировки.
- Контрольный случай: все «Да» дают 8 баллов по каждой шкале: прямые пункты дают 0, обратные — 2.
