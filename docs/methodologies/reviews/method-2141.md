# Шкала измерения адаптированности к школе (RAPS; адаптация для 4–5 классов)

- Статус: `blocked`.
- Русский текст: страница методики содержит описание применения к ученикам 4–5 классов, а доступный бланк — 19 русскоязычных утверждений и варианты ответа: «Полностью так», «Частично так», «Частично не так», «Совсем не так».
- Ключ: не установлен. Каталог публикации подтверждает адаптационную статью, но полный текст статьи с ключом/подсчётом недоступен. Не переносил ключи с иных форм RAPS и не реконструировал соответствие шкал.
- Шкалы и подсчёт: не реализованы из-за отсутствия подтверждённого источника точного ключа.
