# Реабилитационный потенциал личности (Кулагина, Сенкевич)

- Статус: `blocked`.
- Русский текст доступен: авторская статья содержит 28 пунктов и три варианта ответа; на Psytests есть визуальный бланк. Целевая группа статьи и описания методики — люди с хроническими заболеваниями старше 16 лет.
- Надёжный ключ для точного автоматического подсчёта подтвердить не удалось. В авторской статье для внутренней картины болезни перечислены баллы 2 и 1 по десяти пунктам, но строка 0 баллов пропускает пункт 18. В воспроизводящей таблицу учебного пособия запись 0 баллов повреждена и дублирует для пункта 22 ответы, уже отнесённые к 2 баллам; это расходится с полным ключом статьи, где для пункта 22 А=2, Б=0, В=1. Страница Psytests прямо отмечает, что её бланк не оригинальный, и не заменяет первичный ключ. Отсутствующий нулевой балл пункта 18 нельзя достоверно вывести из доступных источников, поэтому модуль подсчёта не создавался.
