# Опросник «Уровень комплаентности»

- Решение: подготовлен русский вариант для пациентов с хроническими заболеваниями по опубликованному бланку из учебного пособия; не смешивать с отдельной версией psytests для здоровых людей.
- Русский бланк и точный ключ: [«Опросник “Уровень комплаентности”», учебное пособие по реабилитации, таблица 7, с. 57–61](https://irbis2.rmapo.ru/_UploadsFilesForIrbis/uchposobie_reabilitatsiya_ebzeeva_eyu_v_pechaty.pdf) — содержит все 66 формулировок, три набора пунктов и оценивание.
- Первичная публикация: [Р. В. Кадыров, О. Б. Асриян, С. А. Ковальчук. «Опросник “Уровень комплаентности”: монография» (Владивосток, Морской государственный университет, 2014, 74 с.)](https://www.klex.ru/pi6).
- Алгоритм дополнительно подтверждён в [патенте RU2014143868A «Способ психологического тестирования пациента»](https://patents.google.com/patent/RU2014143868A/en), опубликованном 27.05.2016: 22 пункта на каждую из трех шкал, «Всегда» = 2, «Иногда» = 1, «Никогда» = 0; суммы подшкал и общая сумма.
- Русская онлайн-страница для варианта здоровых: [PsyTests, «Уровень комплаентности» — описание](https://psytests.org/diag/ukompU.html) и [бланк прохождения](https://psytests.org/diag/ukompU-run.html). В этой регистрации использована хроническая форма из опубликованного выше бланка, а не вариант для здоровых.
- Количество и шкалы: 66 пунктов; социальная комплаентность — 22 пункта (2, 3, 7, 8, 9, 10, 11, 14, 18, 25, 26, 34, 40, 42, 43, 48, 50, 52, 55, 60, 64, 65); эмоциональная — 22 пункта (1, 4, 5, 13, 16, 17, 21, 24, 27, 28, 31, 33, 38, 41, 46, 49, 54, 56, 58, 59, 62, 66); поведенческая — 22 пункта (6, 12, 15, 19, 20, 22, 23, 29, 30, 32, 35, 36, 37, 39, 44, 45, 47, 51, 53, 57, 61, 63). Реверсивные пункты в опубликованном ключе не указаны, поэтому не добавлены.
- Формула: для каждого пункта ответу «Всегда» присвоено 2, «Иногда» — 1, «Никогда» — 0; шкальные баллы — простые суммы значений по указанным номерам. Общая комплаентность — сумма трёх подшкал (0–132 по фактической шкале ответов). В пособии и патенте напечатаны общие диапазоны 0–40 / 41–80 / 81–120, а также диапазоны подшкал 0–15 / 16–29 / 30–40, хотя при 22 пунктах и максимуме 2 достижимый максимум равен 44 на подшкалу и 132 в общей сумме. Сохраняем опубликованные пороги как справочные, но не создаём автоматическую категориальную интерпретацию за их пределами.
- Ограничение источника: [Капустина, Кадыров, Григорьева, «Анализ психометрических параметров опросника “Уровень комплаентности”» (2019)](https://portfolio.vvsu.ru/files/8FFCC2CB-8EED-4E41-A461-4805E747DB74.pdf) отмечает, что шкальная структура требует дальнейшей проверки, стандартизация не проводилась, а внутреннюю согласованность и независимость шкал нельзя считать установленными.
