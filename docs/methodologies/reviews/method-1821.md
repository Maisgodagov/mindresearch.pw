# Тест по выявлению уровня внутриличностной конфликтности (А. И. Шипилов)

- Решение: `prepared`. Доступен полный русский вариант из 36 ситуаций и опубликованы ключи и правила балльного подсчёта.
- Русский текст и бланк: [Тест по выявлению уровня внутриличностной конфликтности — Psytests, описание и бланк](https://psytests.org/emvol/uvlk.html); [Тест по выявлению уровня внутриличностной конфликтности — русская публикация вопросов, регистрационного бланка и ключа](https://dip-psi.ru/psikhologicheskiye-testy/post/test-po-vyyavleniyu-urovnya-vnutrilichnostnoj-konfliktnosti-a-i-shipilov).
- Библиография: А. И. Шипилов. *Психологические основы взаимодействия офицеров в трудных межличностных ситуациях*. Диссертация, 1999 (цитируется на [странице методики Psytests](https://psytests.org/emvol/uvlk.html)); А. Я. Анцупов, А. И. Шипилов. *Конфликтология: учебник для вузов*. СПб.: Питер, 2014. Регистрационный бланк и ключ также опубликованы в названной выше русской публикации.
- Пункты и варианты: 36 ситуаций; варианты с ключом: «Не переживаю», «Слегка переживаю», «Переживаю», «В отчаянии», «Открыто выражаю свои эмоции». В регистрационном бланке также есть «Другое», но балл для него не опубликован, поэтому вариант не включён в автоматически оцениваемый инструмент.
- Шкалы: шесть типов конфликта — мотивационный (6, 12, 18, 24, 30, 35), моральный (5, 11, 17, 23, 29, 36), нереализованного желания (4, 10, 16, 22, 28, 34), ролевой (3, 9, 15, 21, 27, 33), адаптационный (1, 8, 14, 20, 26, 32), неадекватной самооценки (2, 7, 13, 19, 25, 31). Три структуры: мотивация, долженствование, самооценка; также общий показатель.
- Подсчёт: «Не переживаю» и «Открыто выражаю свои эмоции» = 0; «Слегка переживаю» = 1; «Переживаю» = 2; «В отчаянии» = 3. Внутри каждой из шести групп баллы суммируются. Км = К1 + К2 + К3; Кд = К2 + К4 + К5; Кс = К3 + К5 + К6; Квк = К1 + К2 + К3 + К4 + К5 + К6. У варианта «Другое» в опубликованном ключе балл не задан, поэтому он не предлагается для автоматического оценивания.
- Контрольный расчёт: при выборе «Переживаю» во всех 36 пунктах каждая шестипунктовая шкала равна 12, Км = Кд = Кс = 36, Квк = 72.
