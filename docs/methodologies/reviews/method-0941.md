# Опросник для самооценки социальной значимости болезни (Сердюк)

- Решение: подготовлен; найден полный русский текст и однозначный ключ для десяти сфер.
- Русский текст: [Опросник для самооценки социальной значимости болезни, страница методики и бланк](https://psytests.org/diag/serduk.html) (страницы бланка/прохождения доступны по ссылкам со страницы методики); полный перечень утверждений приведён в учебно-методическом пособии [«Клинико-психологическая практика»](https://tgmu.ru/sveden/files/eir/MR_B2.O.03%28P%29_Kliniko-psixologicheskaya_praktika.pdf), с. 26–28 PDF.
- Источник ключа и содержания: [Б. В. Михайлов, А. И. Сердюк, В. А. Федосеев, «Психотерапия в общесоматической медицине» (Харьков: Прапор, 2002)](https://psytests.org/diag/serduk.html) — библиографическая ссылка на странице методики; воспроизведение текста и правил обработки опубликовано в [«Клинико-психологической практике»](https://tgmu.ru/sveden/files/eir/MR_B2.O.03%28P%29_Kliniko-psixologicheskaya_praktika.pdf), с. 26–28 PDF. Навигационное описание назначения также есть в [путеводителе «Здоровье и болезнь: тесты и опросники»](https://psytests.org/guide/clinical-health-ru.html).
- Пункты: 10 утверждений; респондент отвечает по пяти вариантам: «Наверняка нет», «Скорее нет», «Затрудняюсь ответить», «Пожалуй, да», «Безусловно да».
- Шкалы: десять самостоятельных показателей, по одному на пункт: ограничение силы и энергии; семейные отношения; удовольствия; отношения на работе; свободное время; карьера; физическая привлекательность; чувство ущербности; общение; материальный ущерб.
- Подсчёт: варианты кодируются соответственно 0, 1, 2, 3, 4 балла; каждый пункт образует одноимённый показатель в диапазоне 0–4 без реверсивных пунктов. По опубликованному правилу два последних ответа означают высокую/очень высокую значимость влияния болезни для соответствующей сферы. Общий суммарный балл источником не задан и не рассчитывается.
- Ручная проверка: все ответы «Безусловно да» дают 4 по каждой сфере; все ответы «Наверняка нет» дают 0.
- Ограничения: первоисточник указан в библиографии агрегатора; формулировки и правило кодирования сверены с опубликованным бланком пособия. Для компьютерной версии на сайте CPD приведены иные условные границы баллов, поэтому они не использованы.
