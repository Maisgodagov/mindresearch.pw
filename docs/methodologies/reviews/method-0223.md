# Диагностика потребностей, удовлетворяемых в интернет-среде — решение по регистрации

- Статус: `blocked`.
- Русский текст: доступен в диссертационном приложении «Интернет как институт социализации старших школьников» (В.А. Плешаков, Т.В. Обидина); поиск по опубликованному тексту показывает инструкцию («да», «нет», «иногда»), пять заявленных шкал и как минимум первый пункт. Страница Psytests из очереди также индексируется как русская карточка/пример.
- Источник методики: [«Интернет как институт социализации старших школьников» — текст диссертационного приложения с бланком](https://dissercatwww.dissercat.com/content/internet-kak-institut-sotsializatsii-starshikh-shkolnikov). [Страница методики Psytests: «Диагностика потребностей, удовлетворяемых в интернет-среде»](https://psytests.org/cyber/dpuis.html); [путеводитель Psytests по киберпсихологии](https://psytests.org/guide/cyberpsychology-ru.html).
- Ключ: в доступных фрагментах нет полного соответствия пунктов шкалам и правил числового подсчёта. Диссертация перечисляет физиологические, экзистенциальные, социальные, престижные и духовные потребности, но этого недостаточно для однозначной реализации. Ключ не реконструировался.
- Шкалы и подсчёт: пять названных шкал; алгоритм и правила подсчёта по источнику не установлены. Число пунктов в полном бланке надёжно не установлено.
- Решение: не создавать регистрацию, поскольку достоверный точный ключ/подсчёт не подтверждён.
