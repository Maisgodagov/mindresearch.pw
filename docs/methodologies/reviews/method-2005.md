# Характер взаимодействия супругов в конфликтных ситуациях (1987)

- Решение: prepared. Русский текст доступен; ключ пунктов, шкала и правило вычисления индексов опубликованы в описании обработки методики.
- Версия: мужской и женский варианты, по 32 ситуации каждый; в регистрации включены оба текста. Ответы кодируются значениями −2, −1, 0, +1, +2. Обратных пунктов нет.
- Шкалы: восемь тематических индексов — отношения с родственниками и друзьями (1, 5, 8, 20), воспитание детей (4, 11, 16, 23), автономия (6, 18, 21, 22), ролевые ожидания (2, 12, 27, 29), нормы поведения (3, 26, 28, 30), доминирование (9, 25, 31, 32), ревность (13, 14, 17, 24), деньги (7, 10, 15, 19).
- Формула: каждый ответ получает значение −2…+2 по указанной шкале реакции; индекс сферы = среднее арифметическое четырёх ответов этой сферы (диапазон −2…+2). Положительный знак отражает согласие/поддержку, отрицательный — несогласие; около ±1 — пассивную, около ±2 — активную реакцию. Отдельная сумма/нормативная классификация не добавлялась.
- Проверка примера: все ответы мужского варианта равны −2; вручную по каждому из восьми наборов из четырёх пунктов среднее равно (−2−2−2−2)/4 = −2.
- Описание первичного издания указывает, что полный текст печатной главы онлайн недоступен. Ключ и схема подсчёта сверены с опубликованной инструкцией обработки; русские формулировки ситуаций взяты из доступных мужского бланка и женского текста. Печатный вариант может иметь редакционные отличия.
