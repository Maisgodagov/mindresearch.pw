# Тест памяти на лица (Exposure Based Face Memory Test, EBFMT)

- Статус: `blocked` — адекватная русская инструкция доступна, но точный ключ и алгоритм подсчёта не удалось подтвердить согласованными первичными материалами.
- Русский текст: русская страница «[Тест памяти на лица](https://psytests.org/opm/ebfmt.html)» указывает, что участнику показывают последовательность фотографий, и для каждой нужно отметить, показывали ли лицо раньше или оно новое; русская версия прямо опубликована на странице прохождения. Перевод пригоден для задания бинарного распознавания.
- Первичный материал: [Exposure Based Face Memory Test — интерактивная версия OpenPsychometrics](https://openpsychometrics.org/tests/EBFMT/) описывает ту же задачу и предлагает проходить тест только один раз.
- Ключ и подсчёт: первичная страница разработки [Development of the Exposure Based Face Memory Test](https://openpsychometrics.org/tests/EBFMT/development/) описывает источник изображений и конструкцию, но не даёт полного ключа или формулы результата; кроме того, автор указывает на статистические и концептуальные проблемы теста. В открытых данных [Exposure Based Face Memory Test [dataset and codebook], Item Response Warehouse](https://itemresponsewarehouse.org/tables/face_memory_test/) указаны 175 пунктов и 5 категорий, тогда как в опубликованных результатах прохождения встречается показатель «из 75». Это не позволяет уверенно восстановить соответствие конкретных предъявлений правильным ответам и формулу итогового балла только по прямым источникам.
- Пункты и шкалы: последовательность изображений лиц, ответы «уже показывали» / «новое лицо»; число 175 относится к датасету с повторными наблюдениями, но расхождение с опубликованным знаменателем 75 мешает зафиксировать полный набор и точный алгоритм. Подшкал не заявлено.
- Решение: модуль не создан. Без согласованного полного ключа нельзя вручную запрограммировать точную оценку, не угадывая.
