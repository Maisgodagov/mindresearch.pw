# Психологический портрет родителя — Г. В. Резапкина

- Решение: подготовлена русская родительская форма из 50 пунктов; опубликованный ключ однозначно задаёт состав пяти шкал и категории ответов. Использована именно родительская форма, не вариант для учителей.
- Русский текст и бланк: [«Опросник “Психологический портрет учителя/родителя” (Г. В. Резапкина)», вариант для родителей](https://nsportal.ru/shkola/raznoe/library/2020/03/05/oprosnik-psihologicheskiy-portret-uchitelyaroditelya-po-rezapkinoy) — опубликованы все 50 вопросов с вариантами и таблица обработки; русский текст родительской формы.
- Описание версии и выходных шкал: [«Психологический портрет родителя» — страница методики Psytests](https://psytests.org/parent/pprrez.html) (автор указан как Г. В. Резапкина, 2006; отмечены пять шкал и ссылка на бланк).
- Каталог автора: [«Тесты Галины Резапкиной», раздел «Для педагогов и родителей»](https://psytests.org/work/rezapkina.html); указан источник Г. В. Резапкина, «Методический кабинет профориентации».
- Шкалы: приоритетные ценности (пункты 1, 6, 11, 16, 21, 26, 31, 36, 41, 46; отношения с детьми / со взрослыми / собственные переживания); психоэмоциональное состояние (2, 7, 12, 17, 22, 27, 32, 37, 42, 47; неблагополучное / нестабильное / благополучное); самооценка (3, 8, 13, 18, 23, 28, 33, 38, 43, 48; позитивная / неустойчивая / негативная); стиль воспитания (4, 9, 14, 19, 24, 29, 34, 39, 44, 49; демократический / либеральный / авторитарный); субъективный контроль (5, 10, 15, 20, 25, 30, 35, 40, 45, 50; высокий / не сформированный / низкий).
- Формула: в каждом пункте один из трёх текстовых вариантов соответствует категории шкалы (1-й, 2-й или 3-й вариант согласно таблице ключа). Считать количество выбранных вариантов каждой категории внутри её десяти пунктов; это и есть балл соответствующей подшкалы, диапазон 0–10. Реверсивных пунктов ключ не задаёт. Авторская интерпретация отмечает преобладание при более чем пяти выборах; равенство категорий указывает на сочетание признаков. Платформа хранит эти счётчики отдельно и не навязывает пороговую классификацию.
- Проверка подсчёта: вручную составленный ответный набор воспроизводит опубликованный на странице Psytests пример частот 3/4/3, 1/7/2, 2/6/2, 1/6/3 и 2/4/4. Родительская форма отличается от учительской в формулировках ряда пунктов, поэтому использован отдельный родительский бланк NSportal.
