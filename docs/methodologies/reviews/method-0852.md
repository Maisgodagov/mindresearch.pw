# 852. Опросник ассертивности

Решение worker: `blocked`.
Основание: Русский бланк доступен, но надёжный точный ключ не подтверждён первоисточником. В книге Хохлова и Портновой есть авторский опросник; доступный фрагмент не содержит ключа или подсчёта. Ключ и формула найдены только во вторичной учебной презентации, а бланк psytests.org отмечает, что пункт 64 пропущен в оригинальной публикации. По workflow нельзя угадывать или переносить непроверенный ключ. Разрешённые файлы не создавались.
