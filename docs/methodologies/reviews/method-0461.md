# Краткий отборочный тест (КОТ), версия по изданию МВД 1997 года

- Статус: подготовлено.
- Русский текст: полный доступный бланк найден в приложении к [«Я выбираю элективный курс» (приложение 6, с. 24–31)](https://www.brroo.ru/files/cro/virtpk/teach/%D0%AF%D0%B2%D1%8B%D0%B1%D0%B8%D1%80%D0%B0%D1%8E_%D1%8D%D0%BB%D0%B5%D0%BA%D1%82%D0%B8%D0%B2%D0%BD%D1%8B%D0%B9_%D0%BA%D1%83%D1%80%D1%81_%D0%9A%D1%83%D0%B7%D0%BD%D0%B5%D1%86%D0%BE%D0%B2%D0%BE%D0%B9_%D0%9B.%D0%93.pdf); страница содержит инструкцию, 50 заданий, ключ и правила подсчёта. Тот же вариант обозначен как основанный на [издании Методического центра МВД РФ (1997)](https://psytests.org/iq/kotM.html).
- Библиография: В. Н. Бузин, «Краткий отборочный тест», Психодиагностическая серия, вып. 4, М.: Смысл, 1992 ([каталожная запись НБУВ](https://irbis-nbuv.gov.ua/cgi-bin/irbis_nbuv/cgiirbis_64.exe?C21COM=S&I21DBN=EC&P21DBN=EC&S21CNR=20&S21COLORTERMS=0&S21FMT=JwU_B&S21P01=0&S21P02=0&S21P03=U%3D&S21REF=10&S21STN=1&S21STR=%D0%AE9+%D1%8127%24)); «Краткий отборочный тест», М.: Методический центр МВД РФ, 1997 (библиографические сведения и идентификация версии приведены на [странице КОТ psytests.org](https://psytests.org/iq/kotM.html)). Русский бланк и ключ см. в приложении, ссылка выше.
- Объём и шкалы: 50 разнородных заданий; единственный суммарный показатель — число правильных ответов (0–50), по одному баллу за задание. Отдельных субшкал источник не задаёт.
- Формула: сумма индикаторов правильности ответов для пунктов 1–50; незаполненный или неправильный ответ даёт 0. Применяется опубликованный ключ для каждого пункта. В нескольких заданиях правильный ответ многозначный (например, в № 3 и № 21), все допустимые ответы перечислены в ключе. Обратных пунктов нет.
- Проверка ключа: вручную сверены пункты № 1–5 с ключом источника; например, № 1 = вариант «ноябрь» (ключ: 3), № 2 = «мягкий» (ключ: 3), № 3 допускает варианты «доверие» и «сомнительный» (ключ: 2 или 4).
- Интерпретационные ограничения: бланк приводит нормативные диапазоны для учащихся 5–11 классов и взрослых, однако автоматическая регистрация показывает только сырой балл, без нормативного вывода.
