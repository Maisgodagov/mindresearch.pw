## Подсчёт

- 36 пунктов, одна интегральная шкала; отдельные субшкалы не заданы.
- Ответы по порядку: «да» = 1, «скорее да, чем нет» = 2, «скорее нет, чем да» = 3, «нет» = 4. Пункты 1–35 учитываются напрямую; ответ на обратный пункт 36 преобразуется по формуле `5 − ответ` (1↔4, 2↔3).
- Сырой балл: сумма оценок после реверсирования пункта 36, диапазон 36–144. Направление обратное: меньший балл соответствует более высокому уровню абнотивности.
- Нормы из таблицы первоисточника (с. 44): 36–42 — максимально высокий уровень; 43–46 — стен 2; 47–51 — стен 3; 52–57 — стен 4; 58–62 — стен 5; 63–67 — стен 6; 68–72 — стен 7; 73–78 — стен 8; 79–83 — стен 9; 84–144 — максимально низкий уровень. В модуле рассчитывается сырой суммарный балл; таблица норм приведена здесь для справки.
- Ручная проверка: при ответе «да» на всех пунктах баллы 1–35 дают 35, пункт 36 реверсируется из 1 в 4, итог `35 + 4 = 39`.
