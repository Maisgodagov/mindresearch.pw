# Торонтская алекситимическая шкала TAS-26
- Решение: prepared; русский бланк содержит полный набор формулировок и инструкцию с пятью вариантами согласия.
- Русский текст: [бланк TAS-26 на PsyTests](https://psytests.org/diag/tas26-bl.html); страница методики указывает адаптацию НИПНИ им. Бехтерева (2005).
- Ключ и подсчёт: диссертация Глазковой о русскоязычной адаптации TAS-26, приложение Б, приводит прямое и обратное присвоение 1–5 и суммирование всех пунктов; [текст диссертации (PDF)](https://www.sechenov.ru/upload/iblock/9e7/443f1ennq3w4lq5j74sn43dtksfdzfn9/DISSERTATSIYA-Glazkova.pdf). Дополнительно сверен ключ обратных пунктов [в опубликованном бланке TAS-26](https://www.imaton.ru/mod_files/zoom_add_files/fle_file_zoom_add_files_7770.pdf): 1, 5, 6, 9, 11, 12, 13, 15, 21, 24.
- Количество пунктов: 26. Шкала: один суммарный показатель, теоретический диапазон 26–130.
- Формула: прямые пункты дают ответ 1–5; обратные (1, 5, 6, 9, 11, 12, 13, 15, 21, 24) дают 6 − ответ; итог — сумма всех 26 значений. Контрольный пример: ответы 3 по всем пунктам дают 78.
- Версия: русскоязычная адаптация TAS-26, НИПНИ им. Бехтерева (2005); не смешивать с TAS-20.
