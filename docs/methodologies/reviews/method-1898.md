# 1898. Тесты Каппони и Новака

Решение worker: `blocked`.
Основание: Страница очереди «Тесты из книг Каппони и Новак» — каталог из десяти разных тестов; доступное описание показывает лишь два теста на ассертивность. Их русские формулировки частично доступны, но надёжно подтверждённого полного ключа для конкретной версии нет. Найдены описания разных форматов и наборов пунктов: статья Беловой сообщает о версиях на 24 и 20 утверждений и приводит пороги для 20-пунктовой версии, а другие источники описывают варианты на 24 пункта с подсчётом по отдельным подшкалам. Они не подтверждают точный ключ для переданного пункта. По workflow нельзя угадывать или объединять версии, поэтому файлы не созданы.
