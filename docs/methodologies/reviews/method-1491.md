# Психологические типы любви — Фролова (2020)

- Решение: `blocked` — русский текст доступен, но надежный полный ключ и правила подсчета не удалось подтвердить по открытому первоисточнику.
- Русская версия: [Бланк «Психологические типы любви»](https://psytests.org/typo/ptlove-bl.html) содержит 48 утверждений и шестипозиционную шкалу согласия: от «Полностью не согласен» до «Полностью согласен». Страница отдельно предупреждает, что номера ответов обозначают колонки, а не баллы для подсчета; следовательно, её нельзя использовать как источник ключа.
- Публикация-источник: [С. В. Фролова. «Сущностные характеристики и методика диагностики психологических типов любви»](https://doi.org/10.18500/1819-7671-2020-20-4-439-448), *Известия Саратовского университета. Новая серия. Философия. Психология. Педагогика*, 2020, т. 20, вып. 4, с. 439–448. Статья описывает шесть типов (эрос, людус, сторге, прагма, мания, агапе), но проверить таблицу/правила полного подсчёта по доступному тексту публикации не удалось.
- Навигационная тематическая страница: [«Любовь и романтический опыт: тесты и опросники»](https://psytests.org/guide/close-love-ru.html) описывает охват шести типов, но не содержит ключа.
- Количество пунктов: 48. Ответы: 6 градаций согласия. Шкалы: шесть типов любви. Формула и распределение пунктов по шкалам не установлены; обратные пункты не подтверждены.
- Итог: модуль не создаётся, поскольку недостающий ключ нельзя угадывать.
