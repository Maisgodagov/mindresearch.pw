# 1150. Опросник профессиональных предпочтений

Решение worker: `blocked`.
Основание: Русский текст и ключ для 30 пунктов доступны, но опубликованный подсчёт присваивает баллы отдельно обоим вариантам каждого пункта (предпочтительный — 3 или 2, другой — 0 или 1). Для ответов из двух альтернатив текущая схема подсчёта не может точно применить ключ по сочетанию номера пункта и выбранного варианта. Не стал подменять её приблизительной формулой. Файлы не созданы.
