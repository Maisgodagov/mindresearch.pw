# Суицидная личность, СЛ-19 — П. И. Юнацкевич

- Статус: подготовлено; ключ однозначно опубликован в авторской книге.
- Русский текст: 19 пунктов и ответы «Да»/«Нет» сверены с мужским/женским бланком и таблицей 2.1 первоисточника. В регистрации грамматический род первых лиц объединён в нейтрально-инклюзивную форму; содержательная последовательность пунктов сохранена.
- Ключ: по таблице 2.2 первоисточника риск-ключевой ответ «Да» для пунктов 3–7, 9–11, 14–17; «Нет» для 1–2, 8, 12–13, 18–19. Совпадение ответа с ключом даёт 1 балл. Пункты с ключом «Нет» отмечены как обратные относительно кодировки ответа «Да».
- Шкала и формула: одна шкала суицидального риска, сумма совпадений, 0–19 баллов. По таблице 2.3 книги: 1–5 — низкий, 6–13 — средний, 14–19 — высокий диапазон риска. В `scoringConfig` реализована сырая сумма; пороговая интерпретация зафиксирована здесь, поскольку формат шкал регистрации считает совпадения по пунктам.
- Контроль: вручную рассчитаны оба крайних случая — полный ключ (19) и ни одного совпадения (0).
- Ограничение: источник позиционирует методику в контексте диагностики военнослужащих; не переносить пороги как самостоятельный клинический вывод на другие группы. Результаты требуют осторожной профессиональной оценки.
