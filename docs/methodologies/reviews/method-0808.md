# Определение административного стиля — Е. Е. Туник (2002)

- Решение: добавлено; русский текст и однозначный ключ доступны в публикации автора.
- Русский текст: 28 утверждений, четыре раздела по семь вариантов. Публикация содержит формулировки инструкции, все пункты и таблицу ключа.
- Целевая группа: руководители и администраторы образовательных учреждений; адаптированная автором форма.
- Шкалы: семь профилей стиля — демократичный, кооперативный, ограниченное участие, бюрократичный, невмешательство, благожелательно-деспотичный, авторитарный. В каждом разделе варианты ранжируются от 1 (наиболее характерный) до 7 (наименее типичный); каждое значение используется ровно один раз внутри раздела.
- Ключ/формула: для каждой шкалы сложить ранги четырёх соответствующих ей вариантов (по одному из каждого раздела). Наименьшая сумма — ведущий стиль, следующая наименьшая — вероятный вторичный; равные минимумы трактуются как совместно ведущие. Реверсивных пунктов нет.
- Контрольный пример: во всех разделах ранги А–Ж равны 1–7 соответственно; суммы стилей по опубликованному ключу: демократичный 8, кооперативный 12, ограниченное участие 16, бюрократичный 16, невмешательство 16, благожелательно-деспотичный 16, авторитарный 12. Это согласуется с опубликованной таблицей ключа и правилом суммы; проверочный случай в модуле использует отдельное циклическое распределение рангов.
