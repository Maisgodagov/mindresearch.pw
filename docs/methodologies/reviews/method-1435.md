# Предпочтительный тип будущей профессии (Е. А. Климов)

- Решение: подготовлена регистрация `test_1463` по 30-пунктовой русской версии для старшеклассников.
- Русский текст и бланк: [«Определение типа будущей профессии» в приложении к материалам профессиональных проб по журналистике](https://ruobr.ru/media/program_dod_files/797b94e70d364a82b25b9b284df88662.pdf), с. 17–18; текст и инструкция также приведены на [странице методики PsyTests](https://psytests.org/work/ptbp.html).
- Первоисточник: Е. А. Климов. [«Путь в профессию: пособие для старших классов общеобразовательной школы»](https://psytests.org/work/ptbp.html), Лениздат, 1974. PsyTests указывает это издание как первую публикацию вспомогательной таблицы для ориентировочного определения предпочтительного типа будущей специальности на основе самооценки.
- Независимый бланк с полным ключом: [«Программа профориентационного навигатора» (ЦДО «Хоста»), приложение «Определение типа будущей профессии»](https://cdod-hosta.ru/wp-content/uploads/2023/06/55274_Programma-Proforientatsionnyj-navigator-OU-72ch-TSDO-Hosta.pdf), с. 52–54 печатной нумерации (PDF 52–54). Подтверждает соответствие всех 30 пунктов пяти столбцам и веса 1/2.
- Количество пунктов: 30. Ответы: согласен (+), не согласен (−), сомневаюсь (зачеркнуть, ноль). В модуле они кодируются как 2, 0 и 1 соответственно; вес пункта 1/2 применяется при подсчёте. Реверсивных пунктов нет.
- Шкалы и формула: «человек — природа» (4, 7, 11, 18, 25, 28); «человек — техника» (2, 9, 13, 16, 21, 26); «человек — знаковая система» (5, 8, 14, 19, 22, 29); «человек — художественный образ» (3, 10, 12, 17, 24, 30); «человек — человек» (1, 6, 15, 20, 23, 27). По каждому столбцу считается алгебраическая сумма: согласие даёт +вес пункта, несогласие −вес, сомнение — 0; вес пункта по бланку равен напечатанному коэффициенту 1 или 2. Наибольшая сумма или суммы указывают на предпочтительный тип; максимум в каждом столбце — 8. Эти пять шкал реализованы с суммированием взвешенных кодированных ответов.
- Контрольный пример: при нулевых ответах по всем пунктам сумма каждой шкалы равна 0. При согласии по всем пунктам «человек — человек» (1, 6, 15, 20, 23, 27), с весами 1, 1, 2, 1, 2, 1, эта шкала равна 8, остальные — 0.
- Ограничение: результат представляет ориентир для профориентационного обсуждения со старшеклассником, а не окончательное предписание профессии.
