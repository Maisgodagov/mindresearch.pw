# Шкала эстетических эмоций (ЭстЭм)

- Статус: подготовлено для `test_2525`.
- Русский текст: опубликованный бланк русскоязычной адаптации содержит все 42 пункта и пять вариантов интенсивности; для вопроса можно привязать объект-переживание в формулировке инструкции формы.
- Надёжный ключ: приложение 5 статьи Шестовой и соавторов перечисляет фасетки, пункты и альтернативный ключ на четыре фактора. Реализация использует заявленную в статье семифакторную структуру и пункты фасеток. Пункт 37 входит в замешательство и заинтригованность согласно ключу. Обратное кодирование не указано.
- Шкалы и формула: ответы 1–5; среднее входящих пунктов по каждой из 7 шкал/объединённых групп фасеток. Шкалы: негативные эмоции (10 пунктов), прототипические эстетические эмоции (10), эпистемические эмоции (6), оживление (6), ностальгия / расслабление (4), развлечение (4), грусть (2). При пропуске ответа расчёт не выдаёт полный профиль; нормативные интерпретации не добавляются.
- Ручная проверка: ответ 3 на все пункты даёт 3 по каждой шкале.
- Ограничение выборки: российская апробация — 473 человека, преимущественно молодёжь Москвы; перенос на другие группы требует осторожности.
- Решение: оба критерия соблюдены; зарегистрировать русскоязычную версию ЭстЭм.
