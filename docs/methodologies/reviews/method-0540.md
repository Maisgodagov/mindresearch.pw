# Методика диагностики личностного роста школьников — форма для 5–8-х классов

- Статус: подготовлена для регистрации под кодом `test_582`.
- Русский текст: опубликованы инструкция и все 91 утверждение формы 5–8 классов. Для регистрации взята эта форма; форма 9–11 классов содержит отдельные формулировки и здесь не объединяется с ней.
- Надёжный ключ: источник содержит бланк из 13 строк, распределяющий каждый 13-й пункт в одну шкалу, и явный перечень прямых и обратных пунктов по каждой шкале. Это позволяет однозначно реализовать подсчёт.
- Пункты: 91 (13 шкал × 7 утверждений). Ответы — от −4 до +4 с девятью подписанными значениями согласия.
- Шкалы: семья; Отечество; Земля/природа; мир; труд; культура; знания; человек как таковой; человек как Другой; человек как Иной; телесное Я; внутренний/душевный мир; духовное Я.
- Формула: для каждой шкалы сложить семь числовых ответов; у перечисленных ключом обратных пунктов поменять знак перед сложением. Диапазон каждой суммы −28…+28. Интерпретационные диапазоны источника: +15…+28 — устойчиво-позитивное, +1…+14 — ситуативно-позитивное, −1…−14 — ситуативно-негативное, −15…−28 — устойчиво-негативное отношение. Нулевой балл остаётся отдельным нейтральным значением.
- Описание инструмента указывает измеряемые ценностные отношения, 13 аспектов, целевую группу и педагогическую пользу; это описание методики для автора опроса, не инструкция респонденту.

## Ручная проверка

При ответе +1 на пункт 1 (прямой, шкала семьи) и +1 на пункт 14 (обратный, та же шкала) сумма семьи равна +1 + (−1) = 0; остальные шкалы равны нулю. Второй validation case в модуле фиксирует этот пример. Все нулевые ответы также должны давать ноль по каждой шкале.
