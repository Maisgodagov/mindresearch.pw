# 101. Методика исследования адаптированности студентов в вузе — отложена

**Решение:** методически подходит для каталога, но не воспроизводить до прояснения прав.

- Дубовицкая и Крылова (2010) разработали русскую методику из 16 суждений для студентов; две шкалы: адаптированность к учебной группе (пункты 1–8) и к учебной деятельности (9–16).
- Ответы: «Да»=2, «Трудно сказать»=1, «Нет»=0. Прямые пункты: 1,3,4,6,9,10,13,14; обратные: 2,5,7,8,11,12,15,16. Для каждой шкалы суммируется соответствующая половина после реверсирования. Общий сырой балл — сумма обеих шкал.
- Первичная психометрическая проверка проводилась на N=167 студентах в России; приведены коэффициенты надёжности 0,90–0,92 и связь с методикой Роджерса—Даймонд r=0,82 на подвыборке N=64.
