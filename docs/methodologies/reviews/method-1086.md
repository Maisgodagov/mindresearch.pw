# Способ оценки внутренней стигмы (СОВС; русская адаптация ISMI)

- Статус: prepared; русскоязычный текст и однозначный ключ подтверждены первичной публикацией.
- Версия: 28-пунктовая адаптация Лутовой и соавт. (2022), предназначенная для взрослых пациентов с психическими расстройствами; испытана на амбулаторных и стационарных пациентах.
- Русский бланк: приложение 1, стр. 195–197 публикации содержит формулировки всех 28 пунктов и варианты ответа от «Нет» до «Да». Текст перенесён без нумерационных цифр в варианты ответов.
- Подсчёт: ответы 1–4; пункты 3, 9, 24, 28 реверсируются по формуле `5 − ответ`. Среднее по субшкалам: «Деморализация» (1, 6, 7, 10, 12, 15, 18, 19, 20, 22, 23, 26), «Самосегрегация» (2, 5, 8, 11, 13, 17, 21, 27), «Восприятие дискриминации» (4, 14, 16, 25), «Сопротивление стигме» (3, 9, 24, 28 после реверсии). Публикация определяет общий показатель как сумму баллов по четырём субшкалам, делённую на 28; значения сопоставляют с эталонными показателями приложения 2. В конфигурации модуля представлены четыре субшкальных средних; общий показатель не вынесен в отдельную шкалу, так как движок поддерживает только независимую агрегацию шкал.
- Проверочный случай: ответы и ожидаемые субшкальные значения из опубликованного примера 1 (стр. 191–192): деморализация 13/12, самосегрегация 1, восприятие дискриминации 1, сопротивление стигме 2,75. Авторский общий расчёт: (13 + 8 + 4 + 11) / 28 = 36/28 ≈ 1,2857; в тексте рядом приведено округлённое значение 1,3192, арифметически не соответствующее дроби 36/28. Это расхождение не затрагивает воспроизведение отдельных шкал, поэтому общий балл не включён в автоматические результаты.
- Ограничения применения по публикации: требуется способность пациента понимать формулировки и сотрудничать; референтная группа — взрослые пациенты психиатрического профиля. Нормативных выводов за пределами опубликованной валидизационной выборки не делается.
