# 714. Многофакторный опросник студенческого гнева

Решение worker: `blocked`.
Основание: Русский бланк содержит 36 пунктов и варианты ответов, а публикация адаптации подтверждает состав четырёх субшкал. Но доступные источники не дают надёжного ключа: для пунктов когнитивной субшкалы остаётся неясным направление подсчёта; ключ исходной школьной версии не подтверждён для студенческой модификации. Не стал угадывать. Файлы не создавал.
