# Двадцать вопросов общества Анонимных Игроков (GA20)

- Решение: добавить русскую версию.
- Русский текст: доступен полный бланк адаптации, указанной для А. А. Карпова и В. В. Козлова (2011); в модуль перенесены 20 формулировок и варианты «Да» / «Нет».
- Надёжный ключ: первоисточник Gamblers Anonymous сообщает, что большинство компульсивных игроков ответят «Да» как минимум на 7 вопросов. Подсчёт — число ответов «Да» (0–20); ориентир от 7, не диагностический вывод. Реверсивных пунктов нет.
- Шкалы: одна суммарная шкала количества ответов «Да» по всем 20 пунктам.
- Формула: `yesCount = Σ(answer_i)`, где «Да» = 1, «Нет» = 0, для i = 1…20. Версия формулы `gamblers-anonymous-ga20-ru-karpov-kozlov-2011-v1`.
- Ручная проверка: семь ответов «Да» и тринадцать «Нет» дают 7.
