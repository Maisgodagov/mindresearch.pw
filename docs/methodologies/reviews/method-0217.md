# 217. Диагностика особенностей самоорганизации

Решение worker: `blocked`.
Основание: Русский текст ДОС-39 и надёжный ключ найдены: 39 пунктов, шесть частных шкал, обратные пункты 5, 9, 21, 27, 35 в шкале коррекции и 27 в шкале волевых усилий; интегральный показатель — округлённое среднее стенов шести шкал. Однако скорингConfig проекта поддерживает только суммирование и среднее по ответам, а не опубликованный перевод сырых баллов каждой шкалы в стены с последующим усреднением. Поэтому точный алгоритм нельзя реализовать в разрешённом формате без изменения общего кода; не стал подменять его приближённым подсчётом. Разрешённые файлы не созданы.
