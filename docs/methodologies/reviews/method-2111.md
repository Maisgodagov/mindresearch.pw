# Шкала диспозиционной осознанности подростков (ШДОП; CAMM)

- Статус: подготовлено для локальной регистрации; код инструмента `test_2125`.
- Русский текст: все 10 пунктов и формулировки пяти вариантов ответа приведены в приложении А1 русскоязычной адаптационной статьи. Авторы использовали двойной перевод и проверяли формулировки на небольшой группе подростков.
- Надёжный ключ: статья прямо указывает, что реверсируются ответы по всем утверждениям, затем значения суммируются; более высокий итог соответствует большей осознанности. Реверс: 0↔4, 1↔3, 2 остаётся 2.
- Пункты и шкалы: 10 пунктов, одна общая шкала от 0 до 40. Публикация обсуждает двухфакторную структуру адаптации, но правила подсчёта задаёт для единого суммарного показателя; отдельные факторные баллы не рассчитываются.
- Формула: `сумма по пунктам (4 − исходный ответ)`; диапазон 0–40. Для русской выборки 13–15 лет авторы также приводят центильные интервалы и стены; они здесь не применяются для интерпретации результата.
- Проверка: вручную проверены крайние случаи: все ответы 0 дают 40 после реверса; все ответы 2 дают 20.
