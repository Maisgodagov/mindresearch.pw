# 733. Мотивационный профиль личности

Решение worker: `blocked`.
Основание: Русский текст доступен, но надёжный полный ключ для переданной версии установить нельзя: первичный бланк задаёт ответы «+ / = / − / ?» и ключ к другой редакции, а psytests использует пять иных вариантов ответа и отдельные формулировки. Перенос ключа между версиями был бы догадкой. Разрешённые файлы не создавались.
