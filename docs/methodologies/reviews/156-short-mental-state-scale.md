# Краткая шкала психического состояния

- Статус: `blocked` — недостаточно точное название для идентификации инструмента.

## Причина решения

Формулировка не содержит автора, сокращения, целевой группы или публикации. Ею могут обозначаться краткие скрининги психического здоровья, локальные формы оценки состояния или сокращённые версии конкретных тестов. Выбирать одну из них по догадке нельзя; соответственно нельзя безопасно зафиксировать полный бланк и ключ.

## Решение

Нужны автор/аббревиатура или источник из исходного списка. До уточнения не добавлять. Не подменять эту запись WHO-5, GHQ или иной краткой шкалой.
