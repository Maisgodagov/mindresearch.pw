# 939. Опросник для оценки типов патриотического поведения

- Решение: `prepared`. Полный русский текст и однозначный ключ найдены в приложении к публикации О. В. Гордяковой и А. Н. Лебедева.
- Русский бланк: [«Опросник для оценки типов патриотического поведения», приложение к статье на сайте «Психологической газеты» (PDF, 2 страницы)](https://psy.su/content/files/%D0%9E%D0%BF%D1%80%D0%BE%D1%81%D0%BD%D0%B8%D0%BA%20%D0%B4%D0%BB%D1%8F%20%D0%BE%D1%86%D0%B5%D0%BD%D0%BA%D0%B8%20%D1%82%D0%B8%D0%BF%D0%BE%D0%B2%20%D0%BF%D0%B0%D1%82%D1%80%D0%B8%D0%BE%D1%82%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B3%D0%BE%20%D0%BF%D0%BE%D0%B2%D0%B5%D0%B4%D0%B5%D0%BD%D0%B8%D1%8F.pdf): на первой странице 19 пунктов с ответами «Не согласен» / «Согласен», на второй полный ключ (плюс/минус по шкалам и таблица ответов А/В).
- Публикация и первоисточник ключа: [О. В. Гордякова, А. Н. Лебедев. «Чувство патриотизма и типы патриотического поведения молодых граждан России», *Психологические и психоаналитические исследования. Ежегодник 2017*, с. 307–327](https://psy.su/feed/9578/). На странице статьи доступно приложение с бланком и ключом.
- Страница русской онлайн-версии: [«Опросник для оценки типов патриотического поведения» на PsyTests](https://psytests.org/group/tpatp.html) называет авторов и три типа; страница результата показывает шкалы и диапазоны сырых баллов 0–17, 0–13, 0–10.
- Объём: 19 пунктов, дихотомические ответы. Шкалы: идеологический (17 ключевых пунктов), проблемный (13), конформный (10).
- Формула: ответ «Согласен» = 1, «Не согласен» = 0; на отмеченных в ключе минусовых пунктах ответ реверсируется как `1 − ответ`. По каждой шкале складываются ключевые значения. Диапазоны сырых баллов: 0–17, 0–13 и 0–10 соответственно. Ключевые плюс/минус группы и реверсивные пункты заданы в модуле по таблице приложения.
- Ручная проверка: при всех ответах «Не согласен» ожидаются 5/9/3; при всех ответах «Согласен» — 12/4/3 для идеологической, проблемной и конформной шкал.
