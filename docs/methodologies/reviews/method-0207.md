# Диагностика киберкоммуникативной зависимости — А. В. Тончева (2012)

- Решение: prepared. Русский текст всех 20 пунктов и ключ опубликованы в статье автора; бланк доступен для сверки формулировок.
- Русский текст и публикация: [А. В. Тончева. «Диагностика киберкоммуникативной зависимости», Науковедение, 2012, № 4, с. 1–5](https://cyberpsy.ru/tests/diagnostika-kiberkommunikativnoj-zavisimosti/). В публикации приведены инструкция, пункты, варианты шкалы, ключ и формула интерпретации; указана возрастная категория 10+.
- Бланк для сверки: [«Диагностика киберкоммуникативной зависимости» — бланк 20 пунктов](https://psytests.org/cyber/cybercom-bl.html). Это отображение ответов онлайн-теста, не оригинальный печатный бланк; указанная на нём шкала 1–5 совпадает с авторским ключом.
- Описание методики и библиография: [Страница методики «Диагностика киберкоммуникативной зависимости»](https://psytests.org/cyber/cybercom.html) указывает автора А. В. Тончеву (2012) и публикацию в журнале «Науковедение».
- Пункты: 20; один общий показатель.
- Шкала ответов: «Очень редко» = 1, «Иногда» = 2, «Часто» = 3, «Очень часто» = 4, «Всегда» = 5. Реверсивных пунктов нет.
- Формула: общий балл = сумма баллов по пунктам 1–20; диапазон 20–100. В публикации приведены уровни: 0–49 — низкий, 50–79 — средний, 80–100 — высокий. Поскольку при обязательных ответах шкала 1–5 даёт минимум 20, диапазон 0–19 недостижим.
- Контроль подсчёта: все ответы «Очень редко» дают 20; все ответы «Всегда» дают 100.
