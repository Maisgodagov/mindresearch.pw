# Типы гражданской идентичности — Р. В. Борисов

- Решение: добавить русскую версию опросника и опубликованный ключ трех шкал.
- Русский текст: все 15 формулировок и пятибалльные варианты ответа доступны в [бланке «Типы гражданской идентичности»](https://psytests.org/group/tgrid-bl.html). В бланке мужской вариант; формулировки представлены без изменения смысла. Основная [страница методики «Типы гражданской идентичности»](https://psytests.org/group/tgrid.html) указывает автора Р. В. Борисова и первичную публикацию.
- Ключ: Р. В. Борисов, [«Гражданская идентичность в терминах психодиагностики»](https://doi.org/10.21779/2542-0313-201631-4-95-99), *Вестник Дагестанского государственного университета. Серия 2: Гуманитарные науки*, 2016, т. 31, № 4, с. 95–99. Публикация является первоисточником инструмента и ключа; DOI ведет к странице публикации. Трехтипное деление методики также упоминается в исследовательском обзоре [«Методики оценки гражданской идентичности российской молодежи» О. В. Поповой](https://journals.rudn.ru/political-science/article/view/45151/ru_RU), с. 365–366. Для точного распределения пунктов по шкалам доступна [страница ключа «Типы гражданской идентичности»](https://statblank.com/metodiki/tipy-grazhdanskoy-identichnosti-borisov); описание ключа и алгоритм подсчета оттуда сверены с авторской публикацией по назначению и структуре методики.
- Количество пунктов: 15.
- Ответы и подсчет: «Согласен» = 4, «Скорее согласен» = 3, «В чем-то согласен, в чем-то нет» = 2, «Скорее не согласен» = 1, «Не согласен» = 0. Баллы суммируются отдельно по трем шкалам, каждая включает 5 утверждений и имеет диапазон 0–20.
- Шкалы: гиперпозитивная — пункты 4, 6, 8, 10, 11; позитивная — 1, 2, 7, 13, 15; негативная — 3, 5, 9, 12, 14. Реверсивных пунктов нет; общего суммарного балла нет. Интерпретируется профиль трех шкал/доминирующий тип, без внесения дополнительных пороговых норм.
- Формула: `score(scale) = Σ answer(item)` для пунктов данной шкалы; реверсирование не применяется.
- Ручной контрольный случай: если по всем пунктам выбрано «Согласен» (4), каждая шкала равна 20; если везде «Не согласен» (0), каждая равна 0.
