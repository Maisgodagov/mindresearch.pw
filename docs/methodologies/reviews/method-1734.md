# Тест жертвенной позиции личности (О. О. Андронникова, 2015)

- Решение: prepared. Полный пригодный русский текст и однозначный ключ доступны.
- Русский бланк: [«Тест жертвенной позиции личности — бланк» (psytests.org)](https://psytests.org/ipl/andzpl-bl.html), 36 утверждений, ответы «Да»/«Нет». Публикация указывает на мужской и женский бланки; регистрация содержит мужскую формулировку, с которой совпадают формулировки использованного бланка.
- Описание и библиографическая ссылка: [«Тест жертвенной позиции личности» (psytests.org)](https://psytests.org/ipl/andzpl.html) описывает назначение и приводит источник: О. О. Андронникова, *Формирование зависимого поведения как результат реализации виктимного потенциала личности*, Новосибирск: НГПУ, 2015. 309 с. ISBN 978-5-00023-884-4. Каталожная запись РГБ на электронное пособие: [запись 01008564249](https://search.rsl.ru/ru/record/01008564249).
- Источник ключа: приложение 2 диссертации [«Виктимность как фактор формирования жертвенной позиции личности» (русскоязычный текст диссертации, приложение 2, с. 168–170)](https://anacec.md/files/Covrova-teza_ru.pdf) воспроизводит все 36 утверждений, их четыре группы и ключевой ответ («Да»/«Нет») для каждого пункта. Ключ использован буквально: «Да» дает балл там, где указано «Да», а «Нет» — там, где указано «Нет»; без предположений о ключе.
- Количество и шкалы: 36 пунктов; по 9 пунктов в каждой суммируемой шкале: 1–9 «Жертвенная любовь», 10–18 «Жертва как наказание других», 19–27 «Жертвенность как наказание себя», 28–36 «Тип ролевой жертвы».
- Подсчет: по одному баллу за ключевой ответ; диапазон каждой шкалы 0–9. Обратные пункты относительно ответа «Да»: 1 и 7 (ключевой ответ «Нет»), 12 и 13 (ключевой ответ «Нет»). Другие пункты ключуются ответом «Да». Суммарный общий показатель не добавлен, поскольку в использованном ключе не задано отдельное правило его вычисления.
- Проверка реализации вручную по ключу приложения 2: все ответы «Нет» дают 2, 2, 0, 0 по четырем шкалам; все ключевые ответы дают 9 по каждой шкале. Эти случаи записаны как validation cases.
