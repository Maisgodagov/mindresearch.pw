# Опросник суеверности (Абитов, Акбирова, 2021)

- Решение: подготовлен; доступен адекватный русский текст и точный ключ в первичной публикации.
- Русская версия и ключ: [«Разработка опросника суеверности», И. Р. Абитов, Р. Р. Акбирова, «Психологические исследования», 2021, т. 14, № 75](https://psystudy.ru/num/article/view/145); полный текст PDF с приложением и инструкцией — [страницы 15–16 публикации (PDF, печатная нумерация 15–16)](https://psystudy.ru/num/article/download/145/87/92). Бланк psytests: [«Опросник суеверности — бланк»](https://psytests.org/life/suever-bl.html).
- Содержание: 29 оцениваемых утверждений и завершающий открытый вопрос о дополнительных ритуалах (не оценивается). Ответы: «Никогда» = 0, «Редко» = 1, «Часто» = 2, «Постоянно» = 3.
- Шкала одна — общий показатель «Суеверность». Формула: сумма значений ответов на пункты 1–29 (диапазон 0–87); обратных пунктов нет. Открытый пункт 30 не включён в подсчёт. В публикации указано исследовательское применение; исходная стандартизация охватывала взрослых 17–66 лет.
- Контроль расчёта: 29 ответов по 0 дают 0; 29 ответов по 3 дают 87.
- Описание инструмента: методика измеряет частоту культурно закреплённых суеверных верований и ритуального поведения, включая следование приметам и представления о сверхъестественном влиянии; подходит для исследовательских опросов взрослых в версии Абитова и Акбировой (2021).
