# 1004. Опросник личностных ориентаций Шострома

Решение worker: `blocked`.
Основание: Указанная страница описывает несколько разных русских адаптаций (150-пунктовую ЛиО, САТ, САМОАЛ и другие), но не содержит текст конкретной формы, а полный ключ доступен только в руководстве, которое не удалось сверить по первоисточнику. Найденная открытая краткая форма Джоунс—Крэндалл имеет 15 пунктов и собственный ключ, поэтому подмена ею пункта «Опросник личностных ориентаций Шострома» была бы угадыванием версии.
