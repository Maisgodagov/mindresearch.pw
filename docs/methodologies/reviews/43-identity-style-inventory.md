# Identity Style Inventory (ISI) — русская адаптация Берзонски

- Статус: `blocked` на проверке прав и точной версии.
- Русская апробация: Е. П. Белинская, И. Д. Бронин (2014), психометрическая проверка русскоязычной версии опубликована в журнале «Психологические исследования».
- Ограничение: оригинальная российская статья описывает конкретную версию, но условия цифрового воспроизведения полного бланка не подтверждены; до получения ясного разрешения вопросы не публиковать.

## Источники

- Первичная статья русской адаптации: https://psystudy.ru/index.php/num/article/view/630
- Полный текст статьи: https://psystudy.ru/index.php/num/article/download/630/734
