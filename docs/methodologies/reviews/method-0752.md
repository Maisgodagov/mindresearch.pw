# Мотивы выбора профессии — С. С. Гриншпун (24 пункта)

- Решение: подготовлено. Найдены пригодный русский текст и однозначное распределение пунктов по трём шкалам.
- Русский бланк: [«Мотивы выбора профессии» Гриншпуна, сборник тестов по профориентации](https://dm.tgl.ru/sp/pic/File/Budushee_nachinaetsya_segodnya/Sbornik_testi_Proforientatsiya.pdf), стр. 6–7 PDF: полный перечень из 24 мотивов и бинарная отметка «значим / не значим».
- Ключ и правила: тот же [сборник, стр. 7 PDF](https://dm.tgl.ru/sp/pic/File/Budushee_nachinaetsya_segodnya/Sbornik_testi_Proforientatsiya.pdf) содержит таблицу ключа А/Б/В; [карточка Psytests «Мотивы выбора профессии»](https://psytests.org/work/mvprof.html) подтверждает три группы: престиж, заработок, реализация. Первоисточник: С. С. Гриншпун, «Оценка личностно-делового потенциала учащихся в профориентационной работе», «Школа и производство», 1994, № 6, с. 11–12.
- Число пунктов: 24. Варианты ответов: «Не значим» (0), «Значим» (1). Реверсивных пунктов нет.
- Шкалы и ключ: Престиж — 3, 4, 7, 17, 18, 19, 21, 24; Заработок — 5, 8, 11, 14, 15, 16, 20, 23; Реализация — 1, 2, 6, 9, 10, 12, 13, 22.
- Формула: для каждой шкалы отдельно суммируются значения ответов её восьми пунктов; диапазон суммы 0–8. Пороги или нормы источники не приводят, поэтому отображаются только баллы.
- Описание для автора опроса: методика измеряет относительную выраженность престижных, материальных и связанных с творческой реализацией мотивов выбора профессии у школьников и студентов; результаты полезны для профориентационного обсуждения оснований выбора.
