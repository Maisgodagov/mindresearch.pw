# Волевые качества личности (ВКЛ), взрослый вариант

- Решение: prepared; доступна русская форма из 78 утверждений с инструкцией и четырьмя вариантами ответа.
- Русский текст: [бланк и ключ взрослого варианта](https://studopedia.net/3_51956_oprosnik-volevih-kachestv-lichnosti-mvchumakova-vzrosliy-variant.html); описание и возраст 18–35 лет: [страница ВКЛ](https://psytests.org/emvol/vkl.html).
- Надежность ключа: в публикации приведено соответствие всех пунктов девяти шкалам и разделение прямых/обратных пунктов; правило начисления 0–3 и реверса 3–0 приведено там же. Авторская статья подтверждает девять шкал: [Чумаков, 2006](https://psyjournals.ru/journals/pse/archive/2006_n1/Chumakov).
- Пункты: 78. Варианты: «Неверно» (0), «Скорее неверно» (1), «Скорее верно» (2), «Верно» (3).
- Шкалы: ответственность (8 пунктов), инициативность (10), решительность (8), самостоятельность (8), выдержка (10), настойчивость (7), энергичность (10), внимательность (8), целеустремленность (9).
- Формула: для прямого ответа использовать значение 0–3; для обратного — `3 − ответ`. Суммировать ориентированные значения отдельно по пунктам каждой шкалы. Общий балл в источнике указан как сумма по шкалам; нормативное преобразование в стены не реализовано.
- Проверка подсчета: включен вручную рассчитанный случай со всеми ответами 1; ожидаемые суммы получены как число прямых пунктов × 1 плюс число обратных × 2.
