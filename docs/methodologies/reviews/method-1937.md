# 1937. Треугольник драмы

Решение worker: `blocked`.
Основание: Страница русской версии «Треугольник драмы» недоступна для проверки: прямой источник возвращает Cache miss, поэтому не удалось подтвердить полный текст пунктов и однозначный ключ подсчёта. Путеводители PsyTests описывают тему, но не содержат ключа; угадывать или восстанавливать его по описанию нельзя. Разрешённые файлы не создавал.
