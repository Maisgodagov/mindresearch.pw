# Способность к самоуправлению (ССУ), 48 пунктов

- Статус: prepared; код регистрации `test_1654`.
- Русский текст: полный набор из 48 утверждений и бинарных ответов воспроизведён по [бланку «Способность к самоуправлению, ССУ»](https://psytests.org/emvol/ssu-bl.html); алгоритм проверен по [«Методике “Способность самоуправления” Н. М. Пейсахова» (учебно-методический PDF)](https://rumc.ggtu.ru/documents/praktiki/metodika_nm_peysahov.pdf) и сверочной публикации [«Методика способность самоуправления (тест ССУ) Н. М. Пейсахов»](https://minakovserhii.com/metodika-sposobnost-samoupravleniya-test-ssu-n-m-pejsaxov/). Описание и библиография также приведены на странице [«Способность к самоуправлению, ССУ»](https://psytests.org/emvol/ssu.html).
- Первоначальная библиография: Н. М. Пейсахов, Г. Ш. Габдреева. [«Методические указания к лабораторным занятиям по психологии»](https://psytests.org/book/peys1988.html). Казань: Казанский университет, 1988. Каталог подтверждает раздел СУ и наличие в издании ключа/диагностической шкалы; полный доступный ключ сверялся по указанному учебно-методическому PDF.
- Количество: 48 утверждений; ответы «Да» / «Нет».
- Шкалы: анализ противоречий, прогнозирование, целеполагание, планирование, критерий оценки качества, принятие решения, самоконтроль, коррекция и общая способность к самоуправлению.
- Ключ и формула: для каждой шкалы подсчитываются совпадения ответа с опубликованным знаком «+» (да) либо «−» (нет) по шести пунктам; общая сумма равна сумме восьми шкал. По примеру контрольной карточки «нет» для пункта 1, «да» для 17 и 33, «да» для 9, «нет» для 25 и «да» для 41 даёт 1 балл этапа 1. Общий результат сопоставляется с половыми диапазонами из источника (мужчины: 0–13, 14–22, 23–31, 32–40, 41–48; женщины: 0–11, 12–21, 22–30, 31–39, 40–48); каждый этап имеет диапазоны 0–1, 2, 3–4, 5, 6. В регистрации реализованы числовые суммы без нормативных текстовых заключений.
- Возрастное применение: сверочная публикация указывает учащихся 14–17 лет; расширять область применения этой версии в описании не предполагается.
- Контрольный случай: вручную сверена шкала анализа противоречий: «да» по пп. 1 и 25 при остальных ответах «нет» даёт 2; прочие семь шкал дают 0.
