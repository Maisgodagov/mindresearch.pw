# Опросник выраженности симптомов подросткового кризиса — форма для родителей

- **Решение:** подготовлен. Адекватный русский текст и полный ключ подсчёта опубликованы в авторском методическом приложении.
- **Русская версия/бланк:** [«Опросник выраженности симптомов подросткового кризиса В. Е. Василенко (форма для родителей)», приложение 1 в сборнике «Психолого-педагогическое сопровождение одаренных учащихся»](https://dokumen.pub/e6e8bd891fdeaff6f1e24d7e86d84403.html) (текст, инструкция, 44 пункта, ключ и обработка, с. 112–115 электронной пагинации). Вопросы в регистрации следуют этой родительской форме; грамматические варианты сын/дочь сохранены.
- **Публикация-основание:** [В. Е. Василенко, В. Р. Манукян. «Возрастные кризисы жизненного цикла»](https://pureportal.spbu.ru/ru/publications/---%28d1ea0f34-4e44-4bf0-bde8-bdade97d63f5%29/export.html), учебное пособие СПбГУ; указанное приложение ссылается на издание 2011 года. Библиографическая запись СПбГУ фиксирует также издание 2006 года.
- **Проверочная публикация:** [В. Е. Василенко, Е. М. Амарей. «Проявления возрастного кризиса в связи с параметрами эмоционального и социального интеллекта подростков»](https://pureportal.spbu.ru/files/129695731/_._._._.pdf), материалы 2024 года, с. 35–39; в исследовании названы отдельные шкалы опросника и общий показатель.
- **Навигационная страница русской онлайн-версии:** [«Опросник выраженности симптомов подросткового кризиса» на PsyTests](https://psytests.org/parent/vspkR.html). Ее веб-бланк предупреждает, что сам бланк не оригинальный и не содержит ключа подсчета; ключ здесь взят из авторского методического приложения, а не выведен из этой страницы.
- **Пункты:** 44; ответы кодируются от 0 до 3: «Нет», «Скорее нет, чем да», «Скорее да, чем нет», «Да».
- **Шкалы:** 11 сумм по четыре пункта: аффект неадекватности (1, 14, 25, 33); имитация (2, 12, 27, 39); оппозиция (4, 16, 23, 36); гиперкомпенсация (7, 22, 29, 41); группирование (8, 19, 31, 37); эмоциональная эмансипация (3, 18, 26, 35); нормативная эмансипация (5, 13, 28, 40); поведенческая эмансипация (9, 20, 30, 43); пространственная автономия (11, 15, 24, 38); хобби-реакции (10, 21, 32, 42); интерес к внутреннему миру (6, 17, 34, 44). Реверсивных пунктов нет. Каждая шкала: сумма четырёх ответов, диапазон 0–12; в источнике 0–4 — не выражен, 5–8 — средне выражен, 9–12 — сильно выражен.
- **Общий показатель:** сумма баллов по 11 шкалам / 132 × 100%. Эта итоговая формула зафиксирована в источнике; модуль кодирует проверенные суммы по каждой шкале и не добавляет отдельный производный показатель, который не поддерживается форматом scoringConfig.
- **Проверка расчёта:** вручную проверены крайние случаи по опубликованному ключу: все нулевые ответы дают 0 на каждой шкале; все ответы 3 дают 12 на каждой шкале. Каждый пункт входит ровно в одну из 11 шкал.
- **Ограничение источника:** приложение помечает опросник как находящийся на стадии апробации; возрастное применение — 10–12 и 13–15 лет. Не выводить диагностический диагноз из результата.
