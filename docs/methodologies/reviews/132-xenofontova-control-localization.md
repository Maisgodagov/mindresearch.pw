# Локализация контроля личности — Е. Г. Ксенофонтова

- Статус: `blocked`.
- Русская взрослая версия 1999 года — существенно переработанный вариант УСК; сообщается о проверке на 1610 испытуемых и 17 интерпретируемых шкалах/субшкалах.

## Источники

- Первичная статья: Ксенофонтова Е. Г. «Исследование локализации контроля личности — новая версия методики “Уровень субъективного контроля”», Психологический журнал, 1999, №2. Библиографическое описание и сведения о версии: https://psytests.org/trait/usklk.html
- Независимое описание взрослой версии (40 утверждений, диапазон 17–87 лет): https://fulltext.tspu.ru/OA/m2025-21.pdf

## Решение

Для цифровой реализации требуется первичная таблица ключей/норм и право воспроизведения. Доступные вторичные источники недостаточны для обещанной точности; не переносить ключ и не смешивать эту версию с УСК.
