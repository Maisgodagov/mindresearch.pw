# Дифференциальный опросник безразличия — К. В. Карпинский (2022)

- **Решение:** подготовлен. Русский текст и однозначный авторский ключ доступны в приложении к первичному изданию.
- **Русский текст и ключ:** [К. В. Карпинский, А. М. Колышко, Т. В. Парфёнова. «Современные методы психологической диагностики» (ГрГУ, 2022), приложение 7, бланк ДОБ, с. 372–373](https://www.researchgate.net/publication/362074412_The_Differential_Questionnaire_of_Indifference_Differencialnyj_oprosnik_bezrazlicia). Книга содержит все девять формулировок, инструкцию, варианты ответов и дешифратор.
- **Страница методики:** [«Дифференциальный опросник безразличия», PsyTests](https://psytests.org/trait/dob.html) — указывает автора, назначение и первоисточник.
- **Количество пунктов и ответы:** 9 утверждений; шесть вариантов согласия, кодируются 1–6 от «Совершенно не согласен» до «Совершенно согласен».
- **Шкалы и ключ:** аккомодативное безразличие — пункты 2, 5, 7; экстернальное — 3, 6, 9; интернальное — 1, 4, 8. По каждому пункту начисляется выбранный балл; реверсивных пунктов в авторском ключе нет. Общий показатель — сумма трёх субшкал, то есть сумма всех девяти пунктов.
- **Диапазоны дешифратора из источника:** аккомодативное 3–4 / 5–11 / 12–18; экстернальное 3–6 / 7–12 / 13–18; интернальное 3–4 / 5–10 / 11–18; общее 9–19 / 20–31 / 32–54 (низкий / средний / высокий). Эти пороги не используются как самостоятельные диагнозы.
- **Контрольный расчёт:** ответы 1–6, 2–1, 3–4, 4–5, 5–2, 6–3, 7–6, 8–4, 9–1 дают аккомодативное 9, экстернальное 8, интернальное 11, общее 28.
- **Формула:** `sum(ответы по пунктам шкалы)`; `total = accommodative + external + internal`.
