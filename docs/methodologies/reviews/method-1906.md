# Тип личности по Нэнси Мак-Вильямс — решение по регистрации

- Решение: `blocked` — не регистрировать: для этого экспериментального опросника не найден надёжный однозначный ключ и алгоритм подсчёта.
- Русский текст: доступен полный бланк из 90 утверждений; варианты ответа — пять градаций согласия.
- Источники текста и статуса: [«Тест на тип личности по Нэнси Мак-Вильямс» — описание методики Psytests](https://psytests.org/typo/nmw.html) называет тест экспериментальным опросником, созданным с помощью ИИ, и предупреждает, что валидизированных диагностических инструментов по типологии Мак-Вильямс не существует; [«Бланк: Тест на тип личности по Нэнси Мак-Вильямс»](https://psytests.org/typo/nmw-bl.html) содержит все 90 русских утверждений и пять вариантов от «Совершенно не согласен» до «Совершенно согласен».
- Ключ и подсчёт: надёжный источник ключа не найден. На странице бланка отдельно указано, что цифры ответов — только обозначения колонок, а не баллы, и что этот бланк не оригинальный. Страница результатов показывает названия шкал, но не публикует распределение пунктов по шкалам, реверсивные пункты или воспроизводимую формулу. Поэтому ключ нельзя восстановить без догадок.
- Библиография: [Нэнси Мак-Вильямс, «Психоаналитическая диагностика: Понимание структуры личности в клиническом процессе» (русское издание, 2001)](https://psytests.org/typo/nmw.html) указана в списке литературы страницы методики; эта публикация не подтверждает ключ именно данного экспериментального онлайн-опросника.
- Шкалы и формула: по странице результата заявлены десять профилей типа личности: психопатический, нарциссический, шизоидный, параноидный, мазохистический, обсессивно-компульсивный, истерический, депрессивно-маниакальный, депрессивный и маниакальный. Формула расчёта и ключевые номера пунктов не опубликованы; численные шкалы и формулу не реализовывать.
- Итог: условия по русскому тексту выполнены, условие надёжного ключа/подсчёта — нет. Модуль не создан.
