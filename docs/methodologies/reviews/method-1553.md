- Объем: 50 утверждений; ответы: «Почти всегда», «В большинстве случаев», «Иногда», «Редко», «Почти никогда».
- Структура: когнитивный компонент (1–10), эмоциональный (11–20), поведенческий (21–40), коммуникативная толерантность (41–50). В статье эти блоки названы четырьмя основными шкалами; опубликована формула только для обобщенного индивидуального балла, без отдельных баллов блоков.
- Подсчет общего балла: пункты 1–5, 11–15, 21–30, 41–45 кодируются частотами 5, 4, 3, 2, 1; пункты 6–10, 16–20, 31–40, 46–50 — обратно, 1, 2, 3, 4, 5. Сумма по всем 50 пунктам, диапазон 50–250; больший балл соответствует более высокому уровню. Обратные пункты: 6–10, 16–20, 31–40, 46–50.
- Ориентиры из публикации: ≥220 — высокий; 180–220 — средний с тенденцией к высокому; 140–180 — средний; 100–140 — средний с тенденцией к низкому; <100 — низкий. Границы 180, 140 и 100 в публикации пересекаются в записи интервалов; поэтому в автоматическое начисление категории они не включены.
- Область применения по автору: самодиагностика коммуникативной компетентности студентов вуза в поликультурной среде; самостоятельное оценивание не является экспертным измерением.
