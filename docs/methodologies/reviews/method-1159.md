# 1159. Опросник психологической безопасности

Решение worker: `blocked`.
Основание: Надёжный ключ найден для опубликованного варианта педагогов (90 пунктов), но он не совпадает с исходным вариантом opbA для учащихся (поиск обнаружил отдельную ученическую форму из 90 пунктов с иной нумерацией и составом). Доступный источник ключа не устанавливает, что его можно применить к версии очереди; точный ключ и русская форма opbA не подтверждены для одного и того же варианта. Не стал угадывать соответствие; файлы не создавал.
