# 1602. Скрининг-тест на сексуальную аддикцию

Решение worker: `blocked`.
Основание: Русский перевод SAST-R на psytests.org существует, однако источник прямо указывает, что сведений о его адаптации нет и подсчёт сделан по оригинальным материалам. Не удалось подтвердить надёжный точный ключ именно для этой русской формы: найденный бланк ключа относится к англоязычной версии и содержит оговорку о предварительном характере подсчёта. Чтобы не переносить неподтверждённый ключ или не угадывать, файлы не созданы.
