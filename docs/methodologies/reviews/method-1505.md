# Пятифакторный личностный опросник для МКБ-11 (FFiCD)

- Статус: `blocked`.
- Русский материал: русская публикация клинической рекомендации содержит бланк на 121 пункт, однако текст извлечённой копии имеет явные пропуски/склейки (например, пункт 73 отсутствует, а пункт 39 склеен с посторонним текстом). Страница psytests.org, указанная в очереди, содержит вариант только на 60 пунктов, что не совпадает с FFiCD.
- Надёжный ключ: не найден для 60-пунктового русского варианта. Первичная публикация FFiCD описывает 121 пункт и 20 фасет, но доступная русская версия с бланком и ключом указывает на 121 пункт; из неё нельзя обоснованно реконструировать ключ для отдельной 60-пунктовой формы. Поэтому регистрация не создаётся.
- Масштаб/подсчёт, подтверждённые для оригинала: 5 доменов и 20 фасет; для русского бланка задано согласие по шкале 1–5 (1 — абсолютно не согласен, 5 — абсолютно согласен). Точного ключа для 60-пунктового варианта не установлено.
- Источники:
  - Oltmanns, J. R., & Widiger, T. A. (2020). [The Five-Factor Personality Inventory for ICD-11: A Facet-Level Assessment of the ICD-11 Trait Model](https://pubmed.ncbi.nlm.nih.gov/31414852/), *Psychological Assessment*, 32(1), 60–71 — первичная публикация, определяет FFiCD как 121-пунктовую меру с 20 фасетами.
  - Минздрав России. [Клинические рекомендации «Специфические расстройства личности», приложение Г2: русская версия FFiCD](https://www.consultant.ru/document/cons_doc_LAW_484486/8c5f4c0163561e0075e709da7cfa97ca5eca4614/) — опубликованный русскоязычный бланк и ссылка на версию переводчиков на Figshare.
  - [Пятифакторный личностный опросник для МКБ-11, FFiCD — страница методики psytests.org](https://psytests.org/diag/fficd.html) и [бланк](https://psytests.org/diag/fficd-bl.html) — указанные в очереди русские страницы; представленный бланк содержит 60 пунктов и не согласуется с описанием исходного FFiCD.

Итог: критерий адекватной русской версии и однозначного полного ключа для одного и того же варианта одновременно не подтверждён; пункты и ключ не угадывались.
