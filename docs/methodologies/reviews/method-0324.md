# 324. Индекс групповой сплоченности Сишора

Решение worker: `blocked`.
Основание: Русский бланк с пятью пунктами доступен, но сам сайт указывает, что это не оригинальный бланк и что ключ следует брать из первоисточника. Надёжный точный ключ для этой русской версии подтвердить не удалось: первоисточник описывает иной индекс группового уровня, а найденные таблицы баллов размещены в непервичных пересказах. По условию не стал угадывать ключ и не создавал файлы.
