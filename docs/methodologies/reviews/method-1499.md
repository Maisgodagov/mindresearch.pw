# Психологический портрет учителя (версия учитель, Г. В. Резапкина)

- Статус: `prepared`
- Русский текст: 50 пунктов и по три варианта ответов; использована учительская форма, опубликованная в сборнике Г. В. Резапкиной «Отбор в профильные классы» (2005). Нумерация ответов не включена в подписи вариантов.
- Ключ: подтверждён полной русской копией бланка и обработки; в каждой шкале по 10 вопросов, варианты a/b/c задают три категории, за каждый совпавший с ключом ответ начисляется один балл.
- Шкалы и формула: приоритетные ценности (отношения с учениками / с коллегами / собственные переживания), психоэмоциональное состояние (неблагополучное / нестабильное / благополучное), самооценка (позитивная / неустойчивая / негативная), стиль преподавания (демократический / либеральный / авторитарный), субъективный контроль (высокий / недостаточно сформированный / низкий). Для каждой категории сумма равна числу ответов соответствующего варианта на 10 назначенных ей пунктов (0–10). Интерпретация — по преобладающей категории; при равенстве описывается сочетание признаков. Реверсивные пункты источником не заданы.
- Ограничения: это самодиагностика для учителя; авторы запрещают использовать методику для аттестации и кадровых решений. Версия для родителей не включена.
