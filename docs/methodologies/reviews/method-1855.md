# 1855. Тест Томаса-Килманна

Решение worker: `blocked`.
Основание: Надёжный точный ключ для доступного русского бланка не подтверждён. Psytests.org публикует 30 пар утверждений, но прямо указывает, что бланк не оригинальный; найденное методическое руководство Шаньгиной и Загорюева описывает отдельную версию TKI-R, и доступные источники не подтверждают соответствие её ключа этому бланку. Угадывать ключ нельзя, поэтому файлы не созданы.
