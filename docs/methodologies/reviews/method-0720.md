# Модифицированный тест-опросник — Я. Г. Анапреенко (2001)

- Решение: подготовлен; доступны пригодный русский текст всех пунктов и однозначное правило подсчёта из текста методического пособия.
- Русская форма: в пособии опубликованы все 100 утверждений с инструкцией отмечать согласие и таблицей 10 × 10; ответы в регистрации — «Да, согласен(на)» и «Нет, не согласен(на)». [Раздел 2.3 «Модифицированный тест-опросник» и анкета](https://www.bibliofond.ru/view.aspx?id=581392), пункты 1–100.
- Первоисточник и ключ: Анапреенко Я. Г. *Диагностика и коррекция поведения акцентуированных подростков: методическое пособие для сотрудников инспекций по делам несовершеннолетних*. Минск, 2001. [Текст пособия, описание процедуры и сетка ключа](https://www.bibliofond.ru/view.aspx?id=581392), раздел 2.3: согласованные утверждения отмечаются; каждая из десяти последовательных групп по десять утверждений соответствует одной шкале. Порог — не менее 6 отметок на шкале; при нескольких шкалах с пороговым значением выделяют наиболее выраженную или две наиболее выраженные.
- Страница русской версии: [«Модифицированный тест-опросник» — PsyTests](https://psytests.org/accent/anapr.html); ссылка [«бланк»](https://psytests.org/accent/anapr-bl.html) опубликована на странице методики, но сама страница бланка при проверке не загрузилась. Точный текст и ключ поэтому сверены по доступному полному тексту пособия.
- Количество пунктов: 100.
- Шкалы: астеничная (1–10), возбудимая (11–20), гипертимная (21–30), идейная (31–40), интроверсивная (41–50), конформная (51–60), лабильная (61–70), неустойчивая (71–80), педантичная (81–90), циклоидная (91–100).
- Подсчёт: согласие («Да») = 1, несогласие («Нет») = 0; балл шкалы — сумма десяти ответов, диапазон 0–10. Пункты в ключе направлены прямо, обратных пунктов нет. Порог источника: ≥6 отметок; при нескольких пороговых шкалах отмечают ведущую, возможно — две ведущие. Порог не изменяет числовой результат шкалы.
- Ограничение: автор описывает методику для несовершеннолетних подростков, в том числе подростков с поведенческими трудностями; результаты следует использовать как материал для специалиста, а не как самостоятельный диагноз.
