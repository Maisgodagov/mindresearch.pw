# 2015. Цветовой тест отношений

Решение worker: `blocked`.
Основание: Для страницы ЦТО Эткинда доступен русский бланк со списком значимых объектов и ранжированием цветов, но однозначный ключ подсчёта именно этой версии не подтверждён прямым источником. Найденный ключ из приложения Г2 клинических рекомендаций Минздрава относится к другой версии с фиксированным бланком понятий и трактовкой совпадений цветов; объединять версии нельзя. Файлы не созданы.
