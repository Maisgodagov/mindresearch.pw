# 821. Определение уровня агрессивности у ребенка

Решение worker: `blocked`.
Основание: Найден русский бланк из 20 пунктов и точное правило подсчёта (каждый ответ «Да» — 1 балл, «Нет» — 0), обратные пункты не указаны. Но пороги уровней расходятся: в бланке и одном учебном источнике это 1–5, 6–10, 11–15, 16–20, а другая публикация для той же анкеты приводит 0–5, 6–9, 10–14, 15–20. Не удалось надёжно установить пороги по первоисточнику, поэтому точный алгоритм неполон; файлы не создавались.
