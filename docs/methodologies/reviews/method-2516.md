# Шкалы знаков зодиака (ZAPS)

- Решение: `blocked` — точный ключ/подсчёт для русской версии 2023 года не подтверждён первоисточником.
- Русская страница: [«Шкалы знаков зодиака, ZAPS» — описание русской версии psytests.org](https://psytests.org/opm/zodiac.html), перевод указан как выполненный psytests.org в 2023 году. Страница описывает назначение опросника, но интерактивная форма [«Шкалы знаков зодиака, ZAPS»](https://psytests.org/opm/zodiac-run.html) при проверке не загрузилась, поэтому полный русский текст вопросов и варианты ответов не удалось сверить.
- Источник ключа: Eric Jorgenson, [Documentation for the Zodiac-sign Associated Personality Scales (ZAPS)](https://openpsychometrics.org/tests/ZAPS/documentation/), Open-Source Psychometrics Project. Документация сообщает о версии ZAPS 2.0 с 66 пунктами (по пять на знак и шесть пунктов с двойным ключом) и перечисляет точное распределение пунктов по шкалам. Она обновлена в 2025 году; соответствие этого ключа русскому переводу 2023 года не подтверждено. Использовать её ключ для русской формы было бы предположением.
- Пункты, шкалы и формула: для русской версии не реализуются, поскольку недоступен полный бланк и нельзя надёжно установить, к какой редакции относится перевод. В документации ZAPS 2.0 описаны 12 шкал знаков и подсчёт ответов отдельно по одно- и многоключевым пунктам; шкала ответа и точные правила преобразования ответов в баллы для версии psytests.org из просмотренных источников не установлены.
- Итог: регистрацию не создавать до доступности русского бланка и прямого подтверждения совпадающего с ним ключа.
