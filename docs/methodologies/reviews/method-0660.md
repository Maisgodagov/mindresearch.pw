# Методика оценки репрезентаций базовых культурных характеристик (Браун, Яницкий, 2015)

- Решение: prepared. Русский текст и однозначный ключ присутствуют в приложении к публикации авторов.
- Русская версия и бланк: [страница методики PsyTests «Методика оценки репрезентаций базовых культурных характеристик»](https://psytests.org/group/orbkh.html), [страница прохождения с инструкцией](https://psytests.org/group/orbkh-run.html).
- Первоисточник ключа и пунктов: О. А. Браун, М. С. Яницкий. [«Методика оценки репрезентации в массовом сознании базовых характеристик культурных типов по М. Мид»](https://journals.tsu.ru/uploads/import/1183/files/55-123.pdf) // Сибирский психологический журнал. 2015. № 55. С. 123–136. DOI: 10.17223/17267080/55/7. Полный бланк и таблица ключа — приложение, с. 133–134 (PDF, стр. 11–12); правила обработки — с. 126.
- Описание домена: [путеводитель PsyTests «Культура и межгрупповые отношения»](https://psytests.org/guide/social-culture-ru.html), раздел «Культурные ценности, социальные аксиомы и культурные измерения».
- Содержание: 6 пунктов с выбором одного из трёх высказываний (варианты A, B, C в ключе; в форме обозначены кириллическими буквами без цифр). Охватываются возрастной конформизм, ориентир при планировании будущего, проживание жизни молодым поколением, отношение к традициям, динамика жизни поколений и семейные межпоколенные связи.
- Шкалы и ключ: A = постфигуративная, B = кофигуративная, C = префигуративная. Все шесть пунктов входят в три шкалы частоты выбранного типа; обратных пунктов нет.
- Формула: для каждого типа посчитать число выборов соответствующей буквы среди шести ответов (диапазон 0–6). По статье профиль с равными частотами всех типов либо с равенством двух лидирующих частот — смешанный; доминирование определяется большинством ответов. При анализе выборки авторы также допускают суммирование частот ответов по каждому типу.
- Проверенный контрольный случай: ответы A, A, A, A, A, A дают постфигуративную 6, кофигуративную 0, префигуративную 0. Второй случай A, B, C, A, B, C даёт частоты 2, 2, 2 и смешанный профиль.
- Ограничение: авторы характеризуют методику как преимущественно качественную и отмечают, что надёжность и валидность требуют дальнейших исследований; результаты описывают восприятие культуры, не объективную классификацию народов.
