# Тест-опросник социальной адаптивности (Санникова, Кузнецова)

- Решение: подготовлено; опубликованы полный доступный русский текст и проверяемый ключ подсчёта.
- Русская версия и бланк: [Тест-опросник социальной адаптивности — страница и бланк (psytests.org)](https://psytests.org/life/sannsa.html) и [бланк с 80 утверждениями и четырьмя вариантами ответа](https://psytests.org/life/sannsa-bl.html). В бланке приведены формулировки пунктов и категории «Безусловно, да», «Пожалуй, да», «Пожалуй, нет», «Безусловно, нет».
- Первоисточник ключа: О. П. Санникова, О. В. Кузнецова. [«Системный анализ адаптивности личности» — монография (Одесса: ВМВ, 2017), глава 2.3, с. 58–84](https://dspace.pdpu.edu.ua/bitstream/123456789/17421/1/Sannikova%20Olha%20Pavlovna.pdf). Здесь опубликованы состав шкал, прямые/обратные утверждения, кодирование ответов и формула ОПА.
- Первоисточник методики: [«Тест-опросник социальной адаптивности» — страница методики (psytests.org)](https://psytests.org/life/sannsa.html), авторство О. П. Санниковой (2015); страница указывает на публикацию выше.

Методика включает 80 утверждений, сгруппированных в восемь блоков по 10 пунктов: ШОСС, ЛИСС, ТОСО, УЭП, ГИ, ГПН, ГДЦ и ПОУ. В каждом блоке прямые пункты оцениваются 4, 3, 1, 0 баллами по порядку ответов; обратные — 0, 1, 3, 4. Баллы суммируются в шкале (диапазон 0–40). ОПА — среднее семи основных шкал (ШОСС, ЛИСС, ТОСО, УЭП, ГИ, ГПН, ГДЦ); ПОУ в ОПА не входит. Процентильные нормы и интерпретационные категории не реализованы.

Ключ соответствует таблице первоисточника (с. 82): ШОСС — прямые 2, 3, 4, 6, 7, 9, 10; обратные 1, 5, 8. ЛИСС — прямые 2, 3, 5, 9; обратные 1, 4, 6, 7, 8, 10. ТОСО — прямые 1, 2, 5, 6; обратные 3, 4, 7, 8, 9, 10. УЭП — прямые 3, 4, 10; обратные 1, 2, 5, 6, 7, 8, 9. ГИ — прямые 5, 6, 7; обратные 1, 2, 3, 4, 8, 9, 10. ГПН — прямые 1, 3, 7, 8, 9; обратные 2, 4, 5, 6, 10. ГДЦ — прямые 2, 3, 5, 6, 7; обратные 1, 4, 8, 9, 10. ПОУ — прямые 1, 5, 6, 7, 10; обратные 2, 3, 4, 8, 9.

Описание `instrument.description` раскрывает измеряемое свойство, охватываемые компоненты и целевую группу; оно предназначено автору опроса, а не участнику.


## Решение после аудита 14–15.10.2026: удалена из каталога

Предыдущее решение prepared/verified не подтверждает работоспособность расчёта. Для test_1910 остались неразрешённые противоречия ключа, формата ввода, реализации или контрольных данных. По указанию владельца редакция снята из каталога; вопросы и ответы существующих опросов сохраняются. Автоматический расчёт и выдача её баллов отключены. Это не заключение о научной непригодности оригинальной методики.

Причины: unsupported-aggregation, valid-response-rejected, control-case-mismatch. Полная запись и зарегистрированные источники: [общий отчёт](../scoring-remediation-2026-10-14.md), [JSON](../scoring-remediation-2026-10-14.json).
