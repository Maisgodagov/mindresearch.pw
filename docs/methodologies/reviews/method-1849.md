# 1849. Тест Социальные фигуры

Решение worker: `ru-ineligible`.
Основание: Русская страница содержит инструкцию, но не предоставляет доступный полный текст вопросов: задания и варианты ответов скрыты в динамических видео. Исследования подтверждают 23 вопроса, четыре варианта и объективный ключ, однако восстановить полный русский инструмент и точно сопоставить ответы без самих стимулов нельзя. Файлы не созданы.
