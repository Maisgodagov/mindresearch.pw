# VSM-94 — решение о регистрации

- Статус: подготовлено (`test_83`).
- Русский текст: полный набор 20 содержательных пунктов и инструкции/варианты представлены в русской форме Psytests; адаптация указана как А. Н. Татарко, Н. М. Лебедева (2009). Страница Psytests описывает расчёт групповых индексов по средним ответам.
- Источники: [русская страница и адаптация](https://psytests.org/group/vsm94.html), [русский бланк пунктов](https://psytests.org/group/vsm94-bl.html), [русская инструкция](https://psytests.org/group/vsm94-run.html), [Hofstede, VSM 94 Manual](https://studylib.net/doc/7719299/v-s-m--94---geert-hofstede) (формулы и обработка пропусков), [расчётные формулы VSM-94, воспроизведённые в академической публикации](https://vtechworks.lib.vt.edu/bitstream/handle/10919/35096/Ira_Jhangiani_MS_thesis.pdf).
- Пункты: 20 содержательных вопросов; демографические пункты не входят в индексный опросник русской формы.
- Шкалы и подсчёт: пять групповых индексов: PDI по вопросам 3, 6, 14, 17; IDV по 1, 2, 4, 8; MAS по 5, 7, 15, 20; UAI по 13, 16, 18, 19; LTO по 10 и 12. Ответы кодируются значениями 1–5 по словесным вариантам каждого блока. Для каждого включённого пункта берётся среднее по валидным ответам группы.
- Формулы (m(n) — групповое среднее ответа на вопрос n): PDI = −35m(3)+35m(6)+25m(14)−20m(17)−20; IDV = −50m(1)+30m(2)+20m(4)−25m(8)+130; MAS = 60m(5)−20m(7)+20m(15)−70m(20)+100; UAI = 25m(13)+20m(16)−50m(18)−15m(19)+120; LTO = −20m(10)+20m(12)+40 (пересмотренная формула 1999). Пустые и множественные ответы исключаются из среднего. Индексы могут выходить за диапазон 0–100. Контрольный случай с ответом 3 на все вопросы рассчитан вручную: −5, 55, 70, 0, 40 соответственно.
- Ограничение: индексы предназначены для сопоставимых групповых выборок, а не для личностного профиля отдельного человека. Русская форма включает адаптационные формулировки Psytests; первичный русскоязычный бланк авторской адаптации снаружи не найден, поэтому зафиксирована именно доступная версия.
