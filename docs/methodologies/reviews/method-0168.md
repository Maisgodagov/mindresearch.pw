Ключ в первоисточнике размечает только 28 позиций ответного бланка по четырём столбцам и буквам А/Б/В, то есть он не задаёт однозначно отображение каждого из 84 текстовых пунктов на баллы/структурные шкалы. Автоматизировать подсчёт без угадывания нельзя.
