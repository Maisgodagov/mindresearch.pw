# Тест на удовлетворённость браком (Алёшина, Гозман, Дубовская), женская форма

- Решение: подготовлен. Доступны русский текст 16 пунктов и явное правило начисления баллов.
- Русский бланк: [«Тест на удовлетворенность браком — бланк» (женский бланк)](https://psytests.org/family/spuudb-bl.html). Для регистрации использована женская форма; четыре ответа в каждом пункте сохранены как отдельные варианты без буквенной нумерации.
- Ключ и подсчёт: [«Опросник (тест/методика) „Уровень удовлетворенность браком“»](https://dip-psi.ru/psikhologicheskiye-testy/post/oprosnik-test-metodika-uroven-udovletvorennost-brakom-yu-e-aleshina-l-ya-gozman-e-m-dubovskaya), раздел «Обработка результатов»: пункты 2, 3, 5, 7, 10, 12, 14, 16 оцениваются по возрастанию от 0 до 3; пункты 1, 4, 6, 8, 9, 11, 13, 15 — в обратном порядке от 3 до 0. Суммируются баллы всех пунктов; диапазон 0–48.
- Библиографический первоисточник: Ю. Е. Алёшина, Л. Я. Гозман, Е. М. Дубовская. *Социально-психологические методы исследования супружеских отношений*. М.: МГУ, 1987. Сведения об издании и его разделе «Тест на удовлетворенность браком»: [страница книги и оглавление](https://psytests.org/book/mgu1987.html).
- Контекст измерения: [«Динамика отношений: тесты и опросники»](https://psytests.org/guide/close-dynamics-ru.html) описывает область удовлетворённости и указывает тест Алёшиной как оценку субъективного отношения человека к своему браку.
- Объём: 16 пунктов, одна суммарная шкала. Реверсивные пункты: 1, 4, 6, 8, 9, 11, 13, 15.
- Формула: для каждого прямого пункта ответам А–Г присваиваются 0, 1, 2, 3 балла; для реверсивных пунктов — 3, 2, 1, 0. Итог равен сумме 16 пунктов. В источнике с ключом также приведены уровни: 0–18 низкий, 19–39 средний, 40–48 высокий.
- Ручная проверка: А на всех прямых пунктах и Г на всех обратных дают по 0 баллов за каждый пункт, суммарно 0.
- Ограничение версии: зарегистрирована именно женская форма, обращённая к женщине о её муже; формулировки не объединены с мужским вариантом.
