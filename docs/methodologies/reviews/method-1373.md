# Оценка состояния адаптированности личности (ОСАДА), С. И. Яковенко (1996)

- Статус: `blocked`.
- Русский текст: первичная публикация содержит инструкцию и полный текст 30 блоков с четырьмя вариантами в каждом. Русская онлайн-страница методики и бланк доступны в каталоге Psytests (страница бланка при проверке не открылась из-за ошибки декодирования).
- Надёжный ключ: подтверждено общее начисление: «а» = 0, «б» = 1, «в» = 2, «г» = 3; каждая шкала включает 6 пунктов (0–18), сумма — 0–90. Однако доступный текст публикации лишь говорит, что бланк — матрица 5×6, не указывая, какие пункты входят в каждую колонку. Без назначения пунктов пяти шкалам точную автоматическую реализацию нельзя подготовить без догадки, поэтому модуль не создавался.
- Пункты и шкалы: 30 блоков; пять шкал удовлетворённости собой, ситуацией, положением в сфере общения, здоровьем и образом жизни, деятельностью на работе и дома.
- Формула известной части: для каждого ответа начислить 0/1/2/3 соответственно; сумма по шести пунктам каждой шкалы, общий балл — сумма пяти шкал. Раскладка пунктов по шкалам в доступном первичном тексте отсутствует.
