# 862. Опросник близости отношений

Решение worker: `blocked`.
Основание: Полный русский текст пунктов и вариантов ответов недоступен на странице версии: форма скрыта за JavaScript, извлечь её текст не удалось. Хотя оригинальная публикация и ключ RCI доступны, русский текст нельзя надёжно восстановить без догадок. Файлы не созданы.
