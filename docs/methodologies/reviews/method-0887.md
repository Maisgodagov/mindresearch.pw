# 887. Опросник гемблинга Южного Оукса

Решение worker: `blocked`.
Основание: Русский текст и ключ подтверждаются для версии SOGS из книги «Психология игровой зависимости» (Карпов и Козлов, приложение 2), но доступный бланк psytests отличается по структуре и формулировкам.
