# Индекс личного благополучия взрослых (PWI-A)

- Решение: подготовлено. Русский текст содержит все семь доменных вопросов; точное правило подсчёта подтверждено руководством International Wellbeing Group.
- Русская версия: [«Индекс личного благополучия взрослых, PWI-A» — описание и сведения о русской модификации](https://psytests.org/life/pwia.html); [русский бланк PWI-A](https://psytests.org/life/pwia-bl.html). Формулировки в регистрации воспроизведены из бланка, варианты представлены баллами 0–10.
- Первоисточник ключа: [International Wellbeing Group, *Personal Wellbeing Index – Adult (PWI-A), 5th Edition Manual* (2013)](https://www.acc.co.nz/assets/provider/pwi-a-manual.pdf), разделы 2.3–2.4, с. 13–14 и 5.2–5.3, с. 18–19. Руководство задаёт семь доменов и среднее семи оценок; ответы 0–10 можно преобразовать в шкалу 0–100 умножением на 10. Обратных пунктов нет.
- Публикация о русскоязычных кратких шкалах: [Осин Е. Н., Леонтьев Д. А. «Краткие русскоязычные шкалы диагностики субъективного благополучия: психометрические характеристики и сравнительный анализ»](https://doi.org/10.14515/monitoring.2020.1.06), *Мониторинг общественного мнения*, 2020, № 1, с. 117–142. Описание адаптации и библиография также приведены на странице [русской версии PWI-A](https://psytests.org/life/pwia.html).
- Количество пунктов: 7; группа: взрослые от 18 лет.
- Шкалы: семь доменов (уровень жизни, здоровье, достижения, близкие отношения, личная безопасность, отношения с окружающими, уверенность в будущем), каждый 0–10; общий PWI — среднее всех семи доменов, диапазон 0–10. При представлении по руководству в процентных пунктах 0–100 результат умножается на 10.
- Формула: `PWI = (п1 + п2 + п3 + п4 + п5 + п6 + п7) / 7`. Доменные оценки также доступны по отдельности; обратного пересчёта пунктов нет.
- Ручная контрольная проверка: `(2 + 4 + 6 + 8 + 10 + 0 + 5) / 7 = 5`; соответствующий результат в шкале 0–100 — 50.
- Ограничение источника: русский бланк psytests.org оговаривает, что является отображением ответов, а не оригинальным бланком для печати; формула сверена отдельно с руководством International Wellbeing Group.
