# Мотивы занятий спортом (А. В. Шаболтас)

- Решение: `blocked` — русский текст доступен, но существующая конфигурация подсчёта проекта не может точно представить ключ этого опросника.
- Русская версия: [«Прохождение: Мотивы занятий спортом»](https://psytests.org/sport/mzshab-run.html) содержит инструкцию и 45 пар суждений с ответом по степени предпочтения; [страница методики «Мотивы занятий спортом»](https://psytests.org/sport/mzshab.html) указывает десять мотивов и автора А. В. Шаболтас (1998). [Приложение 1 к выпускной квалификационной работе Иванова, бланк «Мотивы занятий спортом»](https://vkr.pspu.ru/uploads/4900/Ivanov_vkr.pdf) (печатные страницы 52–60 PDF) содержит полный текст пар и ключ обработки.
- Ключ и подсчёт: тот же бланк (печатная страница 60 PDF) предписывает начислять 1, 2 или 3 балла выбранному суждению, ответ «не знаю» даёт 0; сумма считается по каждой из 10 шкал, максимум на шкалу — 27. Девять из 45 пар относятся к каждой шкале. Наиболее выражены мотивы с наибольшей суммой. Список соответствий «номер + сторона А/Б» напечатан там же.
- Шкалы: эмоциональное удовольствие (ЭУ), социальное самоутверждение (СС), физическое самоутверждение (ФС), социально-эмоциональный (СЭ), социально-моральный (СМ), достижение успеха (ДУ), спортивно-познавательный (СП), рационально-волевой (РВ), подготовка к профессиональной деятельности (ПД), гражданско-патриотический (ГП).
- Ограничение реализации: `ConfigurableScoring` в `apps/api/src/scoring/configurable.ts` принимает для числовых пунктов только целое значение общего диапазона и не имеет таблицы ключа по составному варианту ответа (сторона пары и её интенсивность). Значит, нельзя вычислить сумму мотивов точным опубликованным ключом без изменения общей инфраструктуры или иной модели ответа. По заданному ограничению изменять такие файлы нельзя; модуль методики не создан.
