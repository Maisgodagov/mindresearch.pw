# Шкала тревоги на рабочем месте, JAS — решение

- Статус: `blocked`.
- Русский текст: онлайн-бланк PsyTests содержит 68 пунктов и варианты согласия; он сам предупреждает, что это не оригинальный бланк, номера вариантов не являются баллами и бланк не предназначен для использования. Статья адаптации сообщает о русской версии из 70 пунктов с ответами 0–4, но отмечает, что финальный опросник не опубликован. Значит, доступный русский текст нельзя надёжно сопоставить с валидированной версией.
- Ключ: оригинальное руководство задаёт 14 субшкал, пять измерений, общий показатель; для каждого считается среднее ответов 0–4, обратных пунктов нет. Однако точный ключ оригинала нельзя безопасно наложить на 68-пунктовый веб-бланк, а таблицы русской публикации относятся к версии из 70 пунктов. Поэтому подсчёт для доступного русского текста не регистрируется.
- Пункты и шкалы: доступный веб-бланк — 68 утверждений, одна шкала согласия («Не согласен» … «Полностью согласен»); апробированная русская версия — 70 пунктов и пять эмпирических факторов. Оригинальный ключ включает 14 субшкал и пять измерений.
- Формула: для оригинальной JAS — среднее значение пунктов соответствующей субшкалы, измерения или всей шкалы; реверсивных пунктов нет. Для текущего русского бланка формула неприменима без подтверждённого соответствия пунктов.
- Решение: не создавать модуль, поскольку надёжная точная связка русского текста и ключа для одной и той же версии не подтверждена.
