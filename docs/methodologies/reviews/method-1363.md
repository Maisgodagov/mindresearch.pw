В бланке «Ресурса» пункт 5 содержит отличающуюся формулировку; она не переносится в существующие вопросы платформы.
- Оригинальная англоязычная шкала: [Crowne D. P., Marlowe D. (1960). A New Scale of Social Desirability Independent of Psychopathology. Journal of Consulting Psychology, 24(4), 349–354](https://doi.org/10.1037/h0047358). Оригинальная 33-пунктовая и русская 20-пунктовая формы не смешиваются.

## Подсчёт и исправление

За «Да» в пунктах 1, 2, 3, 4, 5, 8, 11, 14, 15, 16, 20 начисляется 1 балл. За «Нет» в пунктах 6, 7, 9, 10, 12, 13, 17, 18, 19 — также 1 балл. Несовпадение даёт 0. Итог — сумма 0–20 при наличии всех 20 допустимых ответов.

Старая конфигурация `hanin-marlowe-crowne-20item-key-v1` использовала числовую сумму при строковых `yes` / `no` и одновременно отрицательные веса с обратным кодированием. Регрессионные проверки воспроизвели отсутствие результата. В `hanin-marlowe-crowne-20item-key-v2` используется существующий механизм `itemScores` с явными баллами обоих вариантов каждого пункта, без дополнительной инверсии или весов. Идентификатор шкалы `approval_motivation` сохранён.

Контроль: все «Да» = 11; все «Нет» = 9; все ответы по ключу = 20; все против ключа = 0; нечётные «Да» и чётные «Нет» = 9. Отдельно проверены каждый из 20 пунктов, пропуск, недопустимый ответ, каталоговый валидатор и сохранение результата с диапазоном 0–20 из JSON-ответов сессии.

## Описание и ограничения

Карточка содержит авторов, назначение, особенности русской формы, инструкцию, полный ключ, объяснение суммы, источники и категорию `trait-presentation`. Описание включает поисковое название «Шкала социальной желательности» и MC-SDS. Заголовок существующей записи сохранён, чтобы seed корректно обновил её описание без переназвания используемых опросов.

Нормативные границы расходятся: руководство МГППУ приводит 0–6 / 7–13 / 14–20, бланк «Ресурса» — ниже 10 / 10–12 / от 13. Оба варианта обозначены как справочные. Автоматическая категоризация и браковка анкет по этой шкале не добавляются. Высокий балл сам по себе не доказывает ложь. Открытая лицензия или отдельное разрешение правообладателя не подтверждены; существующий текст не расширяется.

## Выпуск

При обычном deploy seed обновляет конфигурацию, версию формулы, описание и метаданные существующего инструмента. Структура опубликованных опросов, ответы респондентов и накопленные результаты не меняются; массовый пересчёт не запускается.

Проверки: `npm run build -w @opora/api`; `npm run test -w @opora/api`. Новые тесты: `marloweCrowneRu.test.ts`, `marloweCrowneSession.test.ts`.
