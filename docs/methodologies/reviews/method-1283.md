# Опросник учебного стресса для школьников (LASRS-2)

- Решение: добавить русскую школьную адаптацию по опубликованной версии.
- Русский текст: 24 формулировки и пятибалльные варианты частоты приведены в приложении C к статье Карповой, Тарасова и Канонир; использованы в опубликованной валидации учащихся 11 классов. Русский бланк также доступен на странице Psytests.
- Ключ: по методическому описанию и приложению A пункты образуют четыре домена: аффективные реакции (1–7), поведенческие (8–13), когнитивные (14–19), физиологические (20–24). Ответы кодируются 1–5 по возрастанию частоты; сумма прямых ответов формирует балл домена. Реверсивных пунктов нет. Сумма 24 пунктов — общий сырой показатель. Публикация рекомендует профиль доменных баллов для более тонкой оценки; индивидуальная диагностика без стандартизации не поддерживается.
- Формула: доменный балл = сумма закодированных ответов соответствующих пунктов; общий показатель = сумма ответов всех 24 пунктов. Диапазоны: аффективный 7–35, поведенческий 6–30, когнитивный 6–30, физиологический 5–25, общий 24–120.
- Контрольный пример вручную: если по всем пунктам выбран минимальный ответ 1, ожидаются доменные суммы 7, 6, 6 и 5, общий балл 24.

## Ограничения версии

Проверка русской версии в приведённой статье выполнена на выборке 11-классников 16–18 лет. Авторы сообщают, что общий показатель допустим методически, однако иерархическая модель не сошлась для подвыборки девушек; поэтому при интерпретации предпочтителен профиль четырёх шкал. Пороговые нормы не приведены.
