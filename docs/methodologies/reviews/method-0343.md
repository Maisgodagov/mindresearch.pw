# Индекс Уитли, WI-8 — русскоязычная адаптация Золотаревой (2024/2025)

- Статус: подготовлено (`test_374`).
- Русский текст и версия: приложение к статье А. А. Золотаревой содержит инструкцию, все 8 пунктов, варианты ответов и условие для пунктов о визите к врачу/сообщении о болезни. Формулировки внесены по приложению без перевода и без объединения версий.
- Ключ: авторская публикация указывает сложить баллы по всем утверждениям; обратных пунктов нет. Значение ≥ 19 обозначено автором как указывающее на клинически значимую тревогу о здоровье (со ссылкой на Cannito et al., 2020). В модуле реализована только воспроизводимая сумма без диагностической интерпретации.
- Пункты: 8.
- Шкалы и формула: одна шкала «Общий показатель тревоги о здоровье»; ответы 1–5 («Никогда (ни разу)» … «Всегда (все время)»). Итог = сумма ответов по пунктам 1–8; диапазон 8–40; реверсивных пунктов нет. Инструкция: за прошедшие 4 недели; если в этот период респондент не посещал врача и не узнавал о чьей-либо болезни, для соответствующего контекста выбрать «Никогда (ни разу)».
- Проверка: вручную рассчитанные контрольные случаи 1×8 = 8 и 1+2+3+4+5+1+2+5 = 23.
- Ограничение: публикация рекомендует шкалу для оценки тревоги о здоровье в общей русскоязычной популяции; дальнейшая проверка в клинических условиях остаётся перспективой.
