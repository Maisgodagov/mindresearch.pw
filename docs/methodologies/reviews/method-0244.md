# 244. Диагностика ургентной аддикции

Решение worker: `blocked`.
Основание: Русский бланк доступен, но надёжный точный ключ и правила подсчёта для его версии не подтверждены первичным источником. Бланк Psytests приводит варианты «Никогда»—«Всегда», однако предупреждает, что цифры колонок не являются баллами; найденное описание ключа опубликовано на агрегаторе, а не в первоисточнике. Чтобы не угадывать подсчёт, регистрацию не создавал.
