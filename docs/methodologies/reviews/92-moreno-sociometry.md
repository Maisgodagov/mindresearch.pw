# 92. Социометрия Морено — нефиксированная процедура

**Решение:** не импортировать как одну автоматизированную методику.

Социометрия — семейство процедур, в которых вопросы выбора, число выборов, референтная группа, ограничения на номинации и расчёт показателей определяются задачей и контекстом. Без конкретной авторской стандартизированной русской формы нельзя корректно задать единые вопросы, ключ и автоматическую интерпретацию. Пользователь может создать собственный тест/исследовательскую форму под конкретную процедуру.

**Статус не означает**, что метод нельзя проводить; только что элемент списка не подходит для добавления как единый фиксированный тест с автоподсчётом.

Источники:
- Moreno, J. L. *Who Shall Survive?* (основной труд по социометрии; библиографическая карточка): https://archive.org/details/whoshallsurvivef00more
