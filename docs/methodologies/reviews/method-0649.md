# Методика оценки адаптивного поведения дошкольников (Калягин, Овчинникова, 2001)

- Решение: `blocked` — полный надёжный ключ/алгоритм для точной автоматической реализации не подтверждён.
- Русский текст: в публикации-репродукции пособия доступен опросник из 80 утверждений (4 блока по 20), однако его инструкция адресована отвечающему о себе («для Вас», «о себе»), тогда как страница Psytests описывает дошкольную версию для оценивания ребёнка информантами. Поэтому не переносил несовпадающий текст как будто это точная детская форма.

- Пункты и шкалы: опубликованная копия содержит 80 утверждений, четыре шкалы/тактики: холерическая, сангвиническая, флегматическая, меланхолическая. В ней дана таблица перевода сырых баллов по каждой шкале в стены (1–10), но ключ приложений представлен испорченной/неоднозначной табличной вёрсткой профилей; целостное соответствие и алгоритм классификации адаптивных типов надёжно не восстановлены.
- Формула: точную формулу и ключ включения пунктов для дошкольной версии нельзя подтвердить из доступных первичных материалов; догадка не использовалась. Модуль не создавался.
