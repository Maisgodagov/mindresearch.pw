# PedsQL 4.0 Generic Core Scales — детская форма 8–12 лет

- Решение: подготовлена регистрация русской версии с надежным ключом подсчета.
- Русский текст: [Приложение Г3. Русская версия опросника PedsQL 4.0 Generic Core Scales для оценки качества жизни детей, клинические рекомендации «ВИЧ-инфекция у детей» (Минздрав РФ, 2020)](https://base.garant.ru/400186478/d2b3224c46a40b9266b496c5f3c6a68a/); форма 8–12 лет. Полный валидизированный бланк приведен также в [клинических рекомендациях Минздрава, PDF, Приложение Г3](https://rushiv.ru/wp-content/uploads/2021/05/KR-459-1.pdf).
- Публикация русской адаптации: Т. П. Никитина, «Разработка и оценка свойств русской версии опросника PedsQL для исследования качества жизни детей 8–18 лет», диссертация, Москва, 2005; описание адаптации, возрастных форм и психометрической оценки доступно в [тексте автореферата/диссертационного описания](https://medical-diss.com/medicina/razrabotka-i-otsenka-svoystv-russkoy-versii-oprosnika-pedsql-dlya-issledovaniya-kachestva-zhizni-detey-8-18-let). Работа указывает на отдельные детские и родительские формы для возрастов 8–12 и 13–18 лет.
- Первичный алгоритм подсчета: [PedsQL Scoring Instructions for all PedsQL Instruments, официальный сайт разработчика](https://www.pedsql.org/score.html). Поддерживающее описание инструмента: Varni et al., [How young can children reliably and validly self-report their health-related quality of life?](https://pmc.ncbi.nlm.nih.gov/articles/PMC1769360/), PedsQL 4.0 Generic Core Scales.
- Пунктов: 23; 4 шкалы: физическое (8), эмоциональное (5), социальное (5) и школьное (5) функционирование.
- Ответы кодируются по источнику: «Никогда» = 0, «Почти никогда» = 1, «Иногда» = 2, «Часто» = 3, «Почти всегда» = 4. Все пункты реверсивно переводятся в 100-балльную шкалу: 0→100, 1→75, 2→50, 3→25, 4→0; более высокий балл означает лучшее качество жизни. В реализации преобразование выполнено кодированием вариантов ответа в 100, 75, 50, 25, 0.
- Формула шкалы: среднее арифметическое преобразованных значений пунктов соответствующей шкалы. Суммарный балл физического компонента равен физической шкале; психосоциальный компонент — среднему всех пунктов эмоциональной, социальной и школьной шкал; общий балл — среднему всех 23 пунктов. Спецификация зарегистрированных 4 шкал и тестовые случаи включены в модуль.
- Обратные пункты в привычном смысле ключа отсутствуют: формулировки описывают затруднения, поэтому преобразование направления одинаково для всех пунктов.
