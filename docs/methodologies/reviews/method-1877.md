# Опросник эмоционального интеллекта ЭмИн (полная версия, 2006)

- Решение: подготовлен. Доступен полный русский текст 46 утверждений и однозначный ключ к пяти субшкалам с пометами прямых и обратных пунктов.
- Русский текст и бланк: [«Тест эмоционального интеллекта, ЭмИн» — страница методики PsyTests](https://psytests.org/eq/emin.html), [страница прохождения с инструкцией и форматом ответа](https://psytests.org/eq/emin-run.html); полный текст также опубликован в статье автора.
- Ключ: [Д. В. Люсин, «Новая методика для измерения эмоционального интеллекта: опросник ЭмИн», *Психологическая диагностика*, 2006, № 4, с. 3–22 — PDF Библиотеки Института психологии РАН](https://lib.ipran.ru/paper/26114976). Статья содержит приложение с текстом опросника и ключом по каждому пункту. Тот же авторский материал доступен в книге [«Социальный интеллект: теория, измерение, исследования» (2009), приложение «Текст опросника ЭмИн»](https://creativity.ipras.ru/texts/books/social_IQ_2009/lusin_social_IQ_2009.pdf).
- Дополнительный русскоязычный бланк для сверки: [«Опросник эмоционального интеллекта ЭмИн (Люсин)» — таблица формулировок, субшкал и ключа](https://eqspb.ru/o-kompanii/articles/oprosnik-emocionalnogo-intellekta-emin-lyusin/).
- Пункты и ответы: 46 утверждений; варианты «Совсем не согласен», «Скорее не согласен», «Скорее согласен», «Полностью согласен» кодируются 0–3.
- Шкалы: МП — понимание чужих эмоций; МУ — управление чужими эмоциями; ВП — понимание своих эмоций; ВУ — управление своими эмоциями; ВЭ — контроль экспрессии. Составные: МЭИ = МП + МУ; ВЭИ = ВП + ВУ + ВЭ; ПЭ = МП + ВП; УЭ = МУ + ВУ + ВЭ; ОЭИ = сумма всех пяти субшкал.
- Формула: для прямого пункта балл равен ответу 0–3, для обратного — 3 минус ответ; балл каждой шкалы — сумма преобразованных ответов по её пунктам. Использованы пять субшкал и четыре составные шкалы, описанные автором; нормы и интерпретации не включены.
- Ручная проверка: при ответе «Полностью согласен» на все пункты обратные пункты дают 0, прямые — 3; суммы по субшкалам: МП 54, МУ 36, ВП 45, ВУ 30, ВЭ 24; ОЭИ 189.
