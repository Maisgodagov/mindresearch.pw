# 1502. Психологическое здоровье семьи

Решение worker: `blocked`.
Основание: Адекватный русский текст и первоисточник доступны, но комплекс Торохтия состоит из шести отдельных методик с разными формами. У доступной страницы семейных ценностей есть алгоритм межсемейного подсчёта, однако он зависит от ответов нескольких членов семьи; определить для неё самостоятельные ключи ответов и реализовать точный автоматический подсчёт по одному респонденту нельзя. Недостающие правила не угадывал; файлы не создавал.
