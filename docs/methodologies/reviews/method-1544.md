# 1544. Русскоязычный опросник каузальных ориентаций

Решение worker: `blocked`.
Основание: Русский бланк на Psytests содержит 26 ситуаций, но сайт указывает, что он не является оригинальным и что инструкции подсчёта нужно брать из первоисточника. Публикации подтверждают три шкалы и ответы по шкале 1–7, но не дают точного ключа для этих 26 ситуаций; статья адаптации описывает другую форму из 30 ситуаций. Без подтверждённого соответствия ответов шкалам точную регистрацию создать нельзя, поэтому разрешённые файлы не создавал.
