# ДОПО-3к — Дифференциальный опросник переживания одиночества

- Решение: prepared. Русский бланк из приложения к статье и однозначный ключ опубликованы авторами.
- Источник методики и ключа: [Е. Н. Осин, Д. А. Леонтьев. «Дифференциальный опросник переживания одиночества: структура и свойства», Психология. Журнал ВШЭ, 2013, т. 10, № 1, с. 55–81 (PDF, приложение с краткой формой и ключом на с. 80–81)](https://psy-journal.hse.ru/article/download/40115/32059/).
- Русский бланк для сверки формулировок: [«Дифференциальный опросник переживания одиночества, ДОПО-3к — Бланк»](https://psytests.org/ipl/dopo3k-bl.html); формулировки дополнительно сверены с авторским приложением.
- Количество пунктов: 24. Ответы: «Не согласен», «Скорее не согласен», «Скорее согласен», «Согласен», кодируются 1–4.
- Шкалы: ОО — пункты 1, 4, 5, 6, 10, 14, 16, 21; ЗО — 2, 8, 11, 13, 18, 20, 23; ПО — 3, 7, 9, 12, 15, 17, 19, 22, 24.
- Формула: для обратных пунктов 4, 10 и 13 заменить ответ `x` на `5 − x`; затем сложить ответы соответствующих пунктов для каждой шкалы. Диапазоны сумм: ОО 8–32, ЗО 7–28, ПО 9–36. Нормативные пороги не добавлялись.
- Ручная проверка: при ответе 1 на все пункты после реверса пункты 4, 10 и 13 равны 4; суммы ОО = 10, ЗО = 9, ПО = 9.


## Решение после аудита 14–15.10.2026: удалена из каталога

Предыдущее решение prepared/verified не подтверждает работоспособность расчёта. Для test_295 остались неразрешённые противоречия ключа, формата ввода, реализации или контрольных данных. По указанию владельца редакция снята из каталога; вопросы и ответы существующих опросов сохраняются. Автоматический расчёт и выдача её баллов отключены. Это не заключение о научной непригодности оригинальной методики.

Причины: control-case-mismatch. Полная запись и зарегистрированные источники: [общий отчёт](../scoring-remediation-2026-10-14.md), [JSON](../scoring-remediation-2026-10-14.json). Возврат требует подтверждения конкретной редакции и независимых тестов; повторный seed не восстанавливает запись.
