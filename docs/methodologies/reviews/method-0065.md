# Анализ стиля педагогической деятельности
- Решение: blocked — надёжный полный ключ отсутствует.
- Русский текст: адекватный бланк содержит 33 вопроса с ответами «да» и «нет»: https://psytests.org/pedag/auispd-bl.html
- Источник методики и подсчёта: статья А. К. Марковой и А. Я. Никоновой, «Психологические особенности индивидуального стиля деятельности учителя», «Вопросы психологии», 1987, № 5: https://voppsy.ru/issues/1987/875/875040.htm
- Шкалы: эмоционально-импровизационный (ЭИС), эмоционально-методичный (ЭМС), рассуждающе-импровизационный (РИС), рассуждающе-методичный (РМС).
- Формула, указанная авторами: отметить все подходящие ответы, затем подсчитать отметки по четырём колонкам; стиль определяется колонкой с максимальным количеством отметок.
- Ограничение ключа: в статье авторы прямо называют таблицу с соответствиями ответов примером и приводят только первые 3 вопроса из 33. Для остальных пунктов распределение «да/нет» по четырём шкалам не опубликовано в доступной статье. Бланк psytests.org также указывает, что он не оригинальный, а инструкцию подсчёта следует брать из первоисточника. Восстановление недостающих 30 строк по интерпретациям стилей было бы догадкой.
- Итог: модуль не создаётся; точный автоматизируемый ключ недостаточен.
