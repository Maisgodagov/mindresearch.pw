# Опросник аутентичности Керниса—Голдмана, AI-3 (русская адаптация)

- Решение: подготовлена регистрация краткой русской версии из 32 пунктов.
- Русский текст: полный бланк AI-3 на Psytests.org; формулировки перенесены из опубликованного бланка. Варианты ответов: «Полностью не согласен», «Не согласен», «Где-то посередине», «Согласен», «Полностью согласен».
- Надёжный ключ: таблица 1 статьи адаптации перечисляет 32 пункта в составе четырёх шкал и помечает реверсивные пункты буквой R. Реализованы номера пунктов финальной русской версии.
- Шкалы и подсчёт: Осознанность (1, 3, 4, 8, 13, 18, 26, 29; обратные 1, 13, 26), Поведение (2, 7, 9, 10, 21, 22, 24, 25; обратные 2, 7, 9, 10, 22, 25), Отношения (5, 11, 14, 16, 19, 20, 30, 32; без обратных), Непредвзятость (6, 12, 15, 17, 23, 27, 28, 31; все обратные). Для обратных ответов используется перекодировка 6 − ответ; итог каждой шкалы — среднее восьми пунктов (диапазон 1–5), как в описании расчёта статьи.
- Выборка русской адаптации: русскоязычные студенты 17–32 лет; применимость за пределами этой группы требует отдельной оценки.
