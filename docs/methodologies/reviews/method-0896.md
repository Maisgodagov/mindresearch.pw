# Опросник Депрископ

- Решение: подготовлен; доступен полный русский текст 31 пункта, точные пороги и правила подсчёта.
- Русская версия и описание методики: [Опросник Депрископ, Psytests](https://psytests.org/depr/dscop.html); [форма и расчёты Депрископа, Psytests](https://psytests.org/result?v=derRDTvd-tEfAEDMhDf26ONBRRIaiKmOOoqMdD5kFfYukgX1DtEG4Lvi).
- Первоисточник и адаптация: [А. И. Подольский, О. А. Идобаева, П. Хейманс. «Диагностика подростковой депрессивности. Теория и практика» (Питер, 2004)](https://urait.ru/book/diagnostika-podrostkovoy-depressivnosti-412096), раздел 2.2 «Депрископ»; авторы и год разработки (P. Heymans, 1996) также указаны на [странице методики Psytests](https://psytests.org/depr/dscop.html). Библиографическая запись подтверждена [каталогом библиотеки МГППУ](https://lib.mgppu.ru/OpacUnicode/app/webroot/index.php?url=%2Fnotices%2Findex%2FIdNotice%3A17958%2FSource%3Adefault).
- Объём: 31 пункт. Каждый пункт — число дней с симптомом за последние три месяца; вариант «сегодня» фиксирует наличие симптома за последние 24 часа.
- Шкалы: `DINTRUSION` — число пунктов, где количество дней достигло или превысило индивидуальный порог (пороги по пунктам: 5, 11, 1, 4, 6, 1, 2, 2, 3, 1, 4, 3, 1, 4, 1, 1, 1, 1, 3, 1, 1, 6, 4, 4, 3, 5, 2, 2, 6, 3, 2); `DNOW` — число симптомов, отмеченных за последние 24 часа. Реверсивных пунктов нет.
- Формула: `DINTRUSION = Σ I(days_i ≥ threshold_i)`; `DNOW = Σ I(today_i = да)`. Значение `DINTRUSION ≥ 21` обозначено источником как пороговый показатель для выявления подростков с возможным депрессивным состоянием или высоким риском. Порог не трактуется как диагноз.
- Вручную проверено: все ответы ниже порогов дают 0 по обеим шкалам; все пункты, отмеченные как достигшие порога, дают `DINTRUSION = 31`.
