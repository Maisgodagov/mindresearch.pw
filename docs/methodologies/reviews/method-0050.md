# Определение типа мышления для школьников (Г. В. Резапкина, 2005)

- Решение: подготовлено; доступен русский текст всех 40 утверждений и согласованный с ним точный ключ.
- Русский текст: [бланк PsyTests](https://psytests.org/typo/ttyper-bl.html); дополнительная сверка описания и состава методики: [страница PsyTests](https://psytests.org/typo/ttyper.html).
- Ключ и подсчет: [ПсиЛаб, «Тип мышления»](https://psylab.org.ua/tools_%D0%9C%D0%B5%D1%82%D0%BE%D0%B4%D0%B8%D0%BA%D0%B0_%22%D0%A2%D0%B8%D0%BF_%D0%BC%D1%8B%D1%88%D0%BB%D0%B5%D0%BD%D0%B8%D1%8F%22), разделы «Обработка результатов» и «Ключ»; источник методики указан как Г. В. Резапкина, «Отбор в профильные классы», М.: Генезис, 2005. Пункты ключа совпадают с нумерацией полного бланка.
- Количество пунктов: 40; ответы «Да» / «Нет».
- Шкалы: предметно-действенное (1, 6, 11, 16, 21, 26, 31, 36); абстрактно-символическое (2, 7, 12, 17, 22, 27, 32, 37); словесно-логическое (3, 8, 13, 18, 23, 28, 33, 38); наглядно-образное (4, 9, 14, 19, 24, 29, 34, 39); креативность (5, 10, 15, 20, 25, 30, 35, 40).
- Формула: по каждой шкале суммируются ответы «Да», кодированные 1; ответ «Нет» кодируется 0. Диапазон каждой шкалы 0–8. Реверсивных пунктов нет. Уровни: 0–2 низкий, 3–5 средний, 6–8 высокий.
- Ограничения: представленная онлайн-форма помечает бланк как визуальный вариант, а не оригинальный печатный материал; регистрация сохраняет формулировки этой версии.
