# 1681. Структурные уровни мотивации

Решение worker: `blocked`.
Основание: Русский текст и инструкция доступны, но надёжный точный ключ/подсчёт не подтверждён доступными прямыми источниками. Не стал угадывать и создавать регистрацию без подтверждённого алгоритма.
