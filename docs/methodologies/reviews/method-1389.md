# 1389. Пакет Гармония

Решение worker: `blocked`.
Основание: «Пакет методик „Гармония“» — это серия отдельных опросников, а не одна методика с единым набором пунктов и подсчётом. Источники подтверждают состав серии, но не дают общего ключа, который позволил бы точно реализовать пакет как один инструмент. Создавать регистрацию наугад нельзя.
