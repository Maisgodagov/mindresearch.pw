# Перечень симптомов пограничного расстройства, BSL-23

- Статус: подготовлено локально (`prepared`).
- Русский текст: полный 23-пунктовый бланк psytests.org; доступна мужская форма формулировок. Ответы в модуле используют точные числовые значения шкалы 0–4 с безномерными подписями русского бланка.
- Надёжный ключ: официальный информационный лист подсчёта BSL-23 от PSM ZI Mannheim описывает один общий фактор и среднее значение как сумму ответов, делённую на число валидных пунктов. При пропуске более 10% пунктов шкалу оценивать не следует; для реализации требуется полный набор ответов, поэтому пропуски дают неопределённый результат.
- Пункты и шкалы: 23 пункта; одна общая шкала выраженности пограничной симптоматики, пункты 1–23, значения ответа 0–4, обратных пунктов нет.
- Формула: среднее = сумма ответов 23 пунктов / 23; диапазон 0–4, большее значение отражает более выраженную симптоматику. В модуле не используются нормативные градации и диагностические пороги.
- Ограничения: русская страница указывает, что её перевод выполнен psytests.org в 2024 году и сведений об адаптации нет. Методика предназначена для количественной оценки симптомов, а не для постановки диагноза.

- Страница русской методики и сведения о переводе: [Перечень симптомов пограничного расстройства, BSL-23 — psytests.org](https://psytests.org/diag/bsl.html).

## Контрольный пример

При ответе 4 на один пункт и 0 на оставшиеся 22 средний балл равен 4/23 ≈ 0,173913. Этот случай включён в validationCases вместе с граничными проверками 0 и 4.
