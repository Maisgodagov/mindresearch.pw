# QIDS-SR16, русская версия psytests.org

- Статус: `blocked`.
- Русский текст: страница методики указывает, что представленный перевод ранее размещался на официальном сайте; русскоязычный бланк содержит 16 пунктов и четыре градации ответов для каждого пункта. [Описание QIDS](https://psytests.org/depr/qids.html), [русский бланк](https://psytests.org/depr/qids-bl.html), [инструкция](https://psytests.org/depr/qids-run.html).
- Надёжный ключ: первичный англоязычный QIDS-SR16 и инструкция по подсчёту подтверждают кодирование пунктов от 0 до 3, максимум для пунктов 1–4 (сон), 6–9 (аппетит/вес), 15–16 (психомоторные симптомы), затем сумму девяти доменов с диапазоном 0–27. [QIDS-SR16, оригинальная форма](https://narr.bmap.ucla.edu/docs/QIDS-SREnglish16item.pdf), [инструкция QIDS-SR16](https://alnursing.org/wp-content/uploads/2020/03/Depression-Questionnaire-QIDS-SR-16.pdf). Однако доступный механизм `scoringConfig` поддерживает для шкалы только сумму или среднее по пунктам, не операцию максимума внутри трёх доменов; с одним модулем нельзя точно реализовать и запустить опубликованное суммирование девяти доменов. Простая сумма всех пунктов была бы неверной.
- Пункты: 16, шкала ответа 0–3; реверсивных пунктов по ключу нет.
- Шкалы и формула: требуется 9 доменных значений — max(1–4), пункт 5, max(6–9), пункты 10, 11, 12, 13, 14, max(15–16); общий балл — сумма, 0–27. Не реализованы из-за несовместимости точной формулы с доступной схемой подсчёта.
- Неизвестные данные и ограничения: расхождения отдельных пороговых формулировок русского бланка и доступных версий оригинала не разрешались догадкой; для решения о блокировке это не требуется.
- Итог: регистрационный модуль не создан; требуется поддержка максимума по группам пунктов в исполняемом подсчёте.
