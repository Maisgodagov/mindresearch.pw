# 1546. Самоактуализационный тест для старшеклассников

Решение worker: `blocked`.
Основание: Русская версия для учащихся 8–9 классов описана, но доступные источники не дают полного бланка с пунктами и проверяемого ключа именно этой сокращённой модификации. Источник книги подтверждает лишь наличие модификации и предупреждает, что онлайн-версии могут отличаться от печатной; ключ полной САТ нельзя переносить на неё без подтверждения. Файлы не создавал.
