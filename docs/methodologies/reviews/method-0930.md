# 930. Опросник для исследования межличностных проблем

Решение worker: `blocked`.
Основание: Русский текст доступен полностью, но однозначный ключ соответствия всех 64 пунктов восьми шкалам и точные правила подсчёта в доступных источниках не приведены. Русский бланк psytests.org прямо указывает, что он не оригинальный, а инструкции по подсчёту нужно брать из первоисточников; руководство IIP-64/IIP-32 описывает ключ, но полный текст доступен только для приобретения. Не стал угадывать ключ. Разрешённые файлы не создавал.
