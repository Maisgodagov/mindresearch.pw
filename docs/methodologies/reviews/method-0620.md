# Методика исследования восприятия индивидом группы

- Статус: `blocked`.
- Русский текст: доступен бланк из 14 пунктов с тремя альтернативами на каждый пункт: [«Методика исследования восприятия индивидом группы — бланк»](https://psytests.org/work/vig-bl.html).

- Ключ: в пособии по психодиагностическим методам обнаружен ключ по трём направлениям (индивидуалистическое, прагматическое, коллективистическое): за выбранный ответ начисляется один балл соответствующему типу; баллы по типам суммируются отдельно. Однако найденная копия — вторичная публикация, а доступная страница первоисточника 1984 года не раскрывает текст книги и ключ. Надёжность и точное соответствие ключа заявленной версии нельзя подтвердить прямым доступом к первоисточнику; поэтому ключ не переносится в регистрацию.
- Шкалы и подсчёт: 14 пунктов; предполагаются три категориальные шкалы, формула — число ответов, совпавших с ключом каждой шкалы (диапазон 0–14). Реверсивных пунктов в этой схеме нет. Регистрация заблокирована, поскольку правила ключа нужно подтвердить доступным первоисточником, а не вторичной перепечаткой.
- Итог: модуль не создан; требуются страницы 64–71 издания 1984 года или другой надёжный прямой источник с полным ключом.
