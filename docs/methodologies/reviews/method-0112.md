# Вендер-Ютская шкала самооценки СДВГ у взрослых, WURS-25

- Решение: подготовлена; критерии проверены по доступным источникам.
- Русский текст: psytests.org, перевод 2023 года; опубликованы инструкция и полный бланк из 25 пунктов. Сайт указывает, что сведений о русскоязычной адаптации нет.
- Ключ и подсчёт: каждый пункт оценивается от 0 до 4; итог — сумма ответов по 25 пунктам (диапазон 0–100). Обратных пунктов в суммарном ключе нет.
- Шкала: суммарный балл WURS-25. Пороговые значения не используются для автоматической классификации.
- Формула: `total = Σ(response_i), i=1…25`, где `response_i ∈ {0,1,2,3,4}`.
- Ручная проверка: 25 минимальных ответов дают 0; 25 максимальных — 100.
