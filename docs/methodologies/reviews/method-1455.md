# 1455. Проективная методика Н. Каплан

Решение worker: `blocked`.
Основание: Надёжный источник описывает протокол и четыре классификационные категории, но не даёт однозначного ключа/алгоритма подсчёта для каждого случая. Русская страница подтверждает, что анализируются рассказы ребёнка и ответы на вопросы психолога, однако полные формулировки пунктов и критерии классификации там не приведены; доступная публикация Каплан также не содержит достаточного для точной автоматизации ключа. По workflow нельзя достраивать эти правила догадками, поэтому файлы не создавались.
