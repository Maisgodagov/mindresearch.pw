# Карта одаренности (модифицированный вариант Савенкова, 2021)

- Решение: `blocked` — надёжного однозначного ключа для автоматического подсчёта не найдено; регистрация не создана.
- Русский текст: опубликованы 77 пунктов и четыре градации оценки. В бланке psytests опубликованы те же формулировки и ответы `++`, `+`, `0`, `–`.
- Проверенные источники:
  - [А. И. Савенков. «Модифицированный вариант диагностической методики “Карта одаренности”», Известия ИППО МГПУ, 2021, № 2, с. 97–103](https://izvestia-ippo.mgpu.ru/savenkov-a-i-modificirovannyy-varian/) — первичная публикация модифицированной версии, полный перечень вопросов, градации ответов и описание обработки.
  - [«Карта одаренности — бланк», PsyTests](https://psytests.org/work/kodar-bl.html) — доступный русскоязычный бланк с пунктами и вариантами `++`, `+`, `0`, `–`; сайт отдельно предупреждает, что его бланк не предназначен для подсчёта и рекомендует брать оригинальные инструкции из первоисточников.
  - [А. И. Савенков. «Модифицированный вариант диагностической методики “Карта одаренности”», Психологическая газета, публикация текста](https://psy.su/feed/10265/) — полный текст статьи и правила обработки: плюсы и минусы по вертикалям взаимно сокращаются; каждый столбец представляет одну из 11 сфер.
  - [«Карта одаренности», страница методики PsyTests](https://psytests.org/work/kodar.html) — описание применения для оценки детской одаренности педагогами и родителями.
- Объём: 77 пунктов; шкалы в публикации: интеллектуальная, творческая, академическая, художественно-изобразительная, музыкальная, литературная, артистическая, техническая, информационные технологии, социальные отношения/социальный интеллект/лидерство, психомоторная (спортивная).
- Формула по описанию публикации: отдельно для каждого вертикального столбца сложить плюсы и минусы; плюс и минус взаимно сокращаются. Однако опубликованный текст не задаёт соответствия каждого из 77 вопросов одному из 11 столбцов, а на странице бланка PsyTests номера столбцов прямо названы условными, не баллами подсчёта. Поэтому точный ключ/подсчёт для воспроизводимой автоматической реализации не подтверждён. Не выводить распределение пунктов из их содержания.
- Итог: требуется оригинальный бланк/ключ с явным распределением 77 пунктов по 11 шкалам; до его нахождения запись остаётся заблокированной.
