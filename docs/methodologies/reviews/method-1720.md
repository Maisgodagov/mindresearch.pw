# 1720. Тест внутренней агрессивности

Решение worker: `blocked`.
Основание: Надёжный точный ключ не подтверждён. Русская страница PsyTests идентифицирует методику как Anger Assessment Сайн Дайхофф и подтверждает 40-пунктовую форму, но русский бланк не загрузился. Найденное описание CPD приводит пороговые диапазоны (0–10, 11–20, 21–30, 31–40), однако не содержит ключа ответов и правила начисления баллов. Поэтому точный подсчёт нельзя реализовать без догадок; файлы не создавались.
