# DISC — открытый DISC-определитель ODAT 1.0

- Статус: `blocked`.
- Русский текст: полный бланк из 16 утверждений и пятибалльной шкалы доступен в переводе PsyTests; инструкция доступна на странице прохождения.
- Ключ: надёжного однозначного алгоритма подсчёта профиля не найдено. Документация разработчика перечисляет четыре пункта для каждого типа, однако не объясняет, как из ответов вычисляются итоговые оценки и профиль. Само соответствие выбранных пунктов типам не устанавливает формулу подсчёта.
- Источники: [русская страница и бланк PsyTests](https://psytests.org/opm/disc.html), [ODAT](https://openpsychometrics.org/tests/ODAT/), [описание разработки и выбранные пункты типов](https://openpsychometrics.org/tests/ODAT/development/).
- Итог: русская версия пригодна, но реализация без ключа потребовала бы выдумать алгоритм; пункт отложен до обнаружения надёжного правила подсчёта.
