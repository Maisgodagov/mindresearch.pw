Однако ключ приведён в таблице-изображении по ссылке «плакат», которая сейчас возвращает 404 ([недоступный плакат из публикации](https://psy.1sept.ru/8_9.htm); файл таблицы [ris-3.gif](https://psy.1sept.ru/ris-3.gif) также недоступен). Полное соответствие всех 40 вариантов четырём стилям надёжно восстановить по доступному тексту нельзя.
- Шкалы и формула: 4 категориальных шкалы; в первоисточнике подсчёт описан как отнесение выбранных ответов к стилям с определением наиболее частой категории. При отсутствии преобладающей категории результат характеризуется как противоречивый стиль. Конкретный ключ для каждого варианта утрачен, поэтому формулу автоматического подсчёта без догадок реализовать невозможно.
