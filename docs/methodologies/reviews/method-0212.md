# 212. Диагностика нарциссизма

Решение worker: `blocked`.
Основание: Русская версия NI (адаптация Шамшиковой и Клепиковой, 2006) подтверждена, но доступные источники не дают надёжного точного ключа и правил подсчёта именно для этой версии. Страница методики прямо указывает, что инструкция по расчётам для адаптации не опубликована; ключ другой версии NI использовать нельзя. Файлы не создавались.
