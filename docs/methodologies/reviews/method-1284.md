# Опросник учебной активности младших школьников (УАмлШк-03/20)

- Решение: подготовлен к регистрации; русский текст и точный ключ подтверждены первичной публикацией.
- Русский текст бланка: [А. В. Краснов, «Опросник учебной активности младших школьников», приложение 2 в полном тексте статьи](https://www.researchgate.net/publication/284601496_Oprosnik_ucebnoj_aktivnosti_mladsih_skolnikov) (с. 87–89). Страница методики и библиографическая привязка: [PsyTests — Опросник учебной активности младших школьников](https://psytests.org/school/ouams.html). Навигационная запись в [путеводителе PsyTests по школьному обучению](https://psytests.org/guide/learning-school-ru.html).
- Источник ключа: [А. В. Краснов, «Опросник учебной активности младших школьников»](https://publications.hse.ru/articles/77956620), *Психологическая диагностика*, 2009, № 5, с. 66–89; доступный полный текст с приложением и ключом — [авторская копия статьи на ResearchGate](https://www.researchgate.net/publication/284601496_Oprosnik_ucebnoj_aktivnosti_mladsih_skolnikov), с. 88–89. Публикация описывает окончательную форму УАмлШк-03/20.
- Состав: 20 оцениваемых утверждений, а также отдельный первый контрольный пункт «Я понял инструкцию». Ответы на все пункты — пятибалльное согласие от «Совершенно не согласен» до «Полностью согласен». В первоисточнике результаты не учитываются, если на контрольный пункт дан ответ 1, 2 или 3.
- Шкалы и подсчёт: сумма по ключу для каждой шкалы. Потенциал — пункты 2, 6, 10, 14, 18; регулятивный компонент — 3, 7, 11, 15, 19; динамический компонент — 4, 8, 12, 16, 20; результативный компонент — 5, 9, 13, 17, 21. Потенциал и регулятивный компонент обратные: 1↔5, 2↔4, 3↔3. Динамический и результативный компоненты прямые. Интегративная «Учебная активность» — сумма четырёх компонентных шкал. Пропуски не допускаются по указанию первоисточника.
- Возрастная форма: для учащихся 3–4-х классов; статья описывает выборки учащихся 9–11 лет.
- Ручной контроль: при ответе 1 на всех 20 оцениваемых пунктах обратные шкалы дают по 20, прямые — по 5, интегральная сумма — 50. Это проверено по преобразованию баллов и группировке пунктов в ключе.
- Итог: оба критерия выполнены. Нормативные границы и диагностические категории в реализации не вводились.
