# Опросник выгорания школьников (ОВШ), русская адаптация SBI

**Решение:** методика подходит по российской адаптации и точности подсчёта; отложена до прояснения лицензии для платформы.

- Адаптация А. А. Бочавер и О. Р. Михайловой выполнена на 3 197 российских школьниках. Финальная русская форма — 9 пунктов, три шкалы: истощение, цинизм, чувство несоответствия.
- В опубликованном приложении приведены формулировки пунктов, шестибалльный формат ответа и полный ключ. Подсчёт — сумма ответов внутри шкалы. Опубликованы отдельные терцильные границы для юношей и девушек; нельзя выводить единый уровень без учёта категории, используемой нормами.
- Статья сообщает приемлемые/высокие показатели надёжности: α=.76 для истощения, .85 для цинизма, .67 для чувства несоответствия; подтверждена трёхфакторная модель. Это школьная методика — возрастную область нельзя расширять на студентов без отдельного основания.

## Ключ и шкалы

- Истощение: пункты 1, 4, 7, 9 (сумма; диапазон 4–24).
- Цинизм: пункты 2, 5, 6 (сумма; диапазон 3–18).
- Чувство несоответствия: пункты 3, 8 (сумма; диапазон 2–12).
- Для нормативной интерпретации источник задаёт разные терцильные границы юношам и девушкам; при публикации следует сохранить эту оговорку и не создавать единые нормы.
