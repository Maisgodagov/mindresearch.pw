# Шкала Альтмана для самооценки мании (ASRM)

- Решение: `prepared`. Доступен полный русский текст пяти пунктов; точный подсчёт подтверждается оригинальной публикацией и официальным руководством APA.
- Русская версия: [«Шкала Альтмана для самооценки мании, ASRM» — описание](https://psytests.org/diag/asrm.html) и [русский бланк](https://psytests.org/diag/asrm-bl.html). Страница отмечает, что автор перевода не установлен и сведений об адаптации нет; текст бланка воспроизведён как данная русская версия, не объявляя её валидированной адаптацией.
- Первичная публикация: Altman EG, Hedeker D, Peterson JL, Davis JM. [“The Altman Self-Rating Mania Scale”](https://doi.org/10.1016/S0006-3223(96)00548-3), *Biological Psychiatry*, 1997;42(10):948–955. В исследовании сообщён порог выше 5 для чувствительности 85,5% и специфичности 87,3%.
- Ключ/подсчёт: [DSM-5-TR Level 2—Mania—Adult: Altman Self-Rating Mania Scale (официальный бланк и инструкция APA)](https://www.psychiatry.org/File%20Library/Psychiatrists/Practice/DSM/DSM-5-TR/APA-DSM5TR-Level2ManiaAdult.pdf) задаёт пять пунктов, суммирование сырых баллов и порог 6 и выше для интерпретации. Сами пять ответов шкалы имеют баллы 0–4; общий возможный диапазон — 0–20.
- Объём: 5 пунктов, каждый с пятью упорядоченными ответами от 0 до 4; все пункты входят в единую шкалу, обратных пунктов нет.
- Формула: `asrm_total = сумма ответов 1–5`; диапазон 0–20. Пороговый ориентир исходной работы — сумма >5, то есть целое значение ≥6. В модуле реализован только сырой суммарный балл.
- Контрольный пример: ответы 0, 0, 0, 0, 0 дают 0; ответы 4, 4, 4, 4, 4 дают 20.
