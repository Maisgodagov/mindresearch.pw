# Маркеры факторов Большой пятёрки Голдберга (IPIP-50)

- Статус: prepared; зарегистрирована русская форма IPIP-50 под кодом `test_1521`.
- Русский текст: [«Маркеры Большой пятёрки Голдберга (IPIP-50, BFFM-50)» — полный русский текст 50 пунктов и ключ на StatBlank](https://statblank.com/metodiki/markery-bolshoy-pyaterki-ipip-50). Используется опубликованный текст именно этой формы.
- Первоисточник формы и ключа: [Lewis R. Goldberg, “The Development of Markers for the Big-Five Factor Structure”, Psychological Assessment, 4 (1992), 26–42](https://doi.org/10.1037/1040-3590.4.1.26); [IPIP, “Administering IPIP Measures, with a 50-item Sample Questionnaire” — оригинальный бланк с кодированием каждого пункта](https://ipip.ori.org/new_ipip-50-item-scale.htm); [IPIP, “Big-Five Factor Markers” — десятипунктовые шкалы и ключ](https://ipip.ori.org/newBigFive5broadKey.htm); [IPIP, “Converting IPIP Item Responses to Scale Scores” — правила кодирования и суммирования](https://ipip.ori.org/newScoringInstructions.htm).
- Страница из очереди: [psytests.org, «Модель Большая пятёрка»](https://psytests.org/big5/bigfive.html) — каталог серии, без текста конкретного опросника и ключа; основанием для формы служат перечисленные выше IPIP-источники и русский бланк.
- Пункты: 50 утверждений; варианты ответов: «Совершенно не верно», «Не совсем верно», «Ни верно, ни неверно», «Отчасти верно», «Совершенно верно» (1–5).
- Шкалы: экстраверсия (1, 6, 11, 16, 21, 26, 31, 36, 41, 46); доброжелательность (2, 7, 12, 17, 22, 27, 32, 37, 42, 47); добросовестность (3, 8, 13, 18, 23, 28, 33, 38, 43, 48); эмоциональная стабильность (4, 9, 14, 19, 24, 29, 34, 39, 44, 49); интеллект/воображение (5, 10, 15, 20, 25, 30, 35, 40, 45, 50). У каждой шкалы диапазон 10–50.
- Формула: для каждого обратного пункта преобразовать ответ как `6 − ответ`; затем сложить десять пунктов соответствующей шкалы. Обратные пункты: экстраверсия — 6, 16, 26, 36, 46; доброжелательность — 2, 12, 22, 32; добросовестность — 8, 18, 28, 38; эмоциональная стабильность — 4, 14, 24, 29, 34, 39, 44, 49; интеллект/воображение — 10, 20, 30. Всего 24 обратных пункта.
- Ручная проверка: для ответа 5 на все пункты прямые пункты дают 5, обратные — 1; по составу ключа результаты E=30, A=34, C=34, ES=18, I=42. Для ответа 3 на все пункты получаются 30 по каждой шкале.
- Ограничение: источник русского перевода характеризует его как подготовленный для этой публикации; отдельные российские нормы для IPIP-50 не заявлены, поэтому регистрация выводит суммы шкал без нормативных интерпретаций.
