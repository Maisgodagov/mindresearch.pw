# DUDIT — Test for Drug Use Disorders Identification

- **Решение:** prepared. Имеются официальный русский бланк DUDIT версии 1.0 и опубликованное правило подсчёта.
- **Русский текст:** [официальный русский бланк DUDIT, версия 1.0 (PDF)](https://d9www.euda.europa.eu/system/files/documents/2025-04/utf-8dudit-russian-version-1.1.pdf), размещённый в библиотеке EUDA. Включены все 11 пунктов; формулировки переданы по бланку с минимальной редактурой очевидных опечаток и неясной грамматики. Список примеров веществ дан в бланке на второй странице; состав вопросов и варианты ответов сохранены.
- **Первичные источники методики:** Anne H. Berman, Hans Bergman, Tom Palmstierna & Frans Schlyter, [“Evaluation of the Drug Use Disorders Identification Test (DUDIT) in Criminal Justice and Detoxification Settings and in a Swedish Population Sample”](https://doi.org/10.1159/000081413), *European Addiction Research*, 2005, 11(1), 22–31. Также официальная карточка [“Drug Use Disorders Identification Test (DUDIT)” EUDA](https://www.euda.europa.eu/drugs-library/drug-use-disorders-identification-test-dudit_en), включающая оригинальный бланк и русский перевод.
- **Источник правил подсчёта:** [“DUDIT: Scoring and interpretation” — Australian Comorbidity Guidelines, Table 70](https://comorbidityguidelines.org.au/appendix-x-drug-use-disorders-identification-test-dudit/dudit-scoring-and-interpretation); ключ совпадает с оригинальным форматом: пункты 1–9 оцениваются от 0 до 4, пункты 10–11 — 0, 2 или 4.
- **Количество пунктов и шкалы:** 11 пунктов; единая суммарная шкала DUDIT от 0 до 44. Обратных пунктов нет.
- **Формула:** `DUDIT = сумма баллов по пунктам 1–11`; для пунктов 1–9 применяется соответствующая частотная/количественная градация `0, 1, 2, 3, 4`; для пунктов 10–11 ответы «Нет», «Да, но не за прошедший год», «Да, за прошедший год» кодируются `0, 2, 4`. Вручную проверенные примеры: все минимальные ответы дают 0; максимальные — 44; ответы 2 и 4 в пунктах 10–11 при нулях в остальных дают 6.
- **Описание для автора опроса:** карточка объясняет охват частоты и интенсивности употребления, тяги, утраты контроля, последствий и обеспокоенности близких и отмечает скрининговое назначение для взрослых, без выдачи результата за диагноз.
