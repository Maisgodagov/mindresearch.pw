# Краткий характерологический опросник (М. Е. Бурно, 2007)

- Решение: подготовлена регистрация (`prepared`).
- Русский текст: доступен мужской бланк из 28 утверждений с вариантами «Да» / «Нет»; формулировки перенесены в модуль. Первая публикация текста отмечает, что опросник предназначен для ориентировочной работы специалиста со взрослыми душевно здоровыми соматическими пациентами.
- Ключ: надёжный. В приложении к исследованию приведены двойные коды каждого утверждения (например, `1.1`) и прямо сказано, что 28 пунктов охватывают семь характеров по четыре утверждения; таким образом первая цифра однозначно задаёт шкалу, вторая — номер пункта внутри неё. Отрицательных (реверсивных) пунктов источник не задаёт.
- Число пунктов: 28.
- Шкалы: сангвинический (синтонный), авторитарный, тревожно-сомневающийся, застенчиво-раздражительный, педантичный, замкнуто-углубленный, демонстративный; по четыре утверждения каждая.
- Подсчёт: ответ «Да» = 1, «Нет» = 0; сумма четырёх ответов, относящихся к шкале. Диапазон каждой шкалы 0–4. Это первичная ориентировочная сумма. Интерпретационные правила о сочетаниях типов в модуле не автоматизированы.
- Реверсивные пункты: нет.
- Контрольные примеры: все ответы «Нет» дают семь нулевых сумм; четыре ответа «Да» по пунктам демонстративной шкалы дают демонстративную сумму 4 и нули по остальным шкалам.
- Ограничение: источник подчёркивает ориентировочную роль опросника; он не выявляет психическую патологию. Доступный онлайн-бланк предупреждает, что это визуальный бланк, а оригинальные офлайн-бланки и инструкции следует брать из первоисточника.

## Источники

- М. Е. Бурно. [«О характерах людей» (издание 2020 года), библиографическая карточка Российской государственной библиотеки](https://search.rsl.ru/ru/record/01004577008) — библиографический источник книги, приложением к которой является опросник; описание применения также приведено на [странице методики PsyTests](https://psytests.org/accent/burno.html).
- И. П. Маркова. [«Психологические методы коррекции тревожных состояний у лиц с соматическими заболеваниями» (выпускная работа, 2024), приложение 1 и раздел «Краткий характерологический опросник»](https://archive-coursework.mmu.ru/files/upload/Diplomas/2024/publish/p_8304_596.pdf) — полный текст утверждений, двойные коды и перечисление семи четырёхпунктовых шкал (приложение 1, с. 57–59 PDF).
