# 1510. Пять языков любви

Решение worker: `blocked`.
Основание: Русская версия подтверждена, но полный текст 30 пар и однозначное соответствие каждого ответа шкале недоступны в проверенных источниках. Страница Psytests скрывает форму за JavaScript, ссылка на русский бланк не открывается. Официальный англоязычный профиль подтверждает формат из 30 пар, но не позволяет восстановить русские формулировки и ключ без догадок. Разрешённые файлы не создавал.
