# CORE-OM (официальный русский перевод, 2024)
- Статус: `implemented-local` (`test_61`).
- Русский текст: финальная официальная форма rus(fm), перевод под руководством Марины Зельдович; [CORE System Trust](https://www.coresystemtrust.org.uk/wp-content/uploads/2024/08/CORE-OM_Russian_FM.pdf).
- Ключ: шкалы благополучия (4, 14, 17, 31), проблем (2, 5, 8, 11, 13, 15, 18, 20, 23, 27, 28, 30), функционирования (1, 3, 7, 10, 12, 19, 21, 25, 26, 29, 32, 33), риска (6, 9, 16, 22, 24, 34); обратные пункты 3, 4, 7, 12, 19, 21, 31, 32.
- Подсчёт: ответы 0–4; обратные пункты кодируются как 4−ответ. Возвращаются средние по доменам, по всем 34 пунктам и по 28 пунктам без риска.
- Источники ключа и алгоритма: [официальная информация CORE-OM](https://www.coresystemtrust.org.uk/home/instruments/core-om-information/) и [русский бланк](https://www.coresystemtrust.org.uk/wp-content/uploads/2024/08/CORE-OM_Russian_FM.pdf).
