# 2067. Шкала включенности Другого в собственную Я-концепцию

Решение worker: `blocked`.

Но русская адаптация Крюковой и Екимчик (2018), на которую ссылается страница методики, недоступна: ссылка на бланк и пример ведут на страницы, которые не удалось получить. В доступных источниках нет самих русских формулировок и полного набора вариантов; восстанавливать их по догадке нельзя. Разрешённые файлы не создавались.
