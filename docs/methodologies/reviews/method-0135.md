# 135. Вопросник на эмоциональную подготовленность

Решение worker: `ru-ineligible`.
Основание: Страница методики и ссылка на неё из путеводителя недоступны (ошибка Cache miss); доступный русский источник описывает концепцию, но не содержит полного текста пунктов, инструкции и вариантов ответов. Полный англоязычный тест и ключ есть у Gottman, однако русскую версию нельзя восстанавливать переводом.
