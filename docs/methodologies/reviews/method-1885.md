# Тест-опросник коммуникативной креативности

- Решение: `prepared` — доступен полный русскоязычный текст и точный авторский ключ.
- Русский текст и описание: [«Адаптивность в системе свойств личности», приложение Ж: мануал, стимульный материал и бланк (Санникова, Кузнецова, 2017)](https://dspace.pdpu.edu.ua/bitstream/123456789/17421/1/Sannikova%20Olha%20Pavlovna.pdf), с. 359–364; копия бланка для сверки: [«Тест-опросник коммуникативной креативности — бланк»](https://psytests.org/trait/creasa-bl.html). Страница методики: [описание теста Санниковой и Белоусовой](https://psytests.org/trait/creasa.html).
- Ключ и подсчёт: [«Адаптивность в системе свойств личности», таблица Ж.1.3 «Ключ» и ключ-дешифратор](https://dspace.pdpu.edu.ua/bitstream/123456789/17421/1/Sannikova%20Olha%20Pavlovna.pdf), с. 365–368. Утверждения каждой шкалы оцениваются по авторскому списку прямых/обратных позиций. Для прямых ответов начисляется 4, 3, 1 или 0 баллов за «безусловно, да», «пожалуй, да», «пожалуй, нет», «безусловно, нет»; для обратных — 0, 1, 3, 4. ОПКК = среднее восьми первичных сумм.
- Пункты: 96 (8 шкал по 12 утверждений).
- Шкалы: легкость в общении, склонность к самопрезентации, независимость, конфликтность, эмоциональная устойчивость в общении, склонность к манипуляции, экспрессивность, коммуникативная компетентность; общий показатель ОПКК.
- Ручная проверка: одинаковый ответ «пожалуй, да» на все пункты даёт первичные суммы 26, 30, 22, 26, 14, 34, 30, 28 и ОПКК 26; сумма каждой шкалы сверена по прямым и обратным пунктам в таблице Ж.1.3.
- Версия предназначена для взрослых; русские формулировки сверены с опубликованным стимульным материалом. Нормативные уровни не включены в расчёт.
