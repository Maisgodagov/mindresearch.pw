Две грамматические редакции доступны для всех 818 активных библиотечных методик, сверенных с рабочей базой 19.10.2026. Реестр охватывает 1174 библиотечные версии, включая архивные; архивные методики не возвращаются в каталог.

## Поведение

Конструктор использует существующие режимы «По полу», «Мужской» и «Женский». Новые блоки по умолчанию получают автоматический режим. При отсутствии ответа о поле используется выбранный автором основной бланк. Уже сохранённые фиксированные настройки сохраняются; ограничения на изменение структуры опросов с ответами продолжают действовать.

Готовые пары фраз находятся в `apps/api/src/data/catalogFormTexts.json`, список поддерживаемых кодов — в `catalogFormCodes.json`. Отдельная таблица пяти ранее добавленных методик сохраняет приоритет. Во время прохождения нет морфологических преобразований, внешних запросов или генерации текста: нужная редакция берётся из снимка вопроса, сохранённого при создании опроса.

## Границы редакции

Изменяется грамматический род высказываний о респонденте и личных вариантов ответа. Нейтральные формулировки совпадают. Сохраняется согласование с существительными: «я хороший человек» остаётся одинаковым, «я хороший ученик» меняется на «я хорошая ученица». Подписи интенсивности («Высокий») и сравнения («Мало похож на меня») сохраняются.

В родительских и наблюдательских формах пол ребёнка не определяется по полу отвечающего взрослого. Прилагательные идеального партнёра, группы и ситуации также не изменяются по полу респондента. Тексты интеллектуальных, языковых заданий и диалогов сохраняются как стимульный материал; для этих случаев в таблице заданы исключения по коду. Это не предполагает ориентацию респондента или пол другого человека.

Это грамматические редакции существующих методик, а не новые психометрические адаптации. Назначение, ограничения применимости, исходные ключи и нормативные таблицы остаются прежними; сам переключатель не подтверждает применимость специализированной методики к другой группе. Нормы нельзя менять или придумывать по аналогии с окончаниями слов.

## Проверка

`src/data/catalogForms.test.ts` загружает все методики из seed, основного JSON и модульного реестра. Проверяются покрытие кодов, обе редакции, автоматическое разрешение и запасной бланк, неизменность исходных объектов, количества, порядка, идентичности вопросов, типов, обязательности, числовых значений ответов и исходной валидации. Отдельные примеры проверяют согласование, других действующих лиц и нейтральные подписи.

Команды: `npm run build -w @opora/api`, `npm run test -w @opora/api -- src/data/catalogForms.test.ts src/data/autoForms.test.ts src/scoring/priorityNorms.test.ts`, `npm run audit:scoring`. Браузерная проверка использует синтетические API-ответы и реальный снимок RSES; производственные ответы респондентов не используются.
