# Иллюстрированные карточки результатов

## Что показала библиотека

Структурная проверка прошла по всем 1 111 модулям реестра методик. Из них 352 сняты с использования, 759 активны: 268 с одним показателем, 422 с двумя–восемью, 69 с девятью и более. У 582 методик встречается сумма, у 178 — среднее, у 12 — подсчёт выбранных вариантов. Группы расчёта пересекаются. В восьми активных формах есть вопросы за пределами формата одиночного выбора. Отдельные встроенные методики используют собственные функции расчёта, в том числе профили с общим индексом, вложенными показателями и авторскими категориями. В публичном каталоге 32 методики; их результат уже приводит эти различия к общему формату шкал.

| Тип результата | Правило карточки |
| --- | --- |
| Один показатель | Крупное значение, верхняя граница, позиция в диапазоне и пояснение |
| Общий балл с подшкалами | Крупное значение и все подшкалы отдельными строками |
| Независимые показатели | Равнозначные строки без искусственного общего балла |
| Длинный профиль | Высота PNG растёт с количеством строк, значения остаются читаемыми |
| Категории, нормы и формулы | Публикация передаёт подтверждённую интерпретацию и числовые шкалы через API. Карточка сама их не рассчитывает |
| Нет проверенного расчёта | Требуется определить формат результата при подключении методики к публичному каталогу |

## Выбор оформления

Фон выбирается по явному правилу для конкретной версии методики. У проверенных направленных шкал используются две сцены для каждого диапазона. Верхняя и нижняя трети числового диапазона влияют только на иллюстрацию. На карточке эти участки не подписываются как норма, степень тяжести, диагноз или процентиль. Для PHQ‑4 учитывается более высокая из двух шкал только при подборе сцены. Для разнонаправленных профилей и методик без явного правила используются нейтральные сцены. Правило не наследуется от похожего названия автоматически.

Доступны четыре фона, два прозрачных персонажа, вариант без персонажа и два стиля графики. Персонаж выбирается вручную, выбор не меняет результат. Высокие значения на шкалах трудностей получают спокойные сумеречные сцены. При выраженных ресурсах предлагаются более светлые сцены. Иллюстрации готовятся заранее, личные данные не отправляются на генерацию. Канвас накладывает текст, фактические баллы и шкалы в браузере, в том числе для ранее сохранённых результатов.

Для новой методики сначала подключается проверенный результат API. Нейтральная пара работает сразу. Направление иллюстрации можно добавить в конфигах только после проверки смысла шкалы, версии и наличия обоснованного общего показателя.
