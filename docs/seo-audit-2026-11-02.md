# SEO mindresearch: аудит и план

## Что проверено и исправлено в коде

Проверены реальные HTTP-ответы главной, лендинга, каталога, теста, фильтра каталога, неизвестного адреса, входа, регистрации, кабинета, ссылки опроса, robots.txt и sitemap. У публичных тестов уже есть HTML статьи без JavaScript, источники, индивидуальные метаданные, изображения и структурированные данные. Эти механизмы сохранены.

- Общая HTML-оболочка теперь содержит исходный `noindex,nofollow`. Публичные документы явно заменяют его на `index,follow`. Кабинет, авторизация, прохождения и личные результаты не являются поисковыми посадочными страницами. Это не замена авторизации.
- При переходе с публичной статьи в личный раздел сбрасываются canonical и публичная разметка. Неизвестный маршрут больше не перенаправляет посетителя на регистрацию.
- Canonical лендинга и sitemap согласованы с фактическим адресом `/for-researchers/`.
- Лендинг получает общие для HTML и браузера title, description, Open Graph, Twitter и JSON-LD Organization/WebSite/WebPage/WebApplication. Добавлено изображение 1200×630.
- Исходный HTML лендинга содержит подробные преимущества, описание качества прохождений, статистики, Excel и совместной работы, а не только сокращённые анонсы.
- Поисковые заголовки первых трёх тестов учитывают понятные названия и авторов; ручные редакторские SEO-поля сохраняют приоритет.
- Robots.txt разрешает чтение `noindex` служебных страниц, закрывает API и содержит sitemap. Яндексу указаны только рекламные параметры, не меняющие содержимое.
- API сохраняет параметры при каноническом перенаправлении и отдаёт `noindex` для поисковых фильтров каталога. Для использования этого на сервере нужен proxy `/methods` (см. ниже).

## Ограничение текущего production Nginx

На момент аудита сервер использует `try_files $uri $uri/ /index.html`: неизвестные URL отвечают 200. В репозитории уже есть proxy `/methods`, но в рабочем конфиге он отсутствует. Новая оболочка закрывает такие страницы от индексации, однако для правильного HTTP 404 требуется настройка сервера. У deploy-пользователя нет прав менять `/etc/nginx`.

Администратору сервера: сохранить резервную копию активного конфига, перенести location для `/methods` из `deploy/nginx.conf`, сохранив действующие TLS, редиректы доменов, API и заголовки. Этот proxy обеспечивает 404 неизвестного теста и исходный noindex фильтров. Для остальных неизвестных адресов заменить безусловный SPA fallback разрешёнными маршрутами приложения, остальные отдавать 404. Проверить `nginx -t` и только затем reload. Не заменять действующий TLS-конфиг целиком примером из репозитория.

Приёмка: известный тест 200, неизвестный `/methods/not-a-test/` 404, неизвестный общий URL 404, вход/кабинет/опросы продолжают открываться, фильтр `?q=...` содержит noindex, адреса без завершающего `/` перенаправляют на canonical. Главную нельзя безусловно редиректить на лендинг: авторизованным нужен `/app`.

## Что сделать владельцу

1. Подтвердить `mindresearch.pro` через DNS в Google Search Console и Яндекс Вебмастере. Добавить `https://mindresearch.pro/sitemap.xml`. Проверить восемь публичных URL через проверку адреса и отправить на переобход.
2. Если старый `.pw` был проиндексирован, подтвердить обе версии домена и оформить переезд в инструментах поисковиков. Редиректы `.pw` → `.pro` уже работают; сохранять их.
3. Через 2–4 недели смотреть показы, запросы, клики, CTR, выбранный canonical и причины исключения. Отсутствие страницы в выдаче не означает ошибку sitemap. Сроки индексации и позиции не гарантированы.
4. Указать настоящего автора/редактора, контакты и процесс проверки статей. Не придумывать квалификацию. Для новых тестов сохранять первоисточники, автора адаптации, версию, условия использования, корректные ограничения интерпретации.
5. Следующие материалы: как собрать опрос для диплома; как проверять качество прохождений; как читать отчёт корреляции Пирсона. Публиковать полезные самостоятельные инструкции с примерами, связывать их с инструментами и тестами.
6. Проверять мобильные Core Web Vitals по реальным данным Search Console. Текущий аудит не является измерением полевых LCP/INP/CLS. Не покупать ссылки: полезнее естественные упоминания в учебных материалах и исследовательских сообществах.

Официальные справки: [Google SEO](https://developers.google.com/search/docs/fundamentals/seo-starter-guide), [JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics), [Яндекс Sitemap](https://yandex.ru/support/webmaster/ru/indexing-options/sitemap), [Clean-param](https://yandex.ru/support/webmaster/ru/robot-workings/clean-param).
