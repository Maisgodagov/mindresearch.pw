Каталог статистических методов для mindresearch. Дата: 19.10.2026. Это план покрытия, не список уже работающих функций.

## Как читать

Обозначения источников:

- **Сайт** — [statpsy.ru](https://statpsy.ru/) и его разделы [корреляций](https://statpsy.ru/correlation/), [регрессии](https://statpsy.ru/regression/), [дисперсионного анализа](https://statpsy.ru/dispersion/), [факторного анализа](https://statpsy.ru/factor/).
- **Н** — А. Д. Наследов, «Математические методы психологического исследования», 2004, файл `mathematical_methods_psychological.pdf`.
- **Е** — О. Ю. Ермолаев, «Математическая статистика для психологов», 2003, файл `mat_statistics.pdf`.
- **С** — Е. В. Сидоренко, «Методы математической обработки в психологии», 2003, длинное имя PDF в корне проекта.

Глава/раздел — надёжнее номера страницы скана: печатная и PDF-нумерация могут различаться. Оглавления всех книг и отдельные ключевые разделы проверены. Перед реализацией каждого пункта нужны последовательная сверка соответствующего раздела, визуальная проверка формул и паспорт процедуры. Варианты ниже объединены в семейства, но должны иметь отдельные параметры и эталоны. Дополнение каталога при обнаружении ещё одного явно описанного метода — задача этапа 0, без незаметного исключения из общего объёма.

«Дополнение» означает необходимую современную вычислительную/диагностическую процедуру к найденному методу, а не утверждение, что она названа в каждой из книг.

Для каждого метода определить отдельный эффект и ДИ, если статистически поддерживаются: разность средних, Cohen d/Hedges g с указанным вариантом, парный стандартизованный эффект, рангово-бисериальный эффект/вероятность превосходства. Один универсальный эффект для всех тестов не подходит.

Для SS, df, F и эффектов фиксировать соглашения: η², partial η², ω² — разные величины. Несбалансированные планы нельзя считать как сбалансированные по одной книжной сокращённой формуле. Случайные эффекты, если раздел их задаёт, требуют отдельного явно описанного варианта, а не переименования фиксированного ANOVA.

| cluster.hierarchical | Иерархическая кластеризация объектов/переменных | Одиночная/полная/средняя связь и другие описанные методы, матрица различий, агломерация, число кластеров | Н гл. 19; конкретные методы из полного раздела |
| cluster.specialinputs | Кластеризация профилей/корреляций/социометрических различий | Тип матрицы, направление «объекты или переменные», преобразование сходства в расстояние | Н гл. 19 |
| distance.metrics | Меры различия для количественных, частотных и бинарных профилей | Евклидова/квадрат евклидовой/манхэттенская и иные описанные меры; χ²/φ² для частот, бинарные меры; точные определения и допустимые сочетания с алгоритмом | Н гл. 18–19 |

PCA и EFA — разные режимы. Метки кластеров и имена факторов не присваиваются системой как психологические диагнозы. Метрики расстояний, вращения и извлечения должны иметь конечный именованный список после сверки; нельзя считать «все варианты поддержаны», оставив один метод за общей кнопкой.

## 10. Многомерное шкалирование

| ID | Метод/варианты | Входы и важные решения | Основание |

## 11. Общие компоненты, обязательные для всех семейств

- Проверки допустимости плана, типов, пропусков, совпадений/нулей, размера и вырожденности.
- Точные/асимптотические/перестановочные варианты только там, где имеют математический смысл и проверенную реализацию. Переключение не скрывается.
- Оценки эффектов и ДИ под конкретный метод; не все процедуры имеют естественный p или одинаковую меру эффекта.
- Поправки на множественные проверки, с явно сохранённым семейством и исходными p.
- Версионируемые параметры алгоритма, seed, правила округления, engine/package versions.
- Отчёт с входами, формулами и промежуточными результатами, источниками и границами применимости.
- Обучающий график/текст не выдаётся за отдельный статистический метод; таблицы критических значений не размножают один метод в несколько пунктов.

## 12. Паспорт метода: обязательный результат этапа 0

Статусы покрытия: «описан в каталоге → паспорт проверен → реализован → численно проверен → проверен в UI → выпущен».
