## Совместный доступ

Управление доступом доступно любому автору своего опроса. Приглашённый пользователь может иметь любую системную роль. Права на конкретный опрос не повышают системную роль.

| Действие | Автор | Просмотр | Редактирование |
| --- | --- | --- | --- |
| Результаты, подробные ответы, статистика, экспорт | Да | Да | Да |
| Конструктор и сохранение опроса | Да | Нет | Да |
| Корзина ответов, метаданные качества и расчёты | Да | Нет | Да |
| Удаление, архивирование и восстановление самого опроса | Да | Нет | Нет |
| Приглашения, изменение прав, отзыв доступа | Автор | Нет | Нет |

Системный доступ администраторов для проверки чужих опросов сохраняется независимо от приглашений. Он не даёт права редактировать чужой опрос.

### Приглашения

В «Совместном доступе» автор выбирает права и, при необходимости, почту или `public_slug` зарегистрированного пользователя. Сервер ищет точное совпадение. Созданную ссылку автор отправляет самостоятельно: автоматическая отправка писем в этой версии не используется.

Ссылка содержит случайный токен из 32 байтов. В базе хранится только SHA-256. Срок — 7 дней, одно приглашение принимает один аккаунт. Адресное приглашение привязано к ID найденного пользователя, поэтому смена почты или имени не переносит доступ на другой аккаунт. Автор может отменить ещё не принятое приглашение; принятый доступ отзывается в списке участников.

Маршрут `/invite/:token` предлагает вход или регистрацию. Параметр возврата разрешает только локальный путь приглашения с корректным форматом токена. После авторизации приглашение принимается и открываются результаты нужного опроса. Принятие выполняется транзакционно, повторный запрос того же аккаунта не создаёт дубликаты и не возвращает отозванные права.

Раздел «Доступные мне» показывает предоставленные опросы, автора и права. Ответы удалённого в корзину опроса недоступны приглашённым пользователям.

### Одновременная работа

`surveys.edit_version` проверяется под блокировкой строки опроса. Конструктор, автосохранение черновика, корзина результатов, метаданные качества и активация версии качества передают `X-Survey-Version`. Устаревшая запись получает HTTP 409 до внесения изменений. Сохранение и увеличение версии происходят в одной транзакции.

Автосохранения одной вкладки выполняются последовательно. При конфликте автосохранение останавливается, локальные правки остаются на экране и доступны для скачивания в JSON. Автоматического слияния конфликтующих правок нет. В результатах можно явно загрузить свежие данные кнопкой «Обновить результаты» и повторить действие.

Новые ответы респондентов не меняют версию редакторских изменений. Операции автора с жизненным циклом опроса увеличивают версию, чтобы открытый редактор не восстановил устаревшее состояние.

### Проверки

`sharing.integration.test.ts` запускает реальный API на отдельной локальной базе: проверки ролей, адресных и одноразовых ссылок, конкурентных изменений, срока действия, смены прав и отзыва. Запуск разрешён только с `COMMUNITY_TEST_DATABASE_URL` на localhost и именем базы `mindresearch_community_test_*`.
