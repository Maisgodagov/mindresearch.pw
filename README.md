# mindresearch — платформа психологических опросов

Платформа для создания психологических исследований: конструктор опросов, каталог методик, сбор ответов по ссылке, результаты, Excel-выгрузка, совместный доступ и статистический анализ.

## Что уже работает

- один вопрос на экране, прогресс и адаптивный интерфейс;
- анонимное начало без регистрации;
- сохранение каждого ответа и продолжение после перезагрузки;
- фиксация частично заполненных анкет;
- авторизация администратора;
- список завершённых и незавершённых прохождений;
- диаграммы распределения по любому вопросу;
- модель данных с владельцами, несколькими опросами и сохраняемыми представлениями дашборда.

## Локальный запуск

Нужны Node.js 22+, npm и MySQL 8. Проще всего запустить MySQL через Docker, если он установлен.

```powershell
Copy-Item .env.example .env
docker compose up -d mysql
npm install
npm run seed
npm run dev
```

Опрос: `http://localhost:5173/s/support-study`  
Админка: `http://localhost:5173/admin/login`

Начальные данные администратора задаются в `.env` (`ADMIN_EMAIL`, `ADMIN_PASSWORD`). Перед публикацией обязательно замените пароль и `JWT_SECRET`.

Если MySQL запущен без Docker, создайте базу и пользователя самостоятельно, затем укажите строку подключения в `DATABASE_URL`. Миграции выполняются автоматически при запуске API или seed-команды.

## Команды

```powershell
npm run dev       # frontend + backend
npm run build     # production-сборка
npm run seed      # идемпотентный импорт анкеты
```

## Структура

- `apps/web` — React, TypeScript, Vite, styled-components, Recharts, TanStack Table;
- `apps/api` — Node.js, Express, TypeScript, MySQL;
- `apps/api/src/data/survey.json` — подготовленный набор вопросов;
- `scripts/generate-seed.mjs` — повторная генерация набора из `anketi.md`.

Перед реальным сбором чувствительных данных нужны HTTPS, резервное копирование БД, политика обработки персональных данных и проверка текста информированного согласия специалистом.


## Основная рабочая копия и доступ к разделам

Работайте из текущей папки `Mindresearch.pro`. Постоянные дополнительные worktree для релизов и обработки методик не требуются. После переноса проекта проверяйте `git worktree list`, а не создавайте новые копии поверх старых.

- `/` проверяет сессию: пользователи с активной сессией переходят в `/app`, гости — в `/for-researchers`.
- `/for-researchers` открыт всем.
- Каталог тестов `/methods`, прохождение и результаты публичных тестов пока доступны только `admin` и `owner`; их API защищён теми же ролями.
- Поиск респондентов `/app/community` также остаётся административным пилотом.
- Опросы исследователей `/s/:slug` доступны респондентам без регистрации.

Для запуска только фронта: `npm run dev -w @opora/web -- --host 127.0.0.1 --port 5181`. По умолчанию Vite использует API `https://mindresearch.pro`; для локального API укажите `VITE_API_PROXY_TARGET` в `apps/web/.env.local`. Не запускайте seed против рабочей базы для проверки интерфейса.

Сборка: `npm ci`, затем `npm run build`. Тесты: `npm test`. Вычислительный движок использует Python и зависимости из `apps/api/statistics/requirements.txt`; путь к интерпретатору можно задать через `STATISTICS_PYTHON`.

Скриншоты, тестовые выгрузки и разовые эксперименты сохраняйте в игнорируемой `.work/`. Секреты — только в локальных `.env`-файлах. Исходники, тесты, документация и воспроизводимые инструменты обслуживания хранятся в Git.
